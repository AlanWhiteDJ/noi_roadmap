# 第 103 章  对拍、调试与卡常
> 🏗️ **前情回顾**：第 80 章你会估复杂度，知道 O(n log n) 能过 10^5。但复杂度一样，常数可能差五倍——这一章把"应该过"变成"真的过"，把 WA 变成可复现的 bug。
## 🎯 本章目标
- 十分钟搭出一套对拍器
- 用 `assert`、GDB、输出定位 RE/WA/TLE，掌握三类卡常手段
- 建立提交前检查清单
## 🧱 知识讲解
### 103.1  对拍器三件套
四个文件：`gen.cpp` 造数据、`brute.cpp` 暴力、`sol.cpp` 正解、`run.sh` 循环比对。
```bash
for i in $(seq 1 1000); do
  ./gen $i > in.txt; ./brute < in.txt > out1.txt; ./sol < in.txt > out2.txt
  if ! diff -q out1.txt out2.txt > /dev/null; then
    echo "WA on case $i"; cat in.txt; break; fi
done
```
数据要覆盖小 n、全相同、极值、随机四类，否则对拍等于没拍。
### 103.2  调试：先缩小，再打断点
`assert` 把"不该发生"变成明确 RE；`-fsanitize=address,undefined` 抓越界与溢出；GDB 三步 `run < in.txt` → `bt` → 看栈。调试输出一定包进宏：
```cpp
#ifdef LOCAL
#define dbg(x) cerr << #x " = " << (x) << endl
#else
#define dbg(x)
#endif
```
### 103.3  卡常三类手段
1. IO：`ios::sync_with_stdio(false); cin.tie(0);` 或手写快读
2. 内存：二维数组按行访问，`vector` 先 `resize` 少 `push_back`
3. 递归改迭代：循环建树、手写栈 DFS
```cpp
static char buf[1 << 20]; int len = 0, pos = 0;
inline int read() {
    int x = 0; char c;
    while (!isdigit(c = getchar()));
    while (isdigit(c)) x = x * 10 + c - '0', c = getchar();
    return x;
}
```
**提交前清单**：数组大小 ×2、`long long`、多组数据清空、文件 IO、`freopen` 文件名、`%d` 与 `%lld`。

## ⚠️ 常见坑
1. 对拍数据太弱，全是小随机，测不出边界
2. 调试输出忘删，正式提交 TLE
3. 只对拍不写暴力；`#define int long long` 后用 `%d` 输出错误
## 📝 练习
- 基础：给线段树搭对拍跑 500 组；进阶：用 GDB 调一次真实 RE
- 挑战：4 小时模拟赛全程对拍；思考：在哪组数据上你的代码会和暴力不同？
