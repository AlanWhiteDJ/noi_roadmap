# 第 105 章  CSP-S 全真模拟（4 套）
> 🏗️ **前情回顾**：M15 前五章你补上了扫描线、离散化、构造、对拍、初赛。现在只剩一件事：**在 4 小时里把这些东西按顺序拿出来用**。这一章不讲新算法，只讲比赛本身。
## 🎯 本章目标
- 按真实赛制完成 2022–2025 四套 S 组题
- 稳定 300 分，依次冲 340/380/400
- 建立时间分配与部分分策略
- 每套产出：代码 + 对拍记录 + 错因复盘
## 🧱 知识讲解
### 105.1  时间分配
- 0–10 min 通读四题，判断难度，别急着写
- 10–40 min T1，必须满分，写完立刻对拍
- 40–90 min T2，先写暴力保底，再优化
- 90–160 min T3，拿 40–60 分部分分
- 160–210 min T4，暴力 + 特殊性质
- 210–240 min 复查文件 IO、数组、`long long`
### 105.2  部分分策略
先拿稳 200（T1/T2 满分 + T3/T4 暴力），再冲 T3 正解。看到 `n ≤ 20` 就写状压，看到链/菊花/权值全相同就写特殊性质——这些分比正解便宜得多。
### 105.3  暴力框架：先跑起来
```cpp
int main() {
    // 读入
    if (n <= 20) { solve_brute(); return 0; }      // 小数据暴力
    if (is_chain()) { solve_chain(); return 0; }    // 特殊性质
    solve_greedy();                                 // 骗分
    return 0;
}
```
一个能编译、能过样例的暴力，永远比写了一半的正解值钱。
### 105.4  复盘：错因四分类
- 不会：没见过该模型 → 补知识点
- 写挂：思路对但代码错 → 对拍
- 看错：题意/数据范围读错 → 读题两遍
- 超时：复杂度或常数 → 卡常
每套赛后填表：题号 / 得分 / 错因 / 下次动作。
## 💻 例题
**例 1（2023 S 全套）**：密码锁（搜索剪枝）、消消乐（栈 + 贪心）、结构体（排序模拟）、种树（二分 + 贪心）。目标前两题满分、第三题 60。
**例 2（2025 S 全套）**：社团招新、道路修复、谐音替换、员工招聘。先 T1/T2，T3 拿特殊性质，T4 写暴力，最后 30 分钟统一对拍。
## ⚠️ 常见坑
1. 前两题耗时过长，T3/T4 连暴力都没写
2. 不检查文件 IO：本地过、评测 0 分
3. 数组开小 1 个，RE 丢整题
4. 不对拍就提交，WA 在样例之外
