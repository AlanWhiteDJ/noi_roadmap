## 🧱 知识讲解

### 105.1  赛制与文件 IO

CSP-S 复赛：4 小时，4 道题，每题 100 分，通常按文件读写。

- 源文件：`lock.cpp` 之类，文件名由题目指定
- 输入输出：`lock.in` / `lock.out`
- 提交：只交 `.cpp`，不交可执行文件

本地测试时用 `freopen`，提交前确认文件名一个字母都没错：

```cpp
freopen("lock.in", "r", stdin);
freopen("lock.out", "w", stdout);
```

两个常见事故：

- 本地用 `freopen` 但评测要求标准 IO → 0 分
- 文件名拼错（`clock.in` vs `lock.in`）→ 0 分

开赛第一件事，把四道题的文件名抄在草稿纸最上面。

### 105.2  240 分钟怎么切

| 时段 | 任务 | 产出 |
|------|------|------|
| 0–10 | 通读四题，判断难度与数据范围 | 一张难度表 |
| 10–45 | T1 | 满分代码 + 对拍 |
| 45–110 | T2 | 先暴力保底，再优化到满分 |
| 110–175 | T3 | 暴力 30–40 分，再冲正解 |
| 175–215 | T4 | 暴力 + 特殊性质 |
| 215–240 | 复查 | 文件 IO、数组、`long long`、调试残留 |

三条纪律：

1. **T1 必须满分**，它是全场最简单的一题，丢了就是硬伤
2. **每题先写暴力**，保证有分可拿，再谈优化
3. **最后 25 分钟不再改算法**，只做检查

### 105.3  看数据范围，定拿分策略

| 数据特征 | 该写的算法 | 大致分值 |
|---------|-----------|---------|
| n ≤ 20 | 状压 DP / 暴搜 | 30–50 |
| n ≤ 100 | O(n³) 区间 DP / Floyd | 40–60 |
| n ≤ 5000 | O(n²) DP | 50–70 |
| n ≤ 10⁵ | O(n log n) 正解 | 100 |
| 是一条链 | 链上 DP / 前缀和 | 20–30 |
| 是菊花图 | 按度数分类讨论 | 15–25 |
| 所有权值相同 | 退化成分组/计数 | 10–20 |

看到"特殊性质"四个字，先别跳过——那往往是整场最便宜的分。命题人把它单独列出来，就是告诉你"这部分可以不想正解"。

### 105.4  暴力框架：先跑起来

一个能编译、能过样例的暴力，永远比写了一半的正解值钱。

```cpp
int main() {
    // 读入
    if (n <= 20) { solve_brute(); return 0; }      // 小数据暴力
    if (is_chain()) { solve_chain(); return 0; }    // 特殊性质
    solve_greedy();                                 // 骗分
    return 0;
}
```

`is_chain()` 就是判断是否每个点度数 ≤ 2，五行代码，可能换 25 分。

写完立刻用 `n = 1`、`n = 2`、样例各跑一遍。连样例都过不了的代码，不要提交。

### 105.5  对拍：每题至少 10 分钟

T1、T2 写完必须对拍。做法就是第 103 章那四件套，数据规模按题目调小：

```bash
for i in $(seq 1 300); do
  ./gen $i > in.txt
  ./brute < in.txt > out1.txt
  ./sol   < in.txt > out2.txt
  diff out1.txt out2.txt > /dev/null || { echo "WA $i"; break; }
done
```

T3、T4 如果只写了部分分，也要用暴力和特殊性质数据各验一遍。**没有对拍的满分，是运气；有对拍的 60 分，是实力。**

### 105.6  复盘：错因四分类

每套赛后填一张表，只填四列：

| 题号 | 得分 | 错因 | 下次动作 |
|------|------|------|---------|
| T1 | 100 | — | 保持 |
| T2 | 70 | 写挂：边界没判 | 提交前加 n=1 测试 |
| T3 | 30 | 不会：没见过强连通缩点 | 补第 72 章 |
| T4 | 0 | 看错：把 n、m 读反 | 读题两遍并圈出变量 |

四类错因的处理方式完全不同：

- **不会** → 补知识点，别急着刷题
- **写挂** → 对拍，把 bug 变成可复现的用例
- **看错** → 改读题习惯，不是改代码
- **超时** → 算复杂度、卡常，或者换算法

分不清错因，刷十套也没用。

## 💻 例题

### 例 1  2023 S 组 T1 密码锁

5 位密码锁，忘了密码。有 n 条"错误尝试"的记录，每条记录是一个 5 位数，并且知道它错的原因属于且仅属于以下两种之一：

1. 恰好有一位与正确密码不同
2. 恰好有相邻两位同时向上（或同时向下）拨动了一格，其余三位相同

求可能的正确密码个数。

**解析**：密码只有 10⁵ 种，直接枚举全部候选，逐条验证。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
vector<string> hint;

bool match(const string &cand, const string &h) {
    // 情况 1：恰好一位不同
    int diff = 0;
    for (int i = 0; i < 5; i++) diff += (cand[i] != h[i]);
    if (diff == 1) return true;

    // 情况 2：相邻两位同向拨动一格，其余相同
    for (int i = 0; i + 1 < 5; i++) {
        bool same = true;
        for (int k = 0; k < 5; k++)
            if (k != i && k != i + 1 && cand[k] != h[k]) { same = false; break; }
        if (!same) continue;
        int d1 = (cand[i] - h[i] + 10) % 10;
        int d2 = (cand[i + 1] - h[i + 1] + 10) % 10;
        if ((d1 == 1 && d2 == 1) || (d1 == 9 && d2 == 9)) return true;
    }
    return false;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;
    hint.resize(n);
    for (int i = 0; i < n; i++) cin >> hint[i];

    int ans = 0;
    for (int x = 0; x < 100000; x++) {
        string cand = to_string(x);
        cand = string(5 - cand.size(), '0') + cand;   // 补足 5 位
        bool ok = true;
        for (int i = 0; i < n && ok; i++)
            if (!match(cand, hint[i])) ok = false;
        if (ok) ans++;
    }
    cout << ans << '\n';
    return 0;
}
```

复杂度 `O(10⁵ × n × 5)`。n 很小时这就是正解；即便 n 到 100，也只有 5×10⁷ 次简单运算，能过。

三个关键点：

- `to_string` 后要补前导零，否则 `123` 变成 `"123"`，长度不对
- 情况 2 里 `d1 == 9` 表示"向下拨"，别只写 `== 1`
- 每位数字是模 10 循环的，`0` 向下拨是 `9`

这题提醒你：**看到 10⁵ 级别的状态空间，先想枚举，不要想复杂算法。**

### 例 2  一次模拟赛的时间账

某次模拟的记录：

| 题号 | 用时 | 得分 | 备注 |
|------|------|------|------|
| T1 | 65 min | 100 | 对拍 10 分钟 |
| T2 | 80 min | 100 | 正解一次写对 |
| T3 | 55 min | 25 | 只写了 n ≤ 10 的暴搜 |
| T4 | 10 min | 0 | 只读了题 |
| 检查 | 30 min | — | 发现 T2 数组开小 |

总分 225。诊断：

- T1 的 65 分钟偏长，目标 45 分钟内
- T3 的 55 分钟只换 25 分，说明**没有先写最便宜的暴力**
- T4 完全放弃，损失了至少 20 分的特殊性质分

调整方案：T1 压到 45 分钟，T3 先花 15 分钟写 `n ≤ 20` 状压（约 40 分），T4 花 25 分钟拿链的部分分。下一套目标 300。

### 例 3  复盘表怎么填

同一套题的复盘：

| 题号 | 得分 | 错因 | 下次动作 |
|------|------|------|---------|
| T1 | 100 | — | 保持 45 分钟内 |
| T2 | 100 | — | 对拍数据加全相同 |
| T3 | 25 | 不会：没看出是区间 DP | 重做第 87 章例题 |
| T4 | 0 | 看错：n 和 m 读反 | 读题时把变量圈出来 |

**解析**：注意"不会"和"看错"的处理完全不同。前者要回去补知识，后者只要改习惯。把"看错"当成"不会"去刷题，是最常见的无效努力。
