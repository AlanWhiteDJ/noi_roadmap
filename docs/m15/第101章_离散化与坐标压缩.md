## 🧱 知识讲解

### 101.1  什么时候需要离散化

三个信号，出现一个就该想到它：

1. 坐标或权值的范围到 10⁹、10¹⁸，但个数只有 10⁵
2. 算法需要以"值"为下标开数组（树状数组、桶、线段树）
3. 题目只关心元素之间的大小关系或相对位置，不关心具体差值

典型场景：

| 题目 | 大的是什么 | 用来干什么 |
|------|-----------|-----------|
| 逆序对 | 元素值域 10⁹ | 树状数组下标 |
| 扫描线 | 矩形 y 坐标 10⁹ | 线段树叶子 |
| 程序自动分析 | 变量下标 10⁹ | 并查集编号 |
| 区间覆盖 | 端点坐标 10⁹ | 差分 / 线段树 |

### 101.2  三步走

```cpp
vector<int> xs;
for (int i = 1; i <= n; i++) xs.push_back(a[i]);

sort(xs.begin(), xs.end());                              // 1. 排序
xs.erase(unique(xs.begin(), xs.end()), xs.end());        // 2. 去重

// 3. 查排名（1-based）
int id(int v) {
    return int(lower_bound(xs.begin(), xs.end(), v) - xs.begin()) + 1;
}
```

`unique` 只是把重复元素移到末尾并返回新的逻辑结尾，必须配合 `erase` 才真正删掉。忘了 `erase`，`xs.size()` 还是原来那么大，后面全乱。

`lower_bound` 找的是**第一个 ≥ v 的位置**。所以：

- v 必须在 `xs` 里，查出来的才是它自己的编号
- 查一个不存在的 v，会得到"它应该插在哪里"，不是错误也不是 0——这种错最难查

需要 0-based 就去掉 `+1`，但整个程序要统一。混用是灾难。

### 101.3  点离散化与区间离散化

这是本章最重要的一节。

**点离散化**：只关心"有哪些值、谁大谁小"。逆序对、去重计数都属于这类。把 10⁹ 换成 1..k，大小关系完全保留。

**区间离散化**：关心"两点之间有多远"。扫描线、区间覆盖、线段树求长度都属于这类。这时候不能只留端点，还要留住**相邻端点的距离**。

```cpp
// 区间题的常见写法
int L = id(l), R = id(r);
update(1, 1, m - 1, L, R - 1, 1);   // 叶子是 [ys[i], ys[i+1])
```

对比一下两种错误写法：

| 写法 | 覆盖 `[2, 9]`（ys = 0,2,5,9） | 结果 |
|------|------------------------------|------|
| 正确：段区间 `[L, R-1]` | 段 1、段 2 | 长度 3 + 4 = 7 ✓ |
| 错误：把端点当点 `[L, R]` | 点 1、2、3 | 长度被算成 3 个点 ✗ |
| 错误：全部 +1 后再当点 | 点 2、3 | 偏移整体错位 ✗ |

一句话记法：**点离散化数个数，区间离散化量长度。**

### 101.4  接树状数组：逆序对

逆序对：有多少对 `i < j` 且 `a[i] > a[j]`。

朴素两重循环 O(n²)，n = 5×10⁵ 时必超。换个角度：从右往左扫，对每个 `a[i]`，数一数右边已经出现过多少个比它小的。

树状数组维护"某个排名出现过几次"，前缀和就是"比它小的个数"：

```cpp
long long ans = 0;
for (int i = n; i >= 1; i--) {
    int p = id(a[i]);
    ans += query(p - 1);   // 排名比 p 小的已出现个数
    add(p, 1);
}
```

`query(p-1)` 而不是 `query(p)`：相等元素不算逆序对。

答案用 `long long`：n = 5×10⁵ 时最多约 `n(n-1)/2 ≈ 1.25×10¹¹`，`int` 装不下。

### 101.5  接并查集：程序自动分析

题意：给若干条形如 `x = y` 或 `x ≠ y` 的约束，判断是否可能同时成立。变量下标可达 10⁹。

思路很直接：相等就合并，不等就检查是否已在同一集合。但**顺序是关键**：

```cpp
// 先把所有相等约束合并完
for (auto &q : qs)
    if (q.op == 1) merge(id(q.x), id(q.y));

// 再检查不等约束
bool ok = true;
for (auto &q : qs)
    if (q.op == 0 && find(id(q.x)) == find(id(q.y))) { ok = false; break; }
```

如果边读边处理，先遇到 `x ≠ y` 时两者还没合并，你判它合法；后面又读到 `x = y`，矛盾就漏掉了。**先等后不等**，一遍就够。

多组数据要清空 `xs`、并查集数组和 `qs`。这是这类题最常见的失分点。

### 101.6  离散化 + 扫描线的接口

扫描线里离散化的产物是 `ys`，另外还要保留"段"的概念：

```cpp
sort(ys.begin(), ys.end());
ys.erase(unique(ys.begin(), ys.end()), ys.end());
int m = ys.size();          // 端点 m 个，叶子 m-1 个

int L = lower_bound(ys.begin(), ys.end(), l) - ys.begin();
int R = lower_bound(ys.begin(), ys.end(), r) - ys.begin();
update(1, 0, m - 2, L, R - 1, v);
```

注意树的区间是 `[0, m-2]`，不是 `[0, m-1]`。开成 `m-1` 会访问到不存在的段，`ys[r+1]` 直接越界。

## 💻 例题

### 例 1  手算一次离散化

`a = {100, 5, 100, 999999999, 5, 42}`。

**解析**：

1. 排序：`5, 5, 42, 100, 100, 999999999`
2. 去重：`5, 42, 100, 999999999`
3. 映射：

| 原值 | 5 | 42 | 100 | 999999999 |
|------|---|----|-----|-----------|
| 编号 | 1 | 2 | 3 | 4 |

原数组变成 `{3, 1, 3, 4, 1, 2}`。

验证：`5 < 42 < 100 < 999999999`，编号 `1 < 2 < 3 < 4`，大小关系完全保留。而原来的差值（比如 999999999 − 100）已经没了——这正是"丢掉的东西"。

### 例 2  P1908 逆序对

输入：

```
6
5 4 2 6 3 1
```

输出：`11`。

**解析**：手算验证——5 后面比它小的有 4 个（4,2,3,1）；4 后面 3 个（2,3,1）；2 后面 1 个（1）；6 后面 2 个（3,1）；3 后面 1 个（1）；1 后面 0 个。合计 `4+3+1+2+1 = 11`。

完整代码：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 500005;
int a[N], bit[N], n;
vector<int> xs;

void add(int p, int v) {
    for (; p <= (int)xs.size(); p += p & -p) bit[p] += v;
}
int query(int p) {
    int s = 0;
    for (; p > 0; p -= p & -p) s += bit[p];
    return s;
}
int id(int v) {
    return int(lower_bound(xs.begin(), xs.end(), v) - xs.begin()) + 1;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;
    for (int i = 1; i <= n; i++) { cin >> a[i]; xs.push_back(a[i]); }
    sort(xs.begin(), xs.end());
    xs.erase(unique(xs.begin(), xs.end()), xs.end());

    long long ans = 0;
    for (int i = n; i >= 1; i--) {
        int p = id(a[i]);
        ans += query(p - 1);
        add(p, 1);
    }
    cout << ans << '\n';
    return 0;
}
```

复杂度 O(n log n)。若不用离散化而直接以值为下标，`bit` 要开到 10⁹，直接爆内存。

### 例 3  P1955 程序自动分析

输入：

```
2
2
1 2 1
1 2 0
2
1 2 1
2 1 1
```

输出：

```
NO
YES
```

**解析**：第一组先要求 1 = 2，又要求 1 ≠ 2，矛盾；第二组两个约束一致。

关键代码就是 101.5 的"两遍扫描"。多组数据别忘了：

```cpp
xs.clear();
for (int i = 1; i <= n; i++) fa[i] = i;   // 只清到 n，别 memset 整个数组
```

`fa` 按离散化后的编号初始化，所以上界是 `xs.size()`，不是变量最大值。

## ⚠️ 你踩过这些坑吗

- [ ] **坑 1：忘了 `erase`** — `unique` 不删元素，`size()` 没变，后面遍历到垃圾值。
- [ ] **坑 2：查了不存在的值** — `lower_bound` 返回插入位置，不报错，静默算错。
- [ ] **坑 3：区间题把端点当点** — 长度少算一段，扫描线整体偏移。
- [ ] **坑 4：多组数据不清空** — `xs`、并查集、答案变量都要重置。
- [ ] **坑 5：用 `map` 代替离散化** — 能过但常数大约十倍，10⁵ 次查询就可能 TLE。

## 🧠 本章小结

```
离散化三步：
  1 sort(xs)                 排序
  2 erase(unique(...), end)  去重
  3 lower_bound + 1          查排名（1-based）

点离散化：只保留大小关系 → 逆序对、计数
区间离散化：保留相邻端点距离 → 扫描线、覆盖长度
            叶子 i = [ys[i], ys[i+1])，区间写 [L, R-1]

接树状数组：从右往左，ans += query(p-1)
接并查集：先处理全部相等，再检查不等
```
