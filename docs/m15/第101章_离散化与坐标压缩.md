# 第 101 章  离散化与坐标压缩
> 🏗️ **前情回顾**：第 36 章你学过"排序 + 去重 + 二分"，那时它只是个技巧。到了扫描线、树状数组、并查集面前，离散化是把 10^9 塞进 10^5 数组的**唯一门票**。
## 🎯 本章目标
- 背下离散化三步并写成一函数
- 分清"点"与"区间"离散化
- 会把离散化接到树状数组、并查集上
## 🧱 知识讲解
### 101.1  三步走
```cpp
vector<int> xs;
for (int i = 1; i <= n; i++) xs.push_back(a[i]);
sort(xs.begin(), xs.end());
xs.erase(unique(xs.begin(), xs.end()), xs.end());
auto id = [&](int v) {   // 1-based
    return int(lower_bound(xs.begin(), xs.end(), v) - xs.begin()) + 1; };
```
关键：`lower_bound` 找第一个 ≥ v 的位置，所以原值必须真在 `xs` 里；查一个不存在的值会得到错误下标。
### 101.2  点离散化 vs 区间离散化
逆序对只关心大小关系，点离散化就够；扫描线、区间覆盖关心长度，必须保留相邻端点的距离：
```cpp
int L = id(l), R = id(r);
upd(1, 1, m - 1, L, R - 1, 1);   // 叶子是 [ys[i], ys[i+1])
```
若把 `l, r` 都 +1 再当点用，长度会被算成"点数"而不是"坐标差"。
### 101.3  与树状数组结合：逆序对
从右往左扫，数右边有多少个比当前小：
```cpp
long long ans = 0;
for (int i = n; i >= 1; i--) {
    int p = id(a[i]);
    ans += query(p - 1); add(p, 1);   // 比 a[i] 小的已出现个数
}
```
### 101.4  与并查集结合：程序自动分析
相等约束可以合并，不等约束必须等所有相等处理完再查。顺序反了会把本可合并的点判死：
```cpp
for (auto &q : qs) if (q.op == 1) merge(id(q.x), id(q.y));
for (auto &q : qs) if (q.op == 0 && find(id(q.x)) == find(id(q.y))) { ok = false; break; }
```
## 💻 例题
**例 1（P1908 逆序对）**：n ≤ 5×10^5、值域 10^9。离散化后树状数组，从右往左统计，答案 `long long`。
**例 2（P1955 程序自动分析）**：多组数据，先读入全部约束并离散化全部变量，再"先等后不等"跑两遍；注意清空 `xs` 与并查集。
## ⚠️ 常见坑
1. 离散化后忘记映射回原值，输出成了下标
2. 区间题把端点当点用，长度整体少 1
3. 多组数据没清空 `xs` / 并查集；用 `map` 代离散化常数大十倍
