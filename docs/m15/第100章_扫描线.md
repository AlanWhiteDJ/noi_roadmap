# 第 100 章  扫描线
> 🏗️ **前情回顾**：第 64 章你会用线段树维护区间信息，第 101 章你会把大坐标压成端点。扫描线就是二者的合体：一条竖线从左扫到右，线段树记住"当前被盖住多长"。
## 🎯 本章目标
- 把矩形面积并转成"事件 + 覆盖长度"
- 写出覆盖次数不下传的线段树
- 求矩形周长并，明白扫描线为什么必须配线段树
## 🧱 知识讲解
### 100.1  事件：把矩形拆成两条竖边
每个矩形拆成入边（v=+1）与出边（v=-1），按 x 排序。扫到一条边时，先结算"上一条边到这条边"的宽度产生的面积，再改动 y 区间覆盖。
```cpp
struct Seg { int l, r, x, v; } e[N];        // l,r 为原始 y 坐标
sort(e + 1, e + cnt + 1, [](Seg a, Seg b) { return a.x < b.x; });
```
### 100.2  线段树：覆盖次数与覆盖长度
叶子 i 表示区间 `[ys[i], ys[i+1])`，m 个端点只有 m-1 个叶子。`cov[p]` 是整段被完全覆盖的次数，**不需要下传**：只要 `cov[p]>0`，长度就是整段。
```cpp
int cov[N << 2]; long long len[N << 2];
void upd(int p, int l, int r, int ql, int qr, int v) {
    if (ql <= l && r <= qr) cov[p] += v;
    else { int mid = (l + r) >> 1;
        if (ql <= mid) upd(p << 1, l, mid, ql, qr, v);
        if (qr > mid)  upd(p << 1 | 1, mid + 1, r, ql, qr, v); }
    if (cov[p]) len[p] = ys[r + 1] - ys[l];
    else len[p] = (l == r ? 0 : len[p << 1] + len[p << 1 | 1]);
}
```
### 100.3  面积并主循环
```cpp
long long ans = 0;
for (int i = 1; i <= cnt; i++) {
    ans += len[1] * (e[i].x - e[i - 1].x);      // 先算上一段贡献
    int L = lower_bound(ys + 1, ys + m + 1, e[i].l) - ys;
    int R = lower_bound(ys + 1, ys + m + 1, e[i].r) - ys;
    upd(1, 1, m - 1, L, R - 1, e[i].v);         // 注意 R-1
}
```
### 100.4  周长并
周长 = 每次扫描后覆盖长度的变化量 + 竖直边总长。前者取 `abs(len[1]-old)`，后者累加所有入边长度；同一 x 的多条边要先全部更新再统计变化。
## 💻 例题
**例 1（P5490 矩形面积并）**：n 个矩形求并集面积。按 100.1–100.3 实现，`long long` 存答案，`ys` 开 2n。
**例 2（P1856 矩形周长并）**：套用面积并框架，累加 `len[1]` 的变化量与入边竖直长度；同一 x 的边必须合并统计，否则重复。
## ⚠️ 常见坑
1. 叶子是"段"不是"点"，查询区间要写 `R-1`，否则多算一段
2. `cov[p]` 为 0 时不能直接返回 0，要由儿子合并
3. 坐标与答案都要 `long long`；离散化后别忘 `lower_bound` 映射
