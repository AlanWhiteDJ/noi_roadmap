# 第 100 章  扫描线

---
> 🏗️ **前情回顾**：第 64 章你会用线段树维护区间信息，第 101 章你会把 10⁹ 的坐标压成 10⁵ 个端点。扫描线就是二者的合体：一条竖线从左扫到右，线段树随时告诉你"此刻被盖住的总长度"。
> 💡 **动机**：n 个矩形求并集面积，一个一个加会把重叠部分算两遍；把二维图形切成 2n 个"时刻"，重复就变成了一次区间加。

## 🎯 本章目标

学完这一章，你能：

- 把矩形面积并拆成 2n 个事件，并按 x 排序
- 写出"覆盖次数不下传"的线段树
- 解释叶子节点为什么表示"一段"而不是"一个点"
- 在 n ≤ 10⁵ 时用 O(n log n) 求出面积并
- 求矩形周长并，知道同一 x 的边为什么要合并处理

## 📖 故事引入

校庆前夜，学生会在宣传栏上贴 n 张矩形海报。宣传栏的坐标是 10⁹ 级别，一格一格涂色显然不可能。会长把坐标抄给你，问：**被海报盖住的总面积是多少？**

你想了想："把每张海报的面积加起来？"

"重叠的地方就算两遍了。"

"那就减去两两重叠……"话没说完你自己也停了——三张、四张叠在一起时，容斥的项数会爆炸。

学长画了一条竖线："别把它当二维的。想象这条线从左往右扫，每扫过宽度 dx，被盖住的竖直长度 L 乘 dx，就是这一小条的面积。"

"L 怎么知道？"

"把每张海报拆成左右两条竖边。碰到左边，就在 y 区间上加一；碰到右边，减一。任何时刻 y 轴上被覆盖的长度就是 L。"

剩下的工作，是让这个长度在 10⁵ 次区间加减中被快速问出来——那是线段树的事。

## 🧱 知识讲解

### 100.1  把矩形拆成事件

一个矩形由左下角 `(x1, y1)` 和右上角 `(x2, y2)` 给出，它是两条竖边夹出来的：

- 左边界 `x1`：从这里开始，y 区间 `[y1, y2]` 被覆盖 → 权值 `+1`
- 右边界 `x2`：从这里开始，该区间不再被覆盖 → 权值 `-1`

n 个矩形共 2n 个事件，按 x 升序排列：

```cpp
struct Seg { int l, r; int x, v; };   // y 区间、竖边位置、±1

vector<Seg> e;
e.push_back({y1, y2, x1, +1});
e.push_back({y1, y2, x2, -1});
sort(e.begin(), e.end(), [](const Seg &a, const Seg &b) {
    return a.x < b.x;                 // 面积并只关心 x 先后
});
```

面积并中，同一个 x 上的边谁先谁后都不影响答案；求周长并时就必须认真处理（见 100.6）。

### 100.2  y 坐标离散化

y 坐标只有 2n 个取值，没必要开 10⁹ 的数组。排序去重后得到 m 个端点，相邻两个端点夹出一"段"：

```
ys[0] ---- ys[1] ---- ys[2] ---- ys[3]
   段 0       段 1       段 2
```

- 端点个数 m，段数 m − 1
- 第 i 段表示半开区间 `[ys[i], ys[i+1])`
- **线段树的叶子是"段"，不是"点"**

```cpp
int ys[N], m = 0;
for (int i = 0; i < n; i++) {
    ys[m++] = y1;
    ys[m++] = y2;
}
sort(ys, ys + m);
m = int(unique(ys, ys + m) - ys);   // 端点 m 个，叶子编号 0 .. m-2
```

为什么强调"段"？因为面积靠长度算。若把端点当点去覆盖，长度会被算成"点的个数"，比真实长度少 1。这是扫描线最经典的错误。

### 100.3  每个节点维护什么

每个节点维护两个值：`cov[p]` 是这个区间被**完整**覆盖的次数，`len[p]` 是当前被覆盖的总长度（重复只算一次）。

合并方式就是 `pushup` 里的三个分支：

```cpp
int cov[N << 2];
long long len[N << 2];

void pushup(int p, int l, int r) {
    if (cov[p] > 0) {
        len[p] = ys[r + 1] - ys[l];          // 整段长度
    } else if (l == r) {
        len[p] = 0;
    } else {
        len[p] = len[p << 1] + len[p << 1 | 1];
    }
}
```

**关键点：`cov` 不下传。** 普通线段树做区间加要打 lazy 标记往下推，这里不用——查询永远只问根节点的 `len[1]`，不需要知道某个叶子自己的覆盖次数。

### 100.4  区间修改

把事件映射到叶子区间 `[L, R-1]`，然后区间加：

```cpp
void update(int p, int l, int r, int ql, int qr, int v) {
    if (ql <= l && r <= qr) {
        cov[p] += v;
    } else {
        int mid = (l + r) >> 1;
        if (ql <= mid) update(p << 1, l, mid, ql, qr, v);
        if (qr > mid)  update(p << 1 | 1, mid + 1, r, ql, qr, v);
    }
    pushup(p, l, r);          // 改完必须自下而上重算
}
```

映射时注意那个 `-1`：`ys = {0, 2, 5, 9}` 覆盖 `[2, 9]`，对应段 1 和段 2，即 `[1, 2]`。

```cpp
int L = int(lower_bound(ys, ys + m, e[i].l) - ys);
int R = int(lower_bound(ys, ys + m, e[i].r) - ys);
update(1, 0, m - 2, L, R - 1, e[i].v);   // 段区间是 [L, R-1]
```

### 100.5  主循环与完整代码

每扫到一个事件，先用**上一段**的覆盖长度结算宽度，再修改覆盖状态：

```cpp
long long area = 0;
for (int i = 0; i < (int)e.size(); i++) {
    if (i > 0) area += len[1] * (e[i].x - e[i - 1].x);
    // 再更新
    int L = lower_bound(ys.begin(), ys.end(), e[i].l) - ys.begin();
    int R = lower_bound(ys.begin(), ys.end(), e[i].r) - ys.begin();
    update(1, 0, m - 2, L, R - 1, e[i].v);
}
```

顺序不能反：`len[1]` 代表的是 `[e[i-1].x, e[i].x)` 这一段的覆盖长度；先更新再乘，就是新长度配旧宽度，必错。

完整程序（P5490 的骨架）：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 200005;
struct Seg { int l, r, x, v; } e[N];
int ys[N], m;
int cov[N << 2];
long long len[N << 2];

void pushup(int p, int l, int r) {
    if (cov[p] > 0) len[p] = ys[r + 1] - ys[l];
    else if (l == r) len[p] = 0;
    else len[p] = len[p << 1] + len[p << 1 | 1];
}

void update(int p, int l, int r, int ql, int qr, int v) {
    if (ql <= l && r <= qr) cov[p] += v;
    else {
        int mid = (l + r) >> 1;
        if (ql <= mid) update(p << 1, l, mid, ql, qr, v);
        if (qr > mid)  update(p << 1 | 1, mid + 1, r, ql, qr, v);
    }
    pushup(p, l, r);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; cin >> n;
    int cnt = 0, tot = 0;
    for (int i = 0; i < n; i++) {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        ys[tot++] = y1; ys[tot++] = y2;
        e[cnt++] = {y1, y2, x1, +1};
        e[cnt++] = {y1, y2, x2, -1};
    }
    sort(ys, ys + tot);
    m = int(unique(ys, ys + tot) - ys);
    sort(e, e + cnt, [](const Seg &a, const Seg &b) { return a.x < b.x; });

    long long area = 0;
    for (int i = 0; i < cnt; i++) {
        if (i) area += len[1] * (e[i].x - e[i - 1].x);
        int L = int(lower_bound(ys, ys + m, e[i].l) - ys);
        int R = int(lower_bound(ys, ys + m, e[i].r) - ys);
        update(1, 0, m - 2, L, R - 1, e[i].v);
    }
    cout << area << '\n';
    return 0;
}
```

复杂度 O(n log n)，空间 O(n)。

### 100.6  周长并：多维护两个量

周长 = 竖直边界 + 水平边界。

- **竖直边界**：每次扫过一条边，覆盖长度变化多少，就有多长的竖直边。所以累加 `|len_after - len_before|`。
- **水平边界**：当前 y 方向上有 `num` 段互不相连的覆盖区间，每一段都有上下两条水平边，各长 dx，所以累加 `2 * num * dx`。

因此节点要多记三个值：

```cpp
int num[N << 2];            // 区间内连续覆盖段的个数
bool lc[N << 2], rc[N << 2]; // 左右端点是否被覆盖

void pushup2(int p, int l, int r) {
    if (cov[p] > 0) {
        len[p] = ys[r + 1] - ys[l];
        num[p] = 1; lc[p] = rc[p] = true;
    } else if (l == r) {
        len[p] = num[p] = 0; lc[p] = rc[p] = false;
    } else {
        len[p] = len[p << 1] + len[p << 1 | 1];
        num[p] = num[p << 1] + num[p << 1 | 1]
               - (rc[p << 1] && lc[p << 1 | 1]);   // 中间接上了就少一段
        lc[p] = lc[p << 1];
        rc[p] = rc[p << 1 | 1];
    }
}
```

把 100.4 的 `update` 末尾改成调用 `pushup2`，主循环再**按 x 分组**：先把同一 x 的边全部更新完，再统一结算。

```cpp
long long ans = 0, lastlen = 0;
int lastx = e[0].x;
for (int i = 0; i < cnt; ) {
    int x = e[i].x;
    ans += 2LL * num[1] * (x - lastx);       // 水平边
    while (i < cnt && e[i].x == x) {          // 同 x 的边一起改
        int L = ..., R = ...;
        update(1, 0, m - 2, L, R - 1, e[i].v);
        i++;
    }
    ans += abs(len[1] - lastlen);             // 竖直边
    lastlen = len[1];
    lastx = x;
}
```

若一条一条结算，中间状态会被当成真实轮廓，凭空多出竖直边，答案偏大。

## 💻 例题

### 例 1  手算三个矩形的面积并

三个矩形：

- A：`[0, 4] × [0, 2]`
- B：`[2, 6] × [1, 3]`
- C：`[5, 8] × [0, 2]`

**解析**：把 x 轴按所有左右边界切成 5 条竖带。
| 竖带 | 覆盖的矩形 | y 方向并集 | 高度 | 面积 |
|------|-----------|-----------|------|------|
| [0, 2) | A | [0, 2] | 2 | 4 |
| [2, 4) | A, B | [0, 3] | 3 | 6 |
| [4, 5) | B | [1, 3] | 2 | 2 |
| [5, 6) | B, C | [0, 3] | 3 | 3 |
| [6, 8) | C | [0, 2] | 2 | 4 |

合计 `4 + 6 + 2 + 3 + 4 = 19`。

用容斥验算：三个面积 8 + 8 + 6 = 22；A∩B = `[2,4]×[1,2]` = 2；B∩C = `[5,6]×[1,2]` = 1；A∩C 与三交都是空。`22 − 2 − 1 = 19`，一致。

去重后 y 只有 4 个端点，叶子 3 段——正是"m 个端点、m−1 段"。

### 例 2  P5490 的实现要点

输入：

```
2
100 100 200 200
150 150 250 250
```

输出：`17500`。

**解析**：两块 100×100 的正方形，重叠 `[150,200]×[150,200]` = 2500，所以 `10000 + 10000 − 2500 = 17500`。

提交前重点检查四处：

1. `ys`、`e` 开 `2n`，即 `N = 200005`；`len` 开 4 倍
2. 叶子区间是 `[0, m-2]`，映射写 `R - 1`
3. `area`、`len` 用 `long long`：坐标 10⁹ 时面积可达 10¹⁸
4. 先累加面积，再 `update`

### 例 3  P1856 周长并

输入 7 个矩形，输出 `228`。

**解析**：`ans` 分两部分：竖直是 `Σ|len[1] - lastlen|`，水平是 `Σ 2*num[1]*dx`。

拿单个矩形 `[0,4]×[0,2]` 自测：左边界 `num = 1`，水平 `2*1*4 = 8`，竖直 `|2-0| = 2`；右边界水平 0、竖直 2。合计 `12 = 2×(4+2)`，正确。

## 🧠 本章小结

```
面积并 = 事件 + 线段树

事件：每个矩形拆左右两条竖边，入 +1、出 -1，按 x 排序
离散化：m 个 y 端点 → m-1 个叶子段，叶子 i = [ys[i], ys[i+1])
节点：cov 完整覆盖次数（不下传），len 覆盖总长
pushup：cov>0 → 整段；叶子 → 0；否则左右相加
主循环：先 area += len[1] * dx，再 update(L, R-1, v)

周长并 = Σ|Δlen|（竖直）+ Σ 2*num*dx（水平）
        同 x 的边必须一起更新后再结算
```
