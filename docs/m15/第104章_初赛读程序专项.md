## 🧱 知识讲解
### 104.1  读程序三步
先看输入输出（求值/计数/判断），再找主循环与不变量（哪句是状态转移），最后代 n=3 手跑一遍，比盯着代码快。
看到 `while (n) { s += n & 1; n >>= 1; }` 就该条件反射：这是 `popcount`，二进制中 1 的个数。
### 104.2  完善程序：先通读，再代入
不要从第一个空硬想。先通读判断算法，再把选项**代回原文**读一遍，最后用边界（n=1、空串、全相同）验证。常见空位：循环边界、初始化、取模、返回值。
```cpp
for (int i = 1; i <= n; i++)
    for (int j = m; j >= w[i]; j--)      // 必须倒序，否则成了完全背包
        f[j] = max(f[j], f[j - w[i]] + v[i]);
```
依据：`f[j]` 依赖上一行的 `f[j-w[i]]`，倒序保证它还没被本轮更新。
### 104.3  高频模型一：字符串哈希
```cpp
const int B = 131; unsigned long long h[N], p[N];
p[0] = 1;
for (int i = 1; i <= n; i++) {
    h[i] = h[i - 1] * B + s[i];
    p[i] = p[i - 1] * B;
}
// [l,r] 哈希：h[r] - h[l-1] * p[r-l+1]
```
题目常问两子串是否相等，就是比较这两段哈希；也可能问冲突概率与 `unsigned` 回绕。
### 104.4  高频模型二：完全二叉树与状压
完全二叉树用数组存：i 的儿子是 `2i`、`2i+1`，深度 `floor(log2 i)+1`。状压把集合压成整数，枚举子集：
```cpp
for (int s = 0; s < (1 << n); s++)
    for (int t = s; t; t = (t - 1) & s)   // t 遍历 s 的所有非空子集
        /* 在此处理子集 t */;
```
## 💻 例题
**例 1（2024 S1 字符串哈希 + 完全二叉树）**：先确认 `h` 是哈希、`p` 是幂次，再确认下降次数等于树深，答案自然出来。
**例 2（2024 S1 01 串状压 DP）**：`f[s]` 表示已选集合 s 的最优值，转移枚举补集元素；看 `f[s | (1<<i)]` 是否比 `f[s]` 多一项贡献。
## ⚠️ 常见坑
1. 死抠某行语法不抓主干，时间全耗进去；完善程序只看选项通顺
2. 做题前没通读逻辑，空位一改就崩
3. 忽略 `int` 溢出与 `unsigned` 回绕（哈希必考）
4. 时间失衡：阅读程序 30 分钟，大题没时间
