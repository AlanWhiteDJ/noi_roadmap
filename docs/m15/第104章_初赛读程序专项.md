# 第 104 章  初赛读程序与完善程序专项

---
> 🏗️ **前情回顾**：M9–M14 你已经把 DP、图论、数据结构过了一遍。初赛阅读程序题考的不是新知识，而是**在 8 分钟内看懂一段陌生代码在干什么**。
> 💡 **动机**：初赛的程序往往只有三四十行，但每行都可能是陷阱。会读代码，比会写代码更值钱——因为它考的是"抓主干"的能力。

## 🎯 本章目标

学完这一章，你能：

- 按"输入输出 → 主干 → 小数据"的顺序读一段陌生代码
- 认出初赛最爱考的六类模型
- 用"代回原文 + 边界验证"做完善程序
- 把一篇阅读程序稳定控制在 8 分钟
- 不在某一行语法上耗掉半场考试

## 🧱 知识讲解

### 104.1  读程序三步

**第一步：看输入输出。**

先看 `cin` 读什么、`cout` 输出什么、输出几行。这决定了你要算的是"一个值"还是"一张表"。

**第二步：找主干和不变量。**

跳过 `#include`、变量声明，直接找最内层循环和它的状态更新。问自己：

- 哪个变量是"答案"？
- 哪一句在更新它？
- 循环的每一轮，什么量保持不变？

**第三步：代小数据手跑。**

取 n = 3 或字符串 `"aba"`，在纸上跑一遍。比盯着代码想快得多，也能立刻发现"下标从 0 还是 1 开始"。

### 104.2  六个高频模型

初赛阅读程序翻来覆去就这几类：

| 代码特征 | 它在干什么 | 复杂度 |
|---------|-----------|--------|
| `while (n) { c += n & 1; n >>= 1; }` | 二进制中 1 的个数（popcount） | O(log n) |
| `while (b) { t = a % b; a = b; b = t; }` | 最大公约数（辗转相除） | O(log n) |
| `for (i=2; i*i<=n; i++) if (!vis[i]) for (j=i*i; j<=n; j+=i)` | 埃氏筛 | O(n log log n) |
| `h[i] = h[i-1]*B + s[i]` | 字符串哈希 | O(n) |
| `i` 的儿子是 `2i`、`2i+1` | 完全二叉树（数组存储） | 树高 O(log n) |
| `for (t = s; t; t = (t-1)&s)` | 枚举子集 | O(3ⁿ) 总量 |

再加两个常客：0/1 背包的倒序循环、双指针的 `while (l < r)`。

看到 `n & (n-1)` 要想到"去掉最低位的 1"，它常用来判 2 的幂：`n > 0 && (n & (n-1)) == 0`。

### 104.3  完善程序：先通读，再代入

不要从第一个空硬想。正确顺序是：

1. **通读全文**，判断这是什么算法（DP？图遍历？二分？）
2. 看每个选项，把它**代回原文**读一遍，读不通就排除
3. 用边界验证：n = 1、空串、全部相同、只有一个元素

常见空位就四类：

| 空位位置 | 常见答案 |
|---------|---------|
| 循环边界 | `i <= n`、`j >= w[i]`、`l < r` |
| 初始化 | `f[0] = 0`、`ans = -INF`、`p[0] = 1` |
| 状态转移 | `f[j] = max(f[j], f[j-w[i]]+v[i])` |
| 返回值 / 输出 | `return ans`、`f[m]` |

0/1 背包是最经典的完善程序题：

```cpp
for (int i = 1; i <= n; i++)
    for (int j = m; j >= w[i]; j--)          // 必须倒序
        f[j] = max(f[j], f[j - w[i]] + v[i]);
```

为什么倒序？因为 `f[j]` 依赖**上一行**的 `f[j-w[i]]`。倒着走时，`f[j-w[i]]` 还没被本轮更新，拿到的正是上一行的值；正着走会用到本轮刚更新的值，等于把每件物品放了无数次——那就变成了完全背包。

### 104.4  时间分配

初赛 120 分钟，建议：

| 题型 | 时间 | 策略 |
|------|------|------|
| 单选 | 20 min | 会就会，不会先标记 |
| 阅读程序 | 45 min | 每篇 8 分钟，超时就跳 |
| 完善程序 | 35 min | 每篇 15 分钟 |
| 检查 | 20 min | 填涂、边界、回头补 |

一篇阅读程序超过 10 分钟还没头绪，先选一个最像的答案，做下一题。初赛是选择题，**空着和选错都是 0 分**。

### 104.5  读不懂时的三个急救动作

1. 把循环变量的取值列成表（i = 1,2,3 时各变量是多少）
2. 把递归展开两层，看它返回什么
3. 找"最不像废话"的那一行——它通常就是算法的核心

## 💻 例题

### 例 1  阅读程序写输出

```cpp
#include <iostream>
using namespace std;

int f(int n) {
    int c = 0;
    while (n) { c += n & 1; n >>= 1; }
    return c;
}
int g(int a, int b) {
    while (b) { int t = a % b; a = b; b = t; }
    return a;
}
int main() {
    int ans = 0;
    for (int i = 1; i <= 20; i++)
        if (f(i) == 2) ans += g(i, 12);
    cout << ans << endl;
    return 0;
}
```

**解析**：

第一步，认模型：`f` 是 popcount，`g` 是 gcd。整段的意思是"把 1..20 中二进制恰有 2 个 1 的数挑出来，累加它与 12 的 gcd"。

第二步，列候选。1..20 中 popcount 为 2 的数：

| 数 | 二进制 | gcd(·,12) |
|----|--------|-----------|
| 3 | 11 | 3 |
| 5 | 101 | 1 |
| 6 | 110 | 6 |
| 9 | 1001 | 3 |
| 10 | 1010 | 2 |
| 12 | 1100 | 12 |
| 17 | 10001 | 1 |
| 18 | 10010 | 6 |
| 20 | 10100 | 4 |

第三步，求和：`3+1+6+3+2+12+1+6+4 = 38`。

答案 `38`。注意 7（111）、11（1011）、13（1101）、14（1110）、19（10011）都是 3 个 1，别数进去。

### 例 2  字符串哈希判断题

设字符串存在 `s[1..n]`（下标从 1 开始）：

```cpp
const int B = 131;
unsigned long long h[N], p[N];
p[0] = 1;
for (int i = 1; i <= n; i++) {
    h[i] = h[i - 1] * B + s[i];
    p[i] = p[i - 1] * B;
}
// 子串 [l, r] 的哈希：h[r] - h[l-1] * p[r-l+1]
```

下列说法正确的是：

A. 该哈希不会发生冲突  
B. `unsigned long long` 溢出等价于对 2⁶⁴ 取模  
C. `B` 必须小于字符集大小  
D. 把 `l` 和 `r` 交换，哈希值不变

**解析**：

- A 错。任何把长串压成 64 位的哈希都可能冲突，只是概率低。
- B 对。无符号整数溢出在 C++ 中是良定义的，等价于模 2⁶⁴。
- C 错。`B` 通常取大于字符集的质数（如 131、13331），以减少冲突。
- D 错。子串方向反了，哈希值一般不同。

答案 B。这类题的套路：**"一定不冲突"永远错，"溢出即取模"永远对。**

### 例 3  完善程序：0/1 背包

```cpp
int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> w[i] >> v[i];
    for (int i = 1; i <= n; i++)
        for (int j = m; j >= ①; j--)
            f[j] = max(f[j], ②);
    cout << ③ << endl;
    return 0;
}
```

**解析**：

① 填 `w[i]`。容量小于 `w[i]` 时放不下这件物品，没有转移的意义。

② 填 `f[j - w[i]] + v[i]`。不放是 `f[j]`，放是"腾出 `w[i]` 的容量后的最优值 + 这件物品的价值"。

③ 填 `f[m]`。`f[j]` 表示容量为 j 时的最大价值，答案是容量 m。

验证边界：n = 1、w[1] > m 时，内层循环一次都不执行，`f[m] = 0`，正确。

## 🧠 本章小结

```
读程序三步：
  1 看输入输出（求值？计数？判断？）
  2 找主干与不变量（哪句更新答案）
  3 代 n=3 手跑（确认下标与边界）

六个模型：
  popcount  gcd  埃氏筛  字符串哈希  完全二叉树  状压子集枚举

完善程序：
  通读定算法 → 选项代回原文 → 边界验证
  空位四类：循环边界 / 初始化 / 转移 / 返回

时间：阅读 8 分钟一篇，超时就跳；选择题不留空
```
