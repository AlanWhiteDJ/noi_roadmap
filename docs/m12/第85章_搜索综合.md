## 🧱 知识讲解

### 85.1  先估状态数

状态数 × 每个状态的转移数 = 大致运算量。几个常用规模：

| 枚举对象 | 数量 | 备注 |
|----------|------|------|
| 10! | 3.6×10⁶ | 全排列，n ≤ 10 |
| 2²⁰ | 1.0×10⁶ | 子集，n ≤ 20 |
| 3¹⁵ | 1.4×10⁷ | 每项三选一 |
| C(20,10) | 1.8×10⁵ | 组合数 |
| 9! | 3.6×10⁵ | 九宫格排列 |

拿到题先做三件事：

1. 数一数"一个状态"要存多少信息
2. 算一算总共有多少状态
3. 乘上转移代价，和 10⁸ 比

如果状态数是 10¹²，无论怎么剪枝都不可能全搜；如果只有 10⁶，哪怕每个状态做 100 次操作也能过。

### 85.2  搜索与 DP 的分界

判断标准只有两条：

- **状态会不会重复出现？** 会，就该记忆化或 DP
- **有没有最优子结构？** 有，就能把大问题拆成小问题

同一格子被不同路径反复走到，就是典型的重复状态：

```cpp
int dfs(int x, int y) {
    if (x > n || y > m) return 0;
    if (done[x][y]) return f[x][y];        // 记忆化
    done[x][y] = 1;
    return f[x][y] = max(dfs(x + 1, y), dfs(x, y + 1)) + a[x][y];
}
```

这段代码和"从下往上填表"的 DP 完全等价，只是方向相反。记忆化搜索的好处是不用想清楚递推顺序，坏处是递归开销和栈深度。

反过来，如果状态里必须记录"已经走过哪些点"（比如哈密顿路径），状态无法压缩，就只能搜索 + 剪枝。判据还是那句：**状态会不会重复；重复了，能不能用更少的维度描述它。**

### 85.3  折半搜索

n ≤ 40 的子集枚举是 2⁴⁰ ≈ 10¹²，直接搜必死。把数组切成两半，各枚举 2²⁰，再合并：

```cpp
int n;
long long S, a[45];
vector<long long> A, B;

void gen(int l, int r, vector<long long> &v) {
    int len = r - l;
    for (int mask = 0; mask < (1 << len); mask++) {
        long long sum = 0;
        for (int i = 0; i < len; i++)
            if (mask >> i & 1) sum += a[l + i];
        if (sum <= S) v.push_back(sum);
    }
}

// 主函数
gen(0, n / 2, A);
gen(n / 2, n, B);
sort(B.begin(), B.end());
long long ans = 0;
for (long long x : A) {
    auto it = upper_bound(B.begin(), B.end(), S - x);
    if (it != B.begin()) ans = max(ans, x + *prev(it));
}
```

复杂度从 O(2ⁿ) 降到 O(2^(n/2) · n)。合并时排序 + 二分，或者双指针。折半搜索适用于"每个元素选或不选、答案可加"的一类问题，比如子集和、最大异或和、方程解的个数。

### 85.4  部分分策略

一道题往往分好几档数据。写代码前先看数据范围表，按档拿分：

- **小数据**：纯暴力枚举，先拿 30–50 分
- **特殊性质**：链、菊花图、所有数相同、没有修改操作——单独写一档
- **正解**：在暴力基础上加记忆化、剪枝，或换算法

三档互不干扰，哪档写挂都不影响其他档。最忌讳的是一上来追正解，写到一半发现推错，最后 0 分。

### 85.5  构造题里的搜索

构造题常要求"输出任意合法方案"。这类题不需要最优，找到一个就退出：`dfs` 一旦某条分支返回 `true`，上层直接返回，不再撤销。

配合随机化：随机打乱候选顺序，多跑几次；或者用爬山、模拟退火在解空间里游走。构造题的正确性通常由 special judge 判定，只要满足条件就给分。

### 85.6  对拍：验证搜索的第一步

剪枝写错最容易漏解，而手造数据很难覆盖。写三个程序：不剪枝的 `brute.cpp`、你的 `sol.cpp`、随机生成小数据的 `gen.cpp`，循环跑一千组，用 `diff` 比较两份输出，第一组不同就停下并打印组号。小数据范围要压到暴力能跑完，但结构要覆盖边界：全相同、逆序、只有一个元素、答案不存在。

## 💻 例题

### 例 1  CSP-S 2023 [密码锁](https://hydro.ac/p/ccf-CSPS2023A)

5 位密码，每位 0–9。一次拨动可以：转某一位任意格；或同时转相邻两位相同的格数（同方向）。给出 n 个"最多拨动两次可达"的状态，求可能的正确密码个数。n ≤ 5。

**解析**：正确密码只有 10⁵ 种。反过来想：从一个观测状态出发，枚举“两步内能到达的所有状态”，它们都可能是正确密码。对 n 个观测各生成一个集合，取交集即可。拨动是可逆的，所以“从观测可达”等价于“从密码可达”。

```cpp
int encode(int d[5]) {
    int x = 0;
    for (int i = 0; i < 5; i++) x = x * 10 + d[i];
    return x;
}

void gen(int s, vector<int> &v) {
    set<int> st;
    st.insert(s);
    vector<int> cur{s};
    for (int step = 0; step < 2; step++) {
        vector<int> nxt;
        for (int x : cur) {
            int d[5], y = x;
            for (int i = 4; i >= 0; i--) { d[i] = y % 10; y /= 10; }
            for (int i = 0; i < 5; i++)
                for (int k = 1; k <= 9; k++) {
                    int e[5]; memcpy(e, d, sizeof(e));
                    e[i] = (e[i] + k) % 10;
                    int z = encode(e);
                    if (st.insert(z).second) nxt.push_back(z);
                }
            for (int i = 0; i < 4; i++)
                for (int k = 1; k <= 9; k++) {
                    int e[5]; memcpy(e, d, sizeof(e));
                    e[i] = (e[i] + k) % 10;
                    e[i + 1] = (e[i + 1] + k) % 10;
                    int z = encode(e);
                    if (st.insert(z).second) nxt.push_back(z);
                }
        }
        cur.swap(nxt);
    }
    v.assign(st.begin(), st.end());   // set 迭代有序，可二分
}

int main() {
    int n; cin >> n;
    vector<vector<int>> S(n);
    for (int i = 0; i < n; i++) {
        int d[5];
        for (int j = 0; j < 5; j++) cin >> d[j];
        gen(encode(d), S[i]);
    }
    int ans = 0;
    for (int x = 0; x < 100000; x++) {
        bool ok = true;
        for (int i = 0; i < n && ok; i++)
            if (!binary_search(S[i].begin(), S[i].end(), x)) ok = false;
        if (ok) ans++;
    }
    cout << ans << '\n';
}
```

每个集合最多约 `1 + 81 + 81×81 ≈ 6.7×10³` 个状态，n ≤ 5，枚举 10⁵ 个候选并二分判断，总运算量约 10⁷。

**易错点**：第一步生成后必须再扩展一层，只枚举一次拨动会漏解；拨动可逆，所以从观测反推和从密码正推结果一样。

### 例 2  CSP-S 2021 [回文](https://hydro.ac/p/ccf-CSPS2021C)

2n 个数排成一行，每次从最左或最右取一个数，依次放到新序列的末尾，要求新序列是回文。输出取数方案。

**解析**：先写暴力 DFS 拿小数据的分：每步两种选择，取 2n 层，n ≤ 20 时 2⁴⁰ 太大，实际要配合"当前新序列必须是回文前缀"剪枝。

正解的观察是：回文串的第一位和最后一位相同。第一步只能取左端或右端，这决定了最终回文的第一个数；而最后一个数必须是同一个数，它在剩余区间的哪一端是可以确定的。于是只需枚举 4 种组合（第一步左/右 × 配对位置左/右），之后用双端队列模拟，O(n) 判断可行性。

回文的配对关系一旦确定，剩下的取法就被唯一确定，所以枚举量从指数降到常数。

### 例 3  折半搜索：子集和不超过 S

n ≤ 40，每个数 ≤ 10⁹，求和不超过 S 的最大子集和。

**解析**：套 85.3 的模板。两半各生成不超过 2²⁰ 个和，排序后对每个左半和二分右半。注意 `1 << len` 在 `len = 20` 时是 1,048,576，用 `int` 没问题；`sum` 用 `long long`，因为 40 个 10⁹ 相加会超 `int`。生成时按“加入新数就产生一批新和”递推，每个和只算一次加法，比枚举 mask 再逐位求和快一个 n 倍。

## ⚠️ 你踩过这些坑吗

- [ ] **坑 1：该 DP 时硬搜** — 状态数 10¹² 还写 DFS，剪枝再好也过不了。
- [ ] **坑 2：该搜时硬推** — 状态必须记录完整路径（如哈密顿路径），却非要压成二维 DP，转移推不出来。
- [ ] **坑 3：不会写暴力部分分** — 正解写挂就得 0 分；先交暴力，再改正解。
- [ ] **坑 4：折半搜索合并写错** — 忘了排序、二分边界写成 `lower_bound`，或 `S - x` 为负时越界。
- [ ] **坑 5：多测不清空** — 标记数组、答案、队列都要重置，否则第二组开始就错。
- [ ] **坑 6：构造题非要最优** — 题目只要"任意合法方案"，找到就退出，别浪费时间优化。

## 🧠 本章小结

```
决策顺序：
  1 估状态数（b^d 或 2ⁿ）
  2 状态重复 + 最优子结构 → 记忆化 / DP
  3 状态不可压缩 → 搜索 + 剪枝
  4 2ⁿ 太大但 n≤40 → 折半搜索

折半搜索：
  两半各枚举 2^(n/2)，排序后二分合并

部分分：
  小数据暴力 / 特殊性质 / 正解，分档写，互不影响

构造题：
  找到一个解就 return true，配合随机化

验证：
  对拍 brute + sol + gen，先保证正确再加剪枝
```
