## 🎯 本章目标
- 估算状态空间，判断搜索能否在时限内跑完

- 会写暴力部分分，再逐步换正解

## 🧱 知识讲解
### 85.1  先估状态数
状态数 × 每个状态的转移数就是大致运算量。n≤10 的全排列 3.6×10⁶ 可以搜；n≤20 的 2ⁿ 子集要状压；n≤10⁵ 却还想着枚举子集，说明方向错了。先算，再写。

### 85.2  搜索与 DP 的分界
若同一条路径会被不同顺序重复到达，且有最优子结构，就记忆化；记忆化把 `dfs(state)` 的结果存表，等价于自顶向下的 DP。若状态无法压缩（如需要记录完整路径），只能搜索 + 剪枝。判据：状态是否会重复出现，重复了就该记忆化或 DP。

```cpp
int dfs(int x, int y) {
    if (x > n || y > m) return 0;
    if (done[x][y]) return f[x][y];
    done[x][y] = 1;
    return f[x][y] = max(dfs(x+1,y), dfs(x,y+1)) + a[x][y];
}
```

### 85.3  部分分策略
- 小数据：纯暴力枚举，先拿 30–50 分
- 特殊性质：链、菊花图、全相同——单独写一档
- 正解：在暴力基础上加记忆化/剪枝/换算法

先保证每档都能过自己的数据，再谈优化；不要一上来追正解导致 0 分。

### 85.4  构造题里的搜索
构造题常要求"输出任意合法方案"。此时搜索只需找到一个解，找到即退出，配合随机化和多次尝试，比求最优容易得多。
