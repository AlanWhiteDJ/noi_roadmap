# 第 82 章  KMP

---
> 🏗️ **前情回顾**：第 19–21 章你用 `string` 做过查找，暴力匹配在主串每个位置都从头比，最坏 O(nm)。KMP 让指针永不回退。
💡 **动机**：暴力匹配在 `aaaa…ab` 上会退化到 O(nm)，KMP 用一块数组存下历史信息，是"用空间换时间"的典型。

## 📖 故事引入

你在一个两万字的文本里找一个五字的词。最直接的办法：从第一个字开始，逐字比对；不对就往后挪一位，从头再比。

大部分时候很快。可如果文本是"啊啊啊啊……啊"，要找的是"啊啊啊啊啵"，你就会在每一个位置都比到最后一个字才失败。两万字 × 五个字 = 十万次比较，机器还扛得住；文本换成两百万字，就是一千多万次，明显变慢。

更气人的是：前四个"啊"明明已经比过了，下一次却还要再比一遍。

KMP 的三位作者问了一个问题：**已经匹配上的那一段，能不能不重比？** 答案是可以——只要你还记得"这段前缀里，多长的前缀等于后缀"。这块记忆就是 `pi` 数组。

## 🧱 知识讲解

### 82.1  暴力匹配为什么慢

```cpp
for (int i = 0; i + m <= n; i++) {
    int j = 0;
    while (j < m && s[i + j] == p[j]) j++;
    if (j == m) cout << i + 1 << '\n';   // 1-based 起点
}
```

外层每个起点，内层最多比 m 次，最坏 O(nm)。退化发生在"大量重复前缀"时：`s = aaaaa…a`、`p = aaaab`，每次都在最后一位失败，前面的比较全部作废。

关键观察：失败时，主串指针 `i` 不必回退到 `i+1`，模式串指针 `j` 也不必归零。已经匹配的那段 `p[0..j-1]` 里，如果存在一个真前缀等于它的真后缀，那么这段后缀已经和主串对上了，直接把 `j` 挪到那个前缀的长度即可。

### 82.2  前缀函数 pi

对模式串 `p`，定义：

> `pi[i]` = 子串 `p[0..i]` 的**最长相等真前缀与真后缀**的长度。

"真"表示不能是整段自己。以 `p = ababaca` 为例：

| i | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 字符 | a | b | a | b | a | c | a |
| pi | 0 | 0 | 1 | 2 | 3 | 0 | 1 |

验证 `i = 4`：子串 `ababa`，前缀 `aba` 等于后缀 `aba`，长度 3，不能取 5（那是整段），所以 `pi[4] = 3`。

`pi[i]` 同时就是"第 i+1 位失配时，模式串该跳到的位置"——因为 `p[0..pi[i]-1]` 已经保证和主串对上了。

### 82.3  递推求 pi

暴力求每个 pi 是 O(n²)。利用 `pi[i-1]` 可以均摊 O(n)：

```cpp
vector<int> pi(n, 0);
for (int i = 1; i < n; i++) {
    int j = pi[i - 1];                  // 先继承前一位的答案
    while (j > 0 && p[i] != p[j])
        j = pi[j - 1];                  // 失配就沿 pi 链回跳
    if (p[i] == p[j]) j++;
    pi[i] = j;
}
```

思路是：`p[0..i-1]` 的最长公共前后缀长度是 `j`，那么 `p[0..i]` 的候选答案只能是 `j+1`，前提是 `p[i] == p[j]`。如果不等，就退而求其次，看 `p[0..i-1]` 的次长公共前后缀——那正好是 `pi[j-1]`，于是沿链跳。

```
p = a b a b a c a
i=1: j=0, p[1]!=p[0] → pi[1]=0
i=2: j=0, p[2]==p[0] → j=1, pi[2]=1
i=3: j=1, p[3]==p[1] → j=2, pi[3]=2
i=4: j=2, p[4]==p[2] → j=3, pi[4]=3
i=5: j=3, c!=b → j=pi[2]=1, c!=b → j=pi[0]=0, pi[5]=0
i=6: j=0, a==a → j=1, pi[6]=1
```

`while` 看起来可能跳很多次，但 `j` 每次至少减 1，而 `j` 在整个循环里最多增加 n 次，所以总跳转次数不超过 n，均摊 O(n)。

### 82.4  匹配

主串指针 `i` 只前进不回退，模式串指针 `j` 失配时沿 pi 链跳：

```cpp
for (int i = 0, j = 0; i < (int)s.size(); i++) {
    while (j > 0 && s[i] != p[j]) j = pi[j - 1];
    if (s[i] == p[j]) j++;
    if (j == (int)p.size()) {
        cout << i - j + 2 << '\n';   // 1-based 起始位置
        j = pi[j - 1];               // 继续找重叠的匹配
    }
}
```

两个地方最容易错：

- 匹配成功后必须写 `j = pi[j-1]`，否则下一次从 `j = m` 开始，`p[j]` 直接越界
- 输出位置换算：当前匹配结束于 `i`（0-based），起点是 `i - m + 1`（0-based），转成 1-based 要加 1，即 `i - m + 2`

整个匹配 O(n + m)：`i` 走 n 步，`j` 最多增加 n 次，回跳总数也不超过 n。

### 82.5  最小周期

设 `n = |p|`，`c = n - pi[n-1]`。

- `c` 一定是 p 的一个周期（不要求整除）
- 如果 `n % c == 0`，整串就由长度为 `c` 的循环节重复构成，`c` 是最小循环节长度
- 如果 `n % c != 0`，说明还差一点才能补齐，最少要补 `c - n % c` 个字符

例：`ababab` 的 `pi[5] = 4`，`c = 2`，`6 % 2 == 0`，循环节是 `ab`。

例：`ababa` 的 `pi[4] = 3`，`c = 2`，`5 % 2 == 1`，补 1 个字符变成 `ababab`。

### 82.6  统计前缀出现次数

把所有 `pi[i]` 看成一条"失配边" `i+1 → pi[i]`，会形成一棵树（fail 树）。每个前缀 `p[0..i]` 至少出现一次（它自己），它的每次出现都对应某个更长前缀沿 fail 链跳到它。

做法：先令 `cnt[i] = 1`（i ≥ 1），然后按长度从大到小：

```cpp
for (int i = n; i >= 1; i--)
    cnt[pi[i - 1]] += cnt[i];
```

`cnt[len]` 就是长度为 `len` 的前缀在 p 中出现的次数。这个技巧在"统计每个前缀出现次数"和"求公共前后缀"类题目里反复出现。

## 💻 例题

### 例 1  [P3375](https://hydro.ac/p/luogu-P3375) 【模板】KMP

给定文本 `s1` 和模式 `s2`，先输出 `s2` 每个前缀的 pi 值，再每行输出 `s2` 在 `s1` 中所有出现位置的起始下标（1-based）。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s, p;
    cin >> s >> p;
    int n = p.size();
    vector<int> pi(n, 0);
    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];
        while (j > 0 && p[i] != p[j]) j = pi[j - 1];
        if (p[i] == p[j]) j++;
        pi[i] = j;
    }
    for (int i = 0; i < n; i++)
        cout << pi[i] << (i + 1 == n ? '\n' : ' ');
    for (int i = 0, j = 0; i < (int)s.size(); i++) {
        while (j > 0 && s[i] != p[j]) j = pi[j - 1];
        if (s[i] == p[j]) j++;
        if (j == n) {
            cout << i - n + 2 << '\n';
            j = pi[j - 1];
        }
    }
    return 0;
}
```

**解析**：两段代码结构几乎一样，区别是求 pi 时在模式串内部跳，匹配时在主串上走。模板题考的就是下标：pi 数组 0-based，输出位置 1-based。写完先拿 `p = aaaaa` 手动跑一遍，确认输出是 `0 1 2 3 4` 而不是 `0 0 0 0 0`。

### 例 2  [P4391](https://hydro.ac/p/luogu-P4391) Radio Transmission

给一个字符串，求它的最短循环节长度。

**解析**：答案就是 `n - pi[n-1]`。不需要判断整除——题目保证这个字符串是由某个循环节重复若干次得到的，即使最后一段不完整，`n - pi[n-1]` 也仍是最短循环节。

```cpp
int n = p.size();
cout << n - pi[n - 1] << '\n';
```

这类题的关键是记住结论并理解为什么：`pi[n-1]` 是最长的"前缀等于后缀"，把它剪掉，剩下的就是错位后能对上的最小位移，也就是周期。

### 例 3  [P4824](https://hydro.ac/p/luogu-P4824) Censoring

从文本中反复删除模式串，直到删不掉为止。

**解析**：不能每删一次就重新跑 KMP，那样最坏 O(n²)。用栈把"在线匹配"和"删除"合起来：栈里存字符，另一个栈存"处理到该字符时的 j 值"。一旦 `j == m`，弹出 m 个字符，`j` 自然回到删除前的位置。

```cpp
string s, t;
cin >> s >> t;
int m = t.size();
vector<int> pi(m, 0);
for (int i = 1; i < m; i++) {
    int j = pi[i - 1];
    while (j > 0 && t[i] != t[j]) j = pi[j - 1];
    if (t[i] == t[j]) j++;
    pi[i] = j;
}

string st;
vector<int> js;
js.push_back(0);
for (char c : s) {
    int j = js.back();
    while (j > 0 && c != t[j]) j = pi[j - 1];
    if (c == t[j]) j++;
    st.push_back(c);
    js.push_back(j);
    if (j == m) {
        for (int k = 0; k < m; k++) {
            st.pop_back();
            js.pop_back();
        }
    }
}
cout << st << '\n';
```

**解析**：每个字符进栈一次、出栈至多一次，总 O(n + m)。删除后 `js.back()` 正好是删除前那个位置的匹配长度，接着往下比即可。注意 `m = 1` 时也成立。

## ⚠️ 你踩过这些坑吗

- [ ] **坑 1：0/1 下标混用** — `pi[j-1]` 和 `pi[j]` 差一位，调不出来时先把 pi 数组整个打印出来。
- [ ] **坑 2：匹配成功后忘记跳转** — 不写 `j = pi[j-1]`，下一轮访问 `p[m]` 越界，或漏掉重叠匹配。
- [ ] **坑 3：`s.size()` 与 `int` 比较** — `i < s.size()` 中 `i` 是 `int`、右边是 `size_t`，`i` 为负时会转成巨大正数。统一转 `(int)`。
- [ ] **坑 4：空模式串** — `p` 为空时 `p[0]` 越界，读入后先特判。
- [ ] **坑 5：多组数据不重置** — pi 数组按新串长度重新分配，别沿用上一组的。
- [ ] **坑 6：把 pi 当成"最长回文"** — pi 只管前缀等于后缀，和回文无关。

## 🧠 本章小结

```
pi[i] = p[0..i] 的最长相等真前缀/真后缀长度
        也是第 i+1 位失配时的跳转位置

求 pi：
  j = pi[i-1]
  while (j && p[i] != p[j]) j = pi[j-1]
  if (p[i] == p[j]) j++
  pi[i] = j

匹配：
  主串指针只前进；失配 j = pi[j-1]
  成功后输出 i-m+2，再 j = pi[j-1]

最小周期 = n - pi[n-1]
  能整除 n → 最小循环节
  不能整除 → 还需补 c - n%c 个字符

复杂度：O(n + m)，空间 O(m)
```
