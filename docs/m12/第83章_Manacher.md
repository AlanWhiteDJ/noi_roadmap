# 第 83 章  Manacher

---
> 🏗️ **前情回顾**：第 82 章 KMP 用前缀函数复用已算信息。求最长回文子串也有同样的思路：利用已求出的回文，避免重复扩展。
💡 **动机**：回文题最怕 O(n²) 枚举中心，Manacher 让每个位置均摊 O(1)，是字符串里最优雅的均摊分析。

## 🎯 本章目标

学完这一章，你能：

- 用插分隔符把奇偶回文统一处理
- 理解回文半径、最右边界与对称转移
- 在 O(n) 内求最长回文子串
- 用半径数组统计各长度回文的数量

## 📖 故事引入

学校门口有一排灯箱，编号 1 到 n，每个灯箱上写一个字。物业想找出最长的"左右对称"的一段，做成宣传栏。

你从中间往两边看：以每个灯箱为中心，向左右同时扩展，字符相同就继续，不同就停。这方法很直观，可灯箱全是"灯"字时，每个中心都要扩到底，n = 10⁶ 就是 10¹² 次比较。

更亏的是，你刚在位置 500 扩展出一个半径 400 的大回文，走到位置 501 时又把同样的字符重新比了一遍。

Manacher 的想法和 KMP 一样：**右边那个点，其实是你左边某个点的镜像，它的半径你早就知道了。**

## 🧱 知识讲解

### 83.1  暴力：枚举中心

回文分奇偶：`aba` 以 `b` 为中心，`abba` 以两个 `b` 之间为中心。暴力要分别处理：

```cpp
// 奇数长度
for (int c = 0; c < n; c++)
    for (int k = 0; c - k >= 0 && c + k < n && s[c-k] == s[c+k]; k++)
        ans = max(ans, 2 * k + 1);

// 偶数长度
for (int c = 0; c + 1 < n; c++)
    for (int k = 0; c - k >= 0 && c + 1 + k < n && s[c-k] == s[c+1+k]; k++)
        ans = max(ans, 2 * k + 2);
```

两套代码、两个循环，最坏 O(n²)。全相同字符时，每个中心都扩到边界。

### 83.2  奇偶统一：插入分隔符

在原串每两个字符之间插入一个不会出现的字符（常用 `#`），首尾也各加一个：

```
aba   → # a # b # a #
abba  → # a # b # b # a #
```

这样所有回文在新区间里都变成**奇数长度**，中心一定落在某个字符上（原字符或 `#`），一套逻辑就能处理。

长度换算：若以某点为中心、在变换串里的半径是 `p`（包含中心），对应的原串回文长度是 `p - 1`。例如 `#a#b#a#` 以 `b` 为中心，`p = 4`，原串长度 `4 - 1 = 3`，正是 `aba`。

### 83.3  半径与最右边界

```cpp
string t = "#";
for (char c : s) { t += c; t += '#'; }
int n = t.size();
vector<int> p(n, 1);
int mid = 0, r = 0;          // 当前最右回文：中心 mid，右边界 r（开区间）

for (int i = 0; i < n; i++) {
    int k = (i < r) ? min(p[2 * mid - i], r - i) : 1;
    while (i - k >= 0 && i + k < n && t[i - k] == t[i + k]) k++;
    p[i] = k;
    if (i + k > r) { mid = i; r = i + k; }
}
```

变量含义：

- `p[i]`：以 i 为中心、向两侧能扩展的半径（含中心）。回文覆盖 `[i-p[i]+1, i+p[i]-1]`
- `mid`、`r`：目前所有已处理中心里，右端点最靠右的那个回文，其中心和右边界（`r` 是回文右边界的**下一个位置**）

`s[i]` 回文的右端是 `i + p[i] - 1`，所以 `r = i + k` 正好是开区间右端。

### 83.4  对称转移为什么对

设当前最右回文是 `[mid-r, mid+r]`（用开区间理解），`i` 落在里面，即 `i < r`。令 `j = 2*mid - i`，它是 `i` 关于 `mid` 的对称点。

因为大回文左右对称，`j` 周围的字符与 `i` 周围完全一致。于是：

- 若 `p[j]` 没有顶到大回文的左边界，那么 `p[i]` 至少等于 `p[j]`
- 若 `p[j]` 顶出去了，`i` 只能保证继承到 `r - i`，再往外的部分必须实际比较

这就是 `min(p[2*mid-i], r-i)` 的来历。继承之后再用 `while` 尝试扩展——只有真正超出 `r` 的比较才会成功，而 `r` 单调不减，所以总扩展次数是 O(n)。

```
        j        mid        i        r
  ... ---|---|---|---|---|---|---
            大回文范围
```

`i` 越靠右，能继承的信息越多；`r` 每次右移都意味着一次成功的字符比较，而 `r` 最多从 0 走到 2n+1，因此总比较次数线性。

### 83.5  答案与回文计数

最长回文长度：

```cpp
int ans = 0;
for (int i = 0; i < n; i++) ans = max(ans, p[i] - 1);
```

如果题目要统计"每个长度的回文各有多少个"，可以按中心的最长长度做桶。以 i 为中心，最长原串回文长度 `L = p[i]-1`；这个中心对每个与 L 同奇偶、且不超过 L 的长度各贡献一个回文。先把 `cnt[L]` 记成"最长长度恰好为 L 的中心数"，再从大到小做**同奇偶**后缀和：

```cpp
vector<long long> cnt(n + 2, 0);
for (int i = 0; i < n; i++) cnt[p[i] - 1]++;
for (int L = n; L >= 2; L--) cnt[L - 2] += cnt[L];
// 此时 cnt[L] = 长度为 L 的回文子串个数（L ≥ 1）
```

注意奇偶：中心落在原字符上得到奇数长度，落在 `#` 上得到偶数长度。后缀和必须走 `L-2`，跨奇偶累加会把计数算重。

### 83.6  双回文串

有些题要求把串切成 `XY`，其中 `X`、`Y` 都非空且都是回文，求最大总长。做法是正反各跑一次 Manacher（或者一次跑完再对称处理）：

- `L[i]`：以 i 结尾的最长回文长度
- `R[i]`：以 i 开头的最长回文长度
- 答案：`max(L[i] + R[i+1])`

求 `L` 时，对每个中心 i，它覆盖的右端点 `e = i + p[i] - 1`，用 `p[i]-1` 更新 `L[e]`；然后从右往左做一次"收缩传递"：`L[i] = max(L[i], L[i+2] - 2)`，因为去掉两端各一个字符仍是回文。`R` 同理从右往左。

## 💻 例题

### 例 1  [P3805](https://hydro.ac/p/luogu-P3805) 【模板】Manacher

求最长回文子串长度，|s| ≤ 1.1×10⁷。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    string t = "#";
    for (char c : s) { t += c; t += '#'; }
    int n = t.size();
    vector<int> p(n, 1);
    int mid = 0, r = 0, ans = 0;
    for (int i = 0; i < n; i++) {
        int k = (i < r) ? min(p[2 * mid - i], r - i) : 1;
        while (i - k >= 0 && i + k < n && t[i - k] == t[i + k]) k++;
        p[i] = k;
        if (i + k > r) { mid = i; r = i + k; }
        ans = max(ans, k - 1);
    }
    cout << ans << '\n';
    return 0;
}
```

**解析**：|s| 到 10⁷，O(n²) 必死，O(n) 正好。注意内存：变换串约 22 MB，`p` 用 `int` 要 88 MB，合计 110 MB 左右；空间更紧时用 `char` 数组读入并复用缓冲区，别把 `p` 开成 `long long`。

### 例 2  [P1659](https://hydro.ac/p/luogu-P1659) 拉拉队排练

给出长度为 n 的串，把所有回文子串按长度从大到小排列，取前 k 个，求它们长度的乘积模 19930726。若总数不足 k，输出 -1。

**解析**：先用 83.5 的桶统计每个长度的回文个数，再从大到小取。个数可能很大，用快速幂批量乘。

```cpp
const int MOD = 19930726;

long long qpow(long long b, long long e) {
    long long r = 1;
    while (e) {
        if (e & 1) r = r * b % MOD;
        b = b * b % MOD;
        e >>= 1;
    }
    return r;
}

long long ans = 1, need = k;
int m = s.size();
for (int len = m; len >= 1 && need > 0; len--) {
    long long c = cnt[len];
    long long take = min(c, need);
    ans = ans * qpow(len, take) % MOD;
    need -= take;
}
if (need > 0) cout << -1 << '\n';
else cout << ans % MOD << '\n';
```

`cnt` 按变换串长度开，但回文长度最多到原串长度，所以循环上界用 `m = s.size()`。注意本题奇数、偶数长度的回文都要算，`len` 逐 1 递减；`need` 和 `c` 都要用 `long long`。

### 例 3  [P4555](https://hydro.ac/p/luogu-P4555) 最长双回文串

求最长子串，能切成两个非空回文串。

**解析**：按 83.6 求出 `L[i]`（以 i 结尾的最长回文）和 `R[i]`（以 i 开头的最长回文），枚举切点 `i`，答案是 `max(L[i] + R[i+1])`，要求 `L[i] > 0` 且 `R[i+1] > 0`。

一个常见错误是只更新每个中心的端点，忘了做 `L[i] = max(L[i], L[i+2] - 2)` 的传递——中心在 i+1 的长回文，去掉两端后中心在 i+2，长度减 2，这个关系必须补上。

## ⚠️ 你踩过这些坑吗

- [ ] **坑 1：分隔符与原串冲突** — 原串可能含 `#`，改用 `|`、`^` 等题目字符集外的符号。
- [ ] **坑 2：数组开小** — 变换串长度是 `2|s|+1`，`p` 也要开这么大；少开一位就是越界。
- [ ] **坑 3：`p[i]` 初始化为 0** — 半径含中心，最小是 1，初始化 0 会让 `while` 从错误位置开始。
- [ ] **坑 4：右边界写成闭区间** — `r` 是回文右端的下一个位置；`i < r` 与 `r - i` 必须配套，混用会漏扩展。
- [ ] **坑 5：答案忘记减 1** — `max(p)` 是变换串里的半径，原串长度要 `-1`。
- [ ] **坑 6：后缀和跨了奇偶** — 回文长度按奇偶分成两类，累加要写 `cnt[L-2] += cnt[L]`；写成 `cnt[L-1]` 会把奇偶混在一起，计数算重。

## 🧠 本章小结

```
插分隔符：#a#b#a#，奇偶回文统一为奇数长度
p[i]：以 i 为中心的半径（含中心），覆盖 [i-p+1, i+p-1]
原串回文长度 = p[i] - 1，答案 = max(p) - 1

转移：
  i < r 时 p[i] 至少 = min(p[2*mid-i], r-i)
  然后暴力扩展，超出 r 才更新 mid、r

复杂度：r 单调右移，总扩展 O(n)，整体 O(n)
空间：2n+1 的 p 数组

计数：cnt[p[i]-1]++，同奇偶后缀和 cnt[L-2] += cnt[L]
双回文：L[i] 以 i 结尾、R[i] 以 i 开头，枚举切点
```
