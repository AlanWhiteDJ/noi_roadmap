# 第 83 章  Manacher

---
> 🏗️ **前情回顾**：第 82 章 KMP 用前缀函数复用已算信息。求最长回文子串也有同样的思路：利用已求出的回文，避免重复扩展。
💡 **动机**：回文题最怕 O(n²) 枚举中心，Manacher 让每个位置均摊 O(1)，是字符串里最优雅的均摊分析。
## 🎯 本章目标
- 用插分隔符把奇偶回文统一处理
- 理解回文半径、最右边界与对称转移
- 在 O(n) 内求最长回文子串

## 🧱 知识讲解
### 83.1  奇偶统一
在原串每个字符间插入 `#`（首尾也加），如 `aba` 变成 `#a#b#a#`，所有回文都变成奇数长度，半径减一就是原串长度。

### 83.2  半径与最右边界

```cpp
string t = "#";
for (char c : s) { t += c; t += '#'; }
int n = t.size();
vector<int> p(n);
int mid = 0, r = 0;
for (int i = 0; i < n; i++) {
    int k = (i < r) ? min(p[2 * mid - i], r - i) : 1;
    while (i - k >= 0 && i + k < n && t[i - k] == t[i + k]) k++;
    p[i] = k;
    if (i + k > r) { mid = i; r = i + k; }
}
```

`[mid-r, mid+r]` 是当前最右回文。若 `i` 在边界内，`i` 关于 `mid` 的对称点 `2*mid-i` 的半径可直接复用，再尝试向外扩展。

### 83.3  答案与计数
最长回文长度是 `max(p[i]) - 1`。若要统计每个长度的回文出现次数，可对半径做差分：以 i 为中心贡献长度 `1..p[i]-1` 各一次（选讲）。

### 83.4  复杂度
每个位置最多被最右边界向右推一次，总扩展 O(n)，加建串也是 O(n)。

## ⚠️ 常见坑
1. 分隔符与原串字符冲突，改用 `#` 或 `|` 等不会出现的字符
2. 半径数组长度要开 `2|s|+1`；`p[i]` 初始为 1 而不是 0
