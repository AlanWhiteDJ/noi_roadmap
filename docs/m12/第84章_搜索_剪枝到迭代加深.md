# 第 84 章  搜索：剪枝到迭代加深

---
> 🏗️ **前情回顾**：上册第 44 章写过递归，第 45 章用记忆化去掉重复子问题。这一章把"枚举所有可能"变成"聪明地枚举"。
💡 **动机**：搜索是保底分的来源：不会正解时，写对暴力 + 剪枝往往能拿到一半以上的分。

## 🎯 本章目标
- 写出回溯三要素：路径、选择、撤销
- 会用可行性、最优性、搜索顺序三类剪枝
- 掌握双向 BFS、迭代加深与 IDA*

## 🧱 知识讲解
### 84.1  回溯模板
```cpp
void dfs(int dep) {
    if (dep == n) { ans++; return; }
    for (int v : choices) {
        if (!ok(v)) continue;
        path.push_back(v); vis[v] = 1;
        dfs(dep + 1);
        vis[v] = 0; path.pop_back();     // 撤销
    }
}
```
搜索树的大小决定成败：先估算分支数 `b^d`，再决定是否需要剪枝。

### 84.2  三类剪枝
可行性剪枝：当前状态已不可能满足约束，立即返回；最优性剪枝：当前代价已不优于已知答案；搜索顺序：先试可能性大的分支，让最优解更早出现。八皇后用列、两条对角线三个数组 O(1) 判冲突。

### 84.3  双向 BFS
从起点和终点同时扩展，每次扩展队列较小的一侧，相遇即最短。状态数从 `b^d` 降到 `2·b^(d/2)`，八数码常用。

### 84.4  迭代加深与 IDA*
限制深度 `limit` 反复 DFS，空间只有 O(limit)，适合"答案很浅但树很深"。把 limit 换成 f = g + h 的上界就是 IDA*，h 必须可采纳（不高估），如八数码的曼哈顿距离。

## ⚠️ 常见坑
1. 剪枝条件写错会漏解，写完先用小数据对拍暴力
2. 双向 BFS 每次只扩展一层，两端轮流而不是一次扩完
