## 📖 故事引入

数学课上，老师让你把 1 到 9 填进九宫格，要求每行、每列、每个 3×3 宫内数字不重复。你从左上角开始，一格一格试：填 1，不行就填 2……

试到第 30 步发现矛盾，你退回上一格换一个数，再继续。这就是搜索。

可如果每格都从 1 试到 9，总共 9⁸¹ 种填法，宇宙毁灭都算不完。真正下过数独的人不会这样：看到这一行已经有 1、3、7，就只试剩下的六个；看到某个格子只剩一个候选，直接填。

**搜索不是"把所有情况列一遍"，而是"用约束把不可能的分支提前砍掉"。** 砍得越早，能搜的规模越大。

## 🧱 知识讲解

### 84.1  先估搜索树，再写代码

搜索的代价 ≈ 搜索树节点数 × 每个节点的转移代价。树的大小由分支数 b 和深度 d 决定：

| 场景 | 规模 | 节点数 | 可行性 |
|------|------|--------|--------|
| 全排列 | 10! | 3.6×10⁶ | 可以 |
| 子集枚举 | 2²⁰ | 1.0×10⁶ | 可以 |
| 三进制枚举 | 3¹⁵ | 1.4×10⁷ | 勉强 |
| 八皇后 | 8! 量级 | 4×10⁴ | 轻松 |
| 每格 9 种、81 格 | 9⁸¹ | 天文数字 | 必须剪枝 |

### 84.2  回溯三要素

回溯 = 深度优先遍历 + 状态恢复。模板只有三件事：

1. **路径**：当前已经做出的选择
2. **选择**：本层可以尝试哪些分支
3. **撤销**：递归返回后，把状态改回进入前的样子

以全排列为例：

```cpp
int n, path[15];
bool used[15];

void dfs(int dep) {
    if (dep == n) {                    // 路径长度够了，输出
        for (int i = 0; i < n; i++) cout << path[i] << ' ';
        cout << '\n';
        return;
    }
    for (int v = 1; v <= n; v++) {
        if (used[v]) continue;         // 已选过，跳过
        used[v] = true;
        path[dep] = v;
        dfs(dep + 1);
        used[v] = false;               // 撤销，关键
    }
}
```

`used[v] = false` 忘了写，第一次搜到底之后就回不来。

### 84.3  三类剪枝

**可行性剪枝**：当前状态已经不可能满足约束，直接返回。

```cpp
// 凑数：剩下所有数都加上也不够 target
if (sum + remain < target) return;
// 已经超过 target
if (sum > target) return;
```

**最优性剪枝**：当前代价已经不优于已知最优解，继续搜也不会更好。

```cpp
if (cost >= best) return;      // 求最小值时
```

**搜索顺序**：先试更可能成功的分支，让最优解更早出现，好让最优性剪枝更早生效。比如凑数时从大数开始试，八皇后从中间列开始试（某些题有效），最短路搜索先走估价小的方向。

还有一类常被忽略的**等效冗余剪枝**：同一层里，值相同的分支只试第一个。

```cpp
for (int i = start; i < n; i++) {
    if (i > start && a[i] == a[i - 1]) continue;   // 排序后去重
    ...
}
```

### 84.4  八皇后

在 n×n 棋盘放 n 个皇后，任意两个不同行、不同列、不同对角线。逐行放置，只需判断列和两条对角线：

```cpp
int n, cnt, ans[15];
bool col[15], d1[30], d2[30];   // d1: r+c, d2: r-c+n

void dfs(int r) {
    if (r > n) {
        cnt++;
        if (cnt <= 3) {
            for (int i = 1; i <= n; i++)
                cout << ans[i] << " \n"[i == n];
        }
        return;
    }
    for (int c = 1; c <= n; c++) {
        if (col[c] || d1[r + c] || d2[r - c + n]) continue;
        col[c] = d1[r + c] = d2[r - c + n] = true;
        ans[r] = c;
        dfs(r + 1);
        col[c] = d1[r + c] = d2[r - c + n] = false;
    }
}
```

因为列从小到大枚举，第一次搜到的解就是字典序最小的，前三个解直接输出即可。

### 84.5  双向 BFS

单向 BFS 的分支数是 b^d。从起点和终点同时扩展，每次只扩一层、且优先扩队列较小的一侧，相遇时路径长度相加：

```cpp
int bfs(string S, string T) {
    if (S == T) return 0;
    unordered_map<string, int> d1, d2;
    queue<string> q1, q2;
    d1[S] = 0; d2[T] = 0;
    q1.push(S); q2.push(T);
    while (!q1.empty() && !q2.empty()) {
        if (q1.size() > q2.size()) {          // 扩小的一侧
            swap(q1, q2); swap(d1, d2);
        }
        int sz = q1.size();
        while (sz--) {                        // 一次只扩一层
            string u = q1.front(); q1.pop();
            for (string v : nextStates(u)) {
                if (d1.count(v)) continue;
                if (d2.count(v)) return d1[u] + 1 + d2[v];
                d1[v] = d1[u] + 1;
                q1.push(v);
            }
        }
    }
    return -1;
}
```

状态数从 b^d 降到约 2·b^(d/2)，适合八数码这类状态多、答案浅的题。

注意两点：每次只扩展**一层**，不能把整个队列扩完；交换队列时距离表要一起交换。

### 84.6  迭代加深与 IDA*

有些搜索树很深，但答案很浅；用 DFS 会一头扎进死路，用 BFS 又存不下所有状态。迭代加深限制深度 `limit`，从 0 开始逐次加一：

```cpp
bool dfs(int dep, int limit) {
    if (dep > limit) return false;
    if (isGoal()) return true;
    for (auto v : choices) {
        apply(v);
        if (dfs(dep + 1, limit)) return true;
        undo(v);
    }
    return false;
}

for (int lim = 0; lim <= maxDepth; lim++)
    if (dfs(0, lim)) { cout << lim << '\n'; break; }
```

浅层被重复搜的代价是几何级数，总和仍由最后一层主导；空间只有 O(limit)。

把 `limit` 换成 `f = g + h` 的上界，就是 IDA*：

- `g`：已经走的步数
- `h`：到目标的估计代价，必须**可采纳**（绝不高估）
- 若 `g + h > limit`，直接剪掉

八数码常用曼哈顿距离作 h：每个数字当前位置到目标位置的横纵距离之和。它不会高估，因为一次移动只能让一个数字的距离减 1。

## 💻 例题

### 例 1  [P1219](https://hydro.ac/p/luogu-P1219) 八皇后

输出前三个解的列号，再输出解的总数。

**解析**：直接套 84.4 的代码。n ≤ 13，节点数在千万级以内，三个布尔数组把冲突判断压到 O(1)。

```cpp
#include <bits/stdc++.h>
using namespace std;
int n, cnt, ans[15];
bool col[15], d1[30], d2[30];

void dfs(int r) {
    if (r > n) {
        cnt++;
        if (cnt <= 3) {
            for (int i = 1; i <= n; i++)
                cout << ans[i] << " \n"[i == n];
        }
        return;
    }
    for (int c = 1; c <= n; c++) {
        if (col[c] || d1[r + c] || d2[r - c + n]) continue;
        col[c] = d1[r + c] = d2[r - c + n] = true;
        ans[r] = c;
        dfs(r + 1);
        col[c] = d1[r + c] = d2[r - c + n] = false;
    }
}
int main() {
    cin >> n;
    dfs(1);
    cout << cnt << '\n';
    return 0;
}
```

### 例 2  [P1379](https://hydro.ac/p/luogu-P1379) 八数码难题

3×3 棋盘，0 表示空格，每次把 0 与相邻格交换，求从给定状态到 `123456780` 的最少步数。

**解析**：状态用 9 位字符串（或压成 `int`）表示，双向 BFS 或 IDA* 都行。IDA* 写法更省内存：

```cpp
string s, goal = "123456780";
int lim;
int dx[4] = {-1, 1, 0, 0}, dy[4] = {0, 0, -1, 1};

int h(const string &u) {
    int sum = 0;
    for (int i = 0; i < 9; i++) {
        if (u[i] == '0') continue;
        int v = u[i] - '1';
        sum += abs(i / 3 - v / 3) + abs(i % 3 - v % 3);
    }
    return sum;
}

bool dfs(int g, int pre, string &u) {
    int f = g + h(u);
    if (f > lim) return false;
    if (u == goal) return true;
    int pos = u.find('0');
    int x = pos / 3, y = pos % 3;
    for (int d = 0; d < 4; d++) {
        if ((d ^ 1) == pre) continue;        // 不走回头路
        int nx = x + dx[d], ny = y + dy[d];
        if (nx < 0 || nx > 2 || ny < 0 || ny > 2) continue;
        swap(u[pos], u[nx * 3 + ny]);
        if (dfs(g + 1, d, u)) return true;
        swap(u[pos], u[nx * 3 + ny]);
    }
    return false;
}
```

主函数从 `lim = h(s)` 开始递增，找到即输出。`pre` 记录上一步方向，`d ^ 1` 正好是反方向，避免立刻走回去。

### 例 3  [P2324](https://hydro.ac/p/luogu-P2324) 骑士精神

5×5 棋盘上有 12 个白骑士、12 个黑骑士和一个空格，每次按骑士走法交换空格与棋子，求最少步数到目标局面，超过 15 步输出 -1。

**解析**：典型的 IDA*。估价函数取"不在目标位置的骑士数"（空格不计），因为一次移动最多让一个骑士归位，所以不会高估。深度上限固定 15，超过直接 -1。

```cpp
int h() {
    int c = 0;
    for (int i = 0; i < 5; i++)
        for (int j = 0; j < 5; j++)
            if (board[i][j] != goal[i][j] && board[i][j] != '*') c++;
    return c;
}
```

## ⚠️ 你踩过这些坑吗

- [ ] **坑 1：剪枝条件写错漏解** — 剪枝前先用小数据对拍暴力，确认答案一致再加。
- [ ] **坑 2：忘记撤销** — 标记数组、路径数组、累计和都要成对恢复，建议把"做选择 / 撤销"写在一起。
- [ ] **坑 3：双向 BFS 一次扩完整层** — 必须按层扩展，否则距离不是最短路；交换队列时距离表也要换。
- [ ] **坑 4：IDA\* 的 h 高估** — 估价函数一旦超过真实剩余代价，最优解会被剪掉。宁可估小，不可估大。
- [ ] **坑 5：迭代加深上限设太小** — 无解时要能退出，别写成死循环。
- [ ] **坑 6：状态编码冲突** — 八数码压成 `int` 时进制要统一（9 进制或 10 进制），编码规则不一致会把不同状态当成同一个。

## 🧠 本章小结

```
搜索前先估：节点数 ≈ b^d
  n≤10 → n!    n≤20 → 2ⁿ    n≤100 → 别枚举

回溯三要素：路径、选择、撤销

剪枝：
  可行性  已不可能满足约束 → return
  最优性  已不优于 best     → return
  顺序    先试更可能成功的分支
  去重    同层相同值只试一次

八皇后：col / r+c / r-c+n 三个数组

双向 BFS：两端轮流扩一层，扩小的一侧
迭代加深：limit 从 0 递增，空间 O(limit)
IDA*：f = g + h ≤ limit，h 必须可采纳
```
