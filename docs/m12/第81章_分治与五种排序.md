## 🧱 知识讲解
### 81.1  分治三步骤
把原问题划成规模更小的同类子问题，递归求解，再合并子答案。归并排序是标准范本：取中点划分，递归两半，双指针合并。

### 81.2  五种排序怎么选
归并 O(n log n) 稳定、可求逆序对，需 O(n) 空间；快排平均 O(n log n) 不稳定但常数最小；堆排原地、适合只要前 k 大；桶排 O(n+m) 要求值域小；基数排 O(d(n+b)) 按位稳定分配，适合整数。

### 81.3  归并排序与逆序对
```cpp
void mergeSort(int l, int r) {
    if (l >= r) return;
    int mid = (l + r) >> 1;
    mergeSort(l, mid); mergeSort(mid + 1, r);
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r)
        tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++];  // <= 保证稳定
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (int t = l; t <= r; t++) a[t] = tmp[t];
}
```

合并时若右段 `a[j]` 出队，说明它比左段剩下的 `mid-i+1` 个都小，答案加上 `mid-i+1` 即可统计逆序对。

### 81.4  快速选择
只递归包含第 k 小的那一半，期望 O(n)；`nth_element` 就是这个思路，常用于求中位数。

## ⚠️ 常见坑
1. 合并时写成 `<` 会破坏稳定性，相等元素顺序被交换
2. 快排固定取首元素做基准，遇到有序数据退化成 O(n²)
