## 📖 故事引入

校运会结束，体育老师把成绩单交给你：每行是"编号 总分"。要求按总分从高到低排名，**总分相同的，编号小的在前**。

你随手写了个快排，按总分比较。跑完发现同分的两个人顺序乱了——老师要的是稳定排序，而快排不保证这一点。

更麻烦的是，成绩单有三万行。冒泡排序要比较九亿次，跑了一分钟还没结束。

"拆成两半，各自排好，再合起来。"老师说，"合并的时候，遇到相同的分数，先拿左边那份——顺序就保住了。"

这就是归并排序，也是分治最标准的样板：**分、治、合**。

## 🧱 知识讲解

### 81.1  分治三步骤

分治（divide and conquer）把一个问题拆成三个动作：

1. **划分**：把原问题切成若干规模更小的同类子问题
2. **求解**：递归地解决每个子问题；规模足够小时直接给出答案
3. **合并**：把子问题的答案拼成原问题的答案

写分治代码时，先想清楚这三件事，再动手。以归并排序为例：

- 划分：取中点 `mid`，把区间 `[l, r]` 分成 `[l, mid]` 和 `[mid+1, r]`
- 求解：递归排序两半
- 合并：两个有序段用双指针并成一段有序的

### 81.2  归并排序

```cpp
int a[100005], tmp[100005];

void mergeSort(int l, int r) {
    if (l >= r) return;
    int mid = (l + r) >> 1;
    mergeSort(l, mid);
    mergeSort(mid + 1, r);
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];   // <= 保证稳定
        else              tmp[k++] = a[j++];
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r)   tmp[k++] = a[j++];
    for (int t = l; t <= r; t++) a[t] = tmp[t];
}
```

三个细节决定对错：

- `<=` 而不是 `<`：相等时先取左段，稳定性才成立
- 两段剩余的尾巴要单独搬完，不能只写一个 `while`
- 最后必须复制回原数组，否则上一层拿到的还是旧数据

### 81.3  快速排序

快排的思路是"选一个基准，把小的扔左边、大的扔右边，再递归两边"。它不需要合并，划分完就位。

```cpp
void quickSort(int l, int r) {
    if (l >= r) return;
    int x = a[l + rand() % (r - l + 1)];   // 随机基准
    int i = l, lt = l, gt = r;
    while (i <= gt) {
        if (a[i] < x)       swap(a[i++], a[lt++]);
        else if (a[i] > x)  swap(a[i], a[gt--]);
        else                i++;
    }
    quickSort(l, lt - 1);
    quickSort(gt + 1, r);
}
```

这是三路快排：等于基准的一段不用再递归，遇到大量重复元素时优势明显。

快排平均 O(n log n)，常数在几种 O(n log n) 排序里最小；但它是**不稳定**的，最坏情况（基准总取到极值）会退化到 O(n²)。随机基准能把退化的概率压到极低，考场上也可以改用"三数取中"。

### 81.4  堆排序

堆排利用完全二叉树的性质：大根堆的堆顶是最大值，把堆顶换到末尾，再调整剩下的部分。

```cpp
void sift(int i, int n) {          // 1-based，向下调整
    while (true) {
        int l = i << 1, r = l | 1, mx = i;
        if (l <= n && a[l] > a[mx]) mx = l;
        if (r <= n && a[r] > a[mx]) mx = r;
        if (mx == i) break;
        swap(a[i], a[mx]);
        i = mx;
    }
}

void heapSort(int n) {
    for (int i = n / 2; i >= 1; i--) sift(i, n);       // 建堆 O(n)
    for (int i = n; i > 1; i--) {
        swap(a[1], a[i]);                              // 最大值归位
        sift(1, i - 1);
    }
}
```

堆排最坏也是 O(n log n)，额外空间 O(1)，而且不稳定。它的常数比快排大，单独排序时不如快排；但"只要前 k 大"时，维护一个大小为 k 的小根堆非常划算。

### 81.5  桶排序与基数排序

这两种不是比较排序，靠"按值分配"绕过 O(n log n) 下界，代价是要求值域可控。

桶排序：值域 `[0, m]` 时，开 m+1 个桶计数，再按值从小到大输出。

```cpp
int cnt[MAXV + 1];
for (int i = 0; i < n; i++) cnt[a[i]]++;
for (int v = 0; v <= MAXV; v++)
    while (cnt[v]--) cout << v << ' ';
```

复杂度 O(n + m)。m 很大而 n 很小时，开数组反而浪费内存，这时应该用比较排序。

基数排序：从低位到高位，每轮做一次稳定的计数排序。

```cpp
void radixSort(int n) {
    int mx = *max_element(a, a + n);
    for (int exp = 1; mx / exp > 0; exp *= 10) {
        int cnt[10] = {0};
        for (int i = 0; i < n; i++) cnt[a[i] / exp % 10]++;
        for (int i = 1; i < 10; i++) cnt[i] += cnt[i - 1];
        for (int i = n - 1; i >= 0; i--)          // 逆序保证稳定
            tmp[--cnt[a[i] / exp % 10]] = a[i];
        for (int i = 0; i < n; i++) a[i] = tmp[i];
    }
}
```

复杂度 O(d(n + b))，d 是位数、b 是进制。它适合位数不多的非负整数；有负数要先偏移，`exp` 用 `int` 时还要小心溢出。

### 81.6  五种排序怎么选

| 算法 | 平均 | 最坏 | 额外空间 | 稳定 | 适用场景 |
|------|------|------|----------|------|----------|
| 归并排序 | O(n log n) | O(n log n) | O(n) | 是 | 要求稳定、求逆序对、外排序 |
| 快速排序 | O(n log n) | O(n²) | O(log n) | 否 | 通用、常数最小 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 否 | 内存紧、只要前 k 大 |
| 桶排序 | O(n + m) | O(n + m) | O(m) | 是 | 值域小且集中 |
| 基数排序 | O(d(n+b)) | O(d(n+b)) | O(n + b) | 是 | 定长整数、字符串 |

### 81.7  归并排序统计逆序对

逆序对是满足 `i < j` 且 `a[i] > a[j]` 的数对。归并的合并阶段正好能数清：

```cpp
long long cnt = 0;

void mergeSort(int l, int r) {
    if (l >= r) return;
    int mid = (l + r) >> 1;
    mergeSort(l, mid);
    mergeSort(mid + 1, r);
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) {
            tmp[k++] = a[i++];
        } else {
            tmp[k++] = a[j++];
            cnt += mid - i + 1;   // 左段剩下多少个，就有多少个逆序对
        }
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r)   tmp[k++] = a[j++];
    for (int t = l; t <= r; t++) a[t] = tmp[t];
}
```

为什么是 `mid - i + 1`？右段的 `a[j]` 出队时，它比左段从 `i` 到 `mid` 的所有元素都小，而这些元素下标都在它前面，于是每一个都构成一个逆序对。

答案要用 `long long`：n = 5×10⁵ 时逆序对最多约 1.25×10¹¹，`int` 装不下。

### 81.8  快速选择

只要求第 k 小，不需要整体有序。划分之后，看 k 落在哪一段，只递归那一段：

```cpp
int kth(int l, int r, int k) {          // 0-based 第 k 小
    if (l == r) return a[l];
    int x = a[l + rand() % (r - l + 1)];
    int i = l, lt = l, gt = r;
    while (i <= gt) {
        if (a[i] < x)       swap(a[i++], a[lt++]);
        else if (a[i] > x)  swap(a[i], a[gt--]);
        else                i++;
    }
    if (k < lt)      return kth(l, lt - 1, k);
    else if (k > gt) return kth(gt + 1, r, k);
    else             return x;
}
```

递推式 T(n) = T(n/2) + O(n)，展开是 O(n)，这是期望复杂度。`nth_element` 就是它的工业版。

## 💻 例题

### 例 1  [P1177](https://hydro.ac/p/luogu-P1177) 排序

n ≤ 10⁵，把 n 个数从小到大输出。

**解析**：直接 `sort` 即可。想练手可以手写归并、快排、堆排各交一次，对比耗时。注意快排要随机基准或三数取中，否则本题的部分有序数据会让固定基准退化。

### 例 2  [P1908](https://hydro.ac/p/luogu-P1908) 逆序对

n ≤ 5×10⁵，求逆序对个数。

**解析**：套 81.7 的归并模板，`cnt` 开 `long long`。也可以用树状数组：从右往左扫，统计已出现的比当前小的个数，值域大时先离散化。两种做法都是 O(n log n)，归并的常数通常更小。

一个常见错误是把 `cnt += mid - i + 1` 写在 `if` 分支里而不是 `else` 分支。只有在右段元素出队时才产生新的逆序对；左段出队不产生。

### 例 3  [P1309](https://hydro.ac/p/luogu-P1309) 瑞士轮

2n 名选手，每轮按当前分数排序后相邻两人比赛，胜者加 1 分。求 r 轮后的排名。

**解析**：每轮都 `sort` 是 O(r·n log n)，n = 10⁵、r = 50 时约 8.5×10⁷，勉强但危险。观察性质：本轮结束后，**胜者组的相对顺序不变，败者组的相对顺序也不变**——因为所有人同加 1 分或不变，原来分高的仍然不低。

于是每轮把胜者、败者分别按原顺序收集，再用一次归并合并两个有序段，O(n)。总复杂度 O(n log n + r·n)。

```cpp
// 每轮：win[]、lose[] 已按原排名有序
int i = 1, j = 1, k = 1;
while (i <= n && j <= n) {
    if (score[win[i]] > score[lose[j]] ||
       (score[win[i]] == score[lose[j]] && win[i] < lose[j]))
        order[k++] = win[i++];
    else
        order[k++] = lose[j++];
}
while (i <= n) order[k++] = win[i++];
while (j <= n) order[k++] = lose[j++];
```

这里"同分编号小的在前"正是稳定性的体现：合并时左边的胜者组优先。

## ⚠️ 你踩过这些坑吗

- [ ] **坑 1：合并时写成 `<`** — 相等元素被交换，稳定性被破坏，P1309 这类题会直接 WA。
- [ ] **坑 2：快排固定取首元素** — 遇到有序或逆序数据退化成 O(n²)，n = 10⁵ 时必然 TLE。
- [ ] **坑 3：忘记把 `tmp` 复制回 `a`** — 上层合并拿到旧数据，结果看起来"只排好了一部分"。
- [ ] **坑 4：逆序对用 `int`** — n = 5×10⁵ 时答案可达 1.25×10¹¹，必须 `long long`。
- [ ] **坑 5：桶排值域开太大** — 值到 10⁹ 时开数组直接 MLE，应该改用比较排序或离散化。
- [ ] **坑 6：基数排遇到负数** — 取模得到负下标，数组越界；先整体加偏移量变成非负。

## 🧠 本章小结

```
分治三步：划分 → 递归求解 → 合并

归并：稳定，O(n) 空间，合并时 <= 保稳定
      右段出队时 cnt += mid - i + 1  → 逆序对
快排：不稳定，常数最小，随机基准防退化
堆排：不稳定，O(1) 空间，适合前 k 大
桶排：O(n+m)，值域必须小
基数：O(d(n+b))，按位稳定分配

选择：
  要稳定 / 求逆序对 → 归并
  通用最快         → 快排
  内存紧           → 堆排
  值域小           → 桶排
```
