## 📖 故事引入

桌上两堆石子，一堆 5 颗，一堆 7 颗。规则很简单：两人轮流从任意一堆里取走任意多颗，至少取一颗，取走最后一颗的人获胜。

小华先手。他盯着两堆石子，试了几种取法：从 5 颗里拿 2 颗，剩 3 和 7；对手立刻把 7 拿到 3，变成 3 和 3。小华拿一堆，对手照做，最后小华无子可取。

「怎么拿都输？」他不服气，把所有局面列在纸上。很快他发现一个奇怪的现象：**两堆一样多的时候，后手只要模仿先手，就一定能赢。** 而 5 和 7 不一样多，先手把 7 拿到 5，就能把局面交给对手去输。

再往下推，他发现胜负根本不看出具体怎么拿，而看两堆数量的「异或」：`5 ^ 7 = 2`，非 0，先手必胜；`5 ^ 5 = 0`，后手必胜。

这就是博弈 DP 的第一个惊喜：**胜负往往由一个极简的不变量决定。**

## 🧱 知识讲解

### 91.1  必胜态与必败态

把一个局面看成一个结点，一次合法操作看成一条有向边。只要游戏一定结束（没有环），就得到一个 DAG。定义：

- **必败态**：无论怎么走，都会把局面交给对手的必胜态；没有合法操作的局面也是必败态。
- **必胜态**：存在一种走法，能把局面交给对手的必败态。

换成递推：

```
必败 = 所有后继都是必胜（或没有后继）
必胜 = 存在一个后继是必败
```

记忆化搜索：

```cpp
bool vis[N], win[N];

bool dfs(int S) {
    if (vis[S]) return win[S];
    vis[S] = true;
    for (int T : nxt[S]) {
        if (!dfs(T)) {          // 后继里有一个必败
            win[S] = true;
            return true;
        }
    }
    win[S] = false;             // 所有后继都必胜
    return false;
}
```

> ⚠️ 递归前提是游戏无环。如果存在「走一步又回到原局面」的循环，这套定义会失效，需要另外处理平局。

### 91.2  Nim 游戏：异或判据

`n` 堆石子，每次从一堆取任意多颗，取走最后一颗者胜。结论：

```
异或和 = a[1] ^ a[2] ^ … ^ a[n]
异或和非 0 → 先手必胜；异或和为 0 → 先手必败
```

```cpp
int x = 0;
for (int i = 1; i <= n; ++i) x ^= a[i];
cout << (x ? "Yes" : "No") << endl;
```

为什么？设异或和为 `x`：

- 若 `x = 0`，任何一次操作都会让某一堆变小，异或和必然变成非 0（否则新旧异或和都为 0，矛盾）。
- 若 `x ≠ 0`，设 `x` 的最高位是第 `k` 位，必有一堆 `a[i]` 的第 `k` 位为 1。把 `a[i]` 改成 `a[i] ^ x`，这个数一定比 `a[i]` 小，且操作后异或和变成 0。

所以「非 0 只能走到 0，0 只能走到非 0」，终局（全 0）异或和为 0，是必败态。归纳即得结论。

### 91.3  SG 函数：把游戏压成一个数

不是所有游戏都能直接异或石子数。SG 函数给出通用做法：

```
sg(S) = mex{ sg(T) : T 是 S 的合法后继 }
mex 是最小的不在集合中的非负整数
```

终局没有后继，`sg = 0`。多个**互相独立**的游戏组合时：

```
总局面必胜 ⇔ sg(G1) ^ sg(G2) ^ … ^ sg(Gk) ≠ 0
```

SG 计算的记忆化写法：

```cpp
int sg(int x) {
    if (f[x] != -1) return f[x];
    bool seen[1005] = {false};
    for (int k : moves)
        if (x >= k) seen[sg(x - k)] = true;
    int g = 0;
    while (seen[g]) ++g;        // mex
    return f[x] = g;
}
```

> 💡 `mex` 从 0 开始试，遇到第一个没出现过的数就停。后继的 SG 可能重复，用 `bool` 数组比 `set` 更快。

### 91.4  博弈 + 区间 DP

取两端型游戏：一排数，两人轮流从两端取一个数，都希望自己的总和最大。设 `f[l][r]` 表示「区间 `[l,r]` 上，先手最多能比后手多拿多少」：

```
f[l][r] = max( a[l] - f[l+1][r], a[r] - f[l][r-1] )
f[i][i] = a[i]
```

拿走左端后，对手在 `[l+1,r]` 上先手，他能领先 `f[l+1][r]`，所以当前玩家的净胜是 `a[l] - f[l+1][r]`。右端同理。

```cpp
for (int len = 2; len <= n; ++len)
    for (int l = 1, r = l + len - 1; r <= n; ++l, ++r)
        f[l][r] = max(a[l] - f[l + 1][r], a[r] - f[l][r - 1]);
```

`f[1][n]` 是先手与后手的得分差。若总和为 `S`，先手得分就是 `(S + f[1][n]) / 2`。

### 91.5  树上博弈

树上删点、移动棋子一类游戏，通常把每个子树看成一个子游戏，后序合并儿子的 SG，再对兄弟子树取异或。套路和树型 DP 一致：**局面是状态，走法是转移，独立子游戏用异或合并。**

## 💻 例题与解析

### 例 1  Nim 游戏（P2197）

**题意**：`T` 组数据，每组 `n` 堆石子，两人轮流从一堆取任意多颗，取走最后一颗者胜。判断先手是否必胜。

**思路**：求异或和，非 0 输出 `Yes`，否则 `No`。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        int x = 0;
        for (int i = 1; i <= n; ++i) {
            int a;
            cin >> a;
            x ^= a;
        }
        cout << (x ? "Yes" : "No") << endl;
    }
    return 0;
}
```

**复杂度**：每组 `O(n)`，空间 `O(1)`。

**易错点**：只判断「石子总数是否为奇数」是常见误解。胜负看异或和，不看总和。

### 例 2  SG 函数入门（取 1、3、4 颗）

**题意**：一堆 `n` 颗石子，每次可以取 1、3 或 4 颗，不能取者输。多组询问，判断先手胜负。

**思路**：`sg(0) = 0`，`sg(x) = mex{ sg(x-1), sg(x-3), sg(x-4) }`。单堆游戏，`sg(n) ≠ 0` 先手胜。

```cpp
#include <bits/stdc++.h>
using namespace std;

int f[1005];

int sg(int x) {
    if (f[x] != -1) return f[x];
    bool seen[1005] = {false};
    int mv[3] = {1, 3, 4};
    for (int k : mv)
        if (x >= k) seen[sg(x - k)] = true;
    int g = 0;
    while (seen[g]) ++g;
    return f[x] = g;
}

int main() {
    memset(f, -1, sizeof f);
    f[0] = 0;
    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        cout << (sg(n) ? "Yes" : "No") << endl;
    }
    return 0;
}
```

**复杂度**：每个状态 `O(1)` 个后继，预处理 `O(maxn)`。

**易错点**：`f[0]` 必须手动设为 0；`memset(f, -1, ...)` 对 `int` 数组得到的是 `-1`，可以安全表示「未计算」。

### 例 3  两端取数

**题意**：`n` 个数排成一排，两人轮流从两端取一个数，都采取最优策略。求先手最终得分。

**思路**：`f[l][r]` 表示区间 `[l,r]` 上先手相对后手的最大净胜分，按长度递推。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, a[1005], f[1005][1005], pre[1005];

int main() {
    cin >> n;
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
        pre[i] = pre[i - 1] + a[i];
        f[i][i] = a[i];
    }

    for (int len = 2; len <= n; ++len)
        for (int l = 1, r = l + len - 1; r <= n; ++l, ++r)
            f[l][r] = max(a[l] - f[l + 1][r], a[r] - f[l][r - 1]);

    int sum = pre[n];
    cout << (sum + f[1][n]) / 2 << endl;
    return 0;
}
```

**复杂度**：时间 `O(n²)`，空间 `O(n²)`。

**易错点**：`f` 存的是「净胜分」，不是「先手得分」。最后要换算，不能直接输出 `f[1][n]`。

## ⚠️ 常见错误

- **必胜 / 必败定义写反**：把「所有后继必胜」记成必胜，答案整体取反。
- **多堆游戏忘取异或**：把各堆 SG 相加，而不是异或。
- **`mex` 从 1 开始**：SG 可能为 0，必须从 0 开始找。
- **后继状态重复**：同一局面被多次枚举，`mex` 结果不受影响，但复杂度会变差。
- **区间 DP 边界漏掉 `f[i][i]`**：长度为 1 的区间没有初始化，后面全错。
- **游戏有环**：直接记忆化会死循环，需要先确认局面图是 DAG。

## 🧠 本章小结

```
胜负递推：
  必败 = 所有后继必胜（或没有后继）
  必胜 = 存在后继必败

Nim：
  异或和非 0 → 先手胜
  非 0 可以一步走到 0；0 只能走到非 0

SG：
  sg(S) = mex{ sg(T) }
  多游戏组合：异或

区间博弈：
  f[l][r] = max(a[l] - f[l+1][r], a[r] - f[l][r-1])
  f 是净胜分，不是总分
```
