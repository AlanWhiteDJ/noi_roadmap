# 第 91 章  博弈 DP（选学）
> 🏗️ **前情回顾**：第 67 章你在 DAG 上判过「能不能走到终点」。博弈的胜负递推本质相同——只是每一步换人走。

## 🎯 本章目标
- 写对必胜 / 必败态的递推方向，理解 Nim 的异或判据与 SG 函数
- 把博弈嵌进区间 / 树形 DP

## 🎬 动机
两堆石子，你先手。随便抓一把可能立刻输，也可能逼得对手无路可走。胜负不靠算尽所有走法，而靠一条性质：**能走到必败态的就是必胜态**。

## 🧱 知识讲解
### 91.1  必胜态与必败态
定义：**所有后继都是必胜态**（或没有后继）的是必败态；**存在后继是必败态**的是必胜态。

```cpp
// 从终局倒推
for (int T : nxt[S])
  if (!win[T]) { win[S] = true; break; }
```

口诀：必败 = 所有后继必胜；必胜 = 存在后继必败。
### 91.2  Nim 与 SG
n 堆石子，每次从一堆取任意多个：**异或和非 0 先手必胜**。

```cpp
int x = 0;
for (int i = 0; i < n; i++) x ^= a[i];
puts(x ? "Yes" : "No");
```

SG 函数把每堆独立游戏压成一个数，多堆组合时同样取异或：`sg(G) = sg(G1) ^ sg(G2) ^ …`。
### 91.3  博弈 + 区间 / 树形
只能取两端 → `f[l][r]` 记录区间剩余时的胜负；树上删点 → 后序合并儿子的 SG。共同点：**局面是状态，走法是转移**。
