## 🧱 知识讲解

### 89.1  位运算当集合用

把一个 `n` 位二进制数看成 `{0, 1, …, n-1}` 的子集：第 `i` 位是 1，表示元素 `i` 在集合里。

| 操作 | 写法 | 含义 |
|------|------|------|
| 判断 | `(S >> i) & 1` | 元素 `i` 是否在 `S` 中 |
| 加入 | `S \| (1 << i)` | 把 `i` 放进集合 |
| 删除 | `S & ~(1 << i)` | 把 `i` 移出集合 |
| 取反 | `S ^ (1 << i)` | 切换 `i` 的存在状态 |
| 最低位 | `S & -S` | 取出最低的 1 |
| 位数 | `__builtin_popcount(S)` | 集合大小 |

枚举 `S` 的所有子集：

```cpp
for (int T = S; T; T = (T - 1) & S) {
    // T 依次取 S, S 去掉一个元素, ...，不含 0
}
```

这个写法的原理是「每次把最低的 1 减掉，再与 `S` 相交」，保证 `T` 始终是 `S` 的子集，且不重不漏。需要空集时，循环结束后单独处理 `T = 0`。

### 89.2  规模边界：`2ⁿ` 到底能多大

状压的复杂度通常带着 `2ⁿ`，先记住几个数：

| `n` | `2ⁿ` | 感受 |
|-----|------|------|
| 15 | 32,768 | 很轻松 |
| 18 | 262,144 | 轻松 |
| 20 | 1,048,576 | 约 `10⁶`，可做 |
| 22 | 4,194,304 | 要小心常数 |
| 25 | 33,554,432 | 多半要换思路 |

判断能不能做，不只看 `2ⁿ`，还要乘上转移代价：

- `O(2ⁿ · n)`：`n = 20` 时约 `2×10⁷`，可以。
- `O(2ⁿ · n²)`：`n = 20` 时约 `4×10⁸`，很悬。
- `O(3ⁿ)` 的子集枚举：`n = 15` 时约 `1.4×10⁷`，`n = 20` 就爆了。

> ⚠️ `1 << n` 是 `int` 运算。`n` 接近 31 时会溢出成负数，此时要写 `1LL << n`。状压题里数组下标也常因此出错。

### 89.3  棋盘状压：一行一个状态

[P1879 Corn Fields](https://hydro.ac/p/luogu-P1879) 是标准模型：`n × m` 的玉米地，有些格子贫瘠不能种，相邻格子不能同时种，求方案数。

把每一行的种植情况压成一个 `m` 位整数 `S`。需要满足三类限制：

1. **行内限制**：不能有左右相邻的 1，即 `S & (S << 1)` 为 0。
2. **行间限制**：上一行的状态 `T` 与本行 `S` 不能在同一列都为 1，即 `S & T` 为 0。
3. **地形限制**：贫瘠格不能种。把贫瘠格压成 `bad[i]`，要求 `S & bad[i]` 为 0。

先预处理出所有行内合法的状态：

```cpp
vector<int> st;
for (int S = 0; S < (1 << m); ++S)
    if (!(S & (S << 1))) st.push_back(S);
```

这样 `2^m` 个状态里通常只剩几百个，后续枚举快一个数量级。

### 89.4  多一维：放置个数

[P1896 互不侵犯](https://hydro.ac/p/luogu-P1896) 要在 `n × n` 棋盘上放 `k` 个国王，国王周围八个格子不能有另一个国王。

状态变成 `f[i][S][j]`：前 `i` 行、第 `i` 行状态为 `S`、已经放了 `j` 个国王的方案数。行间要判三条：

```cpp
if (S & T) continue;              // 正上方
if (S & (T << 1)) continue;       // 左上方
if ((S << 1) & T) continue;       // 右上方
```

行内仍用 `S & (S << 1)` 判左右相邻。每个状态的国王数 `cnt[S]` 可以预处理。

### 89.5  集合 DP：旅行商

`f[S][i]` 表示「已经访问过集合 `S`，当前停在 `i`」的最小代价。枚举下一个要去的点 `j`：

```cpp
for (int j = 0; j < n; ++j)
    if (!(S >> j & 1))
        f[S | (1 << j)][j] = min(f[S | (1 << j)][j], f[S][i] + d[i][j]);
```

答案是 `min f[(1<<n)-1][i]`。复杂度 `O(2ⁿ · n²)`，`n ≤ 15` 很稳，`n = 20` 要压缩常数。

## 💻 例题与解析

### 例 1  玉米田（P1879）

**题意**：`n × m` 的网格，`1` 表示可以种，`0` 表示贫瘠。相邻格子不能同时种，求种植方案数对 `10⁸` 取模。

**思路**：预处理行内合法状态，逐行转移，用 `bad[i]` 排除贫瘠格。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MOD = 100000000;
int n, m, bad[13], f[13][1 << 12];
vector<int> st;

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; ++i)
        for (int j = 0; j < m; ++j) {
            int x;
            cin >> x;
            if (!x) bad[i] |= 1 << j;
        }

    for (int S = 0; S < (1 << m); ++S)
        if (!(S & (S << 1))) st.push_back(S);

    f[0][0] = 1;
    for (int i = 1; i <= n; ++i)
        for (int S : st) {
            if (S & bad[i]) continue;
            for (int T : st) {
                if (T & bad[i - 1]) continue;
                if (S & T) continue;
                f[i][S] = (f[i][S] + f[i - 1][T]) % MOD;
            }
        }

    int ans = 0;
    for (int S : st) ans = (ans + f[n][S]) % MOD;
    cout << ans << endl;
    return 0;
}
```

**复杂度**：设合法状态数为 `K`，时间 `O(nK²)`，空间 `O(nK)`。`m ≤ 12` 时 `K` 最多几百。

**易错点**：`bad[0] = 0`，所以第一行的 `T = 0` 合法；如果忘记初始化 `f[0][0] = 1`，整张表全为 0。

### 例 2  互不侵犯（P1896）

**题意**：`n × n` 的棋盘放 `k` 个国王，任意两个国王不能相邻（包括斜对角），求方案数。

**思路**：`f[i][S][j]`，预处理 `cnt[S]`，行间判三条冲突。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, k;
int cnt[1 << 9];
long long f[10][1 << 9][82];
vector<int> st;

int main() {
    cin >> n >> k;
    for (int S = 0; S < (1 << n); ++S)
        if (!(S & (S << 1))) {
            st.push_back(S);
            cnt[S] = __builtin_popcount(S);
        }

    f[0][0][0] = 1;
    for (int i = 1; i <= n; ++i)
        for (int S : st) {
            int cs = cnt[S];
            for (int T : st) {
                if (S & T) continue;
                if (S & (T << 1)) continue;
                if ((S << 1) & T) continue;
                for (int j = cs; j <= k; ++j)
                    f[i][S][j] += f[i - 1][T][j - cs];
            }
        }

    long long ans = 0;
    for (int S : st) ans += f[n][S][k];
    cout << ans << endl;
    return 0;
}
```

**复杂度**：`O(n · K² · k)`，`K` 是行内合法状态数（`n = 9` 时为 89）。

**易错点**：三个冲突条件少写任何一个都会多算。尤其斜对角，最容易被忽略。

### 例 3  吃奶酪（P1433）

**题意**：平面上有 `n` 个奶酪（`n ≤ 15`），从原点出发，求访问完所有奶酪的最短距离。

**思路**：`f[S][i]` 表示已访问集合 `S`、当前在第 `i` 个奶酪的最短距离，枚举下一个奶酪。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
double x[16], y[16], d[16][16], f[1 << 15][15];

double dist(int i, int j) {
    double dx = x[i] - x[j], dy = y[i] - y[j];
    return sqrt(dx * dx + dy * dy);
}

int main() {
    cin >> n;
    for (int i = 0; i < n; ++i) cin >> x[i] >> y[i];

    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j)
            d[i][j] = dist(i, j);

    for (int S = 0; S < (1 << n); ++S)
        for (int i = 0; i < n; ++i)
            f[S][i] = 1e18;

    for (int i = 0; i < n; ++i)
        f[1 << i][i] = sqrt(x[i] * x[i] + y[i] * y[i]);

    for (int S = 1; S < (1 << n); ++S)
        for (int i = 0; i < n; ++i) {
            if (!(S >> i & 1)) continue;
            if (f[S][i] > 1e17) continue;
            for (int j = 0; j < n; ++j) {
                if (S >> j & 1) continue;
                int T = S | (1 << j);
                f[T][j] = min(f[T][j], f[S][i] + d[i][j]);
            }
        }

    double ans = 1e18;
    for (int i = 0; i < n; ++i) ans = min(ans, f[(1 << n) - 1][i]);
    cout << fixed << setprecision(2) << ans << endl;
    return 0;
}
```

**复杂度**：时间 `O(2ⁿ · n²)`，空间 `O(2ⁿ · n)`。`n = 15` 时约 `7×10⁶` 次转移。

**易错点**：起点是原点而不是 0 号奶酪；初始化要单独算原点到每个奶酪的距离。

## ⚠️ 常见错误

- **忘记行内检查**：只判了上下冲突，左右相邻仍被算进方案。
- **斜对角漏判**：国王题只写 `S & T`，少算两个方向。
- **不预处理合法状态**：在 `2^m` 里枚举大量废状态，时间翻几倍。
- **`1 << n` 溢出**：`n` 接近 31 时用 `1LL << n`，数组下标也要用 `long long` 算。
- **答案取错**：棋盘题要对最后一行的所有状态求和，不是只取 `f[n][0]`。
- **`f` 没清成 INF**：集合 DP 里未访问状态被当成 0 距离，答案偏小。

## 🧠 本章小结

```
状压 = 用二进制整数表示集合

常用操作：
  (S >> i) & 1        判断
  S | (1 << i)        加入
  S & ~(1 << i)       删除
  S & -S              最低位
  for (T = S; T; T = (T-1) & S)   枚举子集

规模：2^20 ≈ 10^6 可做，2^25 ≈ 3×10^7 要谨慎

棋盘：
  行内 S & (S << 1)
  行间 S & T（斜对角再加两条）
  地形 S & bad[i]

集合 DP：
  f[S][i]，枚举未访问的 j 转移
```
