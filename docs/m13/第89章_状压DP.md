# 第 89 章  状压 DP
> 🏗️ **前情回顾**：第 58 章你用 `bitset` 压过 01 背包的可行性。当「选了哪些」本身就是状态时，一个二进制整数就能顶一整个集合。

## 🎯 本章目标
- 用二进制表示集合，掌握与/或/异或与子集枚举
- 写棋盘状压：先筛行内合法再判行间冲突；估清 2^n 的规模边界

## 🎬 动机
十个人排座位，谁跟谁不能相邻。若把「这一排坐了谁」写成十位二进制，一行状态只有 1024 种，冲突判定退化成一条位运算——这就是状压的全部魔法。

## 🧱 知识讲解
### 89.1  位运算当集合用
```cpp
if (S >> i & 1)                     // i 在集合里
T = S | (1 << i);                   // 加入 i
T = S & ~(1 << i);                  // 删除 i
for (int T = S; T; T = (T-1) & S)   // 枚举 S 的非空子集
```

`n <= 20` 时 `2^n ≈ 10^6` 可做；`n = 25` 就是 3×10^7，多半要换思路。
### 89.2  棋盘状压：P1879 Corn Fields
一行一个二进制状态。**行内**不能有相邻 1：`S & (S<<1)` 为 0；**行间**不能上下相邻：`S & T` 为 0。

```cpp
for (int S = 0; S < (1 << m); S++)
  if (!(S & (S << 1)) && (S & bad) == 0) ok[S] = 1;   // bad = 贫瘠格
```
### 89.3  集合 DP：TSP
`f[S][i]` 表示已访问集合 S、当前停在 i 的最短路，枚举下一个点 j：

```cpp
f[S | 1 << j][j] = min(f[S | 1 << j][j], f[S][i] + d[i][j]);
```

## 💻 例题
**例 1**：[P1879](https://hydro.ac/p/luogu-P1879)——预处理合法行状态，逐行转移，答案为最后一行所有状态之和。

**例 2**：[P1896 互不侵犯](https://hydro.ac/p/luogu-P1896)——多一个「已放国王数」维度 `f[i][S][k]`；行内判 `S&(S<<1)`，行间判 `S&T`、`S&(T<<1)`、`(S<<1)&T`。

## ⚠️ 常见坑
1. 没预处理合法状态，2^n 里大半是废的
2. 行间只判了正上方，漏了斜对角
3. `1 << n` 用 int 溢出（n 接近 31 时用 `1LL << n`）
