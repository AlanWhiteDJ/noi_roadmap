## 🧱 知识讲解

### 90.1  先做一次「拆式子」

拿到一个 `O(n²)` 的转移，先把它拆成两类项：

- 只和 `i` 有关的项；
- 只和 `j` 有关的项；
- 同时含 `i`、`j` 的交叉项。

如果交叉项能消掉或被分离，通常就能优化。例如：

```
f[i] = min_j ( f[j] + pre[i] - pre[j] )
     = pre[i] + min_j ( f[j] - pre[j] )
```

`pre[i]` 对每个 `j` 都一样，提到 `min` 外面；括号里只剩 `j`。于是只要维护「`f[j] - pre[j]` 的最小值」，转移就是 `O(1)`。

### 90.2  前缀和与前缀最值

区间求和是最常见的「重复计算」。先做前缀和：

```cpp
for (int i = 1; i <= n; ++i) pre[i] = pre[i - 1] + a[i];
// sum(l..r) = pre[r] - pre[l-1]
```

如果转移里有 `min_{j<i} pre[j]`，就再维护前缀最小值：

```cpp
int minPre = 0;          // min pre[0..i-1]
int ans = -INF;
for (int i = 1; i <= n; ++i) {
    pre[i] = pre[i - 1] + a[i];
    ans = max(ans, pre[i] - minPre);
    minPre = min(minPre, pre[i]);
}
```

这段代码求最大子段和，复杂度从 `O(n²)` 降到 `O(n)`。

> 💡 前缀和优化的本质是「用空间换时间」：把每次都要重新累加的东西提前存好。二维前缀和同理，矩形求和也能 `O(1)`。

### 90.3  单调队列优化：窗口最值

当转移是

```
f[i] = max_{i-R ≤ j ≤ i-L} ( f[j] ) + a[i]
```

内层是一个长度固定的滑动窗口。用单调队列维护窗口内的最大值，均摊 `O(1)`：

```cpp
deque<int> q;                 // 存下标，对应值单调递减
for (int i = 1; i <= n; ++i) {
    while (!q.empty() && q.front() < i - R) q.pop_front();  // 过期
    if (i - L >= 0) {
        while (!q.empty() && f[q.back()] <= f[i - L]) q.pop_back();
        q.push_back(i - L);
    }
    if (!q.empty()) f[i] = f[q.front()] + a[i];
}
```

三个动作的顺序很重要：

1. **先淘汰过期**：队头下标小于 `i-R` 的已经不在窗口里。
2. **再插入新元素**：插入前把队尾所有不优于它的元素弹掉，保持单调。
3. **最后取队头**：队头就是当前窗口的最值。

### 90.4  单调队列优化多重背包

[P1776](https://hydro.ac/p/luogu-P1776) 的朴素多重背包是 `O(V·Σs)`。按重量 `w` 的余数分组后，同一组内的容量是：

```
v = r, r+w, r+2w, ...
```

设 `k` 是组内下标，`g` 是上一层（前 `i-1` 件）的 DP 值，则用 `t` 件第 `i` 种物品的收益是：

```
g[r + (k-t)w] + t·c
= ( g[r + (k-t)w] - (k-t)c ) + k·c
```

括号里只和 `k-t` 有关，而 `k-t` 落在窗口 `[k-s, k]` 内。于是把 `key(t) = g[r+tw] - t·c` 放进单调队列，取窗口最大值即可。

### 90.5  决策单调性与斜率优化（选讲）

**决策单调性**：如果最优断点 `opt[i]` 随 `i` 不减，可以用分治计算：

```cpp
void solve(int l, int r, int optL, int optR) {
    if (l > r) return;
    int mid = (l + r) >> 1, opt = -1;
    for (int j = optL; j <= min(mid - 1, optR); ++j)
        if (f[j] + w(j, mid) < g[mid]) {
            g[mid] = f[j] + w(j, mid);
            opt = j;
        }
    solve(l, mid - 1, optL, opt);
    solve(mid + 1, r, opt, optR);
}
```

复杂度从 `O(n²)` 降到 `O(n log n)`。

**斜率优化**：若转移能化成

```
f[i] = min_j ( a[j]·x[i] + b[j] ) + c[i]
```

把每个 `j` 看成一条直线 `y = a[j]·x + b[j]`，查询 `x[i]` 处的最小值。用下凸壳 + 单调队列维护，均摊 `O(1)`。判据是：**拆完式子后，交叉项能写成「一个只含 j 的系数 × 一个只含 i 的变量」**。

## 💻 例题与解析

### 例 1  宝物筛选（P1776）

**题意**：`n` 种物品，容量 `V`。第 `i` 种重量 `w`、价值 `c`、数量 `s`，求最大价值。

**思路**：按余数分组，单调队列维护 `key(t) = g[r+tw] - t·c` 的窗口最大值。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 40005;
int n, V, f[N], g[N];

int main() {
    cin >> n >> V;
    for (int i = 1; i <= n; ++i) {
        int w, c, s;
        cin >> w >> c >> s;
        memcpy(g, f, sizeof f);          // g 是上一层，不能被改写

        for (int r = 0; r < w && r <= V; ++r) {
            deque<int> q;
            for (int k = 0; r + k * w <= V; ++k) {
                int v = r + k * w;
                int key = g[v] - k * c;

                while (!q.empty() &&
                       g[r + q.back() * w] - q.back() * c <= key)
                    q.pop_back();
                q.push_back(k);

                while (q.front() < k - s) q.pop_front();

                f[v] = max(f[v], g[r + q.front() * w] + (k - q.front()) * c);
            }
        }
    }
    cout << f[V] << endl;
    return 0;
}
```

**复杂度**：每种物品扫一遍容量，时间 `O(nV)`，空间 `O(V)`。

**易错点**：

1. `key` 必须读 `g`（上一层），不能读正在被改写的 `f`。
2. 过期条件是 `q.front() < k - s`，窗口里最多允许 `s` 件。
3. `r + k*w` 的上界是 `V`，不是 `V - r`。

### 例 2  瑰丽华尔兹（P2254）

**题意**：`n × m` 的舞厅，有些格子有家具不能经过。钢琴在每个时间段向一个方向倾斜，每段时间可以滑行若干格，求最多滑行距离。

**思路**：按时间段做 DP。设 `f[i][j]` 为当前时段结束时停在 `(i,j)` 的最大滑行距离。一个时段内只能沿同一方向移动，转移形如：

```
f[i][j] = max_{0 ≤ k ≤ len} ( g[i - k·dx][j - k·dy] + k )
```

其中 `g` 是上一时段结束时的值，`len` 是该时段长度。把 `k` 换成位置坐标后，`g[pos] - 距离(pos, 当前)` 就是一个滑动窗口最大值，按行或按列用单调队列扫一遍即可。

**易错点**：方向不同，扫描的行列和顺序都不同；家具格要直接跳过，不能作为转移起点。

### 例 3  最大子段和（前缀最值）

**题意**：给一个长度为 `n` 的整数序列，求连续子段的最大和。

**思路**：设 `pre[i]` 为前缀和，以 `i` 结尾的最大子段和是 `pre[i] - min_{0≤j<i} pre[j]`。边走边维护最小前缀。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long pre = 0, minPre = 0, ans = LLONG_MIN;
    for (int i = 1; i <= n; ++i) {
        long long x;
        cin >> x;
        pre += x;
        ans = max(ans, pre - minPre);
        minPre = min(minPre, pre);
    }
    cout << ans << endl;
    return 0;
}
```

**复杂度**：时间 `O(n)`，空间 `O(1)`。

**易错点**：`minPre` 初值为 0，对应「从第一个元素开始」；`ans` 要初始化成负无穷，不能是 0，否则全负数序列会输出 0。

## ⚠️ 常见错误

- **单调队列过期条件写错**：`< i-R` 和 `<= i-R` 差一个元素，窗口少一格。
- **先取队头再插入**：新元素还没进队，当前最优可能漏掉。

## 🧠 本章小结

```
优化第一步：拆式子
  只含 i 的提出去，只含 j 的留在 min/max 里

前缀和：sum(l..r) = pre[r] - pre[l-1]
前缀最值：min_{j<i} pre[j] 边走边记

单调队列：
  淘汰过期 → 维护单调 → 取队头
  适用于窗口 [i-R, i-L] 的最值转移

多重背包：
  按 w 的余数分组，key(t) = g[r+tw] - t*c
  窗口 [k-s, k] 取最大

决策单调：opt[i] 不减 → 分治
斜率优化：交叉项 = 只含 j 的系数 × 只含 i 的变量
```
