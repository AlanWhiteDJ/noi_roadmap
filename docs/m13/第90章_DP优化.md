# 第 90 章  DP 优化
> 🏗️ **前情回顾**：第 59 章你用单调队列求过滑动窗口最值。当 DP 转移式里出现「一段区间的最值」，那套工具就能把一层循环砍掉。

## 🎯 本章目标
- 用前缀和把区间求和转移降成 O(1)，用单调队列把「窗口最值」降成均摊 O(1)
- 认出决策单调性 / 斜率优化的形式

## 🎬 动机
方程写对了却 TLE，是提高级最常见的一幕。优化不是换算法，而是**看出转移式中哪部分是重复计算的**——把它缓存或维护起来，复杂度立刻掉一档。

## 🧱 知识讲解
### 90.1  前缀和优化
转移形如 `f[i] = min_{j<i} f[j] + w[i]` 时维护前缀最值；若代价是 `sum(l..r)` 型，先做前缀和：

```cpp
for (int i = 1; i <= n; i++) pre[i] = pre[i-1] + a[i];
// 代价 sum(j+1..i) = pre[i] - pre[j]
```
### 90.2  单调队列优化：P1776 宝物筛选
多重背包按「模 w 的余数」分组，组内 `f[v]` 只依赖窗口 `[v-s*w, v]` 的最大值。记 `key(t) = g[r+t*w] - t*c`（`g` 是上一层），则：

```cpp
for (int k = 0; r + k*w <= V; k++) {
  if (!q.empty() && q.front() < k - s) q.pop_front();          // 过期
  while (!q.empty() && key(q.back()) <= key(k)) q.pop_back();  // 更优
  q.push_back(k);
  f[r + k*w] = max(f[r + k*w], key(q.front()) + k*c);
}
```

注意 `key` 必须读**上一层**的 `g`，不能读正在被改写的 `f`。
### 90.3  决策单调性 / 斜率优化（选讲）
若最优断点 `opt[i]` 随 i 不减，可用分治或指针平移；若转移能化成 `y = kx + b` 的直线最值，用凸包（斜率优化）。判据：**把含 i、j 的项分离后，交叉项能写成乘积形式**。

## 💻 例题

**例 2**：[P2254 瑰丽华尔兹](https://hydro.ac/p/luogu-P2254)——按时间段、按行/列分别做单调队列，`f[i][j]` 为该时段结束时的最长滑行。

## ⚠️ 常见坑
1. 过期条件写成 `>= k`，窗口少一格
2. 优化后状态含义变了，却还在用旧初值
3. 枚举方向与窗口方向相反，队头取到未来值
