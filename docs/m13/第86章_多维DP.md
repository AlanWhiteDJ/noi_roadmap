# 第 86 章  多维 DP
> 🏗️ **前情回顾**：前面章节的 `f[i]` 只有一个量在变。可现实里的决策常被几件事同时牵制——走到哪、还剩多少、用了几次。这一章把状态从一条线摊成一张表。

## 🎯 本章目标
- 数清「同时变化的量」，据此定状态维度
- 写出二维/三维 DP 的转移与边界
- 用滚动数组把空间压掉一维

## 🎬 动机
两个人同时从左上角走到右下角，各走各的会互相抢格子。若分开算两次，第一次的最优会毁掉第二次；只有**把两条路放进同一个状态**，才能一次算清。

## 🧱 知识讲解
### 86.1  维度从哪来
位置（坐标/下标）、资源（容量/步数）、阶段（第几次）是三大来源；**能由别的维度算出来的量不要单独开维**，例如 `j = s - i` 时 `j` 不该出现。
### 86.2  双路径 DP：两人同时走
[P1004 方格取数](https://hydro.ac/p/luogu-P1004) 走两次、取过变 0。令 `s = i1+j1 = i2+j2`，状态 `f[s][i1][i2]`：

```cpp
int w = a[i1][j1] + (i1 != i2 ? a[i2][j2] : 0);   // 同格只算一次
f[s][i1][i2] = max({f[s-1][i1-1][i2-1], f[s-1][i1-1][i2],
                    f[s-1][i1][i2-1],   f[s-1][i1][i2]}) + w;
```

四个来源 = 两条路各走「下/右」的四种组合；`j = s - i` 省掉一维。
### 86.3  滚动数组
`f[s]` 只依赖 `f[s-1]`，第一维可滚：

```cpp
for (int s = 2; s <= 2*n; s++) { /* 新层写入 g */ swap(f, g); }
```

必须**先算新层、再整体交换**；在同一数组里原地覆盖会读到已被改写的值。

## 💻 例题
**例 1**：[P1006 传纸条](https://hydro.ac/p/luogu-P1006)——与方格取数同构，把「来回」看成「两人同时从左上到右下」，起点/终点重合只算一次。

**例 2**：[P1216 数字三角形](https://hydro.ac/p/luogu-P1216)——一维 `f[j]` 自底向上，`f[j] = a[i][j] + max(f[j], f[j+1])`，倒序枚举 j 即可原地更新。

## ⚠️ 常见坑
1. 漏了「谁在动」这一维，两人路径被压成一条
2. 滚动数组覆盖顺序反了，读到本层新值
3. 越界格没判 `1 <= j <= n`
