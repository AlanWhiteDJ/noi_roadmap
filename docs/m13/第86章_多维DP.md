# 第 86 章  多维 DP

---

> 🏗️ **前情回顾**：前面章节的 `f[i]` 只有一个量在变。可现实里的决策常被几件事同时牵制——走到哪、还剩多少、用了几次。这一章把状态从一条线摊成一张表。

## 🧱 知识讲解

### 86.1  维度从哪里来

DP 的状态是一组「必须记住的信息」。多开一维，通常是因为多了一个**无法由已有维度推出**的量。常见的三个来源：

| 来源 | 例子 | 对应维度 |
|------|------|----------|
| 位置 | 走到第几行、第几列 | `i`、`j` |
| 资源 | 还剩多少容量、还能用几次 | `v`、`k` |
| 阶段 | 第几轮、第几个时间段 | `t` |

判断要不要开维，只问一句：**这个量能不能由别的维度算出来？**

- 网格里已知 `i + j = s`，那么 `j = s - i`，`j` 就不该单独占一维。
- 背包里已经枚举了「前 `i` 件」，就不需要再记录「已经考虑过哪些件」。
- 两个人同步走时，步数相同，所以两个人的步数只留一个 `s`。

**能算出来的量不要存。**

### 86.2  双路径 DP：两个人同时走

以 [P1004 方格取数](https://hydro.ac/p/luogu-P1004) 为例：`n × n` 的方格，每格有一个非负整数，从 `(1,1)` 走到 `(n,n)`，只能向右或向下，走两次，每格的值只能被取一次，求最大和。

两条路同时走。设某一时刻两条路分别在第 `i1` 行和第 `i2` 行，走过的步数都是 `s - 2`（因为从 `(1,1)` 出发，`i + j = s`）。于是：

```
j1 = s - i1,  j2 = s - i2
```

状态定义为：

```
f[s][i1][i2] = 两条路各走 s-2 步，分别停在第 i1 行、第 i2 行时的最大收益
```

每一步，两条路各自可以选择「向下」或「向右」，所以有 `2 × 2 = 4` 种前驱：

```
f[s-1][i1-1][i2-1]   两条都向下
f[s-1][i1-1][i2]     第一条向下，第二条向右
f[s-1][i1][i2-1]     第一条向右，第二条向下
f[s-1][i1][i2]       两条都向右
```

转移时加上当前两格的收益。如果 `i1 == i2`，说明两人在同一格（此时必有 `j1 == j2`），这格的收益只能算一次：

```cpp
int add = a[i1][j1] + (i1 == i2 ? 0 : a[i2][j2]);
f[s][i1][i2] = max({f[s-1][i1-1][i2-1], f[s-1][i1-1][i2],
                    f[s-1][i1][i2-1],   f[s-1][i1][i2]}) + add;
```

> 💡 这里 `s` 不是「多出来的信息」，而是把 `i1 + j1 = i2 + j2` 这条约束显式写出来。两条路速度相同，所以它们必然处在同一条斜线上。

### 86.3  边界与枚举范围

`s` 从 `2` 走到 `2n`（起点 `1+1=2`，终点 `n+n=2n`）。给定 `s` 和 `i`，列 `j = s - i` 必须落在 `[1, n]`，所以：

```cpp
i 从 max(1, s - n) 到 min(n, s - 1)
```

若 `i` 太小，`j` 会超过 `n`；若 `i` 太大，`j` 会小于 `1`。越界格一旦参与转移，答案就会悄悄变大或变小。

另一个细节是**不可达状态**。不是所有 `(s, i1, i2)` 都能从起点走到。把 `f` 初始化为一个很小的数（例如 `-0x3f3f3f3f`），只给起点赋值，转移时就不会把「走不到」当成「收益为 0」。

### 86.4  滚动数组：只留上一层

`f[s]` 只依赖 `f[s-1]`，所以第一维可以滚掉。做法是准备两个二维数组 `cur` 和 `nxt`：

```cpp
int cur[12][12], nxt[12][12];

memset(cur, -0x3f, sizeof cur);
cur[1][1] = a[1][1];

for (int s = 2; s <= 2 * n; ++s) {
    memset(nxt, -0x3f, sizeof nxt);
    for (int i1 = max(1, s - n); i1 <= min(n, s - 1); ++i1)
        for (int i2 = max(1, s - n); i2 <= min(n, s - 1); ++i2) {
            int best = max(max(cur[i1-1][i2-1], cur[i1-1][i2]),
                           max(cur[i1][i2-1],   cur[i1][i2]));
            // ... 写入 nxt[i1][i2]
        }
    memcpy(cur, nxt, sizeof cur);
}
```

顺序只有一条铁律：**先把新一层完整算进另一个数组，再整体交换**。如果你图省事，直接在 `cur` 上原地覆盖，那么同一层里先算出的新值会被后算的格子当成「上一层」读走，等于让两条路多走了好几步。

## 💻 例题与解析

### 例 1  方格取数（P1004）

**题意**：`n × n` 方格（`n ≤ 9`），每格一个非负整数。从 `(1,1)` 到 `(n,n)` 走两次，每次只能向右或向下，同一格的值只取一次，求最大总和。

**思路**：按 86.2 的定义设 `f[s][i1][i2]`，四方向取最大值。答案是 `f[2n][n][n]`。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, a[12][12];
int f[24][12][12];

int main() {
    cin >> n;
    int x, y, v;
    while (cin >> x >> y >> v && (x || y || v))
        a[x][y] = v;

    memset(f, -0x3f, sizeof f);
    f[2][1][1] = a[1][1];

    for (int s = 3; s <= 2 * n; ++s) {
        for (int i1 = max(1, s - n); i1 <= min(n, s - 1); ++i1) {
            int j1 = s - i1;
            for (int i2 = max(1, s - n); i2 <= min(n, s - 1); ++i2) {
                int j2 = s - i2;
                int best = max(max(f[s-1][i1-1][i2-1], f[s-1][i1-1][i2]),
                               max(f[s-1][i1][i2-1],   f[s-1][i1][i2]));
                if (best < 0) continue;          // 前驱全部不可达
                int add = a[i1][j1] + (i1 == i2 ? 0 : a[i2][j2]);
                f[s][i1][i2] = max(f[s][i1][i2], best + add);
            }
        }
    }

    cout << f[2 * n][n][n] << endl;
    return 0;
}
```

**复杂度**：状态数约 `2n × n × n`，转移 `O(1)`，时间 `O(n³)`，空间 `O(n³)`。`n ≤ 9` 时毫无压力。

**易错点**：

1. 循环从 `s = 2` 开始却忘了初始化起点，导致全表不可达。
2. 只写 `i` 从 `1` 到 `n`，越界列被当成 0 参与计算。

### 例 2  传纸条（P1006）

**题意**：`m × n` 的矩阵，从 `(1,1)` 到 `(m,n)` 传两次纸条，每次只能向右或向下，每个格子的「好心程度」最多被加一次，求最大和。

**思路**：看起来是「一去一回」，但把回来的那条路反向看，就是**另一个人也从 `(1,1)` 走到 `(m,n)`**。于是与方格取数完全同构，只是行列数不同。

设 `s = i1 + j1 = i2 + j2`，`f[s][i1][i2]` 表示两人各走到第 `s` 条斜线、分别在第 `i1`、`i2` 行时的最大好感度。转移与例 1 一模一样，答案为 `f[m+n][m][m]`。

```cpp
// 核心转移，行列范围按 m 行 n 列调整
for (int s = 3; s <= m + n; ++s)
    for (int i1 = max(1, s - n); i1 <= min(m, s - 1); ++i1)
        for (int i2 = max(1, s - n); i2 <= min(m, s - 1); ++i2) {
            int j1 = s - i1, j2 = s - i2;
            int best = max(max(f[s-1][i1-1][i2-1], f[s-1][i1-1][i2]),
                           max(f[s-1][i1][i2-1],   f[s-1][i1][i2]));
            int add = a[i1][j1] + (i1 == i2 ? 0 : a[i2][j2]);
            f[s][i1][i2] = max(f[s][i1][i2], best + add);
        }
```

**为什么不能分别求两次最优？** 因为第一次的最优路线可能占掉第二次唯一的好格子。两次决策互相影响，就必须放在同一个状态里一起决定。

### 例 3  数字三角形（P1216）

**题意**：一个 `n` 层的数字三角形，从顶部出发，每次可以走到正下方或右下方，求到底部的最大路径和。

**思路**：如果从上往下写，`f[i][j]` 表示走到 `(i,j)` 的最大和，需要处理「哪些格子可达」。反过来从下往上更省事：`f[j]` 表示从第 `i` 层第 `j` 列出发到底部的最大和。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, a[1005][1005], f[1005];

int main() {
    cin >> n;
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= i; ++j)
            cin >> a[i][j];

    for (int j = 1; j <= n; ++j) f[j] = a[n][j];

    for (int i = n - 1; i >= 1; --i)
        for (int j = 1; j <= i; ++j)
            f[j] = a[i][j] + max(f[j], f[j + 1]);

    cout << f[1] << endl;
    return 0;
}
```

**为什么 `j` 要正序？** `f[j]` 的新值依赖旧 `f[j]` 和旧 `f[j+1]`。正序枚举时，`f[j+1]` 还没被本层改写，仍是下一层的值；如果倒序，`f[j+1]` 已经变成新值，相当于同一层走了两步。

**复杂度**：时间 `O(n²)`，空间 `O(n)`。

## ⚠️ 常见错误

- **维度冗余**：明明 `j = s - i`，却又开一维 `j`，状态数翻倍，还容易忘记同步更新。
- **同格重复计数**：两人相遇时把 `a[i1][j1]` 加了两次，答案偏大。相遇条件用 `i1 == i2` 判断即可。
- **滚动数组原地覆盖**：在同一个数组里既读旧层又写新层，转移读到了「未来」的值。
- **边界写死**：`i` 从 `1` 到 `n` 枚举，`j = s - i` 越界后仍参与 `max`，不可达状态被当成 0。

## 🧠 本章小结

```
多维 DP = 把「同时变化的量」放进状态

双路径：
  s = i1 + j1 = i2 + j2
  j = s - i
  f[s][i1][i2] ← 四个前驱取 max
  同格（i1 == i2）只加一次

边界：
  i ∈ [max(1, s-n), min(n, s-1)]
  不可达用 -INF，不要用 0

滚动：
  先算新层到另一个数组，再整体交换
  绝不在同一数组里边读边写
```
