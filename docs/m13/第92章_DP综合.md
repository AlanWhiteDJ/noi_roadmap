## 📖 故事引入

模拟赛还有 20 分钟。小华读完第三题，脑子里一片空白：题面很长，限制很多，看不出该用什么算法。

他有两种选择：

- 继续硬想正解，赌自己能在一刻钟内顿悟；
- 先写一个 `O(2ⁿ)` 的暴力，把 `n ≤ 20` 的 30 分拿到手，再回头想优化。

上次他选了第一种，最后爆零。这次他选了第二种。暴力写了 8 分钟，过掉小样例；剩下的时间，他盯着暴力里的状态，突然发现「其实只需要记住前一个位置选没选」，于是把 `2ⁿ` 换成 `O(n)`，又多拿了 60 分。

出分时，他这道题 90 分，比班里不少「正解写挂」的人高。

DP 综合考的从来不是「你会不会某个模板」，而是：**面对一道新题，你能不能稳定地拆出阶段、状态、转移、边界，并且在有限时间里先拿到能拿的分。**

## 🧱 知识讲解

### 92.1  题型分类表

先看题面信号，再决定开哪张表：

| 题面特征 | 题型 | 典型状态 | 常见复杂度 |
|----------|------|----------|------------|
| 序列上跳、前缀决策 | 线性 DP | `f[i]` | `O(n)` / `O(n²)` |
| 容量、个数、预算限制 | 背包 | `f[v]` | `O(nV)` |
| 合并相邻段、回文、取两端 | 区间 DP | `f[l][r]` | `O(n³)` / `O(n²)` |
| 树上选点、依赖、子树统计 | 树形 DP | `f[u][…]` | `O(n)` / `O(nm)` |
| `n ≤ 20`、集合、棋盘 | 状压 DP | `f[S]` / `f[S][i]` | `O(2ⁿn)` |
| 两人轮流、胜负、取石子 | 博弈 DP | `win[S]` / `sg` | 视局面数 |
| 数位、前导零、上下界 | 数位 DP | `f[pos][…]` | `O(位数×状态)` |

> 💡 数据范围是最诚实的提示。`n ≤ 20` 基本在暗示状压或 `2ⁿ` 枚举；`n ≤ 500` 允许 `O(n³)`；`n ≤ 10⁵` 基本要求 `O(n log n)` 或 `O(n)`。

### 92.2  四步设计法

拿到题，按顺序回答四个问题，别跳步：

**第一步：阶段是什么？**

阶段是「推到哪里了」。常见选择：下标 `i`、区间长度 `len`、子树 `u`、集合大小 `popcount(S)`、数位 `pos`。

**第二步：状态要记住什么？**

状态 = 阶段 + 无法由阶段推出的信息。信息越少越好，每多一维都要问：「这一维真的影响后续决策吗？」

**第三步：转移从哪里来？**

写出「上一步的所有可能」，取 `max` / `min` / 求和。转移必须覆盖所有情况，尤其是「不选」「空集」「不动」这些容易被漏掉的选项。

**第四步：边界是什么？**

`f[0]`、`f[i][i]`、叶子结点、空区间、全不选。边界错，后面全错。

以「打家劫舍」为例：一排房子，不能偷相邻两家，求最大金额。

```
阶段：前 i 家
状态：f[i][0] = 第 i 家不偷；f[i][1] = 第 i 家偷
转移：f[i][0] = max(f[i-1][0], f[i-1][1])
      f[i][1] = f[i-1][0] + a[i]
边界：f[0][0] = f[0][1] = 0
答案：max(f[n][0], f[n][1])
```

四行写完，代码几乎就是翻译。

### 92.3  从暴力到正解：三档部分分

竞赛题通常有三档数据：

| 档位 | 数据特征 | 常用写法 |
|------|----------|----------|
| 30% | `n ≤ 20` | `2ⁿ` 枚举、DFS、记忆化 |
| 60% | `n ≤ 5000` | `O(n²)` DP、区间 DP |
| 100% | `n ≤ 10⁵` | 降维、单调队列、前缀和、贪心性质 |

策略：

1. **先写暴力，确保正确**。暴力是你唯一的对拍基准。
2. **再看特殊性质**。链、菊花、权值全相等、只有两种颜色——这些往往能单独拿一档。
3. **最后想优化**。优化通常来自「重复计算」或「无用状态」，不是推翻重来。

> ⚠️ 最亏的是会正解却没写暴力，正解写挂后一分没有。

### 92.4  提交前的检查清单

- 状态含义能不能用一句话说清？说不清，转移一定有问题。
- 边界有没有初始化？`f[0]`、`f[i][i]`、叶子。
- 循环顺序对不对？区间按长度、背包按容量方向、树形后序。
- 该倒序的地方有没有写成正序？
- 取模有没有漏？减法有没有 `(x - y + MOD) % MOD`？
- 会不会溢出？`long long` 够不够？
- 多测有没有清空？数组有没有开小一维？

### 92.5  时间与空间权衡

- **滚动数组**：状态只依赖上一层时，第一维可以滚掉。
- **预处理**：组合数、前缀和、合法状态、距离矩阵，能预处理的别在循环里算。
- **减少取模**：能不取模的地方用 `long long` 累加，最后统一取模。
- **访问顺序**：二维数组按行遍历通常比按列快，缓存更友好。
- **递归改迭代**：链状树上 `10⁵` 层递归会爆栈。

## 💻 例题与解析

### 例 1  合唱队形（P1091）

**题意**：`n` 个同学排成一排，身高为 `a[i]`。要选出尽量多的人，排成「先严格上升、再严格下降」的队形（中间最高点只算一次）。求最少需要让几个人出列。

**思路**：枚举最高点 `i`。以 `i` 结尾的最长严格上升子序列长度为 `f[i]`，以 `i` 开头的最长严格下降子序列长度为 `g[i]`（即从右往左的上升子序列）。能留下的最多人数是 `f[i] + g[i] - 1`。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, a[105], f[105], g[105];

int main() {
    cin >> n;
    for (int i = 1; i <= n; ++i) cin >> a[i];

    for (int i = 1; i <= n; ++i) {
        f[i] = 1;
        for (int j = 1; j < i; ++j)
            if (a[j] < a[i]) f[i] = max(f[i], f[j] + 1);
    }

    for (int i = n; i >= 1; --i) {
        g[i] = 1;
        for (int j = n; j > i; --j)
            if (a[j] < a[i]) g[i] = max(g[i], g[j] + 1);
    }

    int keep = 0;
    for (int i = 1; i <= n; ++i)
        keep = max(keep, f[i] + g[i] - 1);

    cout << n - keep << endl;
    return 0;
}
```

**复杂度**：时间 `O(n²)`，空间 `O(n)`。

**易错点**：`f[i] + g[i] - 1` 要减 1，因为最高点被两遍都算了。题目问「出列人数」，答案是 `n - keep`，不是 `keep`。

### 例 2  乌龟棋（P1541）

**题意**：一条长度为 `n` 的赛道，每格有分数 `a[i]`。有 `m` 张卡片，分别是 1、2、3、4 步。从第 1 格出发，按某种顺序使用所有卡片，求最大得分。

**思路**：四种卡片的数量最多各 40 张。状态直接开四维：`f[i][j][k][l]` 表示四种卡片分别用了多少张。当前位置由卡片数唯一确定：

```
pos = 1 + i + 2j + 3k + 4l
```

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m, a[355], cnt[5];
int f[41][41][41][41];

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; ++i) cin >> a[i];
    for (int i = 1; i <= m; ++i) {
        int x;
        cin >> x;
        ++cnt[x];
    }

    f[0][0][0][0] = a[1];

    for (int i = 0; i <= cnt[1]; ++i)
        for (int j = 0; j <= cnt[2]; ++j)
            for (int k = 0; k <= cnt[3]; ++k)
                for (int l = 0; l <= cnt[4]; ++l) {
                    int cur = f[i][j][k][l];
                    int pos = 1 + i + 2 * j + 3 * k + 4 * l;
                    if (i < cnt[1]) f[i+1][j][k][l] = max(f[i+1][j][k][l], cur + a[pos + 1]);
                    if (j < cnt[2]) f[i][j+1][k][l] = max(f[i][j+1][k][l], cur + a[pos + 2]);
                    if (k < cnt[3]) f[i][j][k+1][l] = max(f[i][j][k+1][l], cur + a[pos + 3]);
                    if (l < cnt[4]) f[i][j][k][l+1] = max(f[i][j][k][l+1], cur + a[pos + 4]);
                }

    cout << f[cnt[1]][cnt[2]][cnt[3]][cnt[4]] << endl;
    return 0;
}
```

**复杂度**：状态数 `O(c1·c2·c3·c4)`，转移 `O(1)`，最多约 `41⁴ ≈ 2.8×10⁶`。空间约 11 MB。

**易错点**：`pos` 必须由「已用卡片」算出来，不能另外开一维记录位置，否则状态爆炸。四种卡片的数量要分别统计，不能只记总数。

### 例 3  设计演练：打家劫舍的三档写法

**题意**：`n` 个房子排成一排，第 `i` 个有 `a[i]` 元，不能偷相邻两家，求最大金额。

**30 分写法（`n ≤ 20`）**：枚举每个房子偷或不偷，检查是否有相邻，取最大值。`O(2ⁿ·n)`。

**60 分写法（`n ≤ 5000`）**：`f[i][0/1]` 表示前 `i` 家、第 `i` 家不偷/偷的最大金额：

```cpp
f[i][0] = max(f[i-1][0], f[i-1][1]);
f[i][1] = f[i-1][0] + a[i];
```

**100 分写法（`n ≤ 10⁷`）**：只需要前一项，滚动成两个变量：

```cpp
long long f0 = 0, f1 = 0;      // f0: 当前不偷, f1: 当前偷
for (int i = 1; i <= n; ++i) {
    long long nf0 = max(f0, f1);
    long long nf1 = f0 + a[i];
    f0 = nf0;
    f1 = nf1;
}
cout << max(f0, f1) << endl;
```

**三档的共同点**：状态含义完全一样，只是存储和枚举方式在变。这就是「先写对，再写好」——正解不是另一个算法，而是同一张表被压小、压快。

## ⚠️ 常见错误

- **状态含义没写清**：变量名是 `f[i][j]`，自己却说不清 `j` 代表什么，转移一定漏情况。
- **漏掉「不选」**：只考虑选当前物品，忘记跳过它，答案偏大或偏小。
- **边界没初始化**：`f[0]`、`f[i][i]`、叶子结点，错一个后面全错。
- **循环顺序反了**：区间 DP 没按长度、背包没按方向、树形没后序。
- **不写暴力**：正解写挂直接零分，连部分分都没有。
- **多测不清空**：上一组数据残留，下一组答案莫名其妙。

## 🧠 本章小结

```
四步设计：
  阶段：推到哪里（i / len / u / S / pos）
  状态：阶段 + 必须记住的信息（越少越好）
  转移：上一步从哪来，覆盖所有情况
  边界：f[0]、空区间、叶子

三档策略：
  30%：2^n 枚举 / DFS
  60%：O(n^2) DP
  100%：降维、前缀和、单调队列、贪心性质

提交前：
  状态含义、边界、循环顺序、long long、多测清空
```
