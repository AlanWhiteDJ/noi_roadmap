# 第 92 章  DP 综合
> 🏗️ **前情回顾**：86–91 章你分别练了多维、背包/区间、树形、状压、优化、博弈。考场上没人告诉你用哪一种——这一章练「看到题就知道开哪张表」。

## 🎯 本章目标
- 按题面特征快速归类 DP 题型，用「阶段 / 状态 / 转移 / 边界」四步设计
- 先用暴力 DP 拿部分分，再想正解

## 🎬 动机
同一道题，有人 20 分钟写出 60 分暴力再优化到 100 分，有人一上来追正解最后爆零。差别不在聪明，而在**有没有一套稳定的设计流程**。

## 🧱 知识讲解
### 92.1  题型分类表
| 题面特征 | 题型 | 状态 |
|---|---|---|
| 序列上跳、前缀决策 | 线性 DP | `f[i]` |
| 容量 / 个数限制 | 背包 | `f[v]` |
| 合并相邻段、回文 | 区间 DP | `f[l][r]` |
| 树上选点、依赖 | 树形 DP | `f[u][…]` |
| n ≤ 20、集合 | 状压 DP | `f[S]` |
| 两人轮流、胜负 | 博弈 DP | `win[S]` |
### 92.2  四步设计法
1. **阶段**：按什么推进（下标、长度、子树、集合大小）
2. **状态**：阶段 + 必须记住的信息（越少越好）
3. **转移**：上一步从哪来，写成 `max/min/+=`
4. **边界**：`f[0]`、空区间、叶子

```cpp
// 想清楚 f[i] 的含义再动手
for (int i = 1; i <= n; i++)
  for (int j : pre[i]) f[i] = max(f[i], f[j] + w[i]);
```
### 92.3  部分分策略
- 小数据：`O(2^n)` 枚举 / 记忆化搜索
- 特殊性质：链、权值相等、只有两色——常退化成简单 DP
- 写对暴力再优化，**不要一上来追正解**

## 💻 例题
**例 1**：CSP-S 2024 染色——线性 DP，`f[i][c]` 表示前 i 个位置、第 i 个染 c 色的最小代价，转移看上一段颜色是否相同。
**例 2**：CSP-S 2025 员工招聘——组合计数 + DP，先算方案数再做容量维转移，注意取模与组合数预处理。

## ⚠️ 常见坑
1. 状态含义没写清，转移时自己都读不懂
2. 漏了「不选」「空集」这类情况
3. 不写暴力，正解写挂后一分没有
