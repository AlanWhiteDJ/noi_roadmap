## 📖 故事引入

山上有 `M` 株草药，每一株采下来要花一段时间，能卖不同的价钱。小华只有一个下午，背包里的时间总共 `T` 分钟。他站在第一株草药前，脑子里冒出两个念头：

「这株采不采？」——采，就花掉 `w` 分钟，得到 `c` 的价值；不采，时间留给后面的草药。

如果每株草药只有一株，这就是 01 背包：每件物品只有「拿」和「不拿」两种选择。现实往往更麻烦：草药可能有一大包可以反复取，也可能按药方分组、每组只能选一种。循环方向、拆分方式、枚举顺序稍微变一下，模型就完全不同。

而另一类问题干脆连「物品」都没有：一排石子，每次只能合并相邻两堆，合并的代价是两堆之和。你没法从「第一堆」开始线性推进，因为最后一次合并可能发生在任意位置。这时候，状态得从「前 `i` 个」变成「区间 `[l, r]`」。

## 🧱 知识讲解

### 87.1  01 背包：倒序的本质

设 `f[v]` 表示容量为 `v` 时能获得的最大价值。处理第 `i` 件物品（重量 `w`、价值 `c`）时：

```cpp
for (int v = V; v >= w; --v)
    f[v] = max(f[v], f[v - w] + c);
```

为什么从大到小？因为 `f[v-w]` 必须是**没有考虑第 `i` 件物品**时的值。

- 倒序时，`v` 从大往小走，`v-w < v` 还没被本轮更新，读到的确实是「前 `i-1` 件」的结果。第 `i` 件最多被加一次。
- 正序时，`v-w` 先被本轮更新过，`f[v-w]` 里可能已经包含第 `i` 件。再加一次，就等于这件物品被拿了两次、三次……背包静默变成了「完全背包」。

记住：**倒序 = 每件最多一次；正序 = 每件随便拿。**

### 87.2  完全背包：正序是故意的

完全背包每件物品有无限多个。把上面的循环方向翻过来就行：

```cpp
for (int v = w; v <= V; ++v)
    f[v] = max(f[v], f[v - w] + c);
```

此时 `f[v-w]` 已经允许包含第 `i` 件，再拿一件正好表达「再选一个」。这不是 bug，是需求。

### 87.3  多重背包：二进制拆分

第 `i` 件物品有 `s` 个，最直接的做法是拆成 `s` 个 01 物品，复杂度 `O(V·Σs)`，`s` 一大就崩。

拆分想法是：用 `1, 2, 4, 8, …` 这些「捆绑包」组合出 `0..s` 的任意数量。例如 `s = 13`，拆成 `1, 2, 4, 6`，因为：

```
1 = 1        2 = 2        3 = 1+2      4 = 4
5 = 1+4      6 = 2+4      7 = 1+2+4    8 = 2+6
...
13 = 1+2+4+6
```

任意 `0..13` 都能取其中若干个相加得到。于是把「13 个物品」变成「4 个捆绑物品」，再做 01 背包：

```cpp
int tot = 0;
for (int i = 1; i <= n; ++i) {
    int s = num[i];
    for (int k = 1; s > 0; k <<= 1) {
        int t = min(k, s);
        w[++tot] = t * W[i];
        c[tot]     = t * C[i];
        s -= t;
    }
}
```

复杂度 `O(V·Σlog s)`。

> ⚠️ 最后一份是「余数」，不一定等于 `k`。写成 `t = k` 会让总数超过 `s`，答案偏大。

### 87.4  分组背包：每组至多一件

每组至多一件，循环顺序必须是「组 → 容量（倒序）→ 组内物品」：

```cpp
for (int g = 1; g <= G; ++g) {
    if (items[g].empty()) continue;
    for (int v = V; v >= 0; --v)
        for (auto &it : items[g])
            if (v >= it.first)
                f[v] = max(f[v], f[v - it.first] + it.second);
}
```

容量倒序保证 `f[v-w]` 还没被本组更新；物品循环放在最里面，保证同一组只挑一件。如果把物品循环放到容量外面，就可能在同一组里先选一件、再在它的基础上选第二件。

### 87.5  区间 DP：长度是阶段

区间 DP 的状态是 `f[l][r]`，表示「只考虑区间 `[l, r]`」时的最优值。它由更短的区间拼出来，所以**阶段是区间长度**，必须按长度从小到大枚举。

以石子合并为例，`f[l][r]` 表示把 `l..r` 合并成一堆的最小代价，最后一次合并一定在某个断点 `k` 处把 `[l,k]` 和 `[k+1,r]` 接起来：

```
f[l][r] = min_{l ≤ k < r} ( f[l][k] + f[k+1][r] ) + sum(l, r)
```

```cpp
for (int len = 2; len <= n; ++len)
    for (int l = 1, r; (r = l + len - 1) <= n; ++l)
        for (int k = l; k < r; ++k)
            f[l][r] = min(f[l][r], f[l][k] + f[k+1][r] + pre[r] - pre[l-1]);
```

三个细节：

1. `len = 1` 是边界，`f[i][i] = 0`，不用转移。
2. 断点 `k` 取 `l..r-1`。取到 `r` 会让 `[r+1, r]` 成为空区间。
3. 区间和用前缀和 `pre[r] - pre[l-1]`，不要每次再循环求和，否则复杂度多一个 `n`。

### 87.6  环形区间：断环成链

石子围成一圈时，合并的最后一堆可能是环上任意一段。处理办法是**把数组复制一倍**，长度变成 `2n`：

```cpp
for (int i = 1; i <= n; ++i) a[i + n] = a[i];
```

这样，环上任意一个长度为 `n` 的区间，都对应展开后数组里的某个 `[i, i+n-1]`。按长度 `2..n` 做区间 DP，最后在 `i = 1..n` 的所有 `f[i][i+n-1]` 里取最优。

## 💻 例题与解析

### 例 1  采药（P1048）

**题意**：有 `M` 株草药，总时间 `T`。每株需要 `w[i]` 时间、价值 `c[i]`，每株最多采一次，求最大价值。

**思路**：01 背包模板。`f[v]` 表示用 `v` 时间能采到的最大价值，容量倒序。

```cpp
#include <bits/stdc++.h>
using namespace std;

int T, M, w[105], c[105], f[1005];

int main() {
    cin >> T >> M;
    for (int i = 1; i <= M; ++i) cin >> w[i] >> c[i];

    for (int i = 1; i <= M; ++i)
        for (int v = T; v >= w[i]; --v)
            f[v] = max(f[v], f[v - w[i]] + c[i]);

    cout << f[T] << endl;
    return 0;
}
```

**复杂度**：时间 `O(M·T)`，空间 `O(T)`。

**易错点**：把内层写成 `for (int v = w[i]; v <= T; ++v)`，样例可能过，但每株草药会被重复采，答案偏大。

### 例 2  石子合并（P1880）

**题意**：`n` 堆石子围成一圈，每次合并相邻两堆，代价为两堆之和，求合并成一堆的最小代价和最大代价。

**思路**：断环成链，复制一倍。`f[l][r]` 记最小代价，`g[l][r]` 记最大代价，按长度递推。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 205;
int n, a[N], pre[N];
int f[N][N], g[N][N];

int main() {
    cin >> n;
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
        a[i + n] = a[i];
    }
    for (int i = 1; i <= 2 * n; ++i) pre[i] = pre[i - 1] + a[i];

    memset(f, 0x3f, sizeof f);   // 最小代价，初值要大
    memset(g, 0, sizeof g);      // 最大代价，初值 0

    for (int i = 1; i <= 2 * n; ++i) f[i][i] = g[i][i] = 0;

    for (int len = 2; len <= n; ++len)
        for (int l = 1, r; (r = l + len - 1) <= 2 * n; ++l) {
            int sum = pre[r] - pre[l - 1];
            for (int k = l; k < r; ++k) {
                f[l][r] = min(f[l][r], f[l][k] + f[k + 1][r] + sum);
                g[l][r] = max(g[l][r], g[l][k] + g[k + 1][r] + sum);
            }
        }

    int ansMin = INT_MAX, ansMax = 0;
    for (int i = 1; i <= n; ++i) {
        ansMin = min(ansMin, f[i][i + n - 1]);
        ansMax = max(ansMax, g[i][i + n - 1]);
    }
    cout << ansMin << endl << ansMax << endl;
    return 0;
}
```

**复杂度**：长度 `O(n)`、左端点 `O(n)`、断点 `O(n)`，时间 `O(n³)`，空间 `O(n²)`。`n ≤ 100` 时约 `8×10⁶` 次转移。

**易错点**：`len` 只枚举到 `n` 是对的，但左端点要枚举到 `2n - len + 1`；只开到 `n` 会漏掉跨过原数组末尾的区间。

### 例 3  通天之分组背包（P1757）

**题意**：`n` 件物品，背包容量 `V`，每件物品有重量、价值和组号，同一组最多选一件，求最大价值。

**思路**：把同组物品存进 `vector`，按组做 01 背包。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, V, f[1005];
vector<pair<int, int>> items[1005];

int main() {
    cin >> n >> V;
    for (int i = 1; i <= n; ++i) {
        int w, c, g;
        cin >> w >> c >> g;
        items[g].push_back({w, c});
    }

    for (int g = 1; g <= 1000; ++g) {
        if (items[g].empty()) continue;
        for (int v = V; v >= 0; --v)
            for (auto &it : items[g])
                if (v >= it.first)
                    f[v] = max(f[v], f[v - it.first] + it.second);
    }

    cout << f[V] << endl;
    return 0;
}
```

**复杂度**：`O(V · n)`（每组物品只被扫一遍）。

## ⚠️ 常见错误

- **01 背包写成正序**：每件物品被无限次选取，小数据不一定看得出来。
- **二进制拆分最后一份写错**：余数应取 `min(k, s)`，不能固定为 `k`。
- **区间断点取到 `r`**：访问空区间，转移结果没有意义。

## 🧠 本章小结

```
01 背包：容量倒序，每件一次
完全背包：容量正序，每件无限
多重背包：二进制拆分 1,2,4,...,余数 → 01
分组背包：组 → 容量倒序 → 组内物品

区间 DP：
  阶段 = 区间长度，从小到大
  f[l][r] = min/max(f[l][k] + f[k+1][r]) + 区间代价
  k ∈ [l, r-1]

环形：复制一倍，答案取所有长度 n 的区间
```
