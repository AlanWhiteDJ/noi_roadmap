# 第 87 章  背包与区间 DP
> 🏗️ **前情回顾**：本书你已经会写 01 背包的一维数组。这一章补齐完全/多重/分组背包的细节，并把「区间」这种状态正式请上台。

## 🎯 本章目标
- 说清 01 背包倒序、完全背包正序的原因；用二进制拆分裂解多重背包
- 按区间长度从小到大枚举，写对断点范围

## 🎬 动机
同样一件物品，只能拿一次和能拿无数次，代码只差一个循环方向。理解「这一格是从本层还是上一层来的」，比背模板可靠得多。

## 🧱 知识讲解
### 87.1  正序与倒序
一维 `f[v]` 是容量 v 的最优值。01 背包每件只能用一次，容量**倒序**：

```cpp
for (int i = 1; i <= n; i++) for (int v = V; v >= w[i]; v--) f[v] = max(f[v], f[v-w[i]] + c[i]);
```

正序时 `f[v-w[i]]` 已是本件更新过的值，等于允许重复选——那正是完全背包。
### 87.2  多重背包：二进制拆分
第 i 件有 `s` 个，拆成 1,2,4,…,余数 个「捆绑件」，再跑 01 背包，复杂度 O(V·Σlog s)：

```cpp
for (int k = 1; s > 0; k <<= 1) { int t = min(k, s); add(w*t, c*t); s -= t; }
```
### 87.3  区间 DP：长度是阶段
[P1880 石子合并](https://hydro.ac/p/luogu-P1880)：`f[l][r]` 为合并 l..r 的最小代价，

```cpp
for (int len = 2; len <= n; len++)
  for (int l = 1, r; (r = l + len - 1) <= n; l++)
    for (int k = l; k < r; k++)
      f[l][r] = min(f[l][r], f[l][k] + f[k+1][r] + sum(l, r));
```

断点取 `l..r-1`，取到 `r` 会访问空区间。环形问题**断环成链**：复制一倍，答案取所有长度 n 的区间最优。

## 💻 例题
**例 1**：[P1048 采药](https://hydro.ac/p/luogu-P1048)——01 背包模板，容量倒序，答案为 `f[V]`。
**例 2**：[P1880 石子合并](https://hydro.ac/p/luogu-P1880)——断环成链到 2n，按长度递推；求最大值把 min 换成 max。
## ⚠️ 常见坑
1. 01 背包正序，静默变成完全背包
2. 断点写成 `k <= r`，访问空区间
3. 环形只开 n 长度，答案只取 `f[1][n]`
