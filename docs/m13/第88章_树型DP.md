# 第 88 章  树型 DP
> 🏗️ **前情回顾**：第 77 章你算过子树和——一次后序 DFS 就能把子树信息汇总到根。树型 DP 就是把这个套路变成「每个结点存一张小表」。

## 🎯 本章目标
- 用后序 DFS 合并子树信息，写对「选 / 不选」模型
- 处理树上背包与依赖关系

## 🎬 动机
公司要办年会，谁去谁不去有讲究：上司在场下属就放不开。每棵子树都能给出「根去 / 根不去」两个最优值，父亲只在这两个数里挑——整棵树就这样一层层算完。

## 🧱 知识讲解
### 88.1  阶段就是「子树」
树没有天然顺序，但子树是嵌套的：处理完儿子才能算父亲。所以 `dfs(u)` 先递归所有儿子，回溯时再把 `f[v][*]` 合并进 `f[u][*]`——递归到底再合并，天然是后序。
### 88.2  选 / 不选：P1352 没有上司的舞会
`f[u][0/1]` 表示 u 不去 / 去。u 去则儿子必不去；u 不去则儿子随意：

```cpp
f[u][1] += f[v][0];
f[u][0] += max(f[v][0], f[v][1]);
```

答案 `max(f[root][0], f[root][1])`；根不唯一时建超级源连所有入度 0 的点。
### 88.3  树上背包：P2014 选课
容量是「选几门课」，合并儿子时做一次背包：

```cpp
for (int v : g[u]) {
  dfs(v);
  for (int j = m; j >= 1; j--)          // 倒序，避免同一子树被选两次
    for (int k = 0; k < j; k++) f[u][j] = max(f[u][j], f[u][j-k] + f[v][k]);
}
```

看似 O(nm²)，按子树大小卡上界可证明为 O(nm)。

## 💻 例题
**例 1**：[P1352](https://hydro.ac/p/luogu-P1352)——入度 0 的点作根，后序合并；权值有负时「不去」更优，初值要给对。
**例 2**：[P2014](https://hydro.ac/p/luogu-P2014)——加虚拟根 0（选 0 号课不占容量），`f[u][j]` 表示 u 子树中选 j 门且含 u。

## ⚠️ 常见坑
1. `f` 全初始化为 0，把「不可达」当成 0 分；该用 `-INF` 就用
2. 合并时 j 没倒序，同一子树被重复选
3. 多棵树只 DFS 了其中一棵，没建超级源
