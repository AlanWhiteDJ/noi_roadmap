# 第 88 章  树型 DP

---

> 🏗️ **前情回顾**：第 77 章你算过子树和——一次后序 DFS 就能把子树信息汇总到根。树型 DP 就是把这个套路变成「每个结点存一张小表」。

---

## 🎯 本章目标

学完这一章，你能：

- 用邻接表建树，选对根，写出后序 DFS
- 处理「选 / 不选」模型，正确设置初值与答案
- 把背包合并进子树，写出树上背包
- 用换根 DP 求「以每个点为根」的答案

## 📖 故事引入

公司要办年会，邀请函发下去，人事却犯了难：上司在场，下属就放不开；可上司要是来了，下属多半也愿意来。

规则只有一条：**如果一个员工去了，他的直接上司就不能去。**

小华盯着组织架构图发愁。几百号人，每人去或不去，组合数大得吓人。但他很快发现：不管上面的人怎么决定，每棵子树内部的选择是独立的。只要知道「这棵子树的根去」和「根不去」分别能带来多少快乐值，父亲就只需要在这两个数里挑一个。

于是整棵树从叶子往上，一层层把两张小表合并到根。根的最后两个数取较大者，就是答案。

树型 DP 的核心就一句：**子树是嵌套的，先算儿子，再算父亲。**

---

## 🧱 知识讲解

### 88.1  建树与后序 DFS

输入给 `n-1` 条边，用邻接表存边：

```cpp
vector<int> g[N];

void dfs(int u, int fa) {
    for (int v : g[u]) {
        if (v == fa) continue;     // 不走回父亲
        dfs(v, u);
        // 儿子算完，在这里合并
    }
}
```

为什么必须后序？因为 `f[u]` 依赖 `f[v]`。树没有天然下标顺序，但子树是嵌套的：处理完儿子才能算父亲。递归到底再回溯合并，天然满足。

> ⚠️ 递归深度等于树高。链状树有 `10⁵` 个结点时可能爆栈，需要扩栈或改手工栈。

### 88.2  选 / 不选：没有上司的舞会

设 `f[u][0]` 表示 `u` 不去时子树的最大快乐值，`f[u][1]` 表示 `u` 去时的最大值。初始化 `f[u][1] = r[u]`，`f[u][0] = 0`。合并儿子 `v`：

```cpp
f[u][1] += f[v][0];                    // u 去，v 必不去
f[u][0] += max(f[v][0], f[v][1]);      // u 不去，v 随意
```

答案取 `max(f[root][0], f[root][1])`，根是入度为 0 的点；多棵树时建超级源。

### 88.3  树上背包：选课

[P2014](https://hydro.ac/p/luogu-P2014) 中，选一门课必须先选先修课。设 `f[u][j]` 表示「在 `u` 的子树里选 `j` 门课，且必须选 `u`」的最大学分。合并儿子 `v` 时做一次背包：

```cpp
f[u][0] = 0;
f[u][1] = score[u];

for (int v : g[u]) {
    dfs(v);
    for (int j = min(m + 1, sz[u] + sz[v]); j >= 1; --j)
        for (int k = 0; k <= min(sz[v], j - 1); ++k)
            f[u][j] = max(f[u][j], f[u][j - k] + f[v][k]);
    sz[u] += sz[v];
}
```

三个关键点：

1. **`j` 必须倒序**，`f[u][j-k]` 才是「还没合并这棵子树」的旧值。
2. **`f[u][0] = 0`**，表示这棵子树一门都不选；没有它，`k = 0` 的转移无法进行。
3. **用 `sz` 卡住上界**，总复杂度从 `O(nm²)` 降到 `O(nm)`。

森林加虚拟根 `0`（学分 0），容量 `m+1`，答案 `f[0][m+1]`。

### 88.4  换根 DP

求「以每个点为根的距离和」时，先以 1 为根后序求出 `sz[u]`（子树大小）和 `down[u]`（子树内到 `u` 的距离和），再前序推给儿子。

根从 `u` 移到 `v`：`v` 子树内 `sz[v]` 个点各近 1，其余 `n - sz[v]` 个点各远 1，所以：

```
f[v] = f[u] + n - 2 * sz[v]
```

```cpp
void dfs2(int u, int fa) {
    for (int v : g[u]) if (v != fa) {
        f[v] = f[u] + n - 2LL * sz[v];
        dfs2(v, u);
    }
}
```

## 💻 例题与解析

### 例 1  没有上司的舞会（P1352）

**题意**：`n` 个员工形成一棵树，每人有快乐值。选若干人，若某人被选，他的直接上司不能被选，求最大快乐值总和。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 6005;
int n, r[N], indeg[N], f[N][2];
vector<int> g[N];

void dfs(int u) {
    f[u][1] = r[u];
    for (int v : g[u]) {
        dfs(v);
        f[u][1] += f[v][0];
        f[u][0] += max(f[v][0], f[v][1]);
    }
}

int main() {
    cin >> n;
    for (int i = 1; i <= n; ++i) cin >> r[i];

    for (int i = 1; i < n; ++i) {
        int l, k;
        cin >> l >> k;          // k 是 l 的上司
        g[k].push_back(l);
        ++indeg[l];
    }

    int root = 1;
    while (indeg[root]) ++root;

    dfs(root);
    cout << max(f[root][0], f[root][1]) << endl;
    return 0;
}
```

**复杂度**：时间 `O(n)`，空间 `O(n)`。

**易错点**：快乐值可能为负，「不去」的 0 更优；但不要把 `f[u][0]` 初始化成负无穷，否则丢掉「整棵子树不选」的方案。

### 例 2  选课（P2014）

**题意**：`n` 门课，每门有学分和先修课，选 `m` 门，求最大学分。先修关系形成森林。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 305;
const int NEG = -1000000000;
int n, m, score[N], f[N][N], sz[N];
vector<int> g[N];

void dfs(int u) {
    sz[u] = 1;
    f[u][0] = 0;
    f[u][1] = score[u];

    for (int v : g[u]) {
        dfs(v);
        for (int j = min(m + 1, sz[u] + sz[v]); j >= 1; --j)
            for (int k = 0; k <= min(sz[v], j - 1); ++k)
                if (f[u][j - k] > NEG / 2)
                    f[u][j] = max(f[u][j], f[u][j - k] + f[v][k]);
        sz[u] += sz[v];
    }
}

int main() {
    cin >> n >> m;
    fill(&f[0][0], &f[0][0] + N * N, NEG);

    for (int i = 1; i <= n; ++i) {
        int k;
        cin >> k >> score[i];
        g[k].push_back(i);        // k = 0 时接到虚拟根
    }

    dfs(0);
    cout << f[0][m + 1] << endl;
    return 0;
}
```

**复杂度**：`O(nm)`，空间 `O(nm)`。

**易错点**：`f` 必须初始化成负无穷。初始为 0 会把「选不出 `j` 门」的非法状态当成 0 学分，答案偏大。

### 例 3  树的深度和（P3478 思路）

**题意**：求以每个点为根时所有点的距离和，输出最小的根。

```cpp
int n, sz[N];
long long down[N], f[N];

void dfs1(int u, int fa) {
    sz[u] = 1;
    for (int v : g[u]) if (v != fa) {
        dfs1(v, u);
        sz[u] += sz[v];
        down[u] += down[v] + sz[v];
    }
}

void dfs2(int u, int fa) {
    for (int v : g[u]) if (v != fa) {
        f[v] = f[u] + n - 2LL * sz[v];
        dfs2(v, u);
    }
}
// main: dfs1(1,0); f[1]=down[1]; dfs2(1,0); 取 min
```

**复杂度**：两遍 DFS，`O(n)`。

**易错点**：`f` 用 `long long`；`2LL * sz[v]` 避免中间结果类型问题。

## ⚠️ 常见错误

- **只建单向边却从任意点 DFS**：走不到父亲，子树信息残缺。
- **`f` 全初始化为 0**：把「不可达」当成「0 分」，树上背包尤其致命。
- **合并时 `j` 正序**：同一棵子树被重复选择。
- **换根公式方向写反**：记住「子树内变近、子树外变远」。

## 🧠 本章小结

```
树型 DP：后序 DFS，回溯时合并儿子

选 / 不选：
  f[u][1] = r[u] + Σ f[v][0]
  f[u][0] = 0   + Σ max(f[v][0], f[v][1])

树上背包：
  f[u][j]，j 倒序，k 枚举给儿子几门
  虚拟根处理森林，答案 f[0][m+1]

换根：
  f[v] = f[u] + n - 2 * sz[v]
  第一遍后序求 sz/down，第二遍前序推答案
```
