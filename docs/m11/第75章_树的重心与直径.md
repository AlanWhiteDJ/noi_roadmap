# 第 75 章  树的重心与直径
> 🏗️ **前情回顾**：第 74 章把子树变成了区间。这一章回到树本身：一条最长链（直径）和一个"最平衡"的点（重心），是树上贪心与构造题的两把尺子。
## 🎯 本章目标
- 两遍 DFS 与树形 DP 求直径
- 会求重心，知道重心至多两个
- 用直径、重心性质做贪心与构造
## 🌱 故事：快递站选在哪
> 快递站要选一个点建仓库，使最远客户最近；同时要量出全城最长的两点距离。前者是重心，后者是直径——两个问题都只靠 DFS 就能答。
## 🧱 知识讲解
### 75.1  两遍 DFS 求直径
```cpp
int far, dep[N];
void dfs(int u, int fa, int d) {
    dep[u] = d; if (d > dep[far]) far = u;
    for (auto [v, w] : g[u]) if (v != fa) dfs(v, u, d + w);
}
```
从任意点出发的最远点必是直径端点：`dfs(1,0,0)` 得 a，再 `dfs(a,0,0)` 得 b，`dep[b]` 即直径。
### 75.2  树形 DP 求直径
```cpp
int down[N], ans;
void dp(int u, int fa) {
    for (auto [v, w] : g[u]) if (v != fa) {
        dp(v, u), ans = max(ans, down[u] + down[v] + w);  // 两条链拼成
        down[u] = max(down[u], down[v] + w);
    }
}
```
### 75.3  重心
```cpp
int sz[N], mx[N] = {INF}, ct;
void getCt(int u, int fa) {
    sz[u] = 1;
    for (int v : g[u]) if (v != fa)
        getCt(v, u), sz[u] += sz[v], mx[u] = max(mx[u], sz[v]);
    mx[u] = max(mx[u], n - sz[u]); if (mx[u] < mx[ct]) ct = u;
}
```
重心使最大子树最小，删掉后每块 ≤ n/2；重心至多两个，且一定相邻。
## 💻 例题
**例 1**：P1099 树网的核——先求直径，核必落在直径上；在直径上尺取长度 ≤ s 的段，偏心距取"端点到直径两端"与"段内点挂出的最长枝"的最大值。
**例 2**：P5536 核心城市——以直径中点为根，贪心取深度最大的 k 个点，答案为第 k+1 深的那条链长。
## ⚠️ 常见坑
1. 直径不唯一，只求长度时两遍 DFS 够用，求方案要小心
2. 重心可能有两个，要求编号最小时要特判
