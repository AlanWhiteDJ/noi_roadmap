## 🌱 故事引入：快递站选在哪

快递公司要在小镇建一个仓库。镇长提了两个要求：仓库到最远客户的距离要尽量短；同时还要量出全镇最远两个客户之间的距离，用来估算配送时间。

第一个要求是找"最平衡"的点：删掉它之后，剩下的每一块都不能太大。这个点是**重心**。第二个要求是找最长的一条简单路径，也就是**直径**。

有趣的是，这两个问题都不需要复杂的数据结构，各跑一两遍 DFS 就能解决。直径提供了一条"主干"，很多构造题只要把点往主干上靠，思路就出来了；重心则告诉你"往哪边搬都不会更差"，是贪心的落脚点。

## 🧱 知识讲解

### 75.1  直径：两遍 DFS

**定义**：树上最长的一条简单路径叫直径，它的长度是直径长度。

**结论**：从任意点 s 出发，找到离它最远的点 a；再从 a 出发，找到离 a 最远的点 b，则 a 到 b 就是一条直径。

证明思路：设 (x,y) 是直径。从 s 到 a 的路径与它相交于 p，由"a 是 s 的最远点"可推出 a 到 x 或 a 到 y 不短于 x 到 y；而 x 到 y 已是最长，故只能取等号，a 必为某条直径的端点。再从 a 找最远点，就得到另一端点。

```cpp
const int N = 100005;
struct Edge { int to, w; };
vector<Edge> g[N];
long long dis[N];
int far;

void dfs(int u, int fa, long long d) {
    dis[u] = d;
    if (d > dis[far]) far = u;        // 更新最远点
    for (int i = 0; i < (int)g[u].size(); ++i) {
        int v = g[u][i].to, w = g[u][i].w;
        if (v != fa) dfs(v, u, d + w);
    }
}
```

调用两次：

```cpp
far = 1; dis[0] = -1;
dfs(1, 0, 0);          // 找到端点 a
int a = far;
far = a; dis[0] = -1;
dfs(a, 0, 0);          // 找到端点 b，dis[b] 即直径长度
int b = far;
```

`dis[0] = -1` 让第一次比较必定更新 `far`。边权非负时成立；负权边要改用树形 DP。

### 75.2  直径：树形 DP

换一个角度：对每个点 u，记 `down[u]` 为"从 u 往子树深处走的最远距离"。把两条来自不同儿子的链在 u 处拼起来，就得到一条经过 u 的路径。

```cpp
long long down[N], ans;

void dp(int u, int fa) {
    down[u] = 0;
    for (int i = 0; i < (int)g[u].size(); ++i) {
        int v = g[u][i].to, w = g[u][i].w;
        if (v == fa) continue;
        dp(v, u);
        ans = max(ans, down[u] + down[v] + w);   // 先拼再更新 down
        down[u] = max(down[u], down[v] + w);
    }
}
```

顺序很重要：必须先用"旧的 `down[u]`"（来自之前儿子的最长链）与当前儿子拼接，再把当前儿子并进 `down[u]`。如果先更新 `down[u]`，就会把同一个儿子用两次，拼出一条重复走的假路径。

两种写法对比：

| 写法 | 复杂度 | 优点 | 限制 |
|------|--------|------|------|
| 两遍 DFS | O(n) | 短、能还原路径 | 边权需非负 |
| 树形 DP | O(n) | 能处理负权、能统计方案 | 代码稍长 |

### 75.3  重心

**定义**：删掉点 u 后，树会分成若干连通块。如果 u 使得"最大连通块的点数"最小，u 就是重心。

对每个点，删除它后的连通块有两类：

- 每个儿子的子树，大小为 `sz[v]`
- "父亲那一侧"，大小为 `n - sz[u]`

所以只需最小化 `max(max sz[v], n - sz[u])`。

```cpp
int sz[N], mx[N], ct, best;

void getCt(int u, int fa) {
    sz[u] = 1;
    mx[u] = 0;
    for (int i = 0; i < (int)g[u].size(); ++i) {
        int v = g[u][i].to;
        if (v == fa) continue;
        getCt(v, u);
        sz[u] += sz[v];
        mx[u] = max(mx[u], sz[v]);
    }
    mx[u] = max(mx[u], n - sz[u]);
    if (mx[u] < best || (mx[u] == best && u < ct)) {
        best = mx[u];
        ct = u;
    }
}
```

调用前设 `best = n + 1, ct = n + 1`。

**重心的性质**：

1. 删除重心后，每个连通块大小不超过 `n/2`。
2. 重心至多两个；若有两个，它们一定相邻，且此时 n 为偶数，那条边把树分成两个 `n/2`。
3. 所有点到重心的距离之和最小。沿一条边从 u 走到 v，距离和的变化量是 `n - 2*sz[v]`；重心处所有 `sz[v] <= n/2`，往任何方向走都不会更优。

第 3 条是选址类问题的核心：**无权树上，重心就是距离和最小的点**。

### 75.4  直径的常用性质

- 任意点出发的最远点，一定是某条直径的端点。
- 所有直径的中点相同（可能在一条边的中间）。这是"核心城市"一类题的理论依据。
- 若一条路径的端点在某条直径上，且它到直径两端距离的最大值最小，则它往往是构造题的最优解。
- 偏心距：所有点到某条路径的最大距离。求偏心距时，别漏掉路径上挂出去的枝条。

## 💻 例题

### 例 1  P1099 树网的核

**题意**：带权树，选一条长度不超过 s 的路径作为"核"，使所有点到核的最大距离（偏心距）最小，求这个最小值。

**思路**：最优核一定可以取在一条直径上。先求出直径 `path[1..m]`，把直径上的点标记出来；对每个直径点，求出"不经过直径、向下挂出去的最深枝条" `br[i]`。

对直径做尺取：固定左端 i，右端 j 尽量向右扩展到长度不超过 s。此时

```
偏心距 = max( a 到 path[i] 的距离,
              path[j] 到 b 的距离,
              窗口内最大的 br )
```

第一、二项是直径两端到核的距离，第三项是挂在核上的枝条。三者取最大，再对所有窗口取最小。窗口内 `br` 的最大值用单调队列维护。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 500005;
struct Edge { int to; long long w; };
vector<Edge> g[N];
long long dis[N], br[N];
int pre[N], path[N], m, far;
bool on[N];

void dfs(int u, int fa, long long d) {
    dis[u] = d; pre[u] = fa;
    if (d > dis[far]) far = u;
    for (int i = 0; i < (int)g[u].size(); ++i) {
        int v = g[u][i].to; long long w = g[u][i].w;
        if (v != fa) dfs(v, u, d + w);
    }
}
long long branch(int u, int fa) {
    long long best = 0;
    for (int i = 0; i < (int)g[u].size(); ++i) {
        int v = g[u][i].to; long long w = g[u][i].w;
        if (v != fa) best = max(best, w + branch(v, u));
    }
    return best;
}

int main() {
    int n; long long s;
    scanf("%d%lld", &n, &s);
    for (int i = 1; i < n; ++i) {
        int u, v; long long w;
        scanf("%d%d%lld", &u, &v, &w);
        g[u].push_back({v, w}); g[v].push_back({u, w});
    }
    far = 1; dis[0] = -1;
    dfs(1, 0, 0);
    int a = far;
    far = a; dis[0] = -1;
    dfs(a, 0, 0);
    int b = far;

    for (int x = b; x; x = pre[x]) path[++m] = x;
    reverse(path + 1, path + m + 1);
    for (int i = 1; i <= m; ++i) on[path[i]] = true;

    for (int i = 1; i <= m; ++i) {
        int u = path[i];
        for (int k = 0; k < (int)g[u].size(); ++k) {
            int v = g[u][k].to; long long w = g[u][k].w;
            if (!on[v]) br[i] = max(br[i], w + branch(v, u));
        }
    }

    long long ans = LLONG_MAX;
    int j = 0;
    deque<int> dq;
    for (int i = 1; i <= m; ++i) {
        while (j + 1 <= m && dis[path[j + 1]] - dis[path[i]] <= s) {
            ++j;
            while (!dq.empty() && br[dq.back()] <= br[j]) dq.pop_back();
            dq.push_back(j);
        }
        while (!dq.empty() && dq.front() < i) dq.pop_front();
        long long cur = max(dis[path[i]], dis[b] - dis[path[j]]);
        if (!dq.empty()) cur = max(cur, br[dq.front()]);
        ans = min(ans, cur);
    }
    printf("%lld\n", ans);
    return 0;
}
```

**复杂度**：求直径 O(n)，求枝条 O(n)，尺取 O(n)，总 O(n)。`dis` 是以 a 为源的距离，所以 `dis[path[i]]` 就是 a 到 path[i] 的距离，`dis[b] - dis[path[j]]` 就是 path[j] 到 b 的距离。

### 例 2  P1395 会议

**题意**：n 个点的无权树，选一个点 x，使所有点到 x 的距离之和最小。输出 x 和最小距离和；若有多个，输出编号最小的。

**思路**：距离和最小的点就是重心。先求重心（平局取编号小），再从重心 DFS 一遍求距离和。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 50005;
int n, sz[N], mx[N], ct = N, best = N;
vector<int> g[N];
long long sum;

void getCt(int u, int fa) {
    sz[u] = 1; mx[u] = 0;
    for (int i = 0; i < (int)g[u].size(); ++i) {
        int v = g[u][i];
        if (v == fa) continue;
        getCt(v, u);
        sz[u] += sz[v];
        mx[u] = max(mx[u], sz[v]);
    }
    mx[u] = max(mx[u], n - sz[u]);
    if (mx[u] < best || (mx[u] == best && u < ct)) {
        best = mx[u]; ct = u;
    }
}
void calc(int u, int fa, int d) {
    sum += d;
    for (int i = 0; i < (int)g[u].size(); ++i) {
        int v = g[u][i];
        if (v != fa) calc(v, u, d + 1);
    }
}
int main() {
    scanf("%d", &n);
    for (int i = 1; i < n; ++i) {
        int u, v; scanf("%d%d", &u, &v);
        g[u].push_back(v); g[v].push_back(u);
    }
    getCt(1, 0);
    calc(ct, 0, 0);
    printf("%d %lld\n", ct, sum);
    return 0;
}
```

**复杂度**：两次 DFS，O(n)。

## ⚠️ 常见错误

1. **第一次 DFS 没重置 `far` 和 `dis[0]`**：`dis[far]` 可能还是上一轮的值，导致最远点找错。每次调用前设 `far = 起点, dis[0] = -1`。
2. **两遍 DFS 用在负权树上**：结论失效。负权边要用树形 DP，并把 `ans` 初始化为 0 或最小单点。
3. **树形 DP 先更新 `down[u]` 再拼接**：同一个儿子被用两次，路径重复走。必须先 `ans = max(ans, down[u] + down[v] + w)`，再更新 `down[u]`。
4. **重心漏算父亲一侧**：只取 `max sz[v]` 会漏掉 `n - sz[u]`，得到的不是重心。
5. **重心平局没取最小编号**：题目要求编号最小时，要加 `mx[u] == best && u < ct` 的判断。
6. **求偏心距漏掉枝条**：只算直径两端到核的距离，可能漏掉挂在核中间的深枝。
7. **深链递归爆栈**：10^5 层链在部分环境会崩，必要时写迭代版。

## 🧠 本章小结

```
直径：
  两遍 DFS：任意点 -> 最远点 a -> 最远点 b，ab 即直径
  树形 DP：down[u] 为向下最长链，ans = max(down[u]+down[v]+w)

重心：
  mx[u] = max( max sz[v], n - sz[u] )
  取 mx 最小的点；至多两个，相邻，且每块 <= n/2
  无权树上，重心使所有点到它的距离和最小

直径性质：
  任意点的最远点必是直径端点
  所有直径中点相同
```

看到"最远距离""最长链"想直径；看到"最平衡""距离和最小""删点后最大块最小"想重心。
