# 第 79 章  树综合

> 🏗️ **前情回顾**：DFS 序、直径与重心、倍增 LCA、树上差分、树链剖分都学完了。考场上真正难的是：**先判断这是哪一类树题**。
## 🎯 本章目标
- 按"问路径 / 问子树 / 问整体"分类
- 会选工具：倍增、差分、树剖、DFS 序
- 会写链、菊花、小数据三档部分分
## 🌱 故事：工具箱不是越满越好
> 修车师傅不会一上来就拆发动机。先听声音、判断故障，再挑扳手。树题也一样：先看问的是路径还是子树，工具自然就定了。
## 🧱 知识讲解
### 79.1  题型分类
| 问题 | 首选工具 | 复杂度 |
|---|---|---|
| 子树加/子树和 | DFS 序 + 树状数组/线段树 | O(log n) |
| 路径加/路径和 | 树上差分（离线）或树剖 | O(log n) |
| 两点距离/LCA | 倍增 / 欧拉序 RMQ | O(log n) / O(1) |
| 最长链 | 两遍 DFS / 树形 DP | O(n) |
| 最平衡点 | 重心 | O(n) |
### 79.2  选型口诀
- 只问"子树" → 想 DFS 序，几乎不用 LCA
- 只问"路径 + 离线" → 想树上差分
- "路径 + 在线 + 带修" → 想树剖
- 问"最远/最长/中心" → 想直径与重心
```cpp
bool is_chain = (maxdeg <= 2);          // 链：最大度 ≤ 2
bool is_star  = (maxdeg == n - 1);      // 菊花：某点连所有点
```
### 79.3  部分分怎么写
```cpp
if (is_chain) { /* 路径变成序列：前缀和 / 线段树 */ }
else if (is_star) { /* 菊花：只有根与叶子，分类讨论 */ }
else { /* 小数据：暴力爬父亲，O(nq) */ }
```
先拿 30–60 分，再想正解；S 组题的部分分常藏在这三种特殊性质里。
## 💻 例题
**例 1**：2022 S 数据传输——树上选点/路径问题，倍增预处理 + DP 合并，注意 `long long` 与常数。
**例 2**：2023 S 种树——二分答案 + 树上判定，判定部分用 DFS 序或树上差分把 O(n) 检查写干净。
## ⚠️ 常见坑
1. 不判题型，硬套树剖，常数爆炸还写错
2. 忽略链、菊花部分分，直接交暴力
3. 多测不清空，`dep/dfn/timer` 是上一组的脏数据
