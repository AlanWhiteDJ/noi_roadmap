## 🧱 知识讲解

### 79.1  题型分类表

| 问题 | 首选工具 | 复杂度 | 典型信号 |
|------|----------|--------|----------|
| 子树加 / 子树和 | DFS 序 + 树状数组 / 线段树 | O(log n) | 询问以 u 为根的整棵子树 |
| 路径加 / 路径和（离线） | 树上差分 | O(log n) 每次 | 多次路径操作，最后统一询问 |
| 路径加 / 路径和（在线带修） | 树链剖分 + 线段树 | O(log^2 n) | 操作和询问交替出现 |
| 两点距离 / LCA | 倍增 或 欧拉序 RMQ | O(log n) / O(1) | 反复问两点间关系 |
| 第 k 个祖先 / 路径第 k 点 | 倍增 | O(log n) | 往上跳固定步数 |
| 最长链 | 两遍 DFS / 树形 DP | O(n) | 最远距离、直径 |
| 最平衡的点 | 重心 | O(n) | 删点后最大块最小、距离和最小 |
| 子树内计数 | DFS 序 + 树状数组（离线排序） | O(n log n) | 统计满足值域条件的后代 |

先记住三条粗线：

- **只问子树** → DFS 序，几乎不用 LCA。
- **问路径 + 离线** → 树上差分。
- **问路径 + 在线带修** → 树链剖分。

### 79.2  读题四问

拿到题，按顺序问：

**第一问：问的是谁？**

- 点权、边权，还是路径长度？
- 单点、子树、路径，还是整棵树？
- 统计"个数""和""最大值"还是"是否存在"？

**第二问：在线还是离线？**

- 所有修改做完后只问一次 → 可以差分、可以离线排序。
- 修改和询问交替，下一次询问依赖上一次答案 → 必须在线，树剖或带修数据结构。

**第三问：数据范围多大？**

- `n, q <= 5000`：O(nq) 暴力可能就够。
- `n, q <= 10^5`：O(n log n) 或 O(n log^2 n)。
- `n, q <= 5 * 10^5`：注意常数、递归深度和内存。

**第四问：有没有特殊性质？**

- 树是一条链：路径变成区间，前缀和/线段树直接上。
- 树是菊花：所有点只经过根，分类讨论。
- 每个点度数很小、边权全为 1、点权全相同：都可能是部分分的入口。

### 79.3  选型口诀

```
只问子树          -> DFS 序 + BIT / 线段树
路径 + 离线        -> 树上差分
路径 + 在线 + 带修 -> 树链剖分
问最远 / 最长      -> 直径
问最平衡 / 距离和  -> 重心
问祖先 / 路径第 k  -> 倍增
路径信息可加减     -> 前缀和 + LCA
```

路径信息满足"可加可减"（颜色数量、点权和）时，从根做前缀，用

```
sum(u, v) = pre[u] + pre[v] - pre[lca] - pre[fa[lca]]
```

一次 LCA 求出，完全不需要树剖。第 79 章的很多"看起来很难"的题，实际只是这个公式。

### 79.4  部分分：链、菊花、小数据

S 组题很少让你一分不得。特殊性质往往写在数据范围里，这就是送分入口。

**链**：最大度数不超过 2。此时 DFS 序就是链上的顺序，路径 `u..v` 对应一段连续区间。

```cpp
int maxdeg = 0;
for (int i = 1; i <= n; ++i)
    maxdeg = max(maxdeg, (int)g[i].size());
bool isChain = (maxdeg <= 2);
bool isStar  = (maxdeg == n - 1 && n > 2);
```

链上求路径和，用前缀和即可：

```cpp
// 先按链的顺序求出 pos[u]，再令 pre[i] = pre[i-1] + val[rk[i]]
long long chainSum(int u, int v) {
    int l = min(pos[u], pos[v]), r = max(pos[u], pos[v]);
    return pre[r] - pre[l - 1];
}
```

**菊花**：存在一个中心连向所有其他点。任意两点路径要么是"叶子—中心—叶子"，要么是"中心—叶子"，LCA 不是中心就是其中一个点。路径长度、路径和都能用中心分类讨论，O(1) 回答。

**小数据**：`n, q <= 5000` 时，直接每次爬父亲求 LCA：

```cpp
int lcaBrute(int u, int v) {
    while (dep[u] > dep[v]) u = fa[u];
    while (dep[v] > dep[u]) v = fa[v];
    while (u != v) { u = fa[u]; v = fa[v]; }
    return u;
}
```

单次 O(n)，总共 O(nq)。先把这一档写对，再去想正解，比空着想正解划算。

**统一框架**：

```cpp
if (isChain) solveChain();
else if (isStar) solveStar();
else solveBrute();       // 或 solveGeneral()
```

### 79.5  写完之后怎么查

1. **边界**：n = 1、n = 2、只有一条边、q = 0。
2. **形状**：链、菊花、随机树、完全二叉树各一组。
3. **数值**：全 0、全相同、有负数、最大权值。
4. **多测**：每组之间清空 `dfn/timer/dep/up/diff`。
5. **对拍**：写 O(nq) 暴力，和正解在小数据上随机对拍 1000 组。

## 💻 例题

### 例 1  P3178 [HAOI2015] 树上操作

**题意**：n 个点的树，根为 1，点权初始给定。三种操作：

1. `1 x a`：点 x 权值加 a。
2. `2 x a`：x 的整棵子树加 a。
3. `3 x`：询问 x 到根路径上的点权和。

**思路**：同时有"子树加"和"路径和"，而且操作在线——这是树剖的典型信号。DFS 序只能处理子树，处理不了到根的路径；树上差分适合离线，处理不了交替询问。

用第 78 章的树剖模板：

- 点加：`seg.add(1, 1, n, dfn[x], dfn[x], a)`。
- 子树加：`seg.add(1, 1, n, dfn[x], dfn[x] + sz[x] - 1, a)`。
- 路径和：从 x 跳到根，每次查 `[dfn[top[x]], dfn[x]]`，然后 `x = fa[top[x]]`。

```cpp
long long queryRoot(int x) {
    long long res = 0;
    while (top[x] != 0) {
        res += seg.query(1, 1, n, dfn[top[x]], dfn[x]);
        x = fa[top[x]];
    }
    return res;
}
```

终点固定是根，跳链不必比较两条链的深度，沿 x 一路向上即可。`top[root] = root`，最后 `x` 会变成 0，循环结束。

**复杂度**：每次操作 O(log^2 n)。如果只写子树部分、路径用暴力爬父亲，可以拿到子树操作的分；这正是"部分分"的思路。

### 例 2  P5836 [USACO19DEC] Milk Visits

**题意**：n 个点的树，每个点有一头奶牛，品种为 `H` 或 `G`。m 次询问，每次给出 a、b、c，问路径 a 到 b 上是否存在品种为 c 的奶牛。

**思路**：品种数量可加可减，用根前缀 + LCA。预处理：

```cpp
preH[v] = preH[u] + (s[v] == 'H');
preG[v] = preG[u] + (s[v] == 'G');
```

路径 a 到 b 上品种 H 的数量：

```
preH[a] + preH[b] - preH[lca] - preH[fa[lca]]
```

减 `preH[lca]` 是因为 lca 被加了两次；再减 `preH[fa[lca]]` 是把 lca 以上的部分去掉。G 同理。数量大于 0 就输出 1，否则 0。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
const int LOG = 17;
int n, m;
char s[N];
vector<int> g[N];
int up[LOG][N], dep[N], ph[N], pg[N];

void build() {
    queue<int> q; q.push(1); dep[1] = 1;
    ph[1] = (s[1] == 'H');
    pg[1] = (s[1] == 'G');
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int i = 0; i < (int)g[u].size(); ++i) {
            int v = g[u][i];
            if (v == up[0][u]) continue;
            dep[v] = dep[u] + 1; up[0][v] = u;
            ph[v] = ph[u] + (s[v] == 'H');
            pg[v] = pg[u] + (s[v] == 'G');
            for (int k = 1; k < LOG; ++k)
                up[k][v] = up[k - 1][ up[k - 1][v] ];
            q.push(v);
        }
    }
}
int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);
    int d = dep[u] - dep[v];
    for (int k = 0; k < LOG; ++k) if ((d >> k) & 1) u = up[k][u];
    if (u == v) return u;
    for (int k = LOG - 1; k >= 0; --k)
        if (up[k][u] != up[k][v]) u = up[k][u], v = up[k][v];
    return up[0][u];
}
int countH(int u, int v) {
    int w = lca(u, v);
    return ph[u] + ph[v] - ph[w] - ph[up[0][w]];
}
int countG(int u, int v) {
    int w = lca(u, v);
    return pg[u] + pg[v] - pg[w] - pg[up[0][w]];
}
int main() {
    scanf("%d%d", &n, &m);
    scanf("%s", s + 1);
    for (int i = 1; i < n; ++i) {
        int u, v; scanf("%d%d", &u, &v);
        g[u].push_back(v); g[v].push_back(u);
    }
    build();
    while (m--) {
        int a, b; char c[2];
        scanf("%d%d%s", &a, &b, c);
        int cnt = (c[0] == 'H') ? countH(a, b) : countG(a, b);
        printf("%d", cnt > 0 ? 1 : 0);
    }
    printf("\n");
    return 0;
}
```

**复杂度**：预处理 O(n log n)，每次询问 O(log n)。


### 例 3  链上的路径查询（部分分）

**题意**：树退化成一条链，m 次询问路径 u 到 v 的点权和，点权带修改。

**思路**：链上路径就是区间。用 `pos[u]` 表示 u 在链上的位置，树状数组维护点权，区间和就是 `sum(r) - sum(l-1)`。这是 S 组题"链性质"部分分的标准写法，通常能拿到 30 到 60 分。

```cpp
int l = min(pos[u], pos[v]);
int r = max(pos[u], pos[v]);
long long ans = bitSum(r) - bitSum(l - 1);
```

修改点权时，在 `pos[x]` 处加上差值。若题目还要求路径加，就在链上做差分或线段树，和第 35 章的序列问题完全一样。

## ⚠️ 常见错误

1. **不判题型，硬套树剖**：只问子树的题用树剖，代码长、常数大，还容易在 `dfn` 和 `sz` 上出错。
2. **忽略链、菊花部分分**：明明有 30 分白送，却直接交 O(nq) 暴力，甚至暴力还写错。
3. **在线离线判断错**：树上差分要求所有修改先做完再统一累加；如果修改和询问交替，差分答案会过期。
4. **多测不清空**：`dfn/timer/dep/up/diff` 任意一个残留，整组数据都会错。
5. **递归爆栈**：10^5 层链上，DFS 建 `up` 和树剖都可能崩，改用 BFS。
6. **`long long` 用晚**：路径和、距离和、三个距离相加，都容易超过 `int`。
7. **根不统一**：换根题要小心 `fa` 和 `dep` 的方向。
8. **只测样例**：链、菊花、n=1 才是杀招。

## 🧠 本章小结

```
先分类，再动手：
  问子树 -> DFS 序 + BIT/线段树
  问路径 + 离线 -> 树上差分
  问路径 + 在线带修 -> 树链剖分
  问距离/LCA -> 倍增或欧拉序
  问最远 -> 直径
  问最平衡/距离和 -> 重心
  问祖先/路径第 k -> 倍增
  路径信息可加减 -> 根前缀 + LCA

部分分三件套：
  链：区间前缀和/线段树
  菊花：按中心分类讨论
  小数据：暴力爬父亲 O(nq)

检查：边界、形状、数值、多测、对拍、复杂度
```

选型的本质是"先看询问对象，再看是否在线"。工具没有高低，只有合不合适。
