## 🧱 知识讲解

### 78.1  重儿子、重链与 top

对每个点 u：

- `sz[u]`：子树大小。
- `son[u]`：儿子中 `sz` 最大的那个，叫重儿子；其余叫轻儿子。
- `top[u]`：u 所在重链的链头（这条链上深度最小的点）。
- `dfn[u]`：剖分后的新编号，保证同一条重链上的 `dfn` 连续。

两次 DFS 的分工：

1. 第一次：求 `fa`、`dep`、`sz`、`son`。
2. 第二次：先走重儿子，给重链编号；再走轻儿子，让每个轻儿子成为新链的链头。

**为什么先走重儿子？** 因为同一条重链必须对应一段连续的 `dfn`。先递归重儿子，重儿子及其整棵子树会紧接着 u 被编号；轻儿子放在后面，各自开新链。这样一条重链上的点从上到下 `dfn` 递增且连续。

**子树区间仍然成立**：第二次 DFS 虽然改变了遍历顺序，但仍然是 DFS，子树的所有点仍在 `[dfn[u], dfn[u] + sz[u] - 1]` 内。

### 78.2  两次 DFS

```cpp
const int N = 100005;
vector<int> g[N];
int fa[N], dep[N], sz[N], son[N];
int top[N], dfn[N], rk[N], timer;

void dfs1(int u, int f) {
    fa[u] = f;
    dep[u] = dep[f] + 1;
    sz[u] = 1;
    son[u] = 0;
    for (int i = 0; i < (int)g[u].size(); ++i) {
        int v = g[u][i];
        if (v == f) continue;
        dfs1(v, u);
        sz[u] += sz[v];
        if (sz[v] > sz[son[u]]) son[u] = v;   // 严格大于
    }
}

void dfs2(int u, int t) {
    top[u] = t;
    dfn[u] = ++timer;
    rk[timer] = u;                            // 新编号对应的原点
    if (son[u]) dfs2(son[u], t);              // 重儿子继承链头
    for (int i = 0; i < (int)g[u].size(); ++i) {
        int v = g[u][i];
        if (v != fa[u] && v != son[u]) dfs2(v, v);   // 轻儿子开新链
    }
}
```

调用 `dfs1(root, 0); dfs2(root, root);`。`top[root] = root`，之后每条重链的链头就是它自己。

### 78.3  树剖求 LCA

```cpp
int lca(int u, int v) {
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        u = fa[top[u]];               // 链头更深的先跳上去
    }
    return dep[u] < dep[v] ? u : v;
}
```

每次让"链头更深"的那条链整体跳到链头的父亲，直到两条链相同；此时同链上深度小的就是 LCA。跳链次数 O(log n)。

### 78.4  路径拆成区间

以"路径加、路径和"为例：

路径加对称，把 `query` 换成 `add`：

```cpp
long long pathSum(int u, int v) {
    long long res = 0;
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        res = (res + seg.query(1, 1, n, dfn[top[u]], dfn[u])) % mod;
        u = fa[top[u]];
    }
    if (dep[u] > dep[v]) swap(u, v);
    res = (res + seg.query(1, 1, n, dfn[u], dfn[v])) % mod;
    return res;
}
```

子树操作更简单，直接用 `dfn[u]` 和 `sz[u]`：

```cpp
seg.add(1, 1, n, dfn[u], dfn[u] + sz[u] - 1, x);   // 子树加
seg.query(1, 1, n, dfn[u], dfn[u] + sz[u] - 1);      // 子树和
```

### 78.5  线段树部分

只需要"区间加、区间和"的懒标记线段树。每个结点维护 `sum` 与 `lazy`；`apply` 同时更新两者，`pushdown` 把标记下传，`query` 递归合并。所有值对 `mod` 取模。完整实现见例 1 的 `SegTree`，核心就是 `build`、`add`、`query` 三个函数。

### 78.6  复杂度

预处理 O(n)；路径 O(log^2 n)；子树 O(log n)。

## 💻 例题

### 例 1  P3384 【模板】重链剖分 / 树链剖分

**题意**：n 个点的树，点权初始为 `val[i]`，操作四种：

1. `1 x y z`：x 到 y 的路径上所有点加 z。
2. `2 x y`：求 x 到 y 路径上的点权和。
3. `3 x z`：x 的子树内所有点加 z。
4. `4 x`：求 x 的子树点权和。

所有答案对 mod 取模。

**思路**：完全套上面的模板。读入后 `dfs1`、`dfs2`，把 `val[rk[i]]` 放进线段树；路径操作跳链，子树操作查 `[dfn[u], dfn[u]+sz[u]-1]`。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int n, m, root, mod;
int val[N];
vector<int> g[N];
int fa[N], dep[N], sz[N], son[N];
int top[N], dfn[N], rk[N], timer;
long long a[N];

struct SegTree {
    long long sum[N << 2], lazy[N << 2];
    void build(int p, int l, int r) {
        if (l == r) { sum[p] = a[l] % mod; return; }
        int mid = (l + r) >> 1;
        build(p << 1, l, mid);
        build(p << 1 | 1, mid + 1, r);
        sum[p] = (sum[p << 1] + sum[p << 1 | 1]) % mod;
    }
    void apply(int p, int l, int r, long long v) {
        sum[p] = (sum[p] + v * (r - l + 1)) % mod;
        lazy[p] = (lazy[p] + v) % mod;
    }
    void pushdown(int p, int l, int r) {
        if (!lazy[p]) return;
        int mid = (l + r) >> 1;
        apply(p << 1, l, mid, lazy[p]);
        apply(p << 1 | 1, mid + 1, r, lazy[p]);
        lazy[p] = 0;
    }
    void add(int p, int l, int r, int ql, int qr, long long v) {
        if (ql <= l && r <= qr) { apply(p, l, r, v); return; }
        pushdown(p, l, r);
        int mid = (l + r) >> 1;
        if (ql <= mid) add(p << 1, l, mid, ql, qr, v);
        if (qr > mid) add(p << 1 | 1, mid + 1, r, ql, qr, v);
        sum[p] = (sum[p << 1] + sum[p << 1 | 1]) % mod;
    }
    long long query(int p, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return sum[p];
        pushdown(p, l, r);
        int mid = (l + r) >> 1;
        long long res = 0;
        if (ql <= mid) res += query(p << 1, l, mid, ql, qr);
        if (qr > mid) res += query(p << 1 | 1, mid + 1, r, ql, qr);
        return res % mod;
    }
} seg;

void dfs1(int u, int f) {
    fa[u] = f; dep[u] = dep[f] + 1; sz[u] = 1; son[u] = 0;
    for (int i = 0; i < (int)g[u].size(); ++i) {
        int v = g[u][i];
        if (v == f) continue;
        dfs1(v, u);
        sz[u] += sz[v];
        if (sz[v] > sz[son[u]]) son[u] = v;
    }
}
void dfs2(int u, int t) {
    top[u] = t; dfn[u] = ++timer; rk[timer] = u;
    if (son[u]) dfs2(son[u], t);
    for (int i = 0; i < (int)g[u].size(); ++i) {
        int v = g[u][i];
        if (v != fa[u] && v != son[u]) dfs2(v, v);
    }
}
void pathAdd(int u, int v, long long x) {
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        seg.add(1, 1, n, dfn[top[u]], dfn[u], x);
        u = fa[top[u]];
    }
    if (dep[u] > dep[v]) swap(u, v);
    seg.add(1, 1, n, dfn[u], dfn[v], x);
}
long long pathSum(int u, int v) {
    long long res = 0;
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        res = (res + seg.query(1, 1, n, dfn[top[u]], dfn[u])) % mod;
        u = fa[top[u]];
    }
    if (dep[u] > dep[v]) swap(u, v);
    res = (res + seg.query(1, 1, n, dfn[u], dfn[v])) % mod;
    return res;
}
int main() {
    scanf("%d%d%d%d", &n, &m, &root, &mod);
    for (int i = 1; i <= n; ++i) scanf("%d", &val[i]);
    for (int i = 1; i < n; ++i) {
        int u, v; scanf("%d%d", &u, &v);
        g[u].push_back(v); g[v].push_back(u);
    }
    dfs1(root, 0);
    dfs2(root, root);
    for (int i = 1; i <= n; ++i) a[dfn[i]] = val[i];
    seg.build(1, 1, n);

    while (m--) {
        int op, x, y, z; scanf("%d", &op);
        if (op == 1) {
            scanf("%d%d%d", &x, &y, &z);
            pathAdd(x, y, z % mod);
        } else if (op == 2) {
            scanf("%d%d", &x, &y);
            printf("%lld\n", pathSum(x, y));
        } else if (op == 3) {
            scanf("%d%d", &x, &z);
            seg.add(1, 1, n, dfn[x], dfn[x] + sz[x] - 1, z % mod);
        } else {
            scanf("%d", &x);
            printf("%lld\n", seg.query(1, 1, n, dfn[x], dfn[x] + sz[x] - 1));
        }
    }
    return 0;
}
```

**复杂度**：路径 O(log^2 n)，子树 O(log n)。

### 例 2  P2590 [ZJOI2008] 树的统计

**题意**：n 个点的树，点权可修改。操作三种：修改单点权值；查询路径点权和；查询路径点权最大值。

**思路**：结构不变，把线段树改成"单点赋值、区间和 + 区间最大值"。关键改动：

1. 去掉 `lazy` 和 `pushdown`，单点修改直接递归到叶子。
2. 每个结点多维护一个 `mx`，`pushup` 时 `mx[p] = max(mx[p<<1], mx[p<<1|1])`。
3. `pathSum` 与 `pathMax` 的跳链逻辑相同，只是最后合并时一个用 `+`，一个用 `max`。

单点修改直接递归到叶子，回溯时更新 `sum` 与 `mx`；`queryMax` 的写法与 `query` 相同，只是把 `res +=` 换成 `res = max(res, ...)`，初始值设为 `LLONG_MIN`。

路径最大值查询的跳链逻辑与 `pathSum` 完全相同，只需把累加的 `+` 换成 `max`，线段树调用换成 `queryMax`。

**易错点**：最大值查询的初始值不能设 0，因为点权可能为负；用 `LLONG_MIN` 或 `-1e18`。

## ⚠️ 常见错误

1. **重儿子判定写成 `>=`**：相等时会把后一个儿子也当成重儿子，链的连续性被破坏。必须严格大于。
2. **两次 DFS 顺序反了**：第二次要用第一次求出的 `son`，不能先剖分再求大小。
3. **跳链比较 `dep[u]` 而不是 `dep[top[u]]`**：应该让链头更深的那条链先跳，比较的是链头深度。
4. **第二次 DFS 没先走重儿子**：重链上的 `dfn` 不连续，线段树区间全错。
5. **子树区间写成 `[dfn[u], out[u]]` 但没求 `out`**：树剖里直接用 `dfn[u] + sz[u] - 1` 即可。
6. **建树时用错下标**：线段树第 i 个位置对应原点 `rk[i]`，不是 `i`。
7. **取模出负数**：负值后要 `(x % mod + mod) % mod`。

## 🧠 本章小结

```
dfs1：fa, dep, sz, son（sz 最大的儿子）
dfs2：top, dfn, rk；先重儿子，再轻儿子

重链：top 相同的一段，dfn 连续
路径：跳链，每次让 dep[top] 更深的链先跳
子树：[dfn[u], dfn[u] + sz[u] - 1]

路径操作 O(log^2 n)：O(log n) 段 × 线段树 O(log n)
子树操作 O(log n)
LCA：跳链到同一条链，取深度小的
```

树剖的本质是"把树按重链切成 O(log n) 段连续区间"。只要题目同时涉及路径和子树、又要求在线修改，树剖通常是最稳的选择。
