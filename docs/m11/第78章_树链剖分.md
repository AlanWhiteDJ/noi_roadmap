# 第 78 章  树链剖分（选学）

> 🏗️ **前情回顾**：第 74 章用 DFS 序把子树变成区间，第 64 章学了线段树，第 76 章会了 LCA。树剖把这几件事合起来：让"路径"也能变成 O(log n) 段区间。
## 🎯 本章目标
- 理解重儿子、重链与 `top`
- 写两次 DFS 完成剖分
- 把路径查询拆成若干段线段树查询
## 🌱 故事：把盘山路修成高速
> 上山的小路弯弯曲曲，走一步问一次太慢。树剖把"一直往下最粗的那条路"修成高速（重链），走高速可一次问一整段，只有换路时才下高速。
## 🧱 知识讲解
### 78.1  第一次 DFS：求重儿子
```cpp
void dfs1(int u, int f) {
    fa[u] = f; dep[u] = dep[f] + 1; sz[u] = 1;
    for (int v : g[u]) if (v != f) {
        dfs1(v, u), sz[u] += sz[v];
        if (sz[v] > sz[son[u]]) son[u] = v;
    }
}
```
### 78.2  第二次 DFS：编 dfn
```cpp
void dfs2(int u, int t) {
    top[u] = t; dfn[u] = ++timer; rk[timer] = u;
    if (son[u]) dfs2(son[u], t);              // 重儿子继承链头
    for (int v : g[u]) if (v != fa[u] && v != son[u]) dfs2(v, v);
}
```
先走重儿子，保证一条重链上的 `dfn` 连续。
### 78.3  路径查询
```cpp
while (top[u] != top[v]) {
    if (dep[top[u]] < dep[top[v]]) swap(u, v);
    query(dfn[top[u]], dfn[u]); u = fa[top[u]];
}
if (dep[u] > dep[v]) swap(u, v); query(dfn[u], dfn[v]);   // 同链：深度小的在前
```
子树查询仍是 `[dfn[u], dfn[u] + sz[u] - 1]`。
## 💻 例题
**例 1**：P3384 【模板】重链剖分——路径加/路径和 + 子树加/子树和，线段树带懒标记，注意取模。
**例 2**：P2590 [ZJOI2008] 树的统计——路径求和/求最大值，把 `query` 拆成两个函数即可。
## ⚠️ 常见坑
1. 重儿子判定用 `sz[v] > sz[son[u]]`，别写成 `>=`
2. 两次 DFS 顺序不能反，第二次要用第一次的 `son`
3. 跳链时比较的是 `dep[top[u]]`，不是 `dep[u]`
