## 🧱 知识讲解

### 77.1  从序列差分说起

对数组做区间加 `[l, r] += v`，不用修改每个元素，只改差分数组 d：

```cpp
d[l] += v;
d[r + 1] -= v;
```

最后做前缀和 `a[i] = a[i-1] + d[i]`，区间内的值就都加上了 v。

树上的一条路径不是连续区间，但它是"两条向上的链拼起来"。于是把"区间端点"换成"树上的关键点"，把"前缀和"换成"自底向上累加"。

### 77.2  点差分：路径上的点权 +1

要给路径 u → v 上的每个点加 1，执行：

```cpp
d[u]++;
d[v]++;
d[lca(u, v)]--;
d[fa[lca(u, v)]]--;
```

然后从叶子往根累加：

```cpp
void dfs(int u, int pa) {
    for (int i = 0; i < (int)g[u].size(); ++i) {
        int v = g[u][i];
        if (v != pa) {
            dfs(v, u);
            d[u] += d[v];        // 先递归儿子，再把标记并上来
        }
    }
}
```

累加完后，`d[x]` 就是点 x 被多少条路径覆盖。

**为什么是这四个点？** 在 u 和 v 处各 +1，向上累加时，u 到根、v 到根的所有祖先都会收到 +1。路径上的点正好是"u 的祖先 ∪ v 的祖先"，但多算了 LCA 以上的部分：

- LCA 被两条链各算一次，多算一次，所以 `d[lca]--`。
- LCA 的父亲及以上被两条链各算一次，而路径不包含它们，所以 `d[fa[lca]]--`。

两者相抵后，只有路径上的点保留 1。若 LCA 是根，`fa[lca] = 0`，把 `d[0]` 当垃圾桶即可，不影响真实点。

### 77.3  边差分：路径上的边权 +1

边没有独立编号，通常把边权挂到下面的点上：边 `(fa[x], x)` 由 x 代表。

路径 u → v 上的边加 1：

```cpp
d[u]++;
d[v]++;
d[lca(u, v)] -= 2;
```

累加后，`d[x]` 表示边 `(fa[x], x)` 被多少条路径覆盖。根没有父亲边，`d[root]` 没有意义，不要统计。

**为什么是 `-= 2`？** u 侧和 v 侧的链在 LCA 处汇合，LCA 本身不属于任何一条向下的边；两条链各给 LCA 贡献 1，必须全部减掉，才能让 LCA 以上的边不被覆盖。

两套公式对比：

| 类型 | 四个标记 | 累加后 d[x] 的含义 |
|------|----------|--------------------|
| 点差分 | `d[u]++, d[v]++, d[lca]--, d[fa[lca]]--` | 点 x 被覆盖的次数 |
| 边差分 | `d[u]++, d[v]++, d[lca] -= 2` | 边 `(fa[x], x)` 被覆盖的次数 |

> ⚠️ 两套公式只差一个标记，含义却完全不同。做题前先问：题目统计的是点还是边？

### 77.4  子树和：DFS 序 + 树状数组

第 74 章已把子树变成区间 `[dfn[u], out[u]]`。三种常见组合：

**单点加、子树和**：

```cpp
void add(int x, int v) { for (; x <= n; x += x & -x) bit[x] += v; }
int sum(int x) { int s = 0; for (; x > 0; x -= x & -x) s += bit[x]; return s; }
int subtreeSum(int u) { return sum(out[u]) - sum(dfn[u] - 1); }
```

**子树加、单点查**：在 `dfn[u]` 加 v，在 `out[u] + 1` 减 v，查询时求前缀和。

**子树加、子树和**：用线段树懒标记，或第 74 章的两个树状数组。

树上差分和子树和经常一起出现：先用差分把路径操作记成点标记，累加后再用 DFS 序查子树答案。也有的题反过来，先做子树加，再在路径上查询，这时通常要上树链剖分。

### 77.5  实现顺序

1. 建树，预处理 `dep`、`up` 表（或欧拉序）。
2. 读入每条路径，求 LCA，打四个标记。
3. 从根 DFS 一次，回溯时 `d[u] += d[v]`。
4. 按题目要求统计最大值、和，或再做一次子树查询。

差分是离线算法，LCA 用倍增就够；只有在需要在线带修时，才考虑第 78 章的树剖。

## 💻 例题

### 例 1  P3128 [USACO15DEC] Max Flow

**题意**：n 个点的树，k 条路径，每条路径上的点权 +1。求所有操作结束后点权的最大值。

**思路**：点差分模板。每条路径做四次标记，最后一遍 DFS 累加，取最大值。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 50005;
const int LOG = 17;
int n, k;
vector<int> g[N];
int up[LOG][N], dep[N], d[N], ans;

void build() {
    queue<int> q; q.push(1); dep[1] = 1;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int i = 0; i < (int)g[u].size(); ++i) {
            int v = g[u][i];
            if (v == up[0][u]) continue;
            dep[v] = dep[u] + 1; up[0][v] = u;
            for (int j = 1; j < LOG; ++j)
                up[j][v] = up[j - 1][ up[j - 1][v] ];
            q.push(v);
        }
    }
}
int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);
    int diff = dep[u] - dep[v];
    for (int j = 0; j < LOG; ++j) if ((diff >> j) & 1) u = up[j][u];
    if (u == v) return u;
    for (int j = LOG - 1; j >= 0; --j)
        if (up[j][u] != up[j][v]) u = up[j][u], v = up[j][v];
    return up[0][u];
}
void dfs(int u, int pa) {
    for (int i = 0; i < (int)g[u].size(); ++i) {
        int v = g[u][i];
        if (v != pa) {
            dfs(v, u);
            d[u] += d[v];
        }
    }
    ans = max(ans, d[u]);
}
int main() {
    scanf("%d%d", &n, &k);
    for (int i = 1; i < n; ++i) {
        int u, v; scanf("%d%d", &u, &v);
        g[u].push_back(v); g[v].push_back(u);
    }
    build();
    while (k--) {
        int u, v; scanf("%d%d", &u, &v);
        int w = lca(u, v);
        d[u]++; d[v]++; d[w]--; d[up[0][w]]--;
    }
    dfs(1, 0);
    printf("%d\n", ans);
    return 0;
}
```

**复杂度**：预处理 O(n log n)，k 次操作各 O(log n)，累加 O(n)。

### 例 2  P2680 [NOIP2015] 运输计划

**题意**：n 个点的带权树，m 条运输路径。可以把任意一条边的边权改为 0，使所有路径长度的最大值最小，求这个最小值。

**思路**：二分答案 L。对每个 L，找出所有长度大于 L 的路径，这些路径必须全部被同一条边覆盖——否则无论删哪条边，总有一条超长路径没变短。

设这些路径有 `cnt` 条。用边差分统计每条边被这些路径覆盖的次数；若某条边 `(fa[x], x)` 的覆盖次数正好是 `cnt`，它就是候选。删掉候选边后，最长路径长度变成 `maxLen - w`。若存在候选边使 `maxLen - w <= L`，则 L 可行。

```cpp
// 预处理：len[i] 为第 i 条路径长度，maxLen 为最大长度
// pw[x] 为边 (fa[x], x) 的权值
int diff[N], cnt, mxw;

void dfs(int u, int fa) {
    for (int i = 0; i < (int)g[u].size(); ++i) {
        int v = g[u][i].to;
        if (v == fa) continue;
        dfs(v, u);
        diff[u] += diff[v];
    }
    if (fa && diff[u] == cnt) mxw = max(mxw, pw[u]);
}

bool check(int L) {
    cnt = 0; mxw = 0;
    memset(diff, 0, sizeof(diff));
    for (int i = 1; i <= m; ++i) {
        if (len[i] <= L) continue;
        int u = pu[i], v = pv[i], w = lca(u, v);
        diff[u]++; diff[v]++; diff[w] -= 2;
        ++cnt;
    }
    if (cnt == 0) return true;          // 没有超长路径
    dfs(1, 0);
    return maxLen - mxw <= L;
}
```

主程序只做二分：

```cpp
int lo = 0, hi = maxLen;
while (lo < hi) {
    int mid = (lo + hi) / 2;
    if (check(mid)) hi = mid;
    else lo = mid + 1;
}
printf("%d\n", lo);
```

**复杂度**：预处理 LCA O(n log n)，每次 check O(n + m log n)，二分 O(log W) 次，总 O((n + m log n) log W)，W 为路径长度上界。

> 💡 `dfs` 里必须先递归儿子、再合并 `diff`，否则子树标记还没上传。`diff[u] == cnt` 说明所有超长路径都经过 u 与父亲之间的边。

## ⚠️ 常见错误

1. **点差分和边差分混用**：点差分是 `d[lca]--, d[fa[lca]]--`，边差分是 `d[lca] -= 2`。写错一个符号，答案会整体偏移。
2. **`d[fa[lca]]` 越界**：LCA 为根时 `fa[lca] = 0`，数组要允许下标 0，或者特判。
3. **累加顺序反了**：必须先递归儿子，再把儿子的 `d` 加到父亲；先加自己再递归，子树标记不会上传。
4. **边差分统计了根**：`d[root]` 对应"不存在的父亲边"，不能计入答案。
5. **路径首尾相接时端点重复**：如果题目统计"访问次数"，相邻路径的公共端点可能被算两次，要按题意减掉一次。
6. **多测不清 `diff`**：上一组的覆盖次数会残留，`check` 结果全错。
7. **二分边界写错**：`hi` 要取 `maxLen`，`lo` 取 0；`check` 单调，满足"L 越大越容易"。

## 🧠 本章小结

```
点差分（路径上的点 +1）：
  d[u]++; d[v]++; d[lca]--; d[fa[lca]]--;
  累加后 d[x] = 点 x 的覆盖次数

边差分（路径上的边 +1）：
  d[u]++; d[v]++; d[lca] -= 2;
  累加后 d[x] = 边 (fa[x], x) 的覆盖次数

累加：dfs 回溯时 d[u] += d[v]，必须自底向上
lca 为根时，d[0] 当垃圾桶，不影响答案

子树和：dfn 转区间 + 树状数组
路径加 + 离线：树上差分
路径加 + 在线带修：树链剖分
```

判断口诀：**点差分四个标记，边差分三个标记；看到"运输计划"想二分 + 边差分。**
