# 第 77 章  树上差分与子树和

> 🏗️ **前情回顾**：上册第 35 章的差分把"区间加"变成两个端点；第 76 章学会了 LCA。两者一合，就能把"路径加"压到四个点上。
## 🎯 本章目标
- 记住点差分、边差分两套公式
- 会自底向上累加还原答案
- 用 DFS 序 + 树状数组做子树和
## 🌱 故事：给路上的每盏灯计数
> 一条路径上的灯都要 +1，逐盏走，10^5 次询问就废了。差分只在"入口"和"出口"记账，最后从叶子往根结账。
## 🧱 知识讲解
### 77.1  点差分
```cpp
// 路径 u→v 上每个点点权 +1
d[u]++; d[v]++; d[lca]--; d[fa[lca]]--;
// 还原：dfs 回溯时 d[u] += Σ d[v]
```
`lca` 被加了两次，减一次；它父亲被多减一次，再补回来。
### 77.2  边差分
```cpp
d[u]++; d[v]++; d[lca] -= 2;
// 还原后 d[v] = 边 (fa[v], v) 被覆盖的次数
```
边权挂给"下面的点"，累加时不要把根算进去。
### 77.3  子树和
```cpp
add(dfn[x], k);                  // 单点加
sum(out[u]) - sum(dfn[u] - 1);   // 子树查
```
子树加、单点查反过来用差分；子树加、子树和用线段树维护。
## 💻 例题
**例 1**：P3128 Max Flow——读入 k 条路径，每条做四次点差分，最后一遍 DFS 累加，取最大值。
**例 2**：P3258 松鼠的新家——相邻两点路径做差分；起点被重复计数，最后把 `a[2..n]` 各减 1。
## ⚠️ 常见坑
1. 点差分和边差分混用（`--` 还是 `-=2`）
2. `fa[lca]` 可能是 0，数组要容得下
3. 累加必须自底向上，先递归儿子再合并
