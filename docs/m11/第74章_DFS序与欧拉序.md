# 第 74 章  DFS 序与欧拉序

> 🏗️ **前情回顾**：第 44 章写过递归，第 66 章用 DFS 遍历过图。当时 `vis` 只用来防重复访问；这一章给每个点记一个"到达时间"，把树的结构变成一段段区间。
## 🎯 本章目标
- 用 `dfn/out` 把子树映射成连续区间
- 会写欧拉序，并用 ST 表求 LCA
- 把子树修改/查询搬到树状数组、线段树上
## 🌱 故事：点名册上的一个班
> 校庆拍照，每个班站成一列。校长问"高二(3)班从第几个到第几个"，只要名单按进校顺序排好，一个班就是**连续的一段**。DFS 序就是这个"进校顺序"。

## 🧱 知识讲解
### 74.1  dfn 与 out
```cpp
int dfn[N], out[N], timer;
void dfs(int u, int fa) {
    dfn[u] = ++timer;
    for (int v : g[u]) if (v != fa) dfs(v, u);
    out[u] = timer;            // 子树扫完，timer 停在最后一个后代
}
```
子树 u 的点集恰为 `[dfn[u], out[u]]`，长度 `out[u]-dfn[u]+1` 就是子树大小。
### 74.2  欧拉序与 RMQ
```cpp
void edfs(int u, int fa) {
    euler[++tot] = u;
    for (int v : g[u]) if (v != fa)
        dep[v] = dep[u] + 1, edfs(v, u), euler[++tot] = u;
}
```
序列长 `2n-1`。`LCA(u,v)` 就是 `dfn[u]..dfn[v]` 之间深度最小的点，ST 表 O(1) 查询。
### 74.3  子树操作变区间操作
```cpp
add(dfn[u], k); add(out[u] + 1, -k);   // 子树整体加 k
query(dfn[x]);                          // 单点查 = 前缀和
```
配合线段树还能做"子树加、子树和"；`dfn` 就是序列下标，一切区间工具都能直接用。
## 💻 例题
**例 1**：P3605 Promotion Counting——按能力值降序处理，树状数组在 `dfn` 上单点加，答案取 `[dfn[u]+1, out[u]]` 的区间和。
**例 2**：P2982 Grazing Patterns——信息挂在 `dfn` 上，线段树维护区间和；子树询问就是 `[dfn[u], out[u]]` 的区间查询，O(log n)。
## ⚠️ 常见坑
1. `dfn` 从 0 还是 1 开始，要和树状数组下标统一
2. 欧拉序长 `2n-1`，数组开 `2*N`
3. RMQ 比较的是深度，不是点编号
4. 多测忘了清 `timer` 和 `tot`
