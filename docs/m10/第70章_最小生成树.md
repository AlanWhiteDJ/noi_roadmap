## 📖 故事引入

镇上要铺光纤，把 8 个村子都连上。施工队量出每两个村子之间拉线的费用，共 28 条候选线路。

小元发现：8 个村子只需 7 条线就能全连通，多一条就成环、纯属浪费。问题于是变成：从 28 条里挑 7 条，让 8 个点连通且总费用最小。

他想到一个朴素办法：先把最便宜的线拉上，再看下一条；若这条线连的两个村子**已经连通**，拉它就成环，跳过；否则拉上。从小到大扫一遍，正好挑出 7 条。

这就是 Kruskal。它背后的道理只有一句话：**全局最便宜的边，只要不成环，就一定可以选。**

## 🧱 知识讲解

### 70.1  生成树与最小生成树

**生成树**：连通无向图的一个子图，包含全部 $n$ 个点、恰好 $n-1$ 条边，且连通（等价于无环）。

三个等价说法：$n-1$ 条边且连通；$n-1$ 条边且无环；连通且无环。

**最小生成树（MST）**：所有生成树中边权和最小的那棵。

基本性质：

- 图连通才有生成树；不连通时每个连通块各有一棵，合称**最小生成森林**。
- 边权全为正时，MST 一定不含自环，重边只可能选最小那条。
- **MST 总权唯一，形态不一定唯一**（等权边可互换）。

### 70.2  切割性质与环性质

这两个性质是全部 MST 算法的正确性基础。

**切割性质**：把点集分成两个非空部分 $S$ 和 $V\setminus S$，横跨这个切割的边里，权值最小的那条一定属于**某棵** MST。

**环性质**：对图中任意一个环，环上权值最大的边一定**不属于**某棵 MST（严格最大时，不属于任何 MST）。

Kruskal 中，已选边把点分成若干连通块，下一条不成环的最小边正是某个切割上的最小边，故选它安全；Prim 则每次直接取横跨"已选/未选"切割的最小边。

### 70.3  Kruskal

步骤只有三步：

1. 所有边按权值从小到大排序；
2. 依次取出每条边 $(u,v,w)$；
3. 若 $u,v$ 不在同一并查集，合并并累加答案；否则跳过。

```cpp
struct Edge {
    int u, v, w;
};
Edge e[M];

bool cmp(const Edge &a, const Edge &b) {
    return a.w < b.w;
}

int fa[N];
int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}

int kruskal() {
    for (int i = 1; i <= n; i++) fa[i] = i;
    sort(e + 1, e + m + 1, cmp);
    int ans = 0, cnt = 0;
    for (int i = 1; i <= m; i++) {
        int ru = find(e[i].u), rv = find(e[i].v);
        if (ru == rv) continue;          // 成环，跳过
        fa[ru] = rv;
        ans += e[i].w;
        cnt++;
        if (cnt == n - 1) break;         // 已够 n-1 条
    }
    return cnt == n - 1 ? ans : -1;      // -1 表示不连通
}
```

- 复杂度 $O(m\log m)$：排序加近似 $O(m\alpha(n))$ 的并查集。
- 适合**稀疏图**；边数 $10^6$ 也能跑。
- 判断连通：最后 `cnt < n-1` 说明图不连通。

### 70.4  Prim

从任意点开始，维护"已选集合"，每次加入一条连接已选与未选的最小边。

暴力版 $O(n^2)$，适合稠密图（甚至 $n=5000$、完全图）：

```cpp
int dis[N];                 // dis[v]：v 到已选集合的最小边权
bool vis[N];

int prim() {
    for (int i = 1; i <= n; i++) dis[i] = INF;
    dis[1] = 0;
    int ans = 0;
    for (int it = 1; it <= n; it++) {
        int u = 0;
        for (int i = 1; i <= n; i++)
            if (!vis[i] && (u == 0 || dis[i] < dis[u])) u = i;
        if (u == 0 || dis[u] == INF) return -1;   // 不连通
        vis[u] = true;
        ans += dis[u];
        for (int v = 1; v <= n; v++)
            if (!vis[v] && g[u][v] < dis[v]) dis[v] = g[u][v];
    }
    return ans;
}
```

堆优化版把"找最小 dis"交给优先队列，$O(m\log n)$，写法与 Dijkstra 几乎一样——区别是 `dis[v]` 存"到已选集合的最小边权"，而不是"到起点的距离"。

### 70.5  最小生成森林

图不连通时，Kruskal 自然得到森林。此时：

- 若题目问"每个连通块各求 MST 的权值和"，直接输出 `ans`；
- 若题目要求全图连通，输出无解（如 `-1` 或 `orz`）。

用并查集统计连通块个数也很方便：初始 $n$ 块，每成功合并一条边减一。

### 70.6  次小生成树（选讲）

**次小生成树**是权值第二小的生成树，分非严格（可与 MST 等权）和严格两种。做法：先求 MST，枚举每条非树边 $(u,v,w)$，加入后成环，环上最大树边为 $mx$，用 $ans - mx + w$ 更新。$mx$ 用倍增 LCA 求，总复杂度 $O(m\log n)$。

> 💡 若只求"次小生成树的权值"，枚举 + 暴力爬链在 $n \le 1000$ 时也能过。

### 70.7  常见变形

| 题意 | 转化 |
|------|------|
| 总代价最小 | 标准 MST |
| 最大边权尽量小（瓶颈） | MST 就是最小瓶颈生成树 |
| 总代价最大 | 边权取负，或从大到小排序 |
| 必须包含某条边 | 先并上该边，再跑 Kruskal |
| 删掉一条边后仍连通 | 求 MST 后看该边是否桥 |

## 💻 例题

### 例 1  洛谷 P3366 最小生成树（模板）

**题意**：$n$ 点 $m$ 条无向边，求 MST 的边权和；不连通输出 `orz`。

**思路**：Kruskal 模板。排序后逐条尝试，并查集判环，累计 $n-1$ 条即停。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 5005, M = 200005;
int n, m, fa[N];

struct Edge {
    int u, v, w;
} e[M];

bool cmp(const Edge &a, const Edge &b) {
    return a.w < b.w;
}

int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}

int main() {
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= m; i++)
        scanf("%d%d%d", &e[i].u, &e[i].v, &e[i].w);
    for (int i = 1; i <= n; i++) fa[i] = i;
    sort(e + 1, e + m + 1, cmp);

    long long ans = 0;
    int cnt = 0;
    for (int i = 1; i <= m && cnt < n - 1; i++) {
        int ru = find(e[i].u), rv = find(e[i].v);
        if (ru == rv) continue;
        fa[ru] = rv;
        ans += e[i].w;
        cnt++;
    }
    if (cnt < n - 1) puts("orz");
    else printf("%lld\n", ans);
    return 0;
}
```

### 例 2  洛谷 P1546 最短网络 Agri-Net

**题意**：$n \le 100$，给出邻接矩阵，求 MST。

**思路**：点少边密（完全图），Prim 的 $O(n^2)$ 更合适，不必存边。`0` 表示无边，按 `INF` 处理。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 105, INF = 0x3f3f3f3f;
int n, g[N][N], dis[N];
bool vis[N];

int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++) {
            scanf("%d", &g[i][j]);
            if (i != j && g[i][j] == 0) g[i][j] = INF;
        }

    for (int i = 1; i <= n; i++) dis[i] = INF;
    dis[1] = 0;
    int ans = 0;
    for (int it = 1; it <= n; it++) {
        int u = 0;
        for (int i = 1; i <= n; i++)
            if (!vis[i] && (u == 0 || dis[i] < dis[u])) u = i;
        vis[u] = true;
        ans += dis[u];
        for (int v = 1; v <= n; v++)
            if (!vis[v] && g[u][v] < dis[v]) dis[v] = g[u][v];
    }
    printf("%d\n", ans);
    return 0;
}
```

### 例 3  洛谷 P2330 繁忙的都市

**题意**：$n$ 个路口、$m$ 条道路，选出若干条使全图连通，要求**最大边权尽量小**；输出选了几条、最大边权是多少。

**思路**：MST 是最小瓶颈生成树——所有生成树中，MST 的最大边权最小。所以直接跑 Kruskal，答案就是 $n-1$ 和最后选中的那条边的权值。

```cpp
int cnt = 0, mx = 0;
for (int i = 1; i <= m && cnt < n - 1; i++) {
    int ru = find(e[i].u), rv = find(e[i].v);
    if (ru == rv) continue;
    fa[ru] = rv;
    cnt++;
    mx = e[i].w;                    // 排序后最后一条即最大
}
printf("%d %d\n", n - 1, mx);
```

> 💡 "最大边权最小"不一定非要 MST：也可以二分答案 + 并查集判连通，复杂度 $O(m\log W)$。两种都要会。

---

## ⚠️ 常见错误

1. **并查集忘初始化**。漏写 `fa[i]=i`，`find` 会乱跑甚至死循环。
2. **路径压缩写错**。`fa[x] = find(fa[x])` 的赋值不能丢。
3. **Kruskal 排序用 `>`**，结果求成最大生成树。
4. **`break` 条件写错**。应在 `cnt == n-1` 时停，不是取满 $m$ 条。
5. **不连通却直接输出 `ans`**。必须判 `cnt < n-1`。
6. **无向边只存一次**。Kruskal 存一条就够（并查集无向），Prim 的矩阵要对称。
7. **边权相同就以为 MST 唯一**。总权唯一，方案不唯一，计数题要特别小心。

## 🧠 本章小结

```
生成树：n 个点、n-1 条边、连通无环
MST：边权和最小的生成树；总权唯一，形态可能不唯一

切割性质：横跨切割的最小边一定属于某棵 MST
环性质：环上最大边一定不属于某棵 MST

Kruskal：排序 + 并查集判环，O(m log m)，稀疏图
Prim：每次加"离已选集合最近的边"
  暴力 O(n²) 稠密图；堆优化 O(m log n)
不连通：得到最小生成森林，按题意输出部分和或无解

瓶颈生成树 = MST；次小生成树：枚举非树边 + 环上最大边
```
