# 第 70 章  最小生成树

---

> 🏗️ **前情回顾**：最短路是"两点之间怎么走最近"；最小生成树是"把所有点连起来，总代价最小"。

## 🎯 本章目标

- 写出 Kruskal 与 Prim
- 理解切割性质
- 求最小生成森林
- 处理次小生成树（选讲）

## 🧱 知识讲解

### 70.1  Kruskal

按边权从小到大排序，用并查集判断是否成环：

```cpp
sort(e + 1, e + m + 1, [](Edge a, Edge b){ return a.w < b.w; });
for (int i = 1; i <= m; i++) {
    int u = find(e[i].u), v = find(e[i].v);
    if (u != v) { fa[u] = v; ans += e[i].w; cnt++; }
}
```

复杂度 O(m log m)，适合稀疏图。

### 70.2  Prim

从任意点开始，每次选一条连接"已选集合"和"未选集合"的最小边：

- 暴力 O(n²)
- 堆优化 O(m log n)，适合稠密图

### 70.3  最小生成森林

图不连通时，对每个连通块各求一棵 MST，得到森林。

### 70.4  切割性质

任意切割中，横跨切割的最小边一定属于某棵 MST。这是 Kruskal/Prim 正确性的基础。

## 💻 例题

**例 1**：洛谷 P3366 最小生成树模板。

**例 2**：洛谷 P1546 最短网络 Agri-Net（Prim）。

## ⚠️ 常见坑

1. 边权相同导致方案不唯一，但总权唯一
2. 图不连通时输出森林，不是无解
3. Kruskal 的并查集忘记初始化
4. 重边/自环
