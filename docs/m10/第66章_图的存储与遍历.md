## 🧱 知识讲解

### 66.1  图的基本概念

图 $G=(V,E)$ 由点集 $V$ 和边集 $E$ 组成。记 $n=|V|$，$m=|E|$。

| 概念 | 含义 |
|------|------|
| 无向图 | 边没有方向，`u-v` 和 `v-u` 是同一条边 |
| 有向图 | 边有方向，`u→v` 不等于 `v→u` |
| 度 | 与该点相连的边数；有向图分入度和出度 |
| 路径 | 点的序列，相邻两点之间有边 |
| 简单路径 | 不重复经过同一个点的路径 |
| 环 | 起点和终点相同的路径 |
| 连通 | 两点之间存在路径 |
| 连通块 | 极大的连通点集，块与块之间没有边 |
| 重边 / 自环 | 两点间多条边 / 自己连自己 |

一个立刻能用上的结论：

- 无向图中所有点的度数之和等于 $2m$；有向图中所有点的入度之和 = 出度之和 = $m$。

> 💡 读题先问三句话：**有向还是无向？带不带边权？有没有重边自环？** 这三问决定了建图代码怎么写。

### 66.2  邻接矩阵

用二维数组 `g[u][v]` 表示 u 到 v 是否有边（或边权）。

```cpp
const int N = 1010;
const int INF = 0x3f3f3f3f;
int g[N][N];              // 0 表示无边；带权图用 INF 表示无边

// 无向图加边
g[u][v] = w;
g[v][u] = w;

// 判断 u、v 之间有没有边：O(1)
if (g[u][v] < INF) { /* 有边 */ }
```

- 空间 $O(n^2)$；查边 $O(1)$，枚举邻居 $O(n)$。适合 $n \le 1000$ 的**稠密图**或频繁查边的题（如 Floyd）；$n=10^5$ 时要 40 GB，直接放弃。

### 66.3  邻接表

只存每个点真正连出去的边，这是竞赛里最常用的写法。

```cpp
const int N = 100005;
vector<int> g[N];         // 无权图：g[u] 存 u 的所有邻居

g[u].push_back(v);
g[v].push_back(u);        // 无向图要成对加

// 带权图：pair<终点, 边权>
vector<pair<int,int> > gw[N];
gw[u].push_back(make_pair(v, w));
```

- 空间 $O(n+m)$，枚举 u 的邻居 $O(deg(u))$，总遍历 $O(n+m)$。
- 缺点：查两点是否有边要扫 `g[u]`，最坏 $O(n)$。常数小、写法短，**除非卡常或需要边编号，优先用它**。

### 66.4  链式前向星

用数组模拟链表，把同一个点出发的边串起来。它在需要"边的编号"（判重边、求割边、网络流反向边）时特别方便。

```cpp
const int N = 100005, M = 200005;
int head[N], to[M], nxt[M], w[M], ecnt = 1;
// ecnt 从 1 开始，无向图正反两条边编号为 2k 和 2k+1，可用 e^1 取反向边

void add(int u, int v, int ww) {
    to[++ecnt] = v;
    w[ecnt] = ww;
    nxt[ecnt] = head[u];
    head[u] = ecnt;
}

// 遍历 u 的所有出边
for (int e = head[u]; e; e = nxt[e]) {
    int v = to[e], ww = w[e];
    // ...
}
```

> ⚠️ `head` 要初始化为 0，`ecnt` 从 1 开始，这样 `e != 0` 就能当循环结束条件。

### 66.5  DFS 遍历

DFS 的核心是"一条路走到黑，走不动再回头"。递归写法最直观：

```cpp
bool vis[N];

void dfs(int u) {
    vis[u] = true;
    // 这里处理进入 u 的动作，例如输出、计数
    for (int i = 0; i < (int)g[u].size(); i++) {
        int v = g[u][i];
        if (!vis[v]) dfs(v);
    }
}
```

两件事必须做对：**进入时立刻标记**，否则环上会无限递归；**标记的是点**，无向图靠它避免从父亲走回头。另外递归深度可能达到 $n$，一条 $10^5$ 点的链会爆栈，此时改手工栈或 BFS。

DFS 还能顺便求**时间戳** `dfn[u]`（第几个被访问），它后面会被 Tarjan 反复用到：

```cpp
int timer = 0, dfn[N];
void dfs(int u) {
    dfn[u] = ++timer;
    for (int v : g[u]) if (!dfn[v]) dfs(v);
}
```

### 66.6  BFS 遍历

BFS 用队列一层一层向外扩，是"水波纹"式的遍历：

```cpp
int dis[N];               // 无权图的最短边数

void bfs(int s) {
    memset(dis, -1, sizeof(dis));
    queue<int> q;
    q.push(s);
    dis[s] = 0;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int i = 0; i < (int)g[u].size(); i++) {
            int v = g[u][i];
            if (dis[v] == -1) {      // 没访问过
                dis[v] = dis[u] + 1;
                q.push(v);           // 入队时就已标记
            }
        }
    }
}
```

**为什么能求无权最短路？** 队列保证"距离为 $d$ 的点全部处理完，才处理距离 $d+1$ 的点"，所以第一次被访问时一定走了最少边数。也正因如此必须**入队即标记**：等出队再标记，同一个点会被多个邻居重复塞进队列。

### 66.7  连通块与遍历序

对每个尚未访问的点启动一次 DFS/BFS，就得到一个连通块：

```cpp
int blocks = 0;
for (int i = 1; i <= n; i++) {
    if (!vis[i]) {
        blocks++;
        dfs(i);        // 这一次 dfs 会把整个连通块标记完
    }
}
```

无向图判环：DFS 时遇到**已访问且不是父亲**的点就有环。有重边时"父亲"判断会失效，要改记入边编号。

### 66.8  三种存法怎么选

一句话记：**点少边密用矩阵，点多边稀用邻接表，要边编号或卡常用前向星；网格图直接枚举方向，不必建边。**

## 💻 例题

### 例 1  洛谷 P5318 查找文献

**题意**：给一张 $n$ 点 $m$ 边的有向图，从 1 号点出发，按"邻居编号从小到大"的顺序做 DFS 和 BFS，分别输出访问序列。

**思路**：建邻接表后把每个 `g[i]` 排序，再跑两遍遍历，第二遍前清空 `vis`。排序保证顺序符合要求，这是本题唯一的陷阱。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int n, m;
vector<int> g[N];
bool vis[N];

void dfs(int u) {
    vis[u] = true;
    printf("%d ", u);
    for (int i = 0; i < (int)g[u].size(); i++) {
        int v = g[u][i];
        if (!vis[v]) dfs(v);
    }
}

int main() {
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= m; i++) {
        int u, v;
        scanf("%d%d", &u, &v);
        g[u].push_back(v);          // 有向图，只加一条
    }
    for (int i = 1; i <= n; i++) sort(g[i].begin(), g[i].end());

    dfs(1);
    printf("\n");

    memset(vis, 0, sizeof(vis));
    queue<int> q;
    q.push(1);
    vis[1] = true;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        printf("%d ", u);
        for (int i = 0; i < (int)g[u].size(); i++) {
            int v = g[u][i];
            if (!vis[v]) {
                vis[v] = true;
                q.push(v);
            }
        }
    }
    return 0;
}
```

复杂度 $O(m \log m + n + m)$，瓶颈在排序。

### 例 2  洛谷 P3916 图的遍历

**题意**：每个点 u 求"从 u 出发能到达的编号最大的点"。

**思路**：正向做，每个点都要搜一遍，$O(n(n+m))$ 必超时。反过来想：编号最大的点会"罩住"所有能到达它的点。于是**建反向图**，从 $n$ 到 1 依次出发 BFS，未被标记的点答案就是当前起点。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int n, m, ans[N];
vector<int> rg[N];              // 反向图

int main() {
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= m; i++) {
        int u, v;
        scanf("%d%d", &u, &v);
        rg[v].push_back(u);     // 原边 u->v，反图存 v->u
    }
    for (int i = n; i >= 1; i--) {
        if (ans[i]) continue;
        queue<int> q;
        q.push(i);
        ans[i] = i;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int j = 0; j < (int)rg[u].size(); j++) {
                int v = rg[u][j];
                if (!ans[v]) {
                    ans[v] = i;
                    q.push(v);
                }
            }
        }
    }
    for (int i = 1; i <= n; i++) printf("%d ", ans[i]);
    return 0;
}
```

每个点最多入队一次，总复杂度 $O(n+m)$。

> 🧠 **反向建图**：求"所有点到一个终点"的距离，等于在反图上求"一个起点到所有点"。

### 例 3  洛谷 P1596 Lake Counting

**题意**：$n \times m$ 的网格，`W` 是水，`.` 是陆地，八方向相连的水算同一片湖，求湖的数量。

**思路**：把每个格子看成点，八方向相邻且有水就连边。扫描所有格子，遇到没访问过的 `W` 就答案加一，并从它开始 DFS 淹掉整片湖。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m;
char mp[105][105];
int dx[8] = {-1, -1, -1, 0, 0, 1, 1, 1};
int dy[8] = {-1, 0, 1, -1, 1, -1, 0, 1};

void dfs(int x, int y) {
    mp[x][y] = '.';                       // 访问过就改成陆地
    for (int k = 0; k < 8; k++) {
        int nx = x + dx[k], ny = y + dy[k];
        if (nx >= 1 && nx <= n && ny >= 1 && ny <= m && mp[nx][ny] == 'W')
            dfs(nx, ny);
    }
}

int main() {
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= n; i++) scanf("%s", mp[i] + 1);
    int ans = 0;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            if (mp[i][j] == 'W') {
                ans++;
                dfs(i, j);
            }
    printf("%d\n", ans);
    return 0;
}
```

网格图不必真的建边，用方向数组枚举邻居即可，常数更小。

## ⚠️ 常见错误

1. **无向图只加一条边**。忘了 `add(v,u)`，遍历时"有去无回"。
2. **BFS 出队才标记**。同一个点被多个邻居重复入队，队列爆炸，复杂度退化。
3. **DFS 忘记标记起点**。如果外层循环再调用一次，会重复统计。
4. **多组数据不清空**。`vis`、`head`、`ecnt`、邻接表都要清。
5. **数组开小**。无向图边要开两倍，`to/nxt` 至少 `2m`。
6. **$n=10^5$ 还用邻接矩阵**。直接 MLE。
7. **以为 BFS 能求带权最短路**。BFS 只在边权全相等时正确。

## 🧠 本章小结

```
图的存法：
  邻接矩阵  g[u][v]      查边 O(1)，空间 O(n²)，稠密图/Floyd
  邻接表    vector<int>  空间 O(n+m)，最常用
  前向星    head/to/nxt  可拿边编号，卡常/割边/网络流

DFS：标记 → 递归邻居；求连通块、时间戳、环
BFS：起点入队并标记 → 取队头 → 未访问邻居入队并标记
     第一次到达即最少边数

连通块：外层扫一遍，未访问就启动一次遍历并计数
反向建图：把"多点到一点"变成"一点到多点"
```
