> 🏗️ **前情回顾**：树是"没有环的图"。这一章开始，我们正式进入图论：点与点之间可以有任意多条边，也可以有环。

## 🎯 本章目标

## 🧱 知识讲解

### 66.1  图的存储

**邻接矩阵**：`g[u][v]` 表示 u 到 v 有没有边/边权。适合点数 ≤ 1000 的稠密图。

**邻接表**（最常用）：

```cpp
vector<int> g[N];
g[u].push_back(v);
g[v].push_back(u);   // 无向图
```

带权图用 `vector<pair<int,int>>`。

### 66.2  DFS 遍历

```cpp
void dfs(int u) {
    vis[u] = 1;
    for (int v : g[u])
        if (!vis[v]) dfs(v);
}
```

DFS 适合：连通块、环检测、DFS 序、割点/桥。

### 66.3  BFS 遍历

```cpp
queue<int> q;
q.push(s); vis[s] = 1;
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : g[u]) if (!vis[v]) {
        vis[v] = 1; dis[v] = dis[u] + 1; q.push(v);
    }
}
```

BFS 适合：无权图最短路、分层图、连通块。

### 66.4  连通块与二分图

- 连通块：对每个未访问点做一次 DFS/BFS，计数
- 二分图：BFS/DFS 染色，相邻点颜色不同

## 💻 例题

**例 2**：洛谷 P3916 图的遍历——反向建图 + 记忆化。

## ⚠️ 常见坑

1. 无向图建边忘记成对
2. 重边、自环要按题意处理
3. BFS 入队时就要标记，否则会重复入队
4. 点数 1e5 时不能用邻接矩阵
