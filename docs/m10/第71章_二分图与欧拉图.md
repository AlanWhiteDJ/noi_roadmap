## 📖 故事引入

学校要办辩论赛，两队之间要安排若干场对抗。有些选手之间"有过节"，不能分在同一队。小元画了张图：选手是点，"有过节"是边。他要把点分成两队，使每条边的两端都分属不同队。

试了几次，他发现有一组三个人两两都有过节——无论怎么分，总有一对会落到同一边。这三个人恰好构成一个三角形（奇环）。他意识到：**能分成两队，等价于图里没有奇环。**

另一边，校庆要设计一条"一笔画"路线：每条路恰好走一次，最后回到起点。有的图案可以，有的怎么试都不行。欧拉在三百年前就给出了判据，只看每个点的度数。

两个问题看起来毫不相干，却都只需要一次 DFS。

## 🧱 知识讲解

### 71.1  二分图

若能把点集分成 $X,Y$ 两部分，使**每条边的两个端点分别属于 $X$ 和 $Y$**，这个图就是二分图（偶图）。

三个等价说法：

- 图是二分图；
- 图中不含长度为奇数的环；
- 图可以用两种颜色染色，使相邻点颜色不同。

> 💡 自环一定是奇环（长度 1），所以有自环的图一定不是二分图。

### 71.2  染色判定

从每个未染色的点出发 BFS/DFS，把它染成 1，邻居染成 -1；若遇到已染色且颜色相同的邻居，就不是二分图。

```cpp
vector<int> g[N];
int color[N];              // 0 未染色，1 / -1 两种颜色

bool bfs(int s) {
    queue<int> q;
    color[s] = 1;
    q.push(s);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int i = 0; i < (int)g[u].size(); i++) {
            int v = g[u][i];
            if (color[v] == 0) {
                color[v] = -color[u];
                q.push(v);
            } else if (color[v] == color[u]) {
                return false;          // 冲突
            }
        }
    }
    return true;
}
```

外层必须对所有点扫一遍：

```cpp
bool ok = true;
for (int i = 1; i <= n; i++)
    if (color[i] == 0 && !bfs(i)) { ok = false; break; }
```

复杂度 $O(n+m)$。孤立点单独染成 1 即可，不影响结论。

### 71.3  匈牙利算法（最大匹配）

**匹配**是一组边，任意两条不共端点。二分图最大匹配是很多"分配"问题的模型：任务分给人、课分给教室、多米诺骨牌覆盖棋盘。

核心概念是**增广路**：从左边一个未匹配点出发，交替走"非匹配边—匹配边—非匹配边……"，最后到达右边一个未匹配点。把这条路上的匹配状态取反，匹配数就加一。匈牙利算法就是对每个左部点尝试找一条增广路。

```cpp
int match[N];              // 右部点匹配的左部点，0 表示未匹配
int vis[N], tim = 0;

bool dfs(int u) {
    for (int i = 0; i < (int)g[u].size(); i++) {
        int v = g[u][i];
        if (vis[v] == tim) continue;      // 本轮已试过
        vis[v] = tim;
        if (match[v] == 0 || dfs(match[v])) {
            match[v] = u;
            return true;
        }
    }
    return false;
}

// 主过程
int ans = 0;
for (int u = 1; u <= n; u++) {
    tim++;                             // 用时间戳代替清空 vis
    if (dfs(u)) ans++;
}
```

复杂度 $O(VE)$，$n \le 1000$、$m \le 10^5$ 一般能过。`tim` 时间戳是常用技巧，避免每轮 `memset`。

### 71.4  欧拉道路与欧拉回路

- **欧拉回路**：经过每条边恰好一次，最后回到起点。
- **欧拉道路**：经过每条边恰好一次，起点终点可以不同。

判定（先保证**所有有边的点连通**；有向图指忽略方向后弱连通）：

| 类型 | 无向图 | 有向图 |
|------|--------|--------|
| 欧拉回路 | 所有点度数为偶 | 所有点入度 = 出度 |
| 欧拉道路 | 恰有 0 或 2 个奇度点 | 恰有一个点出度 = 入度+1（起点）、一个点入度 = 出度+1（终点），其余相等 |

两个常见误区：

1. **只判度数不判连通**。两个分离的环，每个点度数都是 2，却画不出一笔画。
2. **把孤立点算进连通性**。孤立点没有边，不影响欧拉路径，判定连通时只考虑有边的点。

### 71.5  Hierholzer 算法

思路：从起点出发，随便走一条未走过的边，删掉它，继续走；走不动时回溯，把点压栈。最后栈的逆序就是欧拉路径。

```cpp
void dfs(int u) {
    for (int v = 1; v <= n; v++) {
        if (g[u][v] > 0) {          // 邻接矩阵，支持重边
            g[u][v]--;
            g[v][u]--;              // 有向图只减 g[u][v]
            dfs(v);
        }
    }
    st.push_back(u);                // 回溯时入栈
}
// 输出时倒序
```

为什么倒序？因为"走不动的点"其实是路径的末端，先被压栈；起点最后才压栈。

**字典序最小**：把邻居从小到大枚举，且选对起点，得到的即是字典序最小的欧拉路径。

**起点怎么选**：

- 有奇度点：选编号最小的奇度点；
- 全是偶度点：选编号最小的有边的点。

## 💻 例题

### 例 1  洛谷 P1330 封锁阳光大学

**题意**：$n$ 点 $m$ 边无向图，选最少的点，使每条边的两个端点中**恰好有一个**被选；若无法做到输出 `Impossible`。

**思路**：每条边恰有一个端点被选，等价于把点染成"选/不选"两色且相邻不同——正是二分图染色。每个连通块独立，取两种颜色中点数较少的一边。图不是二分图则无解。
```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 10005;
int n, m, color[N], cnt[3];
vector<int> g[N];
queue<int> q;

bool bfs(int s) {
    color[s] = 1;
    cnt[1] = cnt[2] = 0;
    q.push(s);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        cnt[color[u]]++;
        for (int i = 0; i < (int)g[u].size(); i++) {
            int v = g[u][i];
            if (!color[v]) {
                color[v] = 3 - color[u];
                q.push(v);
            } else if (color[v] == color[u]) {
                return false;
            }
        }
    }
    return true;
}

int main() {
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= m; i++) {
        int u, v;
        scanf("%d%d", &u, &v);
        g[u].push_back(v);
        g[v].push_back(u);
    }
    int ans = 0;
    for (int i = 1; i <= n; i++) {
        if (color[i]) continue;
        if (!bfs(i)) { puts("Impossible"); return 0; }
        ans += min(cnt[1], cnt[2]);
    }
    printf("%d\n", ans);
    return 0;
}
```

> ⚠️ `cnt` 必须在每次 BFS 开始时清零，否则会把上一个连通块的点数带进来。

### 例 2  洛谷 P2731 骑马修栅栏

**题意**：$m$ 条栅栏（边），结点编号 $1 \sim 500$，求一条经过每条边恰好一次的路径，要求字典序最小。

**思路**：欧拉路径。先统计度数，选起点（最小奇度点，否则最小有边的点）；用邻接矩阵存重边，Hierholzer 从小到大枚举邻居，回溯时记录点，最后倒序输出。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 505;
int m, deg[N], g[N][N];
vector<int> ans;

void dfs(int u) {
    for (int v = 1; v <= 500; v++) {
        if (g[u][v]) {
            g[u][v]--;
            g[v][u]--;
            dfs(v);
        }
    }
    ans.push_back(u);
}

int main() {
    scanf("%d", &m);
    for (int i = 1; i <= m; i++) {
        int u, v;
        scanf("%d%d", &u, &v);
        g[u][v]++;
        g[v][u]++;
        deg[u]++;
        deg[v]++;
    }
    int start = 0;
    for (int i = 1; i <= 500; i++)
        if (deg[i] % 2 == 1) { start = i; break; }
    if (start == 0)
        for (int i = 1; i <= 500; i++)
            if (deg[i] > 0) { start = i; break; }

    dfs(start);
    for (int i = (int)ans.size() - 1; i >= 0; i--)
        printf("%d\n", ans[i]);
    return 0;
}
```

从最小的奇度点出发、邻居从小到大枚举，两点合起来保证字典序最小。

### 例 3  洛谷 P3386 二分图最大匹配

**题意**：左右各 $n,m$ 个点，$e$ 条边，求最大匹配数。

**思路**：匈牙利模板。对每个左部点清一次访问标记（用时间戳），尝试找增广路。

```cpp
const int N = 1005;
int n, m, e, match[N], vis[N], tim = 0;
vector<int> g[N];

bool dfs(int u) {
    for (int i = 0; i < (int)g[u].size(); i++) {
        int v = g[u][i];
        if (vis[v] == tim) continue;
        vis[v] = tim;
        if (!match[v] || dfs(match[v])) {
            match[v] = u;
            return true;
        }
    }
    return false;
}

int main() {
    scanf("%d%d%d", &n, &m, &e);
    for (int i = 1; i <= e; i++) {
        int u, v;
        scanf("%d%d", &u, &v);
        g[u].push_back(v);
    }
    int ans = 0;
    for (int u = 1; u <= n; u++) {
        tim++;
        if (dfs(u)) ans++;
    }
    printf("%d\n", ans);
    return 0;
}
```

---

## ⚠️ 常见错误

1. **染色只从 1 号点开始**。图不连通，必须外层扫所有点。
2. **把"相邻同色"写成"相邻异色"就返回 false**。判断方向反了。
3. **匈牙利每轮 `memset(vis)`**。数据大时会慢，用时间戳。
4. **欧拉路径不判连通**。度数全对但图分成两块，仍然无解。
5. **起点选错**。有奇度点却从偶度点出发，走不完所有边。
6. **重边只存一条**。无向图的重边在欧拉路径里是两条不同的边，矩阵要累加。
7. **输出顺序没反转**。Hierholzer 记录的是逆序。

## 🧠 本章小结

```
二分图：点分两边，边跨两边 ⇔ 无奇环 ⇔ 可二染色
  染色：起点染 1，邻居染相反色；冲突即非二分图
  匈牙利：对每个左点找增广路，O(VE)

欧拉回路：每条边恰走一次并回到起点
  无向：连通 + 所有度为偶
  有向：连通 + 所有点入度 = 出度
欧拉道路：恰有两个奇度点（或无向 0 个即回路）
  Hierholzer：走过即删边，回溯压栈，最后倒序输出
```
