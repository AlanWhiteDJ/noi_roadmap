# 第 71 章  二分图与欧拉图

---

> 🏗️ **前情回顾**：图的遍历能判断连通；这一章看两类特殊图——能把点分成两边的二分图，和能一笔画完的欧拉图。

## 🎯 本章目标

- 用染色法判定二分图
- 了解匈牙利算法求最大匹配
- 判定欧拉道路/欧拉回路
- 用 Hierholzer 算法输出欧拉路径

## 🧱 知识讲解

### 71.1  二分图判定

对每个未染色点 BFS/DFS，相邻点染相反颜色；若冲突则不是二分图。

```cpp
bool bfs(int s) {
    color[s] = 1; queue<int> q; q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u]) {
            if (!color[v]) { color[v] = -color[u]; q.push(v); }
            else if (color[v] == color[u]) return false;
        }
    }
    return true;
}
```

### 71.2  匈牙利算法

求二分图最大匹配：对左部每个点尝试找增广路，`match[v]` 记录右部点匹配的左部点。

### 71.3  欧拉道路与回路

- 欧拉回路：连通 + 所有点度数为偶
- 欧拉道路：连通 + 恰好两个点度数为奇（起点/终点）
- 有向图：入度=出度（回路），或一个点出度比入度大 1、一个点入度比出度大 1（道路）

### 71.4  Hierholzer

从起点 DFS，走过一条边就删除，回溯时把点加入路径，最后反转。

## 💻 例题

**例 1**：洛谷 P1330 封锁阳光大学——二分图染色。

**例 2**：洛谷 P2731 骑马修栅栏——欧拉路径。

## ⚠️ 常见坑

1. 欧拉路径起点要选奇数度点
2. 重边/自环
3. 图不连通时无欧拉路径
4. 二分图染色时孤立点也要处理
