## 📖 故事引入

学校的社团互相"关注"：摄影社关注算法社，算法社关注辩论社，辩论社又关注回摄影社。这三个社形成一个小圈子，圈里任意两个都能互相到达；而算法社关注的棋社谁也没回关，不在圈里。

小元想把这图压缩：每个小圈子缩成一个点。圈子内部怎么绕都行，圈子之间只剩单向边，压缩后就没有环了——它变成了 DAG，可以拓扑排序、可以 DP。

这就是**缩点**：用 Tarjan 找出所有强连通分量，再把每个分量揉成一个点。很多"有环图上做 DP"的题，第一步都是它。

另一半更直观：删掉某个点（或边）后图断成两半，它就是"关键点"（割点）或"关键边"（割边），判断同样只需一次 DFS。

## 🧱 知识讲解

### 72.1  有向图的连通性

- **强连通**：u 能到 v，且 v 能到 u。
- **强连通分量（SCC）**：极大的强连点子集。分量内部任意两点互相可达，分量之间不能互相到达。
- **弱连通**：把有向边当成无向边后连通。弱连通比强连通弱。

任何有向图都能唯一分解成若干 SCC；每个 SCC 缩成一个点后，得到的图一定是 **DAG**（否则这两个分量会合并）。

### 72.2  Tarjan 求 SCC

维护两个数组和一个栈：

- `dfn[u]`：u 第一次被访问的时间戳；
- `low[u]`：从 u 出发，经过若干条边（可以走栈中的点）能追溯到的最小 `dfn`；
- 栈：当前尚未归属任何 SCC 的点；
- `inst[u]`：u 是否在栈中。

```cpp
int dfn[N], low[N], belong[N], timer = 0, scc = 0;
int st[N], top = 0;
bool inst[N];

void tarjan(int u) {
    dfn[u] = low[u] = ++timer;
    st[++top] = u;
    inst[u] = true;
    for (int i = 0; i < (int)g[u].size(); i++) {
        int v = g[u][i];
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (inst[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (dfn[u] == low[u]) {          // u 是分量的根
        scc++;
        int v;
        do {
            v = st[top--];
            inst[v] = false;
            belong[v] = scc;
        } while (v != u);
    }
}
```

两个关键：`else if (inst[v])` 不能写成 `else`，指向已出栈点的边若参与回溯会错误合并分量；`dfn[u] == low[u]` 说明 u 回不到更早的点，它是分量的根。复杂度 $O(n+m)$。

### 72.3  缩点

把每个 SCC 缩成一个点，点权为分量内点权之和（若有权），边为分量之间的边。

```cpp
for (int u = 1; u <= n; u++)
    for (int v : g[u])
        if (belong[u] != belong[v])
            ng[belong[u]].push_back(belong[v]);
```

缩点后的图是 DAG，可以：

- 拓扑排序后做最长路/方案数 DP；
- 统计入度为 0 的分量个数（"最少需要几个起点"）；
- 求"最大权路径"（P3387 就是）。

> ⚠️ 缩点建图常要去重：多条原边可能连到同一对分量，重复边会让入度多算。用 `sort + unique` 或 `set` 处理。

### 72.4  割点

**割点**：删掉该点后，图的连通块数量增加。

判定（DFS 树）：

- 非根节点 u：若存在子节点 v 使 `low[v] >= dfn[u]`，u 是割点；
- 根节点：若有**两个及以上**子树，才是割点。

```cpp
int dfn[N], low[N], timer = 0;
bool cut[N];

void tarjan(int u, int fa) {
    dfn[u] = low[u] = ++timer;
    int child = 0;
    for (int i = 0; i < (int)g[u].size(); i++) {
        int v = g[u][i];
        if (!dfn[v]) {
            tarjan(v, u);
            low[u] = min(low[u], low[v]);
            if (low[v] >= dfn[u]) {
                child++;
                if (fa != 0 || child > 1) cut[u] = true;
            }
        } else if (v != fa) {
            low[u] = min(low[u], dfn[v]);
        }
    }
}
```

`low[v] >= dfn[u]` 表示 v 的子树无法绕过 u 回到祖先，删掉 u 后 v 那部分就独立了。

### 72.5  割边（桥）

**割边**：删掉该边后连通块数量增加。判定条件更严格：

$$low[v] > dfn[u]$$

等号不取：若 `low[v] == dfn[u]`，v 能回到 u，删掉 u—v 仍有替代路径。

```cpp
void tarjan(int u, int inEdge) {
    dfn[u] = low[u] = ++timer;
    for (int e = head[u]; e; e = nxt[e]) {
        int v = to[e];
        if (!dfn[v]) {
            tarjan(v, e);
            low[u] = min(low[u], low[v]);
            if (low[v] > dfn[u]) bridge[e] = bridge[e ^ 1] = true;
        } else if (e != (inEdge ^ 1)) {
            low[u] = min(low[u], dfn[v]);
        }
    }
}
```

> ⚠️ 有重边时**不能用"父节点"判重**，必须记录入边编号（无向边从 2 开始成对编号，`e^1` 取反边）。平行边一树一返祖，桥不成立。

### 72.6  点双与边双

**点双**：任意两点间有两条不经过同一点的路径（分量内无割点）。**边双**：任意两点间有两条不经过同一条边的路径（分量内无桥）。边双缩点后是一棵**树**，每条树边都是原图的桥；"加几条边使图边双连通"的答案常与叶子数有关。

## 💻 例题

### 例 1  洛谷 P3387 缩点

**题意**：$n$ 点 $m$ 边有向图，点有点权，求一条路径使经过的点权之和最大（重复经过只算一次）。

**思路**：环上可以随便绕，绕一圈就能拿完环上所有点权，所以先把 SCC 缩点，点权取和；缩点后是 DAG，做最长路 DP。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 10005, M = 100005;
int n, m, a[N];
int dfn[N], low[N], belong[N], timer = 0, scc = 0;
int st[N], top = 0;
bool inst[N];
vector<int> g[N], ng[N];
vector<pair<int,int> > edges;
int val[N], indeg[N], f[N];

void tarjan(int u) {
    dfn[u] = low[u] = ++timer;
    st[++top] = u;
    inst[u] = true;
    for (int i = 0; i < (int)g[u].size(); i++) {
        int v = g[u][i];
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (inst[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (dfn[u] == low[u]) {
        scc++;
        int v;
        do {
            v = st[top--];
            inst[v] = false;
            belong[v] = scc;
            val[scc] += a[v];
        } while (v != u);
    }
}

int main() {
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
    for (int i = 1; i <= m; i++) {
        int u, v;
        scanf("%d%d", &u, &v);
        g[u].push_back(v);
        edges.push_back(make_pair(u, v));
    }
    for (int i = 1; i <= n; i++)
        if (!dfn[i]) tarjan(i);

    sort(edges.begin(), edges.end());
    edges.erase(unique(edges.begin(), edges.end()), edges.end());
    for (int i = 0; i < (int)edges.size(); i++) {
        int u = belong[edges[i].first];
        int v = belong[edges[i].second];
        if (u != v) {
            ng[u].push_back(v);
            indeg[v]++;
        }
    }

    queue<int> q;
    for (int i = 1; i <= scc; i++) {
        f[i] = val[i];
        if (indeg[i] == 0) q.push(i);
    }
    int ans = 0;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        ans = max(ans, f[u]);
        for (int i = 0; i < (int)ng[u].size(); i++) {
            int v = ng[u][i];
            f[v] = max(f[v], f[u] + val[v]);
            if (--indeg[v] == 0) q.push(v);
        }
    }
    printf("%d\n", ans);
    return 0;
}
```

### 例 2  洛谷 P3388 割点（模板）

**题意**：$n$ 点 $m$ 边无向图，输出割点个数与编号。

**思路**：按 72.4 的规则 DFS。根节点用"子树数 > 1"单独判断。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 20005;
int n, m, dfn[N], low[N], timer = 0;
bool cut[N];
vector<int> g[N];

void tarjan(int u, int fa) {
    dfn[u] = low[u] = ++timer;
    int child = 0;
    for (int i = 0; i < (int)g[u].size(); i++) {
        int v = g[u][i];
        if (!dfn[v]) {
            tarjan(v, u);
            low[u] = min(low[u], low[v]);
            if (low[v] >= dfn[u]) {
                child++;
                if (fa != 0 || child > 1) cut[u] = true;
            }
        } else if (v != fa) {
            low[u] = min(low[u], dfn[v]);
        }
    }
}

int main() {
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= m; i++) {
        int u, v;
        scanf("%d%d", &u, &v);
        g[u].push_back(v);
        g[v].push_back(u);
    }
    for (int i = 1; i <= n; i++)
        if (!dfn[i]) tarjan(i, 0);
    int cnt = 0;
    for (int i = 1; i <= n; i++) if (cut[i]) cnt++;
    printf("%d\n", cnt);
    for (int i = 1; i <= n; i++)
        if (cut[i]) printf("%d ", i);
    return 0;
}
```

## ⚠️ 常见错误

1. **`else if (inst[v])` 写成 `else`**。已出栈的点也更新 `low`，SCC 被错误合并。
2. **Tarjan 递归爆栈**。$n=10^5$ 的长链会 RE，需改手写栈或开栈。
3. **割点根节点不特判**。根只有一个儿子时被误判为割点。
4. **割边用 `v != fa` 判重边**。平行边存在时判定错误，必须用边编号。
5. **缩点后不去重**。重复边让入度偏大，拓扑排序卡住。
7. **把"弱连通"当"强连通"**。缩点前必须按强连通分解。

## 🧠 本章小结

```
SCC：分量内任意两点互相可达；缩点后必为 DAG
Tarjan：dfn 时间戳，low 能回溯到的最早时间戳
  栈存当前未归属的点；dfn[u]==low[u] 时弹栈成一个分量
  复杂度 O(n+m)

割点：非根 low[v] >= dfn[u]；根需 >= 2 个子树
割边：low[v] > dfn[u]（严格大于）
  重边必须用边编号，不能只看父节点

边双缩点 → 树；点双 → 圆方树
```
