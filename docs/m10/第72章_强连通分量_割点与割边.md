# 第 72 章  强连通分量、割点与割边

---

> 🏗️ **前情回顾**：DFS 能判断连通；但"有向图里谁和谁能互相到达"需要更强的工具——Tarjan。

## 🎯 本章目标

- 用 Tarjan 求强连通分量（SCC）
- 缩点后建 DAG
- 求割点与割边
- 了解双连通分量

## 🧱 知识讲解

### 72.1  Tarjan 求 SCC

维护 `dfn[u]`（时间戳）和 `low[u]`（能回到的最早时间戳），用栈存当前路径：

```cpp
void tarjan(int u) {
    dfn[u] = low[u] = ++timer;
    st.push(u); inst[u] = 1;
    for (int v : g[u]) {
        if (!dfn[v]) { tarjan(v); low[u] = min(low[u], low[v]); }
        else if (inst[v]) low[u] = min(low[u], dfn[v]);
    }
    if (dfn[u] == low[u]) {
        int v;
        do { v = st.top(); st.pop(); inst[v] = 0; belong[v] = scc; } while (v != u);
        scc++;
    }
}
```

### 72.2  缩点

把每个 SCC 缩成一个点，原图变成 DAG，可以在上面做拓扑 + DP（最长路/方案数）。

### 72.3  割点与割边

- 割点：删掉后连通块增加的点
- 割边（桥）：删掉后连通块增加的边
- 判定：`low[v] >= dfn[u]`（割点）、`low[v] > dfn[u]`（割边）
- 根节点割点要单独处理（至少两个子树）

### 72.4  双连通

- 点双连通：任意两点间有两条不经过同一点的路径
- 边双连通：任意两点间有两条不经过同一条边的路径

## 💻 例题

**例 2**：洛谷 P3388 割点模板。

## ⚠️ 常见坑

1. 根节点割点判定要单独处理
2. 有重边时割边判定要记录边编号
3. 缩点后建图要去重
4. Tarjan 的栈和 `inst` 忘记清空
