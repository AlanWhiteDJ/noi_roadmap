## 📖 故事引入

模拟赛第三题："有 $n$ 座城市、$m$ 条单向航线，你最多可以免费乘坐 $k$ 次航班，求从 1 到 $n$ 的最小花费。"

小元第一反应是"最短路"，可写到一半卡住了：免费次数是个会变化的状态，普通 `dis[i]` 记不下来。

他盯着数据范围看了两分钟：$n \le 10^4$，$k \le 10$。忽然想到——把"已经用了几次免费"也编进点号里，不就有 $(k+1)n$ 个点了吗？每条航线除了原价边，再连一条到下一层的 0 权边。问题瞬间变回标准 Dijkstra。

这就是图论综合题的真实样子：**算法是旧的，难的是状态设计**。本章不教新模板，只教你怎么在考场上想到它。

## 🧱 知识讲解

### 73.1  建模四问

拿到题，按顺序问自己四句话：

1. **什么是"状态"？** 一个状态就是一个点。位置、时间、剩余次数、血量、是否用过某张牌，都可以是维度。
2. **什么动作让状态改变？** 一次移动、一次选择、一次等待，就是一条边。
3. **动作的代价是什么？** 距离、费用、时间，就是边权；若代价是 1，就是无权图。
4. **要求的是什么？** 最短路、连通性、顺序、总代价、方案数——对应不同算法。

> 💡 如果第 1 问答不出来，先看数据范围：范围里出现 $k \le 10$、$2^m$、$n \le 20$，往往暗示"状态要多一维"或"可以状压"。

### 73.2  算法选型表

| 题目特征 | 首选算法 | 复杂度 |
|----------|----------|--------|
| 无权图最少步数 | BFS | $O(n+m)$ |
| 非负边权单源最短路 | 堆优化 Dijkstra | $O((n+m)\log n)$ |
| 有负权 / 判负环 | Bellman-Ford / SPFA | $O(nm)$ |
| 全源最短路，$n \le 500$ | Floyd | $O(n^3)$ |
| 只要可达性 | Floyd + bitset / DFS | $O(n^3/64)$ |
| 依赖顺序、判有向环 | 拓扑排序 | $O(n+m)$ |
| 总代价最小的连通方案 | Kruskal / Prim | $O(m\log m)$ / $O(n^2)$ |
| 最大边权最小 | MST 或二分 + 并查集 | $O(m\log m)$ |
| 互相可达的圈子 | Tarjan SCC + 缩点 | $O(n+m)$ |
| 关键点 / 关键边 | Tarjan 割点 / 割边 | $O(n+m)$ |
| 分成两边、冲突约束 | 二分图染色 | $O(n+m)$ |
| 一一分配、最大匹配 | 匈牙利 | $O(VE)$ |
| 每条边恰走一次 | 欧拉路 + Hierholzer | $O(n+m)$ |

### 73.3  用数据范围反推

| 范围 | 大概率 |
|------|--------|
| $n \le 20$ | 状压 DP、暴力枚举 |
| $n \le 100$ | Floyd、$O(n^3)$ |
| $n \le 500$，$m$ 很大 | 邻接矩阵、Prim $O(n^2)$ |
| $n,m \le 10^5$ | 一次 BFS/DFS/Tarjan/Dijkstra |
| $n \le 10^5$，$k \le 10$ | 分层图，点数 $(k+1)n$ |
| $m \le 2000$ | 可以 $O(m^2)$、枚举边 |

范围是出题人给的"提示卡"。$10^5$ 基本排除 $O(n^2)$；$n \le 500$ 却在提示你可以用 Floyd。

### 73.4  八个常见套路

| 套路 | 什么时候用 |
|------|------------|
| 反向建图 | 求"所有点到某点"的距离 |
| 分层图 | 有"最多 k 次"的额外操作 |
| 虚拟源点 | 多个起点，或"可以从任意点开始" |
| 拆点 | 点有容量/点权，或要区分进入与离开 |
| 补图 | 原图边太多，补图很稀疏 |
| 二分答案 + 连通性 | 问"最大边权的最小值" |
| 最短路计数 | 问"最短方案有多少条" |
| 时间轴建图 | 状态含时间，边表示等待或乘车 |

### 73.5  三档部分分

以"假期计划"这类题为例，同一个题可以这样拿分：

- **30 分**：$n$ 很小，直接枚举四个不同点，用 Floyd 判断可达，$O(n^4)$。
- **60 分**：预处理任意两点距离，枚举中间两个点，$O(n^2)$ 找两端。
- **100 分**：发现两端只需各自保留"权值最大的前三个候选"，枚举 $B,C$ 后常数时间拼出答案，$O(n^2)$ 但常数更小；或进一步用堆维护。

**写部分分不是浪费时间**：它保证你有分，还能当对拍基准。正解写完先和暴力对拍，是最稳的验证方式。

### 73.6  考场检查清单

- 多测：`g`、`vis`、`dis`、`ind`、`dfn`、`timer`、`ecnt` 是否清空？
- 数组：无向图边开两倍了吗？分层图点数是 $(k+1)n$ 吗？
- 边界：$n=1$、$m=0$、图不连通、起点即终点，分别会怎样？
- 溢出：距离、答案用 `long long` 了吗？`INF` 相加会不会爆？
- 输出：换行、空格、大小写、`-1`/`Impossible` 与题面一致吗？
- 对拍：暴力与正解在随机小数据上跑 1000 组。

## 💻 例题

### 例 1  CSP-S 2022 假期计划

**题意（简化）**：$n$ 个点、$m$ 条边的无向图，边权为 1。选四个**互不相同**的点 $A,B,C,D$，使 $1 \to A \to B \to C \to D \to 1$ 每一段距离都不超过 $k+1$，且四个点点权之和最大。

**建模**：边权为 1，所以"距离不超过 $k+1$"可以用 BFS 预处理；但 $n$ 可达 $2500$，从每个点 BFS 是 $O(n(n+m))$，可以接受。

**关键观察**：枚举 $B,C$ 后，$A$ 只需是"能从 1 到达、且能到达 $B$"的点里权值最大的若干个；$D$ 同理。因为要四个点互不相同，每个位置保留**前三大**就足以避开冲突。

```cpp
// BFS 预处理 dist[i][j]；ok[i][j] = (dist[i][j] <= k + 1)
// cand[i]：满足 ok[1][x] && ok[x][i] 的 x，按 val 从大到小保留前 3
vector<int> cand[N];
for (int i = 2; i <= n; i++)
    for (int x = 2; x <= n; x++)
        if (x != i && ok[1][x] && ok[x][i]) cand[i].push_back(x);
for (int i = 2; i <= n; i++) {
    sort(cand[i].begin(), cand[i].end(), byVal);
    if (cand[i].size() > 3) cand[i].resize(3);
}

long long ans = 0;
for (int b = 2; b <= n; b++)
    for (int c = 2; c <= n; c++) {
        if (b == c || !ok[b][c]) continue;
        for (int a : cand[b])                 // 至多 3 个
            for (int d : cand[c])             // 至多 3 个
                if (a != b && a != c && b != d && c != d && a != d)
                    ans = max(ans, 1LL * val[a] + val[b] + val[c] + val[d]);
    }
```

> 🧠 这题的核心不是图论算法，而是"**只保留前 3 个候选**"的剪枝：因为最多有 4 个点要互不相同，前 3 名里必有一个可用。这种"贪心保留少量最优候选"的思路在综合题里非常常见。

### 例 2  洛谷 P1991 无线通讯网

**题意**：$p$ 个哨所，$s$ 个卫星电话（可以让任意两个装卫星的哨所无视距离通信），其余哨所用无线电，无线电的最大距离由最远的那对决定。求这个最大距离的最小值。

**建模**：把哨所看成点，距离看成边。"最大边权最小"就是瓶颈问题。二分答案 $x$，只保留长度 $\le x$ 的边，用并查集数连通块；若连通块数 $\le s$，说明每个块发一个卫星即可，$x$ 可行。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 505;
int s, p, fa[N];
double x[N], y[N];

int find(int u) {
    return fa[u] == u ? u : fa[u] = find(fa[u]);
}

bool check(double lim) {
    for (int i = 1; i <= p; i++) fa[i] = i;
    int cnt = p;
    for (int i = 1; i <= p; i++)
        for (int j = i + 1; j <= p; j++) {
            double dx = x[i] - x[j], dy = y[i] - y[j];
            if (dx * dx + dy * dy <= lim * lim) {
                int a = find(i), b = find(j);
                if (a != b) { fa[a] = b; cnt--; }
            }
        }
    return cnt <= s;
}

int main() {
    scanf("%d%d", &s, &p);
    for (int i = 1; i <= p; i++) scanf("%lf%lf", &x[i], &y[i]);
    double l = 0, r = 20000;
    for (int it = 0; it < 60; it++) {
        double mid = (l + r) / 2;
        if (check(mid)) r = mid;
        else l = mid;
    }
    printf("%.2f\n", r);
    return 0;
}
```

> 💡 也可以直接求 MST：答案就是 MST 上第 $p-s$ 小的边。两种做法都对，二分更容易想，MST 更快。

### 例 3  洛谷 P1525 关押罪犯

**题意**：$n$ 名罪犯，$m$ 对仇恨关系及冲突值。把罪犯分进两个监狱，使同一监狱内最大的冲突值最小。

**建模**：二分答案 $x$，只保留冲突值 $> x$ 的边，判断这些边能否构成二分图（把两个监狱看成两种颜色）。能，则 $x$ 可行。

```cpp
bool check(int lim) {
    for (int i = 1; i <= n; i++) color[i] = 0;
    for (int st = 1; st <= n; st++) {
        if (color[st]) continue;
        queue<int> q;
        q.push(st);
        color[st] = 1;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int i = 0; i < (int)g[u].size(); i++) {
                int v = g[u][i].first;
                if (g[u][i].second <= lim) continue;   // 只考虑大冲突
                if (!color[v]) {
                    color[v] = 3 - color[u];
                    q.push(v);
                } else if (color[v] == color[u]) {
                    return false;
                }
            }
        }
    }
    return true;
}
```

> 🧠 "最大冲突最小" + "分成两类" = 二分答案 + 二分图染色。这两个知识点分别在第 71 章和本章出现，综合题就是把它们接起来。

## ⚠️ 常见错误

1. **建图方向错**。单向边当双向，或依赖边反向，整题崩盘。
2. **点数/边数开小**。分层图忘了乘 $(k+1)$，无向图忘了乘 2。
3. **多测不清空**。这是图论题最常见的 0 分原因。
4. **不会写部分分**。正解写挂就全空；先交暴力至少保底。
5. **`int` 存距离**。$10^5 \times 10^9$ 超过 `int`。
6. **二分边界错**。`l`、`r` 的初值和精度次数要覆盖答案范围。
7. **忽略孤立点**。连通块计数、欧拉路径、二分图染色都要考虑。

## 🧠 本章小结

```
建模四问：状态是什么 → 什么动作改变它 → 代价是多少 → 要求什么

选型看特征：
  无权最短路 BFS；非负 Dijkstra；负权 BF/SPFA；全源 Floyd

范围看复杂度：n≤20 状压；n≤500 Floyd；n,m≤1e5 线性/堆

套路：反向图、分层图、虚拟源点、拆点、补图、
      二分答案+连通性、最短路计数、时间轴

考场：清空 → 边界 → 溢出 → 对拍 → 部分分保底
```
