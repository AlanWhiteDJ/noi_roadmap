# 第 73 章  图论综合

---

> 🏗️ **前情回顾**：建图、遍历、最短路、MST、SCC 都学过了。真正比赛时，难点不是写模板，而是**看出这道题是图论，并且建对图**。

## 🎯 本章目标

- 把实际问题抽象成点与边
- 根据数据范围选择算法
- 会写 30/60/100 分三档
- 识别图论题的常见套路

## 🧱 知识讲解

### 73.1  建模

常见转化：

- 状态 → 点；转移 → 边
- 约束 → 边权/连通性
- 时间/层数 → 分层图
- 反向关系 → 反向图

### 73.2  算法选型

| 题目特征 | 首选 |
|---|---|
| 无权最短路/最少步数 | BFS |
| 非负边权最短路 | Dijkstra |
| 负权/判负环 | Bellman-Ford/SPFA |
| 全源最短路 | Floyd |
| 连通性/判环 | 并查集/DFS |
| 依赖顺序 | 拓扑排序 |
| 总代价最小连通 | MST |
| 强连通/缩点 | Tarjan |
| 二分图判定/匹配 | 染色/匈牙利 |

### 73.3  部分分策略

- 小数据：暴力 DFS/Floyd
- 特殊性质：链、菊花、边权为 1
- 正解：在前两档基础上优化

## 💻 例题

**例 1**：CSP-S 2022 假期计划——最短路预处理 + 枚举。

**例 2**：CSP-S 2025 道路修复——MST 变体。

## ⚠️ 常见坑

1. 建图方向错
2. 点数/边数开小
3. 不会写部分分，导致 0 分
4. 多测不清空
