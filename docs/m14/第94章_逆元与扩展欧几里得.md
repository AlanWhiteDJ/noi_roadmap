# 第 94 章  逆元与扩展欧几里得

---

> 🏗️ **前情回顾**：第 93 章的同余世界可以加、减、乘，却不能随意除。裴蜀定理给了判据：`gcd(a, m) = 1` 时 `a` 才「可逆」。这一章把判据变成算法，并让除法在模意义下重新可用。

## 📖 故事引入

小华在写一个「分糖果」的程序：`n` 颗糖平均分给 `m` 个人，每人几颗？在普通整数里是 `n / m`；可答案要对 `10⁹ + 7` 取模，他随手写了 `n / m % MOD`，样例立刻错了。

「模意义下没有除法。」同桌说，「但你可以乘 `m` 的倒数。在模 `7` 的世界里，`3` 的倒数是 `5`，因为 `3 × 5 = 15 ≡ 1`。乘 `5` 就等于除以 `3`。」

小华试了试：`6 / 3` 在普通世界是 `2`；在模 `7` 下，`6 × 5 = 30 ≡ 2`，一样。可换成模 `6`，`3` 就找不到倒数了——`3` 的倍数余数只有 `0` 和 `3`，永远到不了 `1`。

**逆元不是每个数都有；有没有，取决于它和模数是否互质。** 而怎样快速求出它，就是这一章的主线。

## 🧱 知识讲解

### 94.1  逆元：模世界里的倒数

若 `gcd(a, m) = 1`，存在唯一的 `x ∈ [0, m)` 使

```
a · x ≡ 1 (mod m)
```

这个 `x` 叫 `a` 在模 `m` 下的**乘法逆元**，记作 `a⁻¹`。

为什么存在？因为 `ax ≡ 1 (mod m)` 等价于 `ax + my = 1`，由裴蜀定理，它有解当且仅当 `gcd(a, m) | 1`，即 `gcd(a, m) = 1`。

为什么唯一？若 `ax₁ ≡ ax₂ ≡ 1`，则 `a(x₁ - x₂) ≡ 0`。因为 `a` 与 `m` 互质，可以约去 `a`，得 `x₁ ≡ x₂ (mod m)`。

模 `7` 的逆元表：

| a | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| a⁻¹ | 1 | 4 | 5 | 2 | 3 | 6 |

验证：`2×4=8≡1`、`3×5=15≡1`。注意 `1` 和 `m-1` 的逆元是自身。

### 94.2  扩展欧几里得：一次求出存在性与解

普通欧几里得算法反复用 `gcd(a, b) = gcd(b, a mod b)`，直到 `b = 0`。扩展版本在回溯时把系数一并带回来：

```
已知 bx' + (a mod b)y' = g
而 a mod b = a - (a/b)·b
代入得 a·y' + b·(x' - (a/b)y') = g
所以 x = y'，y = x' - (a/b)y'
```

代码只有五行：

```cpp
long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}
```

调用 `exgcd(3, 5, x, y)` 会得到 `g = 1, x = 2, y = -1`，即 `3×2 + 5×(-1) = 1`。

若 `ax + by = g` 有一组解 `(x₀, y₀)`，通解是 `x = x₀ + k·(b/g)`，`y = y₀ - k·(a/g)`。

> 💡 模板默认 `a、b` 非负。若题面给负系数，先把绝对值传进去求出解，再按符号调整；或者最后统一用 `norm` 把答案归一到 `[0, m)`。

### 94.3  逆元的三种求法

**方法一：exgcd。** 解 `ax + my = 1`，再把 `x` 归一：

```cpp
long long modInverse(long long a, long long m) {
    long long x, y;
    long long g = exgcd(a, m, x, y);
    if (g != 1) return -1;               // 逆元不存在
    return (x % m + m) % m;
}
```

优点：`m` 是素数或合数都能用，只要 `gcd(a, m) = 1`。复杂度 `O(log m)`。

**方法二：费马小定理。** 当 `m = p` 为素数且 `p ∤ a` 时，`a⁻¹ ≡ a^(p-2) (mod p)`，用第 50 章的快速幂即可。

**方法三：线性递推。** 要求 `1..n` 的所有逆元时，逐个 exgcd 是 `O(n log p)`。利用

```
p = q·i + r，其中 q = p / i，r = p % i
0 ≡ q·i + r (mod p)
两边乘 i⁻¹r⁻¹：i⁻¹ ≡ -q·r⁻¹ (mod p)
```

得到

```cpp
inv[1] = 1;
for (int i = 2; i <= n; ++i)
    inv[i] = (long long)(p - p / i) * inv[p % i] % p;
```

因为 `r = p % i < i`，`inv[r]` 一定已经算过。总复杂度 `O(n)`，是组合数预处理的地基。

> ⚠️ 这个递推要求 `p` 是素数，且 `i < p`。若 `i = p`，`p % i = 0`，`inv[0]` 不存在。

| 方法 | 适用模数 | 复杂度 | 场景 |
|------|----------|--------|------|
| exgcd | 任意互质 | `O(log m)` | 单个、合数模 |
| 费马 | 素数 | `O(log p)` | 模 `10⁹+7` |
| 线性递推 | 素数且 `i<p` | 均摊 `O(1)` | 预处理 `1..n` |

### 94.4  线性同余方程

形如

```
a·x ≡ b (mod m)
```

的方程，解法分三步：

1. 令 `g = gcd(a, m)`。若 `b % g ≠ 0`，无解。
2. 两边同除以 `g`，得 `a'x ≡ b' (mod m')`，其中 `a' = a/g`，`b' = b/g`，`m' = m/g`。此时 `gcd(a', m') = 1`。
3. `x ≡ b' · (a')⁻¹ (mod m')`，最小正整数解为 `x₀`，若 `x₀ = 0` 则取 `m'`。

在 `[0, m)` 内一共有 `g` 个解，它们是 `x₀, x₀ + m', …, x₀ + (g-1)m'`。

```cpp
bool solveCongruence(long long a, long long b, long long m,
                     long long &x0, long long &step) {
    long long x, y;
    long long g = exgcd(a, m, x, y);
    if (b % g != 0) return false;
    step = m / g;
    x0 = (long long)((__int128)(x % step) * ((b / g) % step) % step);
    x0 = (x0 % step + step) % step;
    return true;
}
```

**手算例子**：`14x ≡ 30 (mod 100)`。

`g = gcd(14, 100) = 2`，`30 % 2 = 0`，有解。约分得 `7x ≡ 15 (mod 50)`。`7` 在模 `50` 下的逆元是 `43`，所以 `x ≡ 15 × 43 = 645 ≡ 45 (mod 50)`。最小正整数解是 `45`，另一个解是 `95`，共 `g = 2` 个。

### 94.5  应用：组合数取模

组合数 `C(n, m) = n! / (m!(n-m)!)`，模素数 `p` 时不能直接除，要乘阶乘逆元：

```cpp
fac[0] = 1;
for (int i = 1; i <= n; ++i) fac[i] = fac[i-1] * i % p;
ifac[n] = qpow(fac[n], p - 2, p);
for (int i = n; i >= 1; --i) ifac[i-1] = ifac[i] * i % p;

long long C(int n, int m) {
    if (m < 0 || m > n) return 0;
    return fac[n] * ifac[m] % p * ifac[n-m] % p;
}
```

这里要求 `n < p`，否则 `fac[n] ≡ 0`，费马逆元失效，需要 Lucas 定理（后续再学）。

## 💻 例题与解析

### 例 1  同余方程（P1082）

**题意**：求关于 `x` 的同余方程 `a x ≡ 1 (mod b)` 的最小正整数解。数据保证有解。

**解析**：这就是求 `a` 在模 `b` 下的逆元。用 exgcd 解 `ax + by = 1`，得到 `x` 后归一到 `[0, b)`；若结果为 `0`，按题意输出 `b`。

```cpp
#include <bits/stdc++.h>
using namespace std;

long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

int main() {
    long long a, b;
    cin >> a >> b;
    long long x, y;
    exgcd(a, b, x, y);
    x = (x % b + b) % b;
    if (x == 0) x = b;
    cout << x << endl;
    return 0;
}
```

**复杂度**：`O(log min(a,b))`。**易错点**：`x` 可能是负数，必须先归正；`b = 1` 时答案为 `1`。

### 例 2  乘法逆元（P3811）

**题意**：给定 `n, p`，求 `1..n` 中每个数在模 `p` 下的逆元。`p` 是素数，`n < p`。

**解析**：`n` 可达 `3 × 10⁶`，逐个 exgcd 是 `O(n log p)`。用线性递推。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 3000005;
int inv[N];

int main() {
    int n;
    long long p;
    scanf("%d%lld", &n, &p);
    inv[1] = 1;
    for (int i = 2; i <= n; ++i)
        inv[i] = (long long)(p - p / i) * inv[p % i] % p;
    for (int i = 1; i <= n; ++i)
        printf("%d\n", inv[i]);
    return 0;
}
```

**复杂度**：时间 `O(n)`，空间 `O(n)`。**易错点**：`p % i` 必须小于 `i`，所以循环从 `2` 开始、`inv[1]` 先置 `1`；乘法要转 `long long`；输出用 `printf` 或关闭同步，否则 `3 × 10⁶` 行 `cout` 可能超时。

### 例 3  解一般线性同余方程

**题意**：解 `14x ≡ 30 (mod 100)`，输出最小正整数解和解的个数。

**解析**：按 94.4 的步骤：`g = 2`，约分后 `7x ≡ 15 (mod 50)`，逆元 `43`，得 `x ≡ 45 (mod 50)`。最小正整数解 `45`，解数 `g = 2`。

```cpp
#include <bits/stdc++.h>
using namespace std;

long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

int main() {
    long long a = 14, b = 30, m = 100;
    long long x, y;
    long long g = exgcd(a, m, x, y);
    if (b % g != 0) { cout << "No Solution" << endl; return 0; }
    long long step = m / g;
    long long x0 = (long long)((__int128)(x % step) * ((b / g) % step) % step);
    x0 = (x0 % step + step) % step;
    if (x0 == 0) x0 = step;
    cout << x0 << " " << g << endl;      // 45 2
    return 0;
}
```

**易错点**：周期是 `m/g = 50`，不是 `m = 100`；最小正整数解为 `0` 时要输出 `step`，不能输出 `0`。

## ⚠️ 常见错误

- **负数直接取模**：`-3 % 5` 是 `-3`；逆元、同余解一律用 `(x % m + m) % m` 归正。
- **不检查 `gcd`**：`gcd(a, m) ≠ 1` 时逆元不存在，硬算会得到一个「假答案」。
- **对合数模用费马**：`a^(m-2)` 只在 `m` 为素数时是逆元；合数模请用 exgcd。
- **线性递推越界**：`i` 必须小于 `p`，否则 `p % i` 可能为 `0`，`inv[0]` 未定义。
- **周期写成 `m`**：线性同余解的周期是 `m/g`，解的个数是 `g`。
- **乘法溢出**：`p - p/i` 与 `inv[...]` 相乘接近 `10¹⁸`，必须 `long long`，必要时 `__int128`。

## 🧠 本章小结

```
逆元：a·x ≡ 1 (mod m)
  存在 ⇔ gcd(a,m)=1；在 [0,m) 内唯一

exgcd：
  ax+by=g 的一组解
  通解 x=x0+k·(b/g)，y=y0-k·(a/g)

三种求法：
  exgcd       任意互质模，O(log m)
  费马        素数模，a^(p-2)，O(log p)
  线性递推    素数模，i<p，O(n) 求 1..n

线性同余 ax≡b (mod m)：
  g=gcd(a,m)，b%g≠0 无解
  约分后 x≡(b/g)·inv(a/g) (mod m/g)
  最小正整数解，周期 m/g，共 g 个解
```
