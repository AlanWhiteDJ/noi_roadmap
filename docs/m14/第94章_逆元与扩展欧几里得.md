# 第 94 章 逆元与扩展欧几里得
---
> 🏗️ **前情回顾**：上一章的同余世界可以加、减、乘，却不能随意除。裴蜀定理给了判据：gcd(a,m)=1 时 a 才"可逆"。这一章把判据变成算法。
## 🎯 本章目标
- 理解并默写扩展欧几里得（exgcd）
- 掌握 exgcd、费马小定理、线性递推三种逆元求法
- 解线性同余方程，正确输出最小正整数解

## 🎬 故事/动机
模世界没有除法，但乘一个"倒数"等价于除。问题是：倒数一定存在吗？怎样最快算出来？exgcd 一次回答存在性与构造，而线性递推能在 O(n) 内求出整张逆元表，是组合数取模的地基。

## 🧱 知识讲解
### 94.1 扩展欧几里得
辗转相除的每一步都保留系数：由 `bx'+(a mod b)y'=g` 回推 `ax+by=g`，得到 `x=y'`、`y=x'-(a/b)y'`。返回的 g 取正，a、b 为负时先取绝对值。
```cpp
long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (!b) { x = 1; y = 0; return a; }
    long long d = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return d;
}
```

### 94.2 逆元的三种求法
逆元满足 ax≡1 (mod m)，存在当且仅当 gcd(a,m)=1。exgcd 解 ax+my=1 后把 x 归一到 [0,m)；m 为素数时可用费马小定理 a^(m-2)；要求 1..n 的全部逆元时用线性递推，均摊 O(1)：
```cpp
inv[1] = 1;
for (int i = 2; i <= n; i++)
    inv[i] = (m - m / i) * inv[m % i] % m;
```

### 94.3 线性同余方程
解 ax≡b (mod m)：令 g=gcd(a,m)，若 b%g≠0 则无解；否则两边同除以 g，得 a'x≡b' (mod m')，其中 m'=m/g，x≡b'·inv(a')。通解为 x0+k·m'，最小正整数解是 `((x0 % m') + m') % m'`，结果为 0 时取 m'。

## 💻 例题
**例 1**：[P1082 同余方程](https://hydro.ac/p/luogu-P1082)。即 ax+by=1，exgcd 后输出 `(x % b + b) % b`；若结果为 0，按题意输出 b。

**例 2**：[P3811 乘法逆元](https://hydro.ac/p/luogu-P3811)。n 个逆元逐个 exgcd 是 O(n log p)，会超时；用上面的递推，注意 `m % i` 必须小于 i 且逆元已算出，因此 i 从 2 扫到 n。

## ⚠️ 常见坑
1. C++ 的 `%` 向零取整，负系数回代前不归正会得到错误解。
2. gcd≠1 时逆元不存在，应返回 -1 或报无解，不能硬算。
3. 线性同余的最小解周期是 m/g，不是 m；x0=0 时要输出 m/g。
4. 递推求逆元只适用于素数模且 i<m；合数模要用 exgcd。
