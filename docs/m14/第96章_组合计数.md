## 🧱 知识讲解
### 96.1 多重集排列与组合

n 个元素中有 n1 个同类、n2 个同类……的排列数是 n!/(n1!n2!…nk!)。r 个相同球放入 k 个不同盒子（可空）的方案数是 C(r+k-1,k-1)。模素数时除法要换成逆元，先预处理阶乘与阶乘逆元：
```cpp
fac[0] = 1;
for (int i = 1; i <= n; i++) fac[i] = fac[i-1] * i % MOD;
ifac[n] = qpow(fac[n], MOD - 2, MOD);
for (int i = n; i; i--) ifac[i-1] = ifac[i] * i % MOD;
auto C = [&](int n, int m) -> long long {
    if (m < 0 || m > n) return 0;
    return fac[n] * ifac[m] % MOD * ifac[n-m] % MOD;
};
```
### 96.2 错排与圆排列

错排 D(n) 表示 n 个元素全不在原位的排列数。看第一个元素：它去位置 j（n-1 种），若 j 回到位置 1 则剩下 n-2 个错排，否则剩下 n-1 个错排，故 D(n)=(n-1)(D(n-1)+D(n-2))，D(0)=1、D(1)=0。n 个不同元素的圆排列是 (n-1)!（旋转视为相同）；若翻转也视为相同（项链/手环），再除以 2（n≥3）。
```cpp
D[0] = 1; D[1] = 0;
for (int i = 2; i <= n; i++)
    D[i] = 1LL * (i - 1) * (D[i-1] + D[i-2]) % MOD;
```
### 96.3 二项式定理与组合恒等式

(a+b)^n=Σ C(n,k)a^k b^(n-k)。常用恒等式：C(n,k)=C(n-1,k-1)+C(n-1,k)（杨辉三角）、ΣC(n,k)=2^n、Σ(-1)^k C(n,k)=0、Vandermonde 卷积 ΣC(n,k)C(m,r-k)=C(n+m,r)。它们常把 O(n) 求和变成 O(1)。
## 💻 例题
**例 1**：[P4071 排列计数](https://hydro.ac/p/luogu-P4071)。恰有 m 个位置满足 a_i=i：先选这 m 个位置 C(n,m)，剩下 n-m 个全错排 D(n-m)，答案为两者之积。预处理到 1e6。
**例 2**：[P2822 组合数问题](https://hydro.ac/p/luogu-P2822)。求有多少对 (i,j)（0≤j≤min(i,m)，0≤i≤n）使 k | C(i,j)。用杨辉三角递推对 k 取模，若 C[i][j]==0 则被 k 整除；再对三角区域做二维前缀和，O(1) 回答每组询问。注意 C[i][0]=1%k。
## ⚠️ 常见坑
1. 多重集排列的除法直接写 `/fac[ni]` 再取模；必须乘阶乘逆元。
2. 圆排列是 (n-1)!；项链若翻转也等价，再除以 2，别把旋转重复除一次。
3. 错排边界写错（D[1] 应为 0），或忘记 C(n,m) 在 m<0、m>n 时返回 0。
4. 杨辉三角递推时先取模再判 0，不能拿未取模的大数判断整除。
