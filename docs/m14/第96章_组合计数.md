## 🧱 知识讲解

### 96.1  两个基本原理

一切计数都从这两条出发：

- **加法原理**：做一件事有 `k` 类互不重叠的方法，第 `i` 类有 `n_i` 种，则总数为 `n₁ + n₂ + … + n_k`。
- **乘法原理**：做一件事分 `k` 步，第 `i` 步有 `n_i` 种，则总数为 `n₁ × n₂ × … × n_k`。

由乘法原理得到排列数：

```
A(n, m) = n × (n-1) × … × (n-m+1) = n! / (n-m)!
```

组合数不考虑顺序：

```
C(n, m) = A(n, m) / m! = n! / (m!(n-m)!)
```

规定 `0! = 1`，`C(n, 0) = C(n, n) = 1`，`m > n` 或 `m < 0` 时 `C(n, m) = 0`。

### 96.2  多重集排列

有 `n` 个元素，分成 `k` 类，第 `i` 类有 `n_i` 个**完全相同**的元素，`Σ n_i = n`。把它们排成一排的方案数是

```
n! / (n₁! n₂! … n_k!)
```

推导：先假装所有元素互不相同，有 `n!` 种；每一类内部互换 `n_i!` 次都得到同一个排列，所以除以 `∏ n_i!`。

模素数时，除法要换成逆元。预处理阶乘与阶乘逆元：

```cpp
const int N = 1000005;
const long long MOD = 1000000007;
long long fac[N], ifac[N];

long long qpow(long long a, long long b) {
    long long res = 1;
    while (b > 0) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

void init(int n) {
    fac[0] = 1;
    for (int i = 1; i <= n; ++i) fac[i] = fac[i-1] * i % MOD;
    ifac[n] = qpow(fac[n], MOD - 2);
    for (int i = n; i >= 1; --i) ifac[i-1] = ifac[i] * i % MOD;
}

long long C(int n, int m) {
    if (m < 0 || m > n) return 0;
    return fac[n] * ifac[m] % MOD * ifac[n-m] % MOD;
}
```

**多重集排列**的代码只需把分母的每个阶乘改成乘逆元：

```cpp
long long ways = fac[n];
for (int i = 1; i <= k; ++i) ways = ways * ifac[cnt[i]] % MOD;
```

> ⚠️ 不能写 `fac[n] / (fac[c1] * fac[c2] …) % MOD`。整数除法在模意义下不成立，必须先乘逆元。

### 96.3  多重集组合

从 `k` 类元素中可重复地选 `r` 个，不考虑顺序，方案数是

```
C(r + k - 1, k - 1) = C(r + k - 1, r)
```

这叫「隔板法」：`r` 个相同的球与 `k-1` 块板共 `r+k-1` 个位置，选出 `k-1` 个放板，即可分成 `k` 段。

等价地，方程

```
x₁ + x₂ + … + x_k = r，x_i ≥ 0
```

的非负整数解有 `C(r+k-1, k-1)` 组。若要求 `x_i ≥ 1`，先给每个变量 1，变成 `C(r-1, k-1)`（要求 `r ≥ k`）。

### 96.4  错排

`n` 个元素的全排列中，有多少个排列满足「每个元素都不在原来的位置」？记作 `D(n)`。

看第一个元素：

- 它不能待在位置 1，所以有 `n-1` 个位置可选，设它去了位置 `j`。
- 如果元素 `j` 回到位置 1，剩下 `n-2` 个元素在 `n-2` 个位置上错排，贡献 `D(n-2)`。
- 如果元素 `j` 不回到位置 1，那么可以把位置 1 「当成」元素 `j` 原来的位置，剩下 `n-1` 个元素错排，贡献 `D(n-1)`。

所以

```
D(n) = (n-1) × (D(n-1) + D(n-2))
```

边界：`D(0) = 1`（空排列），`D(1) = 0`，`D(2) = 1`。

| n | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| D(n) | 0 | 1 | 2 | 9 | 44 | 265 |

错排还有容斥形式：

```
D(n) = n! × Σ_{k=0}^{n} (-1)^k / k!
```

所以 `D(n)/n! → 1/e ≈ 0.3679`。

```cpp
D[0] = 1; D[1] = 0;
for (int i = 2; i <= n; ++i)
    D[i] = (long long)(i - 1) * (D[i-1] + D[i-2]) % MOD;
```

### 96.5  圆排列与项链

`n` 个不同元素围成一圈，旋转后相同视为同一种，方案数是

```
(n-1)!
```

推导：先按直线排列有 `n!` 种，每个圆排列被重复算了 `n` 次（从 `n` 个位置任一位置断开），所以除以 `n`。

若翻转（镜像）也视为相同，比如手环、项链，还要再除以 `2`：

```
(n-1)! / 2     （n ≥ 3）
```

`n = 1` 时只有 1 种；`n = 2` 时翻转与旋转重合，不能除 2，仍是 1 种。这两个小边界经常被忽略。

### 96.6  二项式定理与恒等式

```
(a + b)^n = Σ_{k=0}^{n} C(n, k) a^k b^(n-k)
```

令 `a = b = 1`，得

```
Σ_{k=0}^{n} C(n, k) = 2^n
```

令 `a = 1, b = -1`，得

```
Σ_{k=0}^{n} (-1)^k C(n, k) = 0     （n ≥ 1）
```

其它常用恒等式：

| 恒等式 | 组合意义 |
|--------|----------|
| `C(n,k) = C(n-1,k-1) + C(n-1,k)` | 杨辉三角，按是否选第 n 个分类 |
| `Σ_{i=k}^{n} C(i,k) = C(n+1,k+1)` | 曲棍球棒恒等式 |
| `Σ_k C(n,k)C(m,r-k) = C(n+m,r)` | Vandermonde 卷积，两堆里共选 r 个 |
| `k·C(n,k) = n·C(n-1,k-1)` | 先选一个「代表」 |

杨辉三角的递推是 `O(n²)` 预处理组合数的常用手段，适合 `n ≤ 5000` 且需要大量查询的题：

```cpp
for (int i = 0; i <= n; ++i) {
    C[i][0] = C[i][i] = 1;
    for (int j = 1; j < i; ++j)
        C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD;
}
```

### 96.7  鸽巢原理与等价类

**鸽巢原理**：`n+1` 个物品放进 `n` 个盒子，必有一个盒子至少两个；一般地，`kn+1` 个物品放进 `n` 个盒子，必有一个盒子至少 `k+1` 个。常用于证明存在性，例如 `n+1` 个整数中必有两个模 `n` 同余。

**等价关系**满足自反、对称、传递，把集合划成若干**等价类**：类内互相等价，类间不交。计数时按等价类归一，就能处理「旋转相同」「翻转相同」「同类元素不可区分」。

## 💻 例题与解析

### 例 1  排列计数（P4071）

**题意**：求有多少个 `1..n` 的排列，恰好有 `m` 个位置满足 `a_i = i`。答案对 `10⁹+7` 取模，多组询问。

**解析**：先选出这 `m` 个「站对」的位置，有 `C(n, m)` 种；剩下 `n-m` 个位置必须全部错排，有 `D(n-m)` 种。答案是

```
C(n, m) × D(n-m) mod MOD
```

预处理到 `10⁶`，每组询问 `O(1)`。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1000005;
const long long MOD = 1000000007;
long long fac[N], ifac[N], D[N];

long long qpow(long long a, long long b) {
    long long res = 1;
    while (b > 0) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

long long C(int n, int m) {
    if (m < 0 || m > n) return 0;
    return fac[n] * ifac[m] % MOD * ifac[n-m] % MOD;
}

int main() {
    fac[0] = 1;
    for (int i = 1; i < N; ++i) fac[i] = fac[i-1] * i % MOD;
    ifac[N-1] = qpow(fac[N-1], MOD - 2);
    for (int i = N - 1; i >= 1; --i) ifac[i-1] = ifac[i] * i % MOD;

    D[0] = 1; D[1] = 0;
    for (int i = 2; i < N; ++i)
        D[i] = (long long)(i - 1) * (D[i-1] + D[i-2]) % MOD;

    int T;
    scanf("%d", &T);
    while (T--) {
        int n, m;
        scanf("%d%d", &n, &m);
        printf("%lld\n", C(n, m) * D[n-m] % MOD);
    }
    return 0;
}
```

**易错点**：`D[1] = 0` 不能写成 `1`；`C(n,m)` 在 `m > n` 时返回 `0`；`n-m = 1` 时答案必为 `0`，这是检查递推边界的好数据。

### 例 2  组合数问题（P2822）

**题意**：给定 `k`，多次询问 `(n, m)`，求有多少对 `(i, j)` 满足 `0 ≤ i ≤ n`、`0 ≤ j ≤ min(i, m)` 且 `k | C(i, j)`。

**解析**：用杨辉三角递推 `C(i,j) mod k`。若 `C[i][j] == 0`，说明 `k | C(i,j)`。对「是否整除」做二维前缀和，每组询问 `O(1)`。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 2005;
int C[N][N], s[N][N];

int main() {
    int T, k;
    scanf("%d%d", &T, &k);
    for (int i = 0; i < N; ++i) {
        C[i][0] = C[i][i] = 1 % k;
        for (int j = 1; j < i; ++j)
            C[i][j] = (C[i-1][j-1] + C[i-1][j]) % k;
    }
    for (int i = 0; i < N; ++i) {
        for (int j = 0; j < N; ++j) {
            int bad = (j <= i && C[i][j] == 0) ? 1 : 0;
            s[i][j] = bad;
            if (i) s[i][j] += s[i-1][j];
            if (j) s[i][j] += s[i][j-1];
            if (i && j) s[i][j] -= s[i-1][j-1];
        }
    }
    while (T--) {
        int n, m;
        scanf("%d%d", &n, &m);
        if (m > n) m = n;
        printf("%d\n", s[n][m]);
    }
    return 0;
}
```

**易错点**：`C[i][0] = 1 % k`，`k = 1` 时它是 `0`，不能直接写 `1`；前缀和只在 `j ≤ i` 的三角区域计数，`j > i` 的位置不能算；`m > n` 时要截到 `n`。

### 例 3  多重集与圆桌

**题意**：（1）`MISSISSIPPI` 的字母有多少种排列？（2）6 个人围圆桌坐，有多少种坐法？若围成手环、翻转也算同一种呢？

**解析**：

（1）11 个字母，`M` 1 个、`I` 4 个、`S` 4 个、`P` 2 个：

```
11! / (1!·4!·4!·2!) = 39916800 / 1152 = 34650
```

（2）圆排列 `(6-1)! = 120`。手环再除以 2，得 `60`。

**说明**：这里用整数除法是安全的，因为 `11!` 能被分母整除；但在模意义下必须乘逆元。

## ⚠️ 常见错误

- **模意义下直接除**：`fac[n] / (fac[a] * fac[b]) % MOD` 是错的，要乘 `ifac[a] * ifac[b]`。
- **错排边界写错**：`D[1]` 必须是 `0`，`D[0] = 1`；写成 `D[1] = 1` 会让整张表偏移。
- **圆排列与项链混淆**：旋转等价除 `n`，翻转也等价再除 `2`；`n ≤ 2` 时不能除 `2`。
- **多重集分母漏项**：每个出现过的元素都要除以其出现次数的阶乘，次数为 1 的项可省略但不影响。
- **杨辉三角未取模就判 0**：必须先 `% k`，再判断是否等于 `0`。
- **`C(n,m)` 越界**：`m < 0` 或 `m > n` 应返回 `0`，不能直接访问数组。

## 🧠 本章小结

```
多重集排列：n! / (n1! n2! … nk!)
多重集组合：C(r+k-1, k-1)（隔板法）

错排：
  D(0)=1，D(1)=0
  D(n)=(n-1)(D(n-1)+D(n-2))
  D(n)/n! → 1/e

圆排列：(n-1)!
项链（翻转等价）：(n-1)!/2（n≥3）

二项式：
  (a+b)^n = Σ C(n,k) a^k b^(n-k)
  Σ C(n,k)=2^n
  C(n,k)=C(n-1,k-1)+C(n-1,k)

模意义：
  除法 → 乘逆元
  预处理 fac[] 与 ifac[]
```
