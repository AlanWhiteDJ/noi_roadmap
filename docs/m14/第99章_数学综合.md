## 🧱 知识讲解
### 99.1 综合建模的选型表

看到"方案数/至少/恰好"→ 组合、容斥、Catalan；看到"模意义下除法"→ 逆元；看到"多个同余条件"→ CRT/exCRT；看到"线性递推 + 巨大 n"→ 矩阵快速幂；看到"随机游走/步数期望"→ 期望 DP。先写清状态与转移，再决定用哪种数学工具化简。
### 99.2 期望的线性性

期望的线性性 E[X+Y]=E[X]+E[Y] **不要求 X、Y 独立**，这是它最好用的地方；同时 E[aX]=aE[X]。在 DAG 上求从 u 到终点的期望步数，常设 E[u]=Σ(w+E[v])/outdeg(u)，按逆拓扑序递推，终点 E[n]=0。
```cpp
double E[N];
for (int i = 1; i <= n; i++) E[i] = 0;
for (int u : revTopo) {          // 逆拓扑序，保证 v 已算
    for (auto [v, w] : g[u])
        E[u] += (w + E[v]) / g[u].size();
}
cout << fixed << setprecision(2) << E[1];
```
### 99.3 概率取模

若概率为 a/b，模素数下写成 a·b^(-1) mod MOD；分母不能被 MOD 整除。多步概率相乘、期望相加，逐项取模即可。遇到"每种情况等概率"时，先数方案再乘逆元，通常比直接推概率稳。
### 99.4 部分分策略

先写 O(2^n) 或 O(n^2) 暴力；再补"链/菊花/边权为 1/模数为素数"等特殊性质；最后才冲正解。每档单独测试，避免正解写挂后连暴力分也没有。
## 💻 例题
**例 1**：[P4316 绿豆蛙的归宿](https://hydro.ac/p/luogu-P4316)。DAG 上等概率走每条出边，求 1 到 n 的期望路径长度。设 E[u] 为 u 到 n 的期望，E[n]=0，按逆拓扑序用 99.2 的式子递推，输出 E[1]。
**例 2**：CSP-S 2024 [超速检测](https://hydro.ac/p/ccf-CSPS2024B)。把每辆车的超速条件转化为测速仪位置区间，问题变成区间覆盖；用二分定位每个超速区间的端点，再贪心做区间覆盖，注意端点与整数速度的取整方向。
## ⚠️ 常见坑
1. 误以为期望线性性要求独立；只要期望存在，加法总成立。
2. 概率取模忘记乘逆元，或分母与模数不互质导致逆元不存在。
3. DAG 期望的递推方向搞反；终点初值、出度为 0 的节点未处理。
4. 只盯正解不写部分分；多测不清空期望数组与图。
