### 99.1  选型表：题面信号 → 工具

| 题面信号 | 首选工具 | 复杂度 |
|----------|----------|--------|
| 「方案数」「至少」「恰好」 | 组合、容斥、Catalan | 看数据范围 |
| 「模意义下除以」「组合数取模」 | 逆元、阶乘逆元 | `O(log p)` / `O(n)` |
| 「多个同余条件」 | CRT / exCRT | `O(k log m)` |
| 「线性递推 + 巨大 n」 | 矩阵快速幂 | `O(k³ log n)` |
| 「随机游走」「步数期望」 | 期望 DP、期望线性性 | `O(n+m)` |
| 「最大值最小」「可行区间」 | 二分 + 贪心/数学 | `O(n log n)` |
| 「n ≤ 20」 | 枚举、状压、暴力 | `O(2ⁿ)` |
| 「n ≤ 10⁵，值域小」 | 前缀和、筛法、桶 | `O(n log n)` |

先看数据范围，再看题面关键词。`n ≤ 20` 基本在暗示暴力；`n ≤ 10⁵` 要求 `O(n log n)`；`n ≤ 10¹⁸` 往往要矩阵或数论。

### 99.3  期望的线性性

随机变量 `X` 的期望是「加权平均」。最常用的性质是**线性性**：

```
E[X + Y] = E[X] + E[Y]
E[aX + b] = aE[X] + b
```

它**不要求 X、Y 独立**，这是它最好用的地方。很多题因此可以「拆贡献」：把总步数拆成每条边被经过的期望次数，逐条求和，不必关心边与边是否相关。

在 DAG 上求从 `u` 到终点的期望步数，设 `E[u]` 为从 `u` 出发到终点的期望长度。若 `u` 有 `outdeg(u)` 条出边，等概率选择，则

```
E[u] = (1/outdeg(u)) × Σ_{u→v, 权 w} (w + E[v])
```

终点 `E[n] = 0`。这是一个「从后往前」的递推：`E[u]` 依赖所有后继 `E[v]`，所以按**逆拓扑序**计算。

```cpp
double E[N];
for (int i = 1; i <= n; ++i) E[i] = 0;

for (int idx = (int)topo.size() - 1; idx >= 0; --idx) {
    int u = topo[idx];
    if (g[u].empty()) continue;
    for (size_t j = 0; j < g[u].size(); ++j) {
        int v = g[u][j].first;
        int w = g[u][j].second;
        E[u] += (w + E[v]) / g[u].size();
    }
}
```

`g[u].size()` 是 `size_t`，做除法时会把 `(w + E[v])` 转成无符号，结果仍是浮点，但为了可读性可以先存成 `double out = g[u].size();`。

### 99.4  概率取模

若某事件发生的概率是 `a/b`，在模素数 `MOD` 下写成

```
a × b⁻¹ mod MOD
```

前提是 `b` 不是 `MOD` 的倍数，否则逆元不存在。多步概率相乘、期望相加，逐项取模即可。

例如：袋中 3 红 2 蓝，随机取两球，同色的概率是

```
(C(3,2) + C(2,2)) / C(5,2) = (3 + 1) / 10 = 2/5
```

模 `10⁹+7` 下就是 `2 × inv(5) mod MOD`。先数方案再乘逆元，比直接推概率稳。

### 99.5  案例：超速检测的区间建模

CSP-S 2024 的超速检测是一道典型的「数学 → 区间 → 贪心」题。

**题意**：`n` 辆车从 `d_i` 驶入，初速度 `v_i`，加速度 `a_i`；`m` 个测速仪在 `p_j`。限速 `V`。求：

1. 所有测速仪开启时，有多少辆车被判定超速；
2. 在不漏掉这些超速车的前提下，最多能关闭多少个测速仪。

**建模**：对每辆车，求出它会超速的测速仪下标区间 `[l, r]`。速度公式

```
v² = v₀² + 2a·(p - d)
```

令 `v > V`，解出临界位置 `x₀`：

```
x₀ = d + (V² - v₀²) / (2a)
```

分三种情况：

- `a = 0`：`v₀ > V` 时全程超速，否则不超速；
- `a > 0`：速度递增。`v₀ > V` 时从 `d` 起就超速；否则从 `x₀` 之后超速；
- `a < 0`：速度递减。`v₀ ≤ V` 时不超速；否则在 `x₀` 之前超速。

用 `lower_bound / upper_bound` 把位置区间转成测速仪下标区间。注意「超过」是严格大于，临界点上的测速仪不算。

**第一问**：区间非空的车辆数。

**第二问**：每个非空区间至少要保留一个测速仪，才能不漏掉这辆车。问题变成「选最少的点，使每个区间都包含至少一个点」——经典区间选点贪心：

1. 所有区间按右端点升序排序；
2. 维护上一个选中的点 `last`；
3. 若当前区间不包含 `last`（`last < l`），就在它的右端点放一个点，`last = r`，答案加一。

最少保留 `keep` 个，最多关闭 `m - keep` 个。

```cpp
// 假设 p 读入并升序
struct Seg { int l, r; };

vector<Seg> seg;
for (int i = 0; i < n; ++i) {
    long long d, v, a;
    cin >> d >> v >> a;
    int l = -1, r = -1;
    if (a == 0) {
        if (v <= V) continue;
        l = lower_bound(p.begin(), p.end(), d) - p.begin();
        r = m - 1;
    } else if (a > 0) {
        long double x0 = d + (1.0L * V * V - 1.0L * v * v) / (2.0L * a);
        if (v > V) l = lower_bound(p.begin(), p.end(), d) - p.begin();
        else       l = upper_bound(p.begin(), p.end(), x0) - p.begin();
        r = m - 1;
    } else {
        if (v <= V) continue;
        long double x0 = d + (1.0L * V * V - 1.0L * v * v) / (2.0L * a);
        l = lower_bound(p.begin(), p.end(), d) - p.begin();
        r = lower_bound(p.begin(), p.end(), x0) - p.begin() - 1;
    }
    if (l <= r && l < m && r >= 0) seg.push_back({l, r});
}

sort(seg.begin(), seg.end(), [](const Seg &A, const Seg &B) {
    return A.r < B.r;
});

int keep = 0, last = -1;
for (size_t i = 0; i < seg.size(); ++i) {
    if (last < seg[i].l) {
        last = seg[i].r;
        ++keep;
    }
}

cout << seg.size() << " " << m - keep << endl;
```

**易错点**：`x₀` 用 `long double`，比较时加一点余量；`lower_bound` 是「第一个 ≥」，`upper_bound` 是「第一个 >」；`a < 0` 时车可能提前停下，但 `v₀ > V` 时临界点一定在停车点之前，所以区间仍由 `x₀` 决定。

## 💻 例题与解析

### 例 1  绿豆蛙的归宿（P4316）

**题意**：DAG 有 `n` 个点 `m` 条边，从 `1` 出发，每到一个点等概率走一条出边，求到 `n` 的期望路径长度。

**解析**：设 `E[u]` 为从 `u` 到 `n` 的期望。`E[n] = 0`，按逆拓扑序递推：

```
E[u] = Σ (w + E[v]) / outdeg(u)
```

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
vector<pair<int,int> > g[N];
int indeg[N];
double E[N];

int main() {
    int n, m;
    scanf("%d%d", &n, &m);
    for (int i = 0; i < m; ++i) {
        int u, v, w;
        scanf("%d%d%d", &u, &v, &w);
        g[u].push_back(make_pair(v, w));
        ++indeg[v];
    }

    queue<int> q;
    vector<int> topo;
    for (int i = 1; i <= n; ++i)
        if (indeg[i] == 0) q.push(i);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        topo.push_back(u);
        for (size_t i = 0; i < g[u].size(); ++i) {
            int v = g[u][i].first;
            if (--indeg[v] == 0) q.push(v);
        }
    }

    for (int i = 1; i <= n; ++i) E[i] = 0;
    for (int idx = (int)topo.size() - 1; idx >= 0; --idx) {
        int u = topo[idx];
        if (g[u].empty()) continue;
        double out = g[u].size();
        for (size_t i = 0; i < g[u].size(); ++i) {
            int v = g[u][i].first, w = g[u][i].second;
            E[u] += (w + E[v]) / out;
        }
    }
    printf("%.2f\n", E[1]);
    return 0;
}
```

**复杂度**：拓扑 `O(n+m)`，递推 `O(n+m)`。**易错点**：递推方向别反；终点 `E[n] = 0`；出度为 0 且不是终点的点要跳过，避免除零。

### 例 2  概率取模

**题意**：袋中 3 红 2 蓝，随机取两球，求同色的概率，模 `10⁹+7`。

**解析**：同色方案 `C(3,2) + C(2,2) = 4`，总方案 `C(5,2) = 10`，概率 `2/5`。模意义下输出 `2 × inv(5) mod MOD`。

```cpp
#include <bits/stdc++.h>
using namespace std;

const long long MOD = 1000000007;

long long qpow(long long a, long long b) {
    long long r = 1;
    while (b) {
        if (b & 1) r = r * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return r;
}

int main() {
    long long num = 4, den = 10;
    cout << num * qpow(den, MOD - 2) % MOD << endl;   // 2/5
    return 0;
}
```

**易错点**：先约分再取模不是必须的，但分子分母都要对 `MOD` 取模；若 `den` 是 `MOD` 的倍数，逆元不存在，题目通常会避开。

### 例 3  部分分设计

**题意**：某题 `n ≤ 2000` 时允许 `O(n²)`，`n ≤ 10⁵` 要求正解。你只会 `O(n²)`，怎么拿分？

**解析**：按数据档分三支：`n ≤ 2000` 时跑 `O(n²)` 暴力；数据满足特殊性质时跑专用解法；其余情况仍交暴力，但在入口加保护，避免死循环或 RE。核心是**每档单独测试**，不要让暴力在大数据上 TLE 后连小数据分也丢了。

## ⚠️ 常见错误

- **误以为期望线性性要求独立**：`E[X+Y] = E[X] + E[Y]` 对任意期望存在的随机变量都成立。
- **概率取模忘乘逆元**：`a/b % MOD` 是整数除法，必须先乘 `b` 的逆元。
- **分母与模数不互质**：逆元不存在，题目若没保证，要换模数或约分。
- **DAG 期望递推方向反了**：从终点往前推，用逆拓扑序。
- **出度为 0 未处理**：除零会得到 `nan`。
- **只盯正解不写部分分**：正解写挂，连暴力分也没有。
- **多测不清空**：期望数组、图、区间列表都要重置。

## 🧠 本章小结

```
选型：
  方案数 → 组合/容斥/Catalan
  模除法 → 逆元
  多同余 → CRT/exCRT
  线性递推 + 大 n → 矩阵快速幂
  随机游走 → 期望 DP

期望：
  E[X+Y] = E[X] + E[Y]（不要求独立）
  E[u] = Σ(w + E[v]) / outdeg(u)
  逆拓扑序，E[n] = 0

概率取模：
  a/b → a · b^(-1) mod MOD

部分分：
  暴力 → 特殊性质 → 正解
```
