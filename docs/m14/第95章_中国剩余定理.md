# 第 95 章 中国剩余定理
---

## 🎯 本章目标
- 掌握模数两两互质时的 CRT 构造
- 会用 exgcd 合并不互质的方程（exCRT）
- 正确处理乘积溢出与最小非负解
## 🎬 故事/动机
《孙子算经》的"物不知数"就是韩信点兵：士兵排队，3 人一排余 2，5 人一排余 3，7 人一排余 2，问最少多少人。CRT 不只给出答案，还告诉我们：在模 M 的意义下解是唯一的。现代密码学中的大数运算也靠它拆分模数。
## 🧱 知识讲解
### 95.1 互质模数的 CRT 构造
设 m1..mk 两两互质，M=∏mi，Mi=M/mi。因为 Mi 与 mi 互质，可求 ti=Mi^(-1) (mod mi)。令 x=Σ ai·Mi·ti (mod M)：第 i 项在模 mi 下等于 ai，其余项含因子 mi 而消为 0，因此 x 就是解。
```cpp
__int128 M = 1, ans = 0;
for (int i = 0; i < k; i++) M *= m[i];
for (int i = 0; i < k; i++) {
    __int128 Mi = M / m[i];
    ans = (ans + (__int128)a[i] * Mi % M * inv(Mi % m[i], m[i])) % M;
}
cout << (long long)ans;
```
### 95.2 模数不互质：扩展 CRT
把已求出的解记作 x≡a1 (mod m1)，新方程 x≡a2 (mod m2)。设 x=a1+m1·t，则 m1·t≡a2-a1 (mod m2)。令 g=gcd(m1,m2)：若 (a2-a1)%g≠0 则无解；否则 t=((a2-a1)/g)·inv(m1/g) (mod m2/g)，再令 a1=a1+m1·t、m1=lcm(m1,m2)。
```cpp
bool merge(long long &a1, long long &m1, long long a2, long long m2) {
    long long x, y, g = exgcd(m1, m2, x, y);
    if ((a2 - a1) % g) return false;
    long long lcm = m1 / g * m2;
    x = (__int128)x * ((a2 - a1) / g) % (m2 / g);
    a1 = ((a1 + (__int128)m1 * x) % lcm + lcm) % lcm;
    m1 = lcm;
    return true;
}
```
### 95.3 解的范围与溢出
CRT 的解在 [0,M) 内唯一；exCRT 合并完的 a1 已是最小非负解，周期是 lcm。M 与中间乘积可能超过 `long long`，乘法先转 `__int128`；`lcm` 要先除以 g 再乘，避免提前溢出。

**例 2**：[P4777 扩展中国剩余定理](https://hydro.ac/p/luogu-P4777)。模数不保证互质，从第一个方程开始逐个 `merge`，中途返回 false 即无解；输出合并后的 a1。
## ⚠️ 常见坑
1. CRT 的逆元只在模数两两互质时存在；不互质必须用 exCRT。
2. 合并无解条件是 `(a2-a1)%g != 0`，不是 `a2%g != a1%g` 的随意变形。
3. `lcm=m1/g*m2` 顺序写反会先溢出；答案未归一到 [0,lcm) 会输出负数。
4. 多测时忘记重置 M、a1、m1。
