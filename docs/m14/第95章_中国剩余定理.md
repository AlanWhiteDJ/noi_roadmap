## 🧱 知识讲解

### 95.1  问题形式与唯一性

给定 `k` 个同余方程：

```
x ≡ a₁ (mod m₁)
x ≡ a₂ (mod m₂)
…
x ≡ a_k (mod m_k)
```

若 `m₁, m₂, …, m_k` **两两互质**，令 `M = m₁m₂…m_k`，则方程组在模 `M` 下有唯一解。

为什么唯一？若 `x、y` 都是解，则每个 `m_i | (x-y)`。因为 `m_i` 两两互质，它们的乘积 `M` 也整除 `x-y`，所以 `x ≡ y (mod M)`。

> ⚠️ 「两两互质」是 CRT 构造法的前提。不互质时不一定无解，但不能直接套下面的公式，要用扩展 CRT。

### 95.2  CRT 的构造

记

```
M_i = M / m_i
```

因为 `m_i` 与其它模数都互质，所以 `gcd(M_i, m_i) = 1`，`M_i` 在模 `m_i` 下有逆元，记作

```
t_i ≡ M_i⁻¹ (mod m_i)
```

于是 `M_i · t_i ≡ 1 (mod m_i)`，而 `M_i · t_i ≡ 0 (mod m_j)`（`j ≠ i`），因为 `M_i` 含有因子 `m_j`。

构造

```
x = Σ a_i · M_i · t_i  (mod M)
```

逐项检查：对第 `i` 个方程取模 `m_i`，只有第 `i` 项留下 `a_i · 1 = a_i`，其余项都含 `m_i` 的因子而变成 `0`。所以 `x ≡ a_i (mod m_i)`，全部满足。

**手算「物不知数」**：`m = (3, 5, 7)`，`a = (2, 3, 2)`，`M = 105`。

| i | m_i | a_i | M_i | t_i = M_i⁻¹ mod m_i | 项 a_i·M_i·t_i |
|---|-----|-----|-----|---------------------|----------------|
| 1 | 3 | 2 | 35 | 2（35≡2，2⁻¹≡2） | 140 |
| 2 | 5 | 3 | 21 | 1（21≡1） | 63 |
| 3 | 7 | 2 | 15 | 1（15≡1） | 30 |

加起来 `233`，对 `105` 取模得 `23`。验证：`23 % 3 = 2`、`23 % 5 = 3`、`23 % 7 = 2`。

**代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef __int128 i128;

long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

long long modInverse(long long a, long long m) {
    long long x, y;
    exgcd(a, m, x, y);
    return (x % m + m) % m;
}

int main() {
    int k;
    cin >> k;
    vector<long long> a(k), m(k);
    i128 M = 1;
    for (int i = 0; i < k; ++i) {
        cin >> m[i] >> a[i];        // 注意本题输入顺序：模数在前
        M *= m[i];
    }
    i128 ans = 0;
    for (int i = 0; i < k; ++i) {
        i128 Mi = M / m[i];
        long long t = modInverse((long long)(Mi % m[i]), m[i]);
        ans = (ans + (i128)a[i] * Mi % M * t) % M;
    }
    cout << (long long)ans << endl;
    return 0;
}
```

**复杂度**：`k` 次 exgcd，`O(k log max m_i)`。

### 95.3  模数不互质：扩展 CRT

当 `m₁、m₂` 不互质时，`M_i` 在模 `m_i` 下可能没有逆元，上面的构造失效。改用**两两合并**。

假设已经求出前若干个方程的解：

```
x ≡ a₁ (mod m₁)
```

加入新方程 `x ≡ a₂ (mod m₂)`。设 `x = a₁ + m₁·t`，代入得

```
m₁·t ≡ a₂ - a₁ (mod m₂)
```

令 `g = gcd(m₁, m₂)`。这个关于 `t` 的方程有解，当且仅当

```
(a₂ - a₁) % g == 0
```

否则整个方程组无解。有解时，两边同除以 `g`：

```
(m₁/g)·t ≡ (a₂-a₁)/g (mod m₂/g)
```

因为 `gcd(m₁/g, m₂/g) = 1`，可以求逆：

```
t ≡ ((a₂-a₁)/g) · (m₁/g)⁻¹ (mod m₂/g)
```

代回 `x = a₁ + m₁·t`，再把模数更新为 `lcm(m₁, m₂) = m₁/g · m₂`，就完成了一次合并。

```cpp
bool merge(long long &a1, long long &m1, long long a2, long long m2) {
    long long x, y;
    long long g = exgcd(m1, m2, x, y);
    i128 d = (i128)a2 - a1;
    if (d % g != 0) return false;

    long long m2g = m2 / g;
    i128 t = (i128)(x % m2g) * ((d / g) % m2g) % m2g;
    t = (t % m2g + m2g) % m2g;

    i128 lcm = (i128)(m1 / g) * m2;
    a1 = (long long)(((i128)a1 + (i128)m1 * t) % lcm);
    a1 = (a1 % lcm + lcm) % lcm;
    m1 = (long long)lcm;
    return true;
}
```

从第一个方程开始，依次把后面的方程合并进来：

```cpp
long long a1 = a[0], m1 = m[0];
for (int i = 1; i < k; ++i) {
    if (!merge(a1, m1, a[i], m[i])) {
        cout << "No Solution" << endl;
        return 0;
    }
}
cout << a1 << endl;          // 最小非负解
```

### 95.4  溢出与边界

- `M = ∏ m_i` 很容易超过 `long long`。若乘积在 `1.7 × 10³⁸` 内，可以用 `__int128`；但 `k = 20`、每个 `m_i = 10⁹` 时 `M` 有 `10¹⁸⁰` 量级，`__int128` 也装不下，必须写高精度，或依赖题目对答案范围的保证。
- `Mi % m_i` 先取模再传参，避免 `Mi` 太大。
- `lcm = m1/g * m2` 必须先除后乘。写成 `m1 * m2 / g`，`m1 * m2` 可能已经溢出。
- `a_i` 可能为负或大于 `m_i`，先归一到 `[0, m_i)`；`a1` 合并完也要归一到 `[0, lcm)`。
- `m_i = 1` 时方程恒成立，`M_i % 1 = 0`，逆元按模 `1` 处理为 `0`，该项贡献 `0`，不影响结果；但要注意别除以零。
- 多测时把 `a1、m1、ans` 全部重置。

## 💻 例题与解析

### 例 1  中国剩余定理（P1495）

**题意**：给定 `k` 个两两互质的模数 `m_i` 和余数 `a_i`，求最小非负整数解。输入每行先 `m_i` 再 `a_i`。

**解析**：直接套 95.2 的构造。`M` 与每项乘积用 `__int128`，最后转回 `long long`。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef __int128 i128;

long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

int main() {
    int n;
    cin >> n;
    vector<long long> m(n), a(n);
    i128 M = 1;
    for (int i = 0; i < n; ++i) {
        cin >> m[i] >> a[i];
        M *= m[i];
    }
    i128 ans = 0;
    for (int i = 0; i < n; ++i) {
        i128 Mi = M / m[i];
        long long x, y;
        exgcd((long long)(Mi % m[i]), m[i], x, y);
        long long t = (x % m[i] + m[i]) % m[i];
        ans = (ans + (i128)a[i] * Mi % M * t) % M;
    }
    cout << (long long)ans << endl;
    return 0;
}
```

**易错点**：`t` 必须归一到 `[0, m_i)`；`ans` 每加一项就取模，否则 `__int128` 也可能被撑爆；输入顺序别弄反。

### 例 2  扩展中国剩余定理（P4777）

**题意**：给定 `n` 个同余方程，模数**不保证**两两互质，求最小非负解；数据保证有解。输入每行先模数 `m_i`，再余数 `a_i`。

**解析**：用 95.3 的 `merge` 逐个合并。注意 P4777 的输入也是**先模数 `m_i`、再余数 `a_i`**（题面里叫 `a_i, b_i`），别被变量名误导。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef __int128 i128;

long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

bool merge(long long &a1, long long &m1, long long a2, long long m2) {
    long long x, y;
    long long g = exgcd(m1, m2, x, y);
    i128 d = (i128)a2 - a1;
    if (d % g != 0) return false;
    long long m2g = m2 / g;
    i128 t = (i128)(x % m2g) * ((d / g) % m2g) % m2g;
    t = (t % m2g + m2g) % m2g;
    i128 lcm = (i128)(m1 / g) * m2;
    a1 = (long long)(((i128)a1 + (i128)m1 * t) % lcm);
    a1 = (a1 % lcm + lcm) % lcm;
    m1 = (long long)lcm;
    return true;
}

int main() {
    int n;
    cin >> n;
    long long a1, m1;
    cin >> m1 >> a1;
    for (int i = 1; i < n; ++i) {
        long long a2, m2;
        cin >> m2 >> a2;
        if (!merge(a1, m1, a2, m2)) {
            cout << -1 << endl;
            return 0;
        }
    }
    cout << a1 << endl;
    return 0;
}
```

**复杂度**：`O(n log max m_i)`。**易错点**：`d` 用 `__int128`，防止 `a2 - a1` 溢出；`m2g` 可能为 `1`，此时取模结果为 `0`，是正确行为。

### 例 3  无解判定

**题意**：判断 `x ≡ 1 (mod 4)` 与 `x ≡ 2 (mod 6)` 是否有公共解。

**解析**：`g = gcd(4, 6) = 2`，`a₂ - a₁ = 1`，`1 % 2 ≠ 0`，无解。直观理解：第一个方程要求 `x` 是奇数，第二个方程要求 `x` 是偶数，矛盾。

若改成 `x ≡ 3 (mod 4)` 与 `x ≡ 5 (mod 6)`：`a₂ - a₁ = 2`，`2 % 2 = 0`，有解。合并得 `t ≡ 1 · (4/2)⁻¹ ≡ 1 · 2⁻¹ ≡ 2 (mod 3)`，`x = 3 + 4×2 = 11`，模 `lcm(4,6)=12` 下解为 `11`。验证：`11 % 4 = 3`，`11 % 6 = 5`。

## ⚠️ 常见错误

- **不互质硬套 CRT**：`M_i` 没有逆元，算出的 `t` 是垃圾值。先判断 `gcd`，不互质就用 exCRT。
- **无解条件写错**：是 `(a₂-a₁) % g != 0`，不是 `a₂ % g != a₁ % g` 的随意变形。
- **`lcm` 先乘后除**：`m1 * m2 / g` 可能先溢出；写成 `m1 / g * m2`。
- **周期用错**：合并后的模数是 `lcm(m1,m2)`，不是 `m1 * m2`（不互质时两者不同）。
- **忘记归一**：`a1` 可能是负数或超过 `lcm`，输出前必须归一到 `[0, lcm)`。
- **输入顺序**：P1495 与 P4777 都是先模数 `m_i`、再余数 `a_i`，看清题面里的变量名。

## 🧠 本章小结

```
CRT（模数两两互质）：
  M = ∏ m_i，M_i = M / m_i
  t_i = M_i^(-1) mod m_i
  x = Σ a_i·M_i·t_i (mod M)
  每一项只在自己的模数下留下 a_i

exCRT（模数任意）：
  x = a1 + m1·t 代入 a2
  g = gcd(m1,m2)
  (a2-a1) % g != 0 → 无解
  t = ((a2-a1)/g)·(m1/g)^(-1) mod (m2/g)
  a1 = a1 + m1·t，m1 = lcm(m1,m2)

溢出：
  M、乘积用 __int128
  lcm 先除后乘
```
