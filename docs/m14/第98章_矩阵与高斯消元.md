## 📖 故事引入

小华遇到一道题：求斐波那契数列第 `10¹⁸` 项，模 `10⁹+7`。

「递推一次加一次，`10¹⁸` 次……宇宙毁灭都算不完。」

同桌画了一个 `2 × 2` 的表格：

```
[1 1]   [F_n]   [F_{n+1}]
[1 0] × [F_{n-1}] = [F_n]
```

「每推一步，就是乘这个矩阵。乘一次是 `O(1)`，乘 `n` 次是 `O(n)`；但矩阵乘法满足结合律，所以可以用快速幂，把 `n` 次压成 `log n` 次。」

小华盯着表格：「那如果递推式更复杂呢？」

「只要它是线性的，就能写成矩阵。状态里需要记住几项，矩阵就是几阶。」同桌又补了一句，「至于解方程——那是另一套机械动作，叫高斯消元。」

## 🧱 知识讲解

### 98.1  向量与矩阵

向量是一列数，矩阵是数的矩形阵列。`n × m` 的矩阵有 `n` 行 `m` 列，记 `A[i][j]` 为第 `i` 行第 `j` 列的元素。

几种特殊矩阵：

| 名称 | 特征 | 用途 |
|------|------|------|
| 零矩阵 | 所有元素为 0 | 加法单位元 |
| 单位矩阵 `I` | 主对角线为 1，其余为 0 | 乘法单位元 |
| 对角矩阵 | 非对角线元素全为 0 | 快速幂、缩放 |
| 对称矩阵 | `A[i][j] = A[j][i]` | 二次型、图论 |
| 上/下三角 | 对角线一侧全为 0 | 高斯消元结果 |

### 98.2  矩阵乘法

设 `C = A × B`，其中 `A` 是 `n × k`，`B` 是 `k × m`，则 `C` 是 `n × m`，且

```
C[i][j] = Σ_{t=1}^{k} A[i][t] × B[t][j]
```

**合法条件**：左矩阵的列数等于右矩阵的行数。`n × k` 乘 `k × m` 得 `n × m`。

矩阵乘法满足结合律 `(AB)C = A(BC)`，也满足分配律，但**不满足交换律**：一般情况下 `AB ≠ BA`。这一点在快速幂和递推里必须时刻记住——乘的顺序一换，答案就变了。

朴素乘法是 `O(nkm)`。当矩阵很小（比如 `3 × 3`）时，常数可以忽略：

```cpp
const int SZ = 3;
const long long MOD = 1000000007;

struct Mat {
    long long a[SZ][SZ];
    Mat() { memset(a, 0, sizeof(a)); }
};

Mat operator*(const Mat &A, const Mat &B) {
    Mat C;
    for (int i = 0; i < SZ; ++i)
        for (int k = 0; k < SZ; ++k) {
            if (A.a[i][k] == 0) continue;          // 稀疏时提速
            for (int j = 0; j < SZ; ++j)
                C.a[i][j] = (C.a[i][j] + A.a[i][k] * B.a[k][j]) % MOD;
        }
    return C;
}
```

`A.a[i][k] * B.a[k][j]` 最大约 `10¹⁸`，在 `long long` 内；如果模数更大，要改用 `__int128`。

### 98.3  矩阵快速幂

和整数快速幂完全同构，只把「乘」换成矩阵乘法，把累乘器初值换成单位矩阵：

```cpp
Mat matPow(Mat A, long long b) {
    Mat R;
    for (int i = 0; i < SZ; ++i) R.a[i][i] = 1;   // 单位矩阵
    while (b > 0) {
        if (b & 1) R = R * A;
        A = A * A;
        b >>= 1;
    }
    return R;
}
```

如果把 `R` 初始化为零矩阵，第一次乘完就全成 0，后面永远是 0——这是最常见的错误。

### 98.4  矩阵加速线性递推

**斐波那契**：`F_n = F_{n-1} + F_{n-2}`。取状态向量

```
S_n = [F_n, F_{n-1}]^T
```

则

```
S_{n+1} = [1 1] · S_n
         [1 0]
```

所以 `S_n = T^(n-1) · S_1`，其中 `S_1 = [F_1, F_0] = [1, 1]`（若定义 `F_0 = 1`）。

**三阶例子**：`f_n = f_{n-1} + f_{n-3}`。状态需要记住最近三项：

```
S_n = [f_n, f_{n-1}, f_{n-2}]^T
```

下一步

```
S_{n+1} = [f_n + f_{n-2}, f_n, f_{n-1}]^T
```

写成矩阵：

```
T = [1 0 1]
    [1 0 0]
    [0 1 0]
```

第一行是递推系数 `[1, 0, 1]`，下面两行负责把旧状态「下移」。若 `f_1 = f_2 = f_3 = 1`，则 `S_3 = [1,1,1]`，答案为 `T^(n-3) · S_3` 的第一个分量。

**构造矩阵的通用方法**：

1. 状态向量的分量是递推所需的最近 `k` 项；
2. 第一行按递推式填系数，缺的项填 0；
3. 下面 `k-1` 行是「下移」：第 `i` 行在第 `i-1` 列填 1；
4. 用初值确定指数偏移，别把 `T^n` 和 `T^(n-k+1)` 弄混。

### 98.5  高斯消元

把 `n` 元一次方程组写成增广矩阵：

```
[ a11 a12 … a1n | b1 ]
[ a21 a22 … a2n | b2 ]
[  …             | …  ]
[ an1 an2 … ann | bn ]
```

目标是把左侧化成上三角（或对角），再回代。

初等变换有三种：交换两行、某行乘非零数、某行加上另一行的倍数。步骤：

1. 当前列选绝对值最大的行作主元（**列主元**），换到当前行；
2. 用主元行消去其它行的这一列；
3. 处理下一列。

消完后：

- 若某行系数全为 0、常数非 0，则**无解**；
- 若主元个数小于 `n`，则**无穷多解**；
- 否则**唯一解**，回代求出每个未知数。

```cpp
const int N = 105;
const double EPS = 1e-8;
double a[N][N];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= n + 1; ++j)
            cin >> a[i][j];

    for (int i = 1; i <= n; ++i) {
        int p = i;
        for (int j = i; j <= n; ++j)
            if (fabs(a[j][i]) > fabs(a[p][i])) p = j;

        if (fabs(a[p][i]) < EPS) {
            cout << "No Solution" << endl;
            return 0;
        }
        swap(a[p], a[i]);

        for (int j = 1; j <= n; ++j) {
            if (j == i) continue;
            double t = a[j][i] / a[i][i];
            for (int k = i; k <= n + 1; ++k)
                a[j][k] -= t * a[i][k];
        }
    }

    for (int i = 1; i <= n; ++i)
        printf("%.2f\n", a[i][n+1] / a[i][i]);
    return 0;
}
```

复杂度 `O(n³)`。列主元不能省。P3389 只要求输出 `No Solution`，所以主元为 0 时直接退出；若要区分无解与无穷多解，再细分。

> 💡 若题目在模素数下解方程，把除法换成乘逆元，把 `fabs` 比较换成「是否非零」，就得到模意义下的高斯消元。它常用于生成函数、概率期望和线性基的题目。

## 💻 例题与解析

### 例 1  矩阵加速（P1939）

**题意**：`f_1 = f_2 = f_3 = 1`，`f_n = f_{n-1} + f_{n-3}`，求 `f_n mod 10⁹+7`，多组询问，`n` 可达 `2 × 10⁹`。

**解析**：按 98.4 构造 `3 × 3` 矩阵，`n ≤ 3` 直接输出 1，否则算 `T^(n-3)`，答案是其第一行与 `[1,1,1]` 的点积，即第一行三个元素之和。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int SZ = 3;
const long long MOD = 1000000007;

struct Mat {
    long long a[SZ][SZ];
    Mat() { memset(a, 0, sizeof(a)); }
};

Mat operator*(const Mat &A, const Mat &B) {
    Mat C;
    for (int i = 0; i < SZ; ++i)
        for (int k = 0; k < SZ; ++k) {
            if (A.a[i][k] == 0) continue;
            for (int j = 0; j < SZ; ++j)
                C.a[i][j] = (C.a[i][j] + A.a[i][k] * B.a[k][j]) % MOD;
        }
    return C;
}

Mat matPow(Mat A, long long b) {
    Mat R;
    for (int i = 0; i < SZ; ++i) R.a[i][i] = 1;
    while (b > 0) {
        if (b & 1) R = R * A;
        A = A * A;
        b >>= 1;
    }
    return R;
}

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        long long n;
        scanf("%lld", &n);
        if (n <= 3) { puts("1"); continue; }
        Mat base;
        base.a[0][0] = 1; base.a[0][2] = 1;
        base.a[1][0] = 1;
        base.a[2][1] = 1;
        Mat R = matPow(base, n - 3);
        long long ans = (R.a[0][0] + R.a[0][1] + R.a[0][2]) % MOD;
        printf("%lld\n", ans);
    }
    return 0;
}
```

**易错点**：矩阵要清零；`T` 的第一行是 `[1,0,1]`，第二行 `[1,0,0]`，第三行 `[0,1,0]`；指数是 `n-3`；多组询问不要重复初始化错矩阵。

### 例 2  高斯消元（P3389）

**题意**：给定 `n` 个未知数、`n` 个方程，求唯一解；若无唯一解输出 `No Solution`。输出保留两位小数。

**解析**：直接套 98.5 的模板，输入时多读一列常数，输出时除以主元。核心只有两行：

```cpp
for (int i = 1; i <= n; ++i)
    printf("%.2f\n", a[i][n+1] / a[i][i]);
```

完整代码与 98.5 一致，只需在输出前加一句 `if (fabs(x) < 5e-3) x = 0;`，避免打印 `-0.00`。

### 例 3  判定解的情况

**题意**：判断方程组 `x + y = 2`，`2x + 2y = 5` 的解的情况。

**解析**：第二行减去第一行的 2 倍，得到 `0 = 1`，矛盾，**无解**。

若第二个方程是 `2x + 2y = 4`，消元后得到 `0 = 0`，方程退化为一个，未知数有两个，**无穷多解**，通解为 `(x, y) = (2 - t, t)`。

**结论**：消元后出现「系数全 0、常数非 0」是无解；出现「整行全 0」且主元数不足是无穷多解。这两种情况在代码里要分开处理，不能都输出 `No Solution`。

## ⚠️ 常见错误

- **乘法顺序反了**：`A * B` 与 `B * A` 一般不相等；递推里矩阵在左、状态向量在右。
- **快速幂初值不是单位矩阵**：零矩阵会让所有结果变成 0。
- **指数偏移错**：`S_n = T^(n-k) · S_k`，`n = k` 时指数为 0，返回单位矩阵。
- **矩阵不清零**：`Mat` 的构造函数要 `memset`，多测时重新构造。
- **高斯消元不做列主元**：主元过小会导致误差爆炸。
- **无解与无穷多解混为一谈**：前者是「0 = 非 0」，后者是「秩小于未知数个数」。
- **输出 `-0.00`**：浮点负零要归零。

## 🧠 本章小结

```
矩阵乘法：
  C[i][j] = Σ A[i][k]·B[k][j]
  合法：左列数 = 右行数
  结合律成立，交换律不成立

矩阵快速幂：
  累乘器初值 = 单位矩阵 I
  O(k^3 log n)

矩阵加速递推：
  状态 = 最近 k 项
  第一行 = 递推系数
  下面 k-1 行负责下移
  S_n = T^(n-k) · S_k

高斯消元：
  增广矩阵 + 列主元
  消成上三角/对角
  0 = 非 0 → 无解
  秩 < n → 无穷多解
  O(n^3)
```
