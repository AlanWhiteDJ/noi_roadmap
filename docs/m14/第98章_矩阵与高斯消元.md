# 第 98 章 矩阵与高斯消元
---
> 🏗️ **前情回顾**：第 50 章用快速幂把 a^n 降到 O(log n)。如果递推式是线性的，也能把"一次递推"写成矩阵乘法，再用快速幂整体加速；另一方面，多元一次方程组可以用高斯消元系统求解。
## 🎯 本章目标
- 掌握矩阵乘法、单位矩阵与矩阵快速幂
- 把线性递推改写成矩阵形式并确定初值
- 用高斯消元判断唯一解、无解与无穷多解
## 🎬 故事/动机
斐波那契数列递推到第 10^18 项显然不可能。但递推只依赖前两项，把这两项打包成向量，每推一步就是乘一个固定矩阵——于是 O(n) 变成 O(log n)。高斯消元则是"加减消元"的机械化：把方程组的系数排成表，一行行消成上三角。
## 🧱 知识讲解
### 98.1 矩阵乘法
若 C=A·B，则 C[i][j]=Σ A[i][k]·B[k][j]。矩阵乘法满足结合律，但**不满足交换律**；单位矩阵主对角线为 1，其余为 0。实现时把不参与运算的 0 跳过：
```cpp
struct Mat { long long a[3][3] = {}; };
Mat operator*(const Mat &A, const Mat &B) {
    Mat C;
    for (int i = 0; i < 3; i++) for (int k = 0; k < 3; k++) if (A.a[i][k])
        for (int j = 0; j < 3; j++)
            C.a[i][j] = (C.a[i][j] + A.a[i][k] * B.a[k][j]) % MOD;
    return C;
}
```
### 98.2 矩阵加速线性递推
以 f_n=f_{n-1}+f_{n-3} 为例，令状态 S_n=[f_n,f_{n-1},f_{n-2}]^T，则 S_{n+1}=T·S_n，其中 T 的第一行是系数 [1,0,1]，下面两行负责把旧状态下移：`&#123;&#123;1,0,1},{1,0,0},{0,1,0}}`。初值 S_3=[1,1,1]，答案为 T^(n-3)·S_3 的第一分量。快速幂只需把整数乘法换成矩阵乘法，累乘器初值置为单位矩阵。
### 98.3 高斯消元
把方程组写成增广矩阵。逐列选绝对值最大的行作主元（列主元，减小误差），换到当前行，再用它消去其他行的该列。消完后若某行系数全 0 而常数非 0，则无解；若主元个数小于 n，则无穷多解；否则唯一解，回代即可。
```cpp
for (int i = 1; i <= n; i++) {
    int p = i;
    for (int j = i; j <= n; j++) if (fabs(a[j][i]) > fabs(a[p][i])) p = j;
    if (fabs(a[p][i]) < eps) continue;
    swap(a[p], a[i]);
    for (int j = 1; j <= n; j++) if (j != i) {
        double t = a[j][i] / a[i][i];
        for (int k = i; k <= n + 1; k++) a[j][k] -= t * a[i][k];
    }
}
```
## 💻 例题
**例 1**：[P1939 矩阵加速（数列）](https://hydro.ac/p/luogu-P1939)。f_1=f_2=f_3=1，f_n=f_{n-1}+f_{n-3}。按 98.2 构造 3×3 矩阵，n≤3 直接输出 1，否则算 T^(n-3) 后取第一行第一列。
**例 2**：[P3389 高斯消元法](https://hydro.ac/p/luogu-P3389)。n 个未知数 n 个方程，列主元消元后若秩小于 n 输出 `No Solution`，否则输出每个未知数（保留两位小数）。判零用 `fabs(x)<eps`，输出前把 -0.00 归零。
## ⚠️ 常见坑
1. 矩阵乘法顺序写反：A·B 与 B·A 一般不相等；快速幂初值必须是单位矩阵。
2. 递推的初值向量与指数偏移错位，例如 P1939 要用 T^(n-3) 而不是 T^n。
3. 高斯消元不做列主元会误差爆炸；"无解"与"无穷多解"要分开判定，多测记得清空矩阵。
