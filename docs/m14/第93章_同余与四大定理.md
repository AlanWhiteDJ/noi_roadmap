## 📖 故事引入

小华在做一个密码学小作业：求 `2^1000000 mod 13`。

他打开计算器，输入 `2`，然后疯狂按乘号——按到第 30 次，屏幕已经变成一串看不懂的科学计数法。「这得按到什么时候？」

同桌把草稿纸推过来，上面只写了两行：`φ(13) = 12`，`1000000 mod 12 = 4`。「所以答案是 `2^4 mod 13 = 3`。指数太大，就先把它在模 `φ(m)` 下缩小。这不是巧合，是欧拉定理。」

小华第一次意识到：**余数不只是除法剩下的零头，它自己构成一个可以运算的世界。** 这个世界里加减乘都正常，唯独除法处处是坑——四大定理就是四把不同用途的钥匙。

## 🧱 知识讲解

### 93.1  同余：给「余数相同」一个符号

若两个整数 `a`、`b` 除以 `m` 的余数相同，就说它们**模 m 同余**，记作：

```
a ≡ b (mod m)
```

它等价于 `m | (a - b)`。例如 `17 ≡ 2 (mod 5)`，因为 `5 | 15`。

同余式有三条最常用的性质：

- **可加减**：`a ≡ b` ⇒ `a ± c ≡ b ± c`；
- **可相乘**：`a ≡ b` ⇒ `ac ≡ bc`；
- **可乘方**：`a ≡ b` ⇒ `aⁿ ≡ bⁿ`。

但**没有**「可除」：`10 ≡ 4 (mod 6)`，两边同除 `2` 却得到 `5 ≢ 2 (mod 6)`。什么时候能除？要除的数与模数互质才行。这正是第 94 章「逆元」要解决的问题。

写代码时，C++ 的 `%` 对负数向零取整，`-7 % 5` 得到 `-2` 而不是 `3`。所以每次拿余数，都套一层归一化：

```cpp
long long norm(long long x, long long m) {
    return (x % m + m) % m;      // 结果一定落在 [0, m)
}
```

### 93.2  模意义下的运算边界

| 运算 | 能否直接做 | 注意点 |
|------|------------|--------|
| 加减 | ✅ | 减法先加 `m` 再取模 |
| 乘法 | ✅ | 模数近 `10⁹` 时两个余数相乘必爆 `int` |
| 除法 | ❌ | 要乘逆元，且逆元不一定存在 |

乘法的溢出最隐蔽。模数 `m = 10⁹ + 7` 时，两个小于 `m` 的数相乘最大约 `10¹⁸`，已经贴在 `long long` 上限；连乘两次就必须每步取模，或转 `__int128`。

### 93.3  欧拉函数 φ(n)

`φ(n)` 的定义是：`1` 到 `n` 中与 `n` 互质的数的个数。规定 `φ(1) = 1`。

若 `n` 的唯一分解是 `n = p₁^e₁ · p₂^e₂ · … · pₖ^eₖ`，则：

```
φ(n) = n × (1 - 1/p₁) × (1 - 1/p₂) × … × (1 - 1/pₖ)
```

例如 `12 = 2² × 3`，`φ(12) = 4`，与 `12` 互质的是 `1、5、7、11`。

单点求 `φ(n)` 只需试除到 `√n`：

```cpp
long long phi(long long n) {
    long long res = n;
    for (long long p = 2; p * p <= n; ++p) {
        if (n % p == 0) {
            res = res / p * (p - 1);      // 先除后乘，防溢出
            while (n % p == 0) n /= p;
        }
    }
    if (n > 1) res = res / n * (n - 1);   // 剩下一个大素数
    return res;
}
```

注意 `res / p * (p - 1)` 的顺序。写成 `res * (p - 1) / p` 在 `n` 接近 `10¹⁸` 时会先溢出，即使最终结果不大。

如果题目要连续求 `1..n` 的 `φ`，用线性筛，均摊 `O(n)`：

```cpp
const int N = 1000005;
int phi[N], prime[N], cnt;
bool vis[N];

void sievePhi(int n) {
    phi[1] = 1;
    for (int i = 2; i <= n; ++i) {
        if (!vis[i]) {
            prime[++cnt] = i;
            phi[i] = i - 1;                 // 素数的 φ 是自身减一
        }
        for (int j = 1; j <= cnt && 1LL * i * prime[j] <= n; ++j) {
            int x = i * prime[j];
            vis[x] = true;
            if (i % prime[j] == 0) {
                phi[x] = phi[i] * prime[j]; // 多了一个相同素因子
                break;
            } else {
                phi[x] = phi[i] * (prime[j] - 1);
            }
        }
    }
}
```

前 12 个 `φ` 值是 `1, 1, 2, 2, 4, 2, 6, 4, 6, 4, 10, 4`，可以背下来当小数据对拍表。

### 93.4  欧拉定理与费马小定理

**欧拉定理**：若 `gcd(a, m) = 1`，则

```
a^φ(m) ≡ 1 (mod m)
```

它最实用的推论是**降幂**：当 `gcd(a, m) = 1` 时，

```
a^b ≡ a^(b mod φ(m)) (mod m)
```

**费马小定理**：若 `p` 是素数，且 `p ∤ a`，则

```
a^(p-1) ≡ 1 (mod p)
```

因为 `φ(p) = p - 1`，费马小定理就是欧拉定理在素数模下的特例。反过来说：**模数是合数时，费马小定理不能用**，只能退回欧拉定理，并且必须先检查 `gcd(a, m) = 1`。

当 `a` 与 `m` 不互质时，上面的降幂公式失效，要用**扩展欧拉定理**：当 `b ≥ φ(m)` 时，`a^b ≡ a^(b mod φ(m) + φ(m)) (mod m)`。这个 `+ φ(m)` 不能省，否则指数被降得太小，结果会错。

### 93.5  威尔逊定理

**威尔逊定理**：`p` 是素数，当且仅当

```
(p - 1)! ≡ -1 (mod p)
```

它的价值在**证明和构造**，而不是判素：算 `(p-1)!` 是 `O(p)`，比试除还慢。但它能一秒解决一类题：`100! mod 101 = ?`。

`101` 是素数，由威尔逊定理 `100! ≡ -1 ≡ 100 (mod 101)`。再进一步，把 `1..100` 配对成 `i` 与 `101-i`：

```
100! ≡ (50!)² × (-1)^50 ≡ (50!)² ≡ -1 (mod 101)
```

所以 `(50!)² ≡ 100 (mod 101)`，`50!` 是 `100` 的平方根之一。这类「配对 + 符号」的推导，是威尔逊定理的典型用法。

### 93.6  裴蜀定理

**裴蜀定理**：对任意整数 `a、b`，方程

```
ax + by = c
```

有整数解，当且仅当 `gcd(a, b) | c`。特别地，`ax + by = gcd(a, b)` 一定有解。

两个直接推论：

1. `a` 在模 `m` 下存在逆元 ⇔ `gcd(a, m) = 1`。因为 `ax ≡ 1 (mod m)` 就是 `ax + my = 1`。
2. 若 `ax + by = g` 有一组解 `(x₀, y₀)`，则通解是

```
x = x₀ + k·(b/g)
y = y₀ - k·(a/g)
```

例如 `3x + 5y = 1`，观察得 `x = 2, y = -1`；通解为 `x = 2 + 5k, y = -1 - 3k`。

### 93.7  四把钥匙的分工

四把钥匙：**欧拉**管任意模数（要求互质），**费马**管素数模，**威尔逊**管阶乘与配对构造，**裴蜀**管方程和逆元的存在性。一句口诀：欧拉管一般，费马管素数，威尔逊管阶乘，裴蜀管存在。

## 💻 例题与解析

### 例 1  指数降幂（手算 + 验证）

**题意**：求 `2^2024 mod 13`。

**解析**：

`13` 是素数，`gcd(2, 13) = 1`，可以用费马小定理，周期是 `12`。

```
2024 = 12 × 168 + 8
2^2024 ≡ 2^8 = 256 ≡ 256 - 13 × 19 = 9 (mod 13)
```

答案是 `9`。

**验证代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

long long qpow(long long a, long long b, long long m) {
    long long res = 1 % m;
    while (b > 0) {
        if (b & 1) res = res * a % m;
        a = a * a % m;
        b >>= 1;
    }
    return res;
}

int main() {
    cout << qpow(2, 2024, 13) << endl;          // 9
    cout << qpow(2, 2024 % 12, 13) << endl;     // 9，降幂后一致
    return 0;
}
```

**易错点**：真正的大指数常以字符串给出，那时要边读入边对 `φ(m)` 取模，不能读进 `long long`。

### 例 2  仪仗队（P2158）

**题意**：`n × n` 的方阵，从左上角 `(0,0)` 看，能看到多少个士兵？士兵站在整点上，`1 ≤ n ≤ 40000`。

**解析**：

点 `(x, y)` 能被看到，当且仅当线段 `(0,0)-(x,y)` 上没有其他整点。这等价于 `gcd(x, y) = 1`。

按列统计：点 `(x, y)` 可见 ⇔ `gcd(x, y) = 1`。利用方阵关于对角线对称，只数左下三角：对每个 `2 ≤ i ≤ n-1`，第 `i` 列中 `1 ≤ y < i` 的可见点有 `φ(i)` 个；右上三角同样多；再加上 `(1,0)`、`(0,1)`、`(1,1)`。所以答案是 `1 + 2 × Σ_{i=1}^{n-1} φ(i)`，`n = 1` 时特判为 `0`。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 40005;
int phi[N], prime[N], cnt;
bool vis[N];

int main() {
    int n;
    cin >> n;
    if (n == 1) { cout << 0 << endl; return 0; }

    phi[1] = 1;
    for (int i = 2; i <= n; ++i) {
        if (!vis[i]) {
            prime[++cnt] = i;
            phi[i] = i - 1;
        }
        for (int j = 1; j <= cnt && 1LL * i * prime[j] <= n; ++j) {
            int x = i * prime[j];
            vis[x] = true;
            if (i % prime[j] == 0) {
                phi[x] = phi[i] * prime[j];
                break;
            } else {
                phi[x] = phi[i] * (prime[j] - 1);
            }
        }
    }

    long long ans = 1;
    for (int i = 1; i < n; ++i) ans += 2LL * phi[i];
    cout << ans << endl;
    return 0;
}
```

**复杂度**：筛法 `O(n)`，统计 `O(n)`，空间 `O(n)`。`n = 40000` 时答案约 `9.7 × 10⁸`，在 `int` 边缘，用 `long long` 更稳。

### 例 3  威尔逊定理做阶乘

**题意**：给定素数 `p`，求 `(p-1)! mod p`，并说明 `((p-1)/2)!² mod p` 的符号规律。

**解析**：由威尔逊定理，`(p-1)! ≡ -1 ≡ p-1 (mod p)`。把 `1..p-1` 按 `i` 与 `p-i` 配对，共 `(p-1)/2` 对，每对乘积 `≡ -i²`，于是

```
(p-1)! ≡ (-1)^((p-1)/2) × ((p-1)/2)!² (mod p)
```

当 `p ≡ 1 (mod 4)` 时指数为偶数，符号为正；当 `p ≡ 3 (mod 4)` 时为负。由此可反解 `((p-1)/2)!²`。`p` 到 `10⁷` 时直接循环算阶乘即可验证；到 `10⁹` 就只能用定理推结论。**定理的价值在于把「算」变成「推」。**

## ⚠️ 常见错误

- **模合数乱用费马小定理**：`a^(m-1) ≡ 1` 只在 `m` 为素数时成立。`m = 15, a = 2` 时 `2^14 mod 15 = 4`，不是 `1`。
- **降幂不检查互质**：`gcd(a,m) ≠ 1` 时 `a^b ≡ a^(b mod φ(m))` 不成立，必须用扩展欧拉定理。
- **φ 的乘法顺序写反**：`res * (p-1) / p` 可能先溢出；写成 `res / p * (p-1)`。
- **负余数直接输出**：`(-3) % 5` 是 `-3`，不是 `2`；输出前套 `norm`。
- **乘法不转 `long long`**：`int a = 1e9, b = 1e9; a * b` 先按 `int` 算，溢出后再赋值已经晚了。

## 🧠 本章小结

```
同余：a ≡ b (mod m) ⇔ m | (a-b)
  可加减乘、可乘方；除法要看逆元
  norm(x,m) = (x % m + m) % m

欧拉函数：
  φ(n) = n × ∏(1 - 1/p)
  单点 O(√n)，线性筛 O(n)

四把钥匙：
  欧拉：gcd(a,m)=1 → a^φ(m) ≡ 1，可降幂
  费马：m 为素数 → a^(m-1) ≡ 1
  威尔逊：p 素数 ⇔ (p-1)! ≡ -1 (mod p)
  裴蜀：ax+by=c 有解 ⇔ gcd(a,b) | c

降幂：
  gcd(a,m)=1：a^b ≡ a^(b mod φ(m))
  否则：a^b ≡ a^(b mod φ(m) + φ(m))，b ≥ φ(m)
```
