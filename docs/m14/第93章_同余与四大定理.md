# 第 93 章 同余与四大定理
---
> 🏗️ **前情回顾**：上册第 54–55 章学过整除、gcd 与素数筛。那时只关心"能不能整除"；这一章把余数本身当成一个世界，在其中做加减乘。
## 🎯 本章目标
- 在同余意义下正确运算，处理负数与溢出
- 会算欧拉函数，说清欧拉定理的适用条件
- 区分费马、威尔逊、裴蜀三定理，知道各自能做什么

## 🎬 故事/动机
钟表上 10 点再过 5 小时是 3 点，不是 15 点——这就是模 12。密码、哈希、组合数取模都在这个环形世界里运算。但环形世界不能随便做除法；四大定理就是四把钥匙：欧拉与费马负责降幂，威尔逊负责判素，裴蜀负责解方程。

## 🧱 知识讲解
### 93.1 同余运算
`a ≡ b (mod m)` 表示 m | (a-b)。同余式可加减、可相乘，但**不能随意约去**。代码里先把负数归正：`norm(x,m) = (x % m + m) % m`。模数接近 1e9 时两余数相乘会爆 `int`，必须 `long long`；接近 1e18 时用 `__int128`。

### 93.2 欧拉函数
φ(m) 是 1..m 中与 m 互质的数的个数。若 m = p1^e1…pk^ek，则 φ(m)=m∏(1-1/pi)。单点计算试除到 √m 即可：
```cpp
long long phi(long long n) {
    long long r = n;
    for (long long p = 2; p * p <= n; ++p) if (n % p == 0) {
        r = r / p * (p - 1);
        while (n % p == 0) n /= p;
    }
    return n > 1 ? r / n * (n - 1) : r;
}
```

### 93.3 欧拉定理与费马小定理
若 gcd(a,m)=1，则 a^φ(m) ≡ 1 (mod m)。当 m 为素数 p 且 p∤a 时 φ(p)=p-1，退化为费马小定理 a^(p-1) ≡ 1。二者主要用于降幂：a^b ≡ a^(b mod φ(m))，但**仅当 gcd(a,m)=1**；不互质要用扩展欧拉定理。

### 93.4 威尔逊定理与裴蜀定理
p 为素数 ⇔ (p-1)! ≡ -1 (mod p)；它多用于证明与构造，直接判素太慢。裴蜀定理：ax+by=gcd(a,b) 必有整数解，由此 a 在模 m 下可逆 ⇔ gcd(a,m)=1。

## 💻 例题
**例 1**：[P1082 同余方程](https://hydro.ac/p/luogu-P1082)。ax≡1 (mod b) 等价于 ax+by=1；用 exgcd（第 94 章）求出 x 后输出 `(x % b + b) % b`。

**例 2**：[P2158 仪仗队](https://hydro.ac/p/luogu-P2158)。(x,y) 可见 ⇔ gcd(x,y)=1，按列统计得 1+2Σφ(i)（i=1..n-1）。φ 用筛法预处理前缀和，n=1 时特判输出 0。

## ⚠️ 常见坑
1. 费马小定理要求模数为素数且 a 不是 p 的倍数；模合数只能用欧拉定理并检查 gcd。
2. φ(n) 漏乘某个 (1-1/p)，或写成 `r*(p-1)/p` 造成溢出。
3. 降幂直接 `b % φ(m)`，忽略 gcd(a,m)≠1；负余数未归正也会导致输出负数。
