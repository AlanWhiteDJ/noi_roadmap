## A.1  计算机的基本构成

一台计算机由五大部分组成：

| 部件 | 作用 | 类比 |
|---|---|---|
| 运算器（ALU） | 做算术与逻辑运算 | 计算器 |
| 控制器（CU） | 指挥各部件按指令工作 | 导演 |
| 存储器 | 保存程序和数据 | 仓库 |
| 输入设备 | 把信息送进计算机 | 眼睛/耳朵 |
| 输出设备 | 把结果送出来 | 嘴巴 |

运算器 + 控制器合称 **CPU**。存储器分两级：

- **内存**：快、断电丢失，程序运行时用
- **外存**：慢、断电保留，如硬盘、U 盘

**位、字节、字**：

- 1 位（bit）= 一个 0 或 1
- 1 字节（Byte）= 8 位
- 1 KB = 1024 B，1 MB = 1024 KB，1 GB = 1024 MB

> 💡 一个 `int` 通常占 4 字节 = 32 位；`long long` 占 8 字节 = 64 位。

## A.2  计算机网络与 Internet

**计算机网络**：把多台计算机用通信线路连起来，交换数据。

- **局域网（LAN）**：一个机房、一个学校
- **广域网（WAN）**：跨城市、跨国家
- **Internet**：全球最大的互联网，由无数网络互联而成

几个常见概念：

| 概念 | 含义 |
|---|---|
| IP 地址 | 每台联网设备的"门牌号"，如 `192.168.1.3` |
| 域名 | 好记的名字，如 `www.luogu.com.cn` |
| DNS | 把域名翻译成 IP 地址的系统 |
| HTTP/HTTPS | 浏览器和网站之间传网页的协议 |
| URL | 网址，包含协议、域名、路径 |
| 端口 | 一台设备上不同服务的编号，如 80、443 |

> 📦 类比：IP 是门牌号，端口是房间号，DNS 是"名字 → 门牌号"的通讯录。

## A.3  NOI 的历史与规则

**NOI**（National Olympiad in Informatics）全国青少年信息学奥林匹克竞赛，1984 年创办，由中国计算机学会（CCF）主办。

主要活动：

| 名称 | 说明 |
|---|---|
| CSP-J/S | 非专业级软件能力认证，分入门级（J）和提高级（S），第一轮笔试 + 第二轮上机 |
| NOIP | 全国青少年信息学奥林匹克联赛（省级联赛） |
| NOI | 全国赛，各省队参加 |
| NOI 冬令营 / 集训队 | 选拔国家队 |
| IOI | 国际信息学奥林匹克 |

**赛场基本规则**（摘要）：

- 只允许携带纸质资料，禁止使用手机、U 盘、网络
- 代码必须写在指定文件，文件名、输入输出文件名按题目要求
- 以最后一次提交为准；评测用官方数据，不看样例通过与否
- 禁止抄袭、禁止攻击评测系统

> ⚠️ 具体规则每年可能调整，以 CCF 当年发布的须知为准。

## A.4  文件、目录与图形界面操作

- **文件**：存储数据的基本单位，如 `main.cpp`、`data.in`
- **目录（文件夹）**：存放文件或其他目录
- **路径**：文件的位置，如 `C:\Users\alan\main.cpp` 或 `/home/alan/main.cpp`
- **绝对路径**：从根开始；**相对路径**：从当前目录开始

图形界面常用操作：

- 新建文件夹 / 新建文本文档
- 复制（Ctrl+C）、粘贴（Ctrl+V）、剪切（Ctrl+X）
- 重命名（F2）、删除（Delete）
- 移动：剪切后粘贴到目标文件夹

> 💡 竞赛提交前，确认文件名、扩展名、保存位置正确——这是最容易丢分的地方之一。

## A.5  Linux 与编译工具速查

**常用命令**：

| 命令 | 作用 |
|---|---|
| `ls` | 列出当前目录 |
| `cd 目录` | 切换目录 |
| `pwd` | 显示当前路径 |
| `mkdir 名字` | 新建目录 |
| `cp 源 目标` | 复制 |
| `mv 源 目标` | 移动/重命名 |
| `rm 文件` | 删除 |
| `cat 文件` | 查看文件内容 |

**编译与运行**：

```bash
g++ main.cpp -o main -O2 -std=c++14
./main
```

- `-O2`：开启优化（竞赛常用）
- `-std=c++14`：指定语言标准
- `time ./main`：查看运行时间

**GDB 简介**：

```bash
g++ main.cpp -g -o main
gdb ./main
```

常用命令：`break 行号` 设断点、`run` 运行、`next` 单步、`print 变量` 查看值、`continue` 继续。

> 💡 日常练习用 `cout` 调试就够；比赛卡死或段错误时，GDB 能快速定位。
