## 🧱 知识讲解

### 57.1  树的基本概念

树由**节点**和连接节点的**边**组成，满足：

- 有且只有一个**根节点**（没有父节点）
- 除根外，每个节点**有且只有一个父节点**
- 没有环

常用术语：

| 术语 | 含义 |
|---|---|
| 根（root） | 最上面的节点 |
| 父/子（parent/child） | 直接相连的上下级 |
| 兄弟（sibling） | 同一个父节点的子节点 |
| 度（degree） | 一个节点有几个子节点 |
| 叶子（leaf） | 度为 0 的节点 |
| 深度（depth） | 从根到该节点的边数（根深度为 0） |
| 高度（height） | 从该节点到最远叶子的边数 |
| 森林 | 多棵互不相交的树 |

> 📦 类比：树就像公司的组织架构——一个总经理，下面几个部门经理，再下面是员工。每个人只有一个直属上级。

### 57.2  二叉树

**二叉树**：每个节点最多有两个子节点，分别叫**左孩子**和**右孩子**。左右不能互换。

三条常用性质：

1. 第 `i` 层最多有 `2^(i-1)` 个节点（根是第 1 层）
2. 深度为 `k` 的二叉树最多有 `2^k - 1` 个节点
3. 叶子数 = 度为 2 的节点数 + 1

两种特殊形态：

- **满二叉树**：每一层都填满
- **完全二叉树**：除最后一层外全满，最后一层从左到右连续排列

> ⚠️ 完全二叉树不一定是满二叉树；满二叉树一定是完全二叉树。

### 57.3  二叉树的存储

**链式存储**（最常用）：

```cpp
struct Node {
    int val;
    int left, right;   // 左右孩子的下标，0 表示空
} tr[100005];
int tot = 0;           // 节点总数
```

**数组存储**（只适合完全二叉树）：

- 根存 `1`
- 下标 `i` 的左孩子是 `2*i`，右孩子是 `2*i+1`
- 下标 `i` 的父亲是 `i/2`

```cpp
int val[100005];       // val[1] 是根
// 左孩子：val[2*i]；右孩子：val[2*i+1]
```

> 💡 数组存储省指针、访问快，但普通二叉树会浪费大量空位；完全二叉树用它最合适。

### 57.4  四种遍历

遍历就是"按某种顺序访问每个节点一次"。

| 遍历 | 顺序 | 用途 |
|---|---|---|
| 前序 | 根 → 左 → 右 | 复制一棵树、输出前缀表达式 |
| 中序 | 左 → 根 → 右 | 二叉搜索树中序是升序 |
| 后序 | 左 → 右 → 根 | 释放内存、计算子树结果 |
| 层序 | 一层一层从左到右 | BFS、求深度/宽度 |

递归写法（链式存储）：

```cpp
void pre(int u) {          // 前序
    if (!u) return;
    cout << tr[u].val << ' ';
    pre(tr[u].left);
    pre(tr[u].right);
}

void in(int u) {           // 中序
    if (!u) return;
    in(tr[u].left);
    cout << tr[u].val << ' ';
    in(tr[u].right);
}

void post(int u) {         // 后序
    if (!u) return;
    post(tr[u].left);
    post(tr[u].right);
    cout << tr[u].val << ' ';
}
```

层序用队列：

```cpp
void level(int root) {
    queue<int> q;
    q.push(root);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        cout << tr[u].val << ' ';
        if (tr[u].left)  q.push(tr[u].left);
        if (tr[u].right) q.push(tr[u].right);
    }
}
```

**由遍历序列还原**：

- 前序的第一个是根；在中序里找到根，左边是左子树，右边是右子树
- 后序的最后一个是根；同样用中序切分
- 只有"前序 + 后序"不能唯一确定一棵二叉树

### 57.5  哈夫曼树与编码

给每个叶子一个**权值**（比如字符出现的频率），构造一棵二叉树，使**带权路径长度 WPL** 最小：

```
WPL = Σ 权值 × 从根到该叶子的边数
```

构造方法（贪心）：

1. 把所有权值放进一个集合
2. 每次取出**最小的两个**，合并成一个新节点，权值为两者之和
3. 把新节点放回集合，重复直到只剩一个节点

这样得到的树就是**哈夫曼树**。把左分支记 0、右分支记 1，就得到**哈夫曼编码**——频率高的字符编码短，且没有任何编码是另一个的前缀（前缀码）。

> 💡 哈夫曼编码是"贪心 + 树"的经典组合；`priority_queue` 就能实现"每次取最小两个"。

### 57.6  二叉搜索树（BST）

**二叉搜索树**满足：

- 左子树所有节点的值 < 根的值
- 右子树所有节点的值 > 根的值
- 左右子树也都是 BST

性质：**中序遍历是升序序列**。

查找：

```cpp
bool find(int u, int x) {
    if (!u) return false;
    if (tr[u].val == x) return true;
    if (x < tr[u].val) return find(tr[u].left, x);
    return find(tr[u].right, x);
}
```

插入：沿着查找路径走到空位，把新节点挂上去。普通 BST 在极端数据下会退化成链，所以竞赛里更常用 `set`、平衡树或线段树。

## ⚠️ 容易犯的错

### 错 1：数组存储时下标越界

完全二叉树用 `2*i`、`2*i+1`，节点数 `n` 时数组要开到 `4*n`，否则深层节点会越界。

### 错 2：递归遍历忘了边界

`if (!u) return;` 必须放在最前面，否则空指针会被访问。

### 错 3：前序/中序/后序顺序记混

记法：**前序根在前，中序根在中间，后序根在最后**；左右子树的相对顺序始终是"左在前、右在后"（中序是左根右）。

### 错 4：以为"前序 + 后序"能唯一建树

不能。前序和后序只能确定根，无法区分只有一个孩子时它是左还是右。

### 错 5：哈夫曼合并时没取最小的两个

必须每次取当前集合中最小的两个，贪心才正确；顺序错了 WPL 就不是最小。

## 🧠 本章小结

- 树是非线性结构：一个根、每个节点一个父、无环
- 二叉树每个节点最多两个子节点；完全二叉树适合数组存储（`2i`/`2i+1`）
- 四种遍历：前序、中序、后序、层序
- 中序 + 前序/后序可以还原二叉树；前序 + 后序不行
- 哈夫曼树用贪心合并最小两个权值，得到最优前缀编码
- 二叉搜索树中序有序；极端情况会退化
