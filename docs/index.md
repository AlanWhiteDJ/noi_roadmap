## 📖 本书特色

**全书 = 从零到 CSP-S 满分**：一条学习路径走完入门级与提高级。

- 📝 **GROW 教练问题**：每章配备引导式提问，帮助自查理解
- 🛠️ **教师版配套**：每个模块配有完整教师用书，含教学建议和活动设计
- 📋 **配题库**：979 道练习题，覆盖全部 105 章
