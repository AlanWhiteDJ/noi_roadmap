# 第 61 章  并查集与森林表示

---

> 🏗️ **前情回顾**：链表和树能表示"连接关系"，但如果你想动态地回答"这两个人是不是同一个社团的"，每次都用 BFS 扫一遍图，代价是 O(n+m)。**并查集**专治这类"只合并、不拆分"的连通性问题：合并两个集合、查询两个元素是否同集合，均摊接近 O(1)。

## 📖 故事引入

新学期社团招新，小周负责登记。不断有消息传来："文学社和摄影社合并了""编程社并入了科创社"。

校长随时可能问："小明和小红现在是不是同一个社团？"

如果每次都用 BFS 从一个人出发找另一个人，消息一多就慢得没法忍。小周换了个思路：**每个社团选一个"代表"**，每个人只记住"我的代表是谁"。两个代表相同，就是同一个社团；两个社团合并，只要让一个代表认另一个代表当上级。

查询时顺着上级往上找，合并时改一条边——这就是并查集。它不关心社团内部长什么样，只关心"谁和谁一伙"。

## 🧱 知识讲解

### 61.1  并查集的三件套

用 `fa[x]` 表示 x 的父节点。根节点的父亲是它自己。

```cpp
int fa[N];
void init(int n) {
    for (int i = 1; i <= n; i++) fa[i] = i;
}
int find(int x) {
    if (fa[x] == x) return x;
    return fa[x] = find(fa[x]);   // 路径压缩
}
void unite(int x, int y) {
    int fx = find(x), fy = find(y);
    if (fx != fy) fa[fx] = fy;
}
```

- `find(x)`：一路向上找到根；
- `unite(x, y)`：把两个根连起来；
- 判断同集合：`find(x) == find(y)`。

`fa[x] = find(fa[x])` 这行同时做了两件事：递归找到根，并把路径上所有点直接挂到根上。这叫**路径压缩**，下一次查询就是 O(1)。

### 61.2  按大小合并

只做路径压缩，最坏情况仍然可能建出一条长链。合并时把**小树挂到大树**下面，可以让树高保持 O(log n)：

```cpp
int sz[N];   // 每个根所在集合的大小
void unite(int x, int y) {
    int fx = find(x), fy = find(y);
    if (fx == fy) return;
    if (sz[fx] > sz[fy]) swap(fx, fy);
    fa[fx] = fy;
    sz[fy] += sz[fx];
}
```

初始化 `sz[i] = 1`。路径压缩 + 按大小合并后，单次操作的均摊复杂度是 O(α(n))，其中 α 是反阿克曼函数，在 n ≤ 10^9 时不超过 4，可以当作常数。

### 61.3  并查集的典型用法

**统计连通块**：所有边 `unite(u, v)` 后，数有多少个 `find(i) == i`。

**判环**：逐条加边，若两端点已经同集合，这条边就成环。

**Kruskal 最小生成树**：把边按权值排序，依次加入，用并查集判断是否成环。

**动态连通性**：只能合并、不能删除。要删边就**倒着处理**，把删除变成加边（P1197 星球大战）。

### 61.4  带权并查集

除了是否同集合，有时还要知道两个元素的关系，比如每个点到根的距离：

```cpp
int fa[N], d[N];   // d[x]：x 到父节点的距离
int find(int x) {
    if (fa[x] == x) return x;
    int root = find(fa[x]);
    d[x] += d[fa[x]];       // 先递归，再把父亲的权值加上来
    return fa[x] = root;
}
```

合并 `x` 所在集合到 `y` 时，若已知 x 到 y 的距离为 w：

```cpp
int fx = find(x), fy = find(y);
if (fx != fy) {
    fa[fx] = fy;
    d[fx] = w + d[y] - d[x];   // 推导：d[x] + d[fx] = w + d[y]
}
```

> ⚠️ `d[x] += d[fa[x]]` 必须在递归 `find(fa[x])` **之后**做，因为递归会把 `fa[x]` 直接挂到根上，`d[fa[x]]` 才是它到根的距离。顺序写反，权值就错了。

### 61.5  扩展域：朋友与敌人

有些关系不是"相等"，而是"敌对"。做法是把每个元素拆成几个**域**，用多倍的点表示不同身份。

以"食物链"为例，每个动物拆成三个点：

- `x`：x 本身；
- `x + n`：x 的猎物；
- `x + 2n`：x 的天敌。

若 x 吃 y，则：

```cpp
unite(x, y + 2*n);        // x 是 y 的天敌
unite(x + n, y);          // x 的猎物是 y
unite(x + 2*n, y + n);    // x 的天敌就是 y 的猎物
```

三条把"吃"的关系在三个域同时登记，之后用 `find` 判矛盾。扩展域的本质是：**用多个点表示一个元素的不同身份，身份间的等量关系由题目规则决定**。

### 61.6  孩子兄弟表示法

一般的树每个节点可以有任意多个孩子，不方便用"左右指针"存。**孩子兄弟表示法**给每个节点记两个指针：

- `first`：第一个孩子；
- `next`：下一个兄弟。

```cpp
struct Node {
    int val;
    int first, next;   // 0 表示空
} tr[N];
```

这样任意一棵树都能转成二叉树：**左指针指向第一个孩子，右指针指向下一个兄弟**。

```cpp
void dfs(int u) {
    if (!u) return;
    cout << tr[u].val << ' ';
    for (int v = tr[u].first; v; v = tr[v].next)
        dfs(v);
}
```

森林也能表示：把各棵树的根看成兄弟串在 `next` 上，再加一个虚拟根。常考"森林转二叉树后某节点的左右孩子是谁"，记牢"左孩子是原第一个孩子，右孩子是原下一个兄弟"。

## 💻 例题

### 例 1  并查集模板（P3367）

**题意**：n 个元素，m 次操作：`1 x y` 合并，`2 x y` 询问是否同集合。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 10005;
int fa[N], sz[N];
int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}
void unite(int x, int y) {
    int fx = find(x), fy = find(y);
    if (fx == fy) return;
    if (sz[fx] > sz[fy]) swap(fx, fy);
    fa[fx] = fy;
    sz[fy] += sz[fx];
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m; cin >> n >> m;
    for (int i = 1; i <= n; i++) fa[i] = i, sz[i] = 1;
    while (m--) {
        int z, x, y; cin >> z >> x >> y;
        if (z == 1) unite(x, y);
        else cout << (find(x) == find(y) ? 'Y' : 'N') << '\n';
    }
    return 0;
}
```

**解析**：`find` 带路径压缩、`unite` 判重即可。`sz` 只在根节点有意义，合并后累加到新根。

### 例 2  奶酪（P3958）

**题意**：空间中有 n 个球，球心 `(x,y,z)`、半径 r。两个球相交或相切即可通过。问能否从 z=0 的下表面走到 z=h 的上表面。

**思路**：把每个球看成一个点，相交/相切就合并；再加两个虚拟点表示下表面和上表面。球心到面的距离 ≤ r 就与对应表面连通。

```cpp
bool touch(long long x1, long long y1, long long z1,
           long long x2, long long y2, long long z2, long long r) {
    long long dx = x1 - x2, dy = y1 - y2, dz = z1 - z2;
    return dx*dx + dy*dy + dz*dz <= 4*r*r;   // (2r)^2
}
// 读入每个球，若 z-r <= 0 则与 0 号点合并
// 若 z+r >= h 则与 n+1 号点合并
// 两两判断相交则合并
// 最后 find(0) == find(n+1) ?
```

**解析**：距离平方会到 10^18，必须用 `long long`；比较 `4*r*r` 避免开根号的精度问题。

### 例 3  食物链（P2024）

**题意**：n 个动物，k 句话，每句描述"x 和 y 同类"或"x 吃 y"。假话有两种：与前面真话矛盾，或超出编号/自己吃自己。求假话数量。

```cpp
int n, k, ans = 0;
// 并查集大小 3*n
for (int i = 1; i <= k; i++) {
    int op, x, y; cin >> op >> x >> y;
    if (x > n || y > n) { ans++; continue; }
    if (op == 1) {
        if (find(x) == find(y + n) || find(x) == find(y + 2*n)) ans++;
        else {
            unite(x, y);
            unite(x + n, y + n);
            unite(x + 2*n, y + 2*n);
        }
    } else {
        if (x == y) { ans++; continue; }
        if (find(x) == find(y) || find(x) == find(y + n)) ans++;
        else {
            unite(x, y + 2*n);
            unite(x + n, y);
            unite(x + 2*n, y + n);
        }
    }
}
```

**解析**：`x` 与 `y+2n` 同集合表示 x 吃 y。判矛盾时检查 x 与 y 同类，或 x 与 y+n 同集合（x 是 y 的猎物，即 y 吃 x）。三个域必须同步合并，少一条就会漏判。

## ⚠️ 常见错误

1. **忘记初始化**：`fa[i] = i` 必须对 1..n 全部执行，否则 `find` 会死循环。
2. **`find` 没写路径压缩**：链会越来越长，最后退化成 O(n)。
3. **合并时不判同集合**：虽然多数时候不出错，但会破坏 `sz` 的计数。
4. **带权并查集更新顺序反了**：必须先递归 `find(fa[x])`，再累加 `d[fa[x]]`。
5. **扩展域只合并一个域**：每条规定要在所有相关域同步登记，否则关系不完整。
6. **多组数据没重置**：`fa`、`sz`、`d` 都要重新初始化。
7. **递归 `find` 爆栈**：n 很大且数据刻意构造长链时，改成迭代写法或加按秩合并。

## 🧠 本章小结

```
并查集：fa[x] 指向父亲，根的父亲是自己
find：递归找根 + 路径压缩 fa[x] = find(fa[x])
unite：先判同集合，再按大小/秩合并

复杂度：路径压缩 + 按大小合并 → O(α(n)) ≈ O(1)
应用：连通块、判环、Kruskal、逆向加边

带权并查集：d[x] 表示 x 到父亲的权值
  先 find(fa[x])，再 d[x] += d[fa[x]]
扩展域：一个元素拆成多个身份，分别合并

孩子兄弟表示法：first 指向第一个孩子，next 指向下一个兄弟
  森林 → 二叉树：左孩子是原第一个孩子，右孩子是原下一个兄弟
```
