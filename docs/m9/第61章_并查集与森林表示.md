# 第 61 章  并查集与森林表示

---

> 🏗️ **前情回顾**：链表、树都能表示"连接关系"，但判断"两个点是否连通"很慢。并查集专治这个问题：合并两个集合、查询两个元素是否同集合，近似 O(1)。

## 🎯 本章目标

- 写出路径压缩 + 按秩合并的并查集
- 用并查集判连通、判环、分组
- 理解带权并查集与扩展域
- 了解树的孩子兄弟表示法

## 🧱 知识讲解

### 61.1  基本并查集

```cpp
int fa[N];
int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);  // 路径压缩
}
void unite(int x, int y) {
    int fx = find(x), fy = find(y);
    if (fx != fy) fa[fx] = fy;
}
```

初始化 `fa[i] = i`。路径压缩后，单次操作近似 O(α(n))。

### 61.2  按秩合并

记录每个集合的大小或深度，合并时把小的挂到大的下面，避免树退化成链。

### 61.3  带权并查集与扩展域

- 带权：维护每个点到根的距离/关系，路径压缩时更新权值
- 扩展域：把"敌人"拆成另一个点，用 2n 个点表示两种关系

### 61.4  孩子兄弟表示法

每个节点记录"第一个孩子"和"下一个兄弟"，把任意树转成二叉树。这是树的通用存储方式之一。

**例 1**：洛谷 P3367 并查集模板。

**例 2**：洛谷 P3958 奶酪——把相交/相切的球合并，判断上下表面是否连通。

## ⚠️ 常见坑

1. 忘记初始化 `fa[i] = i`
2. `find` 没写路径压缩，链退化
3. 合并时没判断是否已在同一集合
4. 带权并查集的权值更新顺序写错
