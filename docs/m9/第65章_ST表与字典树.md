# 第 65 章  ST 表与字典树

---

> 🏗️ **前情回顾**：线段树能改能查，但静态区间最值有更轻的工具——ST 表，查询 O(1)。字典树则把字符串按前缀组织成一棵树，查前缀、查异或最值都很快。

## 🎯 本章目标

- 用 ST 表做 O(1) 静态区间最值
- 理解笛卡尔树与 RMQ 的关系
- 写出 Trie 的插入与查询
- 了解平衡树的基本操作与适用边界（选学）

## 🧱 知识讲解

### 65.1  ST 表

预处理 `st[k][i]` 表示从 i 开始长度为 `2^k` 的区间最值：

```cpp
for (int i = 1; i <= n; i++) st[0][i] = a[i];
for (int k = 1; (1 << k) <= n; k++)
    for (int i = 1; i + (1 << k) - 1 <= n; i++)
        st[k][i] = max(st[k-1][i], st[k-1][i + (1 << (k-1))]);

int query(int l, int r) {
    int k = log2(r - l + 1);
    return max(st[k][l], st[k][r - (1 << k) + 1]);
}
```

只能处理**静态**区间（不支持修改）。

### 65.2  笛卡尔树

把数组建成一棵树：中序遍历是原数组，父节点权值小于（或大于）孩子。它和 RMQ 可以互相转化，也是 Treap 的基础。

### 65.3  字典树 Trie

```cpp
int ch[N][26], cnt[N], tot = 1;
void insert(string s) {
    int u = 1;
    for (char c : s) {
        int v = c - 'a';
        if (!ch[u][v]) ch[u][v] = ++tot;
        u = ch[u][v];
    }
    cnt[u]++;
}
bool find(string s) {
    int u = 1;
    for (char c : s) {
        int v = c - 'a';
        if (!ch[u][v]) return false;
        u = ch[u][v];
    }
    return cnt[u] > 0;
}
```

Trie 适合：前缀查询、单词检索、异或最大值（01-Trie）。

### 65.4  平衡树（选学）

`set` 已经能完成大部分有序集合操作；需要第 k 小、前驱后继、区间翻转时，才考虑 Treap/Splay。竞赛里优先用 `set` 或线段树。

## ⚠️ 常见坑

1. ST 表不支持修改；查询区间重叠的写法要正确
2. `log2` 用整数预处理，避免浮点误差
3. Trie 的数组大小 = 总字符数，不是单词数
4. 平衡树常数大，能用 `set` 就不要手写
