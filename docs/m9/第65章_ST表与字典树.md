# 第 65 章  ST 表与字典树

> 🏗️ **前情回顾**：线段树能改能查，但"静态区间最值"有更轻的工具——**ST 表**，预处理 O(n log n)，查询 O(1)。**字典树**则把字符串按前缀组织成一棵树，查前缀、查异或最值都很快。这一章学两种"专精"的结构：一个专攻静态 RMQ，一个专攻前缀。

## 🧱 知识讲解

### 65.1  ST 表：倍增预处理

定义 `st[k][i]` 表示从 i 开始、长度为 `2^k` 的区间最值。显然：

```
st[0][i] = a[i]
st[k][i] = max(st[k-1][i], st[k-1][i + 2^(k-1)])
```

也就是把长度 `2^k` 的区间劈成两个长度 `2^(k-1)` 的区间。

```cpp
const int N = 100005, K = 18;
int st[K][N], lg[N];

void build(int n) {
    lg[1] = 0;
    for (int i = 2; i <= n; i++) lg[i] = lg[i / 2] + 1;
    for (int i = 1; i <= n; i++) st[0][i] = a[i];
    for (int k = 1; (1 << k) <= n; k++)
        for (int i = 1; i + (1 << k) - 1 <= n; i++)
            st[k][i] = max(st[k-1][i],
                           st[k-1][i + (1 << (k-1))]);
}
```

查询 `[l, r]` 时，取 `k = lg[r-l+1]`，用两个长度为 `2^k` 的块覆盖整个区间：

```cpp
int query(int l, int r) {
    int k = lg[r - l + 1];
    return max(st[k][l], st[k][r - (1 << k) + 1]);
}
```

两块可以重叠，因为 `max` 对重复元素不敏感。预处理 O(n log n)，单次查询 O(1)，空间 O(n log n)。

> ⚠️ ST 表只能处理**静态**数据，不支持修改。一旦有修改，请用线段树或树状数组。

### 65.2  为什么"和"不行

ST 表查询依赖"两个重叠区间合并后仍等于整个区间"：

- `max(a, a) = a`，重复算一次没关系；
- 但 `a + a = 2a`，重叠部分会被重复求和，答案就错了。

满足 `f(x,x) = x` 的运算叫**可重复贡献运算**，最大值、最小值、GCD、按位或都满足；求和、计数不满足。

### 65.3  笛卡尔树

给数组建一棵二叉树，满足：

- 中序遍历就是原数组顺序；
- 每个节点的值小于（或大于）它的孩子——即堆性质。

以最小值为例，根是整个数组的最小值，左子树是它左边的部分，右子树是右边的部分，递归下去。用单调栈可以 O(n) 建树：

```cpp
int lc[N], rc[N], st[N], top = 0;
for (int i = 1; i <= n; i++) {
    int last = 0;
    while (top && a[st[top]] > a[i]) last = st[top--];
    if (top) rc[st[top]] = i;
    if (last) lc[i] = last;
    st[++top] = i;
}
// 栈底 st[1] 就是根
```

笛卡尔树把"区间最值"变成了"树上 LCA"：`[l, r]` 的最小值就是 l 和 r 的 LCA。它也是 Treap 的结构基础。

### 65.4  字典树 Trie

Trie 的每条边是一个字符，从根到某节点的路径就是一个前缀。

```cpp
const int N = 500005;
int ch[N][26], cnt[N], tot = 1;

void insert(const string &s) {
    int u = 1;
    for (char c : s) {
        int v = c - 'a';
        if (!ch[u][v]) ch[u][v] = ++tot;
        u = ch[u][v];
    }
    cnt[u]++;              // 以这里结尾的单词数
}

bool find(const string &s) {
    int u = 1;
    for (char c : s) {
        int v = c - 'a';
        if (!ch[u][v]) return false;
        u = ch[u][v];
    }
    return cnt[u] > 0;
}
```

- 根固定为 1，0 表示空；
- 数组大小是**总字符数**，不是单词数；
- 查前缀：一路走到底，能走通就说明存在这个前缀；
- 前缀计数：在每个经过的节点上 `pass[u]++`，查询时返回 `pass[u]`。

Trie 的插入和查询都是 O(len)，与集合里有多少单词无关。

### 65.5  01-Trie 与最大异或

把整数看成 31 位二进制，从高位到低位插入 Trie。查询 x 的最大异或值时，尽量走**与当前位相反**的分支：

```cpp
const int M = 3100005;
int ch01[M][2], tot01 = 1;

void insert(int x) {
    int u = 1;
    for (int b = 30; b >= 0; b--) {
        int v = (x >> b) & 1;
        if (!ch01[u][v]) ch01[u][v] = ++tot01;
        u = ch01[u][v];
    }
}

int query(int x) {
    int u = 1, res = 0;
    for (int b = 30; b >= 0; b--) {
        int v = (x >> b) & 1;
        if (ch01[u][v ^ 1]) {
            res |= (1 << b);       // 这一位能异或出 1
            u = ch01[u][v ^ 1];
        } else {
            u = ch01[u][v];
        }
    }
    return res;
}
```

> 💡 为什么从高位走？因为高位的一个 1 比低位所有 1 加起来还大，贪心取反一定最优。

### 65.6  平衡树（选学）

普通二叉搜索树在有序数据下会退化成链。平衡树通过旋转或分裂合并维持 O(log n) 高度，常见的是 **Treap** 和 **Splay**。

CSP-S 范围内，绝大多数"有序集合"需求用 `set/map` 就够：插入、删除、查找、前驱后继它全有；第 k 小用权值线段树或树状数组二分；只有区间翻转才需要 Splay。**能写 `set` 就不要手写平衡树**。

## 💻 例题

### 例 1  ST 表模板（P3865）

**题意**：n 个数，m 次询问，每次求区间 `[l, r]` 的最大值。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 100005, K = 18;
int a[N], st[K][N], lg[N];
int main() {
    int n, m; scanf("%d%d", &n, &m);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
    lg[1] = 0;
    for (int i = 2; i <= n; i++) lg[i] = lg[i / 2] + 1;
    for (int i = 1; i <= n; i++) st[0][i] = a[i];
    for (int k = 1; (1 << k) <= n; k++)
        for (int i = 1; i + (1 << k) - 1 <= n; i++)
            st[k][i] = max(st[k-1][i], st[k-1][i + (1 << (k-1))]);
    while (m--) {
        int l, r; scanf("%d%d", &l, &r);
        int k = lg[r - l + 1];
        printf("%d\n", max(st[k][l], st[k][r - (1 << k) + 1]));
    }
    return 0;
}
```

**解析**：`lg` 数组用递推预处理，避免 `log2` 的浮点误差和慢速。查询的两个块一左一右，正好覆盖 `[l, r]`，中间重叠无妨。

### 例 2  于是他错误的点名开始了（P2580）

**题意**：先给 n 个名字，再给 m 次点名。没出现过输出 `WRONG`；第一次点到输出 `OK`；重复点到输出 `REPEAT`。

```cpp
int ch[N][26], cnt[N], vis[N], tot = 1;
void insert(const string &s) {
    int u = 1;
    for (char c : s) {
        int v = c - 'a';
        if (!ch[u][v]) ch[u][v] = ++tot;
        u = ch[u][v];
    }
    cnt[u] = 1;
}
int query(const string &s) {
    int u = 1;
    for (char c : s) {
        int v = c - 'a';
        if (!ch[u][v]) return 0;      // 不存在
        u = ch[u][v];
    }
    if (!cnt[u]) return 0;
    if (vis[u]) return 2;             // 重复
    vis[u] = 1;
    return 1;                         // 第一次
}
int main() {
    int n, m; cin >> n;
    for (int i = 0; i < n; i++) { string s; cin >> s; insert(s); }
    cin >> m;
    while (m--) {
        string s; cin >> s;
        int r = query(s);
        cout << (r == 0 ? "WRONG" : r == 1 ? "OK" : "REPEAT") << '\n';
    }
    return 0;
}
```

**解析**：`cnt` 标记"这里是某个名字的结尾"，`vis` 标记"被点过"。注意只有走到结尾且 `cnt[u]=1` 才算存在，中途能走通只说明是别人的前缀。

### 例 3  最大异或对

**题意**：给 n 个整数，选两个不同的数，使异或值最大。

```cpp
int ans = 0;
for (int i = 1; i <= n; i++) {
    insert(a[i]);
    ans = max(ans, query(a[i]));
}
cout << ans;
```

**解析**：边插入边查询，先插入再查自己会得到 0，不影响最大值。每次查询走 31 步，总复杂度 O(31n)。01-Trie 节点数约为 `31n`，数组要开够。

---

## ⚠️ 常见错误

1. **用 `log2` 直接算 k**：浮点误差会让 `log2(8)` 得到 2.999…，务必预处理整数 `lg` 数组。
2. **ST 表第二维开小**：`K` 要满足 `2^K > n`，n=10^5 时 K=18 够用。
3. **ST 表处理求和**：重叠区间会重复计算，只能用于可重复贡献运算。
4. **Trie 数组按单词数开**：应该按总字符数开，否则插入长串时越界。
5. **Trie 查询只看能否走通**：还要检查结尾标记，否则前缀会被误判成单词。
6. **01-Trie 从低位开始**：贪心会失效，必须从高位到低位。
7. **多组数据不清空 Trie**：`ch`、`cnt`、`vis`、`tot` 都要重置。

## 🧠 本章小结

```
ST 表：st[k][i] 表示 [i, i+2^k-1] 的最值
  st[k][i] = max(st[k-1][i], st[k-1][i+2^(k-1)])
  查询 [l,r]：k=lg[len]，max(st[k][l], st[k][r-2^k+1])
  预处理 O(n log n)，查询 O(1)，只支持静态

可重复贡献：max/min/gcd/or 可以，sum 不行

笛卡尔树：中序是原数组，堆性质；单调栈 O(n) 建
  区间最值 ↔ 树上 LCA

Trie：根为 1，ch[u][c] 存下一个节点
  插入/查询 O(len)，数组大小 = 总字符数
  01-Trie：从高位贪心走相反位，求最大异或
```
