# 第 62 章  哈希表与字符串哈希

---

> 🏗️ **前情回顾**：`map` 能按键查找，但常数较大；字符串比较一次要 O(len)。哈希把"比较"变成"算一个数"，把 O(len) 降到 O(1)。

## 🎯 本章目标

- 理解哈希函数与冲突处理
- 写出字符串哈希（进制哈希）
- 会用双哈希降低冲突
- 用哈希做子串判等、集合判重、图论计数

## 🧱 知识讲解

### 62.1  哈希函数

把任意数据映射成一个整数：

```
h(s) = (s[0]*B^(n-1) + s[1]*B^(n-2) + ... + s[n-1]) % M
```

`B` 是进制（常用 131、13331），`M` 是大质数（常用 1e9+7、1e9+9）。

### 62.2  子串哈希

预处理前缀哈希 `pre[i]` 和 `B` 的幂 `pw[i]`：

```
hash(l, r) = pre[r] - pre[l-1] * pw[r-l+1]   （模 M）
```

这样任意子串的哈希都是 O(1)。

### 62.3  冲突处理

- 单哈希可能被构造数据卡掉
- **双哈希**：用两个不同的 (B, M) 各算一次，两个都相等才认为相等
- 自然溢出：用 `unsigned long long` 让溢出自动取模 2^64，写法简单但可被卡

### 62.4  应用

- 判重：把字符串/集合映射成哈希值
- 子串判等：O(1) 比较
- 图论计数：星战、谐音替换

## 💻 例题

**例 1**：洛谷 P3370 字符串哈希模板——给 n 个字符串，求不同字符串个数。

**例 2**：洛谷 P5278 算术天才⑨与等差数列——哈希 + 线段树（选讲）。

## ⚠️ 常见坑

1. 单哈希被卡；重要题目用双哈希
2. 模数太小导致冲突率高
3. 前缀哈希减法要 +M 再 %M
4. `unsigned long long` 自然溢出不是"绝对安全"
