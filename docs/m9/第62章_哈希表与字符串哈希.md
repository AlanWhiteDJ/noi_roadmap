# 第 62 章  哈希表与字符串哈希

---

> 🏗️ **前情回顾**：`map` 能按键查找，但每次比较都要走树，常数不小；比较两个字符串更要逐字符看，最坏 O(len)。**哈希**换了个思路：不比较内容，而是把内容算成一个整数。整数相等几乎就代表内容相等，一次比较从 O(len) 降到 O(1)。

## 🎯 本章目标

学完这一章，你能：

- 说清哈希函数、哈希值与冲突的关系
- 写出进制哈希，并解释为什么字符要映射到正整数
- 预处理前缀哈希，O(1) 求任意子串哈希
- 用双哈希或自然溢出降低冲突风险
- 用哈希完成判重、子串判等、A-B 数对

## 📖 故事引入

图书馆新到一万本书，管理员要判断"这本书之前有没有到过"。逐本对比书名，一万本要比较几千万次。

小周想了个办法：给每本书算一个**指纹**——把书名的每个字按位置加权求和，再对一个数取模。只要两本书指纹不同，内容一定不同；指纹相同，再翻开确认一下即可。

这个"指纹"就是哈希值。它把任意长度的内容压成一个固定范围的整数，用极小的存储换来极快的比较。代价是：不同的内容可能算出相同的指纹，这叫**哈希冲突**。整个哈希技术，就是围绕"如何算得快"和"如何冲突少"展开的。

---

## 🧱 知识讲解

### 62.1  哈希函数与冲突

哈希函数把数据映射到整数集合：

```
h(s) = (s[0]*B^(n-1) + s[1]*B^(n-2) + ... + s[n-1]) % M
```

这其实是把字符串看成 **B 进制数**。比如 `"abc"`，令 a=1、b=2、c=3，B=131，则：

```
h = 1*131^2 + 2*131 + 3
```

`B` 叫进制，`M` 叫模数。因为结果要对 M 取模，不同的字符串可能落到同一个值——这是**鸽巢原理**的必然：字符串无限多，而模 M 的余数只有 M 个。

冲突无法根除，只能降低概率。常用手段：

- 选大质数 M（如 `10^9+7`、`10^9+9`）；
- 选合适的 B（如 131、13331，且 B 与 M 互质）；
- 用双哈希；
- 用 `unsigned long long` 自然溢出（相当于模 `2^64`）。

### 62.2  字符映射的陷阱

字符必须映射到**正整数**：

```cpp
h = h * B + (s[i] - 'a' + 1);   // a→1, b→2, ...
```

如果写成 `s[i] - 'a'`，`a` 就变成 0，于是 `"a"` 和 `"aa"` 的哈希都可能是 0，直接冲突。**前导零是进制哈希的天然杀手**。

### 62.3  前缀哈希：O(1) 取子串

预处理前缀哈希 `pre[i]`（前 i 个字符的哈希）和 B 的幂 `pw[i]`：

```cpp
typedef unsigned long long ull;
const ull B = 131;
ull pre[N], pw[N];

pw[0] = 1;
for (int i = 1; i <= n; i++) {
    pre[i] = pre[i-1] * B + (s[i] - 'a' + 1);
    pw[i] = pw[i-1] * B;
}
```

子串 `s[l..r]` 的哈希：

```cpp
ull get(int l, int r) {
    return pre[r] - pre[l-1] * pw[r-l+1];
}
```

原理：`pre[r]` 是前 r 个字符的哈希，`pre[l-1] * B^(r-l+1)` 把前 l-1 个字符"左移"到与 `pre[r]` 对齐，相减就只剩 `[l, r]` 这一段。

> ⚠️ 用自然溢出时，`unsigned long long` 的减法会自动回绕，等价于模 2^64，不需要额外处理。如果用有符号模数，减法后要 `(x % M + M) % M`。

### 62.4  双哈希

单哈希存在被构造数据卡掉的风险。**双哈希**用两组不同的 `(B, M)` 各算一次，两个都相等才认为字符串相等：

```cpp
const int M1 = 1000000007, M2 = 1000000009;
const int B1 = 131, B2 = 13331;

pair<int, int> get2(int l, int r) {
    int h1 = (pre1[r] - 1LL * pre1[l-1] * pw1[r-l+1] % M1 + M1) % M1;
    int h2 = (pre2[r] - 1LL * pre2[l-1] * pw2[r-l+1] % M2 + M2) % M2;
    return {h1, h2};
}
```

两个模数同时撞上的概率约为 `1/(M1*M2)`，实际题目中可视为不会发生。

**自然溢出**写法最简单，速度也快，但出题人可以针对 `2^64` 构造碰撞。日常练习可以用，正式比赛的关键题建议双哈希。

### 62.5  哈希表：冲突怎么存

字符串哈希是"把字符串变成数"，哈希表则是"用哈希值决定数据存在哪"。常见两种冲突处理：

**拉链法**：每个桶挂一条链表，冲突的元素都接在后面。

```cpp
const int MOD = 100003;
vector<int> head(MOD, -1), nxt, val;
void insert(int x) {
    int h = ((x % MOD) + MOD) % MOD;
    for (int i = head[h]; i != -1; i = nxt[i])
        if (val[i] == x) return;       // 已存在
    val.push_back(x);
    nxt.push_back(head[h]);
    head[h] = val.size() - 1;
}
bool find(int x) {
    int h = ((x % MOD) + MOD) % MOD;
    for (int i = head[h]; i != -1; i = nxt[i])
        if (val[i] == x) return true;
    return false;
}
```

**开放寻址**：冲突了就往后找空位。实现简单，但删除麻烦。

竞赛里多数时候直接用 `unordered_map`，只有被卡哈希或需要极致常数时才手写。

### 62.6  哈希的典型应用

- **判重**：把每个字符串的哈希丢进 `set`，统计不同值个数（P3370）；
- **子串判等**：O(1) 比较任意两段（P4824 Censoring 就结合了哈希与栈）；
- **A-B 数对**：把"找差值"变成"查表"（P1102）；
- **回文判定**：正着算一遍、反着算一遍，比较对称区间的哈希；
- **图论计数**：给每个点随机一个哈希值，用异或/和判断集合是否一致（CSP-S 2022 星战）。

## 💻 例题

### 例 1  字符串哈希模板（P3370）

**题意**：给 n 个字符串，求不同字符串的个数。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef unsigned long long ull;
const ull B = 131;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n; cin >> n;
    set<ull> st;
    while (n--) {
        string s; cin >> s;
        ull h = 0;
        for (char c : s) h = h * B + (c - 'a' + 1);
        st.insert(h);
    }
    cout << st.size();
    return 0;
}
```

**解析**：每个字符串算一个 64 位哈希，`set` 去重。复杂度 O(总长度·log n)。如果担心碰撞，把 `ull` 换成 `pair<ull,ull>` 双哈希。

### 例 2  A-B 数对（P1102）

**题意**：给 n 个整数和一个非负整数 C，求满足 `a[i] - a[j] = C` 的数对个数。

**思路**：排序后从左到右扫，用 `map` 记录**已经出现过**的数。对当前 `a[i]`，能和它配对的较小值是 `a[i] - C`：

```cpp
sort(a.begin(), a.end());
map<long long, int> cnt;
long long ans = 0;
for (int x : a) {
    ans += cnt[x - C];
    cnt[x]++;
}
cout << ans;
```

**解析**：只统计"左边已经出现的数"，每个下标对恰好算一次；C=0 时自然得到 `C(k,2)`。答案可能超过 `int`，用 `long long`。用 `map` 是 O(n log n)，换 `unordered_map` 平均 O(n)。

### 例 3  子串判等

**题意**：给字符串 s 和 q 次询问，每次给 `l1 r1 l2 r2`，判断两段子串是否相同。

```cpp
int n = s.size();
s = " " + s;                       // 1 下标
pw[0] = 1;
for (int i = 1; i <= n; i++) {
    pre[i] = pre[i-1] * B + (s[i] - 'a' + 1);
    pw[i] = pw[i-1] * B;
}
while (q--) {
    int l1, r1, l2, r2; cin >> l1 >> r1 >> l2 >> r2;
    if (r1 - l1 != r2 - l2) { cout << "No\n"; continue; }
    ull h1 = pre[r1] - pre[l1-1] * pw[r1-l1+1];
    ull h2 = pre[r2] - pre[l2-1] * pw[r2-l2+1];
    cout << (h1 == h2 ? "Yes\n" : "No\n");
}
```

**解析**：长度不同直接判否；长度相同则 O(1) 比较哈希。预处理 O(n)，每次询问 O(1)。这是字符串题里最常用的"降维"手段。

## ⚠️ 常见错误

1. **字符映射从 0 开始**：`s[i]-'a'` 会让 `"a"` 和 `"aa"` 撞哈希，必须 `+1`。
2. **子串公式少了 `pw`**：`pre[r] - pre[l-1]` 没有对齐位数，结果是错的。
3. **模运算减法出现负数**：有符号模数下要 `(x % M + M) % M`。
4. **`pw[0]` 没设成 1**：所有子串哈希都会错。
5. **单哈希硬扛**：出题人可以根据你的 B 和 M 构造碰撞，关键题用双哈希。
6. **`unsigned long long` 溢出比较**：自然溢出是"自动取模"，不是"不会溢出"；减法回绕是特性，但不要拿它和有符号数混算。
7. **哈希表模数太小**：桶太少会让链表变长，退化成 O(n)。

## 🧠 本章小结

```
哈希：把任意数据映射成整数，用极小代价换快速比较
冲突：必然存在，只能降低概率

进制哈希：h = h * B + (s[i] - 'a' + 1)
  B 常用 131 / 13331，M 常用 1e9+7 / 1e9+9
  字符必须映射到正整数

前缀哈希：pre[i] = pre[i-1]*B + val[i]
子串 [l,r]：pre[r] - pre[l-1] * pw[r-l+1]

双哈希：两组 (B,M) 都相等才算相等
自然溢出：unsigned long long 自动模 2^64

应用：判重、子串判等、A-B 数对、回文、图论计数
```
