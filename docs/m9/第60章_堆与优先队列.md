# 第 60 章  堆与优先队列

---

> 🏗️ **前情回顾**：排序能一次性取最值，但"边插入边取最值"就不行了。堆就是为这个场景设计的：插入、删除、取最值都是 O(log n)。

## 🎯 本章目标

- 理解二叉堆的数组表示
- 手写 push/pop，理解上浮与下沉
- 会用 priority_queue，包括小根堆和自定义比较
- 掌握对顶堆求第 k 大

## 🧱 知识讲解

### 60.1  二叉堆的结构

二叉堆是一棵完全二叉树，用数组存，下标从 1 开始：

- 左孩子 `2*i`，右孩子 `2*i+1`，父亲 `i/2`
- 大根堆：每个节点 ≥ 孩子；小根堆：每个节点 ≤ 孩子

### 60.2  上浮与下沉

```cpp
void push(int x) {
    h[++n] = x;
    int i = n;
    while (i > 1 && h[i] < h[i/2]) {   // 小根堆
        swap(h[i], h[i/2]); i /= 2;
    }
}
void pop() {
    h[1] = h[n--];
    int i = 1;
    while (2*i <= n) {
        int j = 2*i;
        if (j+1 <= n && h[j+1] < h[j]) j++;
        if (h[i] <= h[j]) break;
        swap(h[i], h[j]); i = j;
    }
}
```

建堆可以 O(n)：从 `n/2` 到 1 依次下沉。

### 60.3  STL 优先队列

```cpp
priority_queue<int> q;                              // 大根堆
priority_queue<int, vector<int>, greater<int>> p;   // 小根堆
q.push(3); q.top(); q.pop();
```

存结构体时要自定义比较器，注意方向。

### 60.4  对顶堆

维护"当前最大的 k 个数"：小根堆存这 k 个数，堆顶就是第 k 大。新元素比堆顶大就替换。

**例 1**：洛谷 P3378 堆模板，手写小根堆。

**例 2**：洛谷 P1631 序列合并——两个有序数组各取一个求和，取前 n 小。用堆做多路归并。

## ⚠️ 常见坑

1. 数组下标从 1 开始，`2*i` 不要越界
2. 大根堆/小根堆的比较方向写反
3. `priority_queue` 不支持删除任意元素，需要"延迟删除"
4. 对顶堆要保证两个堆的大小关系
