## 📖 故事引入

食堂窗口前排了一队人，窗口每叫一个号，就有一个新同学加入队伍。小周负责登记，他需要随时回答："现在排队的人里，谁最先到？"

如果用数组存，每次来人就插到末尾，叫号时扫一遍找最小值——来 n 个人就是 O(n²)。如果每次来人都保持数组有序，插入又要移动一大片。

其实他不需要"整个队伍有序"，只需要**随时能拿到最小号**。堆正是这样一种"部分有序"的结构：只保证堆顶是最值，其他位置松散地排着。这份"偷懒"换来了 O(log n) 的插入和删除。

## 🧱 知识讲解

### 60.1  二叉堆的结构

二叉堆是一棵**完全二叉树**，并且满足**堆序**：

- **大根堆**：每个节点的值 ≥ 它的两个孩子，堆顶是全局最大；
- **小根堆**：每个节点的值 ≤ 它的两个孩子，堆顶是全局最小。

完全二叉树可以无缝地存进数组（下标从 1 开始）：

| 关系 | 下标 |
|---|---|
| 根 | 1 |
| 节点 i 的左孩子 | `2*i` |
| 节点 i 的右孩子 | `2*i+1` |
| 节点 i 的父亲 | `i/2` |

```cpp
const int N = 100005;
int h[N], n;   // h[1..n] 是一个小根堆
```

> 💡 下标从 1 开始，`2*i` 和 `i/2` 才成立；从 0 开始会让父子关系变成 `2*i+1`、`(i-1)/2`，容易写错。竞赛里手写堆一律从 1 开始。

堆只保证"父亲 ≤ 孩子"（小根堆），**不保证左右孩子之间有序**，也不保证数组整体有序。所以堆能快速取最值，却不能快速查找任意元素。

### 60.2  上浮与下沉

**插入**：把新元素放到数组末尾，然后不断和父亲比较，比父亲小就交换，直到满足堆序。这叫**上浮**（sift up）。

```cpp
void push(int x) {
    h[++n] = x;
    int i = n;
    while (i > 1 && h[i] < h[i / 2]) {
        swap(h[i], h[i / 2]);
        i /= 2;
    }
}
```

**删除堆顶**：把最后一个元素搬到堆顶，然后不断和较小的孩子比较，比孩子大就交换，直到满足堆序。这叫**下沉**（sift down）。

```cpp
void siftDown(int i) {
    while (2 * i <= n) {
        int j = 2 * i;                       // 左孩子
        if (j + 1 <= n && h[j + 1] < h[j]) j++;  // 选较小的孩子
        if (h[i] <= h[j]) break;
        swap(h[i], h[j]);
        i = j;
    }
}
void pop() {
    h[1] = h[n--];
    siftDown(1);
}
```

两次操作都沿着树的高度走，复杂度 O(log n)。

### 60.3  O(n) 建堆

逐个 `push` 建堆是 O(n log n)。数据已全部读入时，可以从最后一个非叶节点 `n/2` 起向前**下沉**：

```cpp
void build() {
    for (int i = n / 2; i >= 1; i--) siftDown(i);
}
```

越靠下的节点越少，总代价是 O(n)。证明思路：高度为 k 的节点约有 `n/2^(k+1)` 个，每个下沉 O(k)，求和后收敛到 O(n)。

> 💡 建堆 O(n)、排序 O(n log n)，这就是**堆排序**的基础：先建大根堆，再反复把堆顶换到末尾并下沉。

### 60.4  STL 优先队列

`priority_queue` 默认是大根堆：

```cpp
priority_queue<int> q;          // 大根堆
q.push(3); q.push(1); q.push(4);
cout << q.top();                // 4
q.pop();                        // 删掉 4
cout << q.size() << q.empty();
```

小根堆要写全三个模板参数：

```cpp
priority_queue<int, vector<int>, greater<int>> p;   // 小根堆
```

存 `pair` 时，默认先比 first、再比 second，大根堆放进去就是按 first 从大到小：

```cpp
priority_queue<pair<int, int>> pq;
pq.push({1, 2});
pq.push({3, 1});   // top 是 {3,1}
```

存结构体要自定义比较器。注意**比较器表达的是"优先级低"**，写法和大根堆相反：

```cpp
struct Node { int dis, id; };
struct Cmp {
    bool operator()(const Node &a, const Node &b) const {
        return a.dis > b.dis;   // dis 小的优先 → 小根堆
    }
};
priority_queue<Node, vector<Node>, Cmp> pq;
```

> ⚠️ 比较器必须满足严格弱序：不能对相等元素返回 true，否则行为未定义。写 `>=` 是大忌。

`priority_queue` 不支持删除任意元素，也不支持遍历。需要"删除某个旧元素"时，常用**延迟删除**：另开一个 `map` 或 `set` 记录待删元素，取堆顶时如果它已失效就不断弹出。

### 60.5  对顶堆：动态中位数

需要随时回答"当前所有数的中位数"，可以用两个堆：

- **大根堆 L** 存较小的一半，堆顶是这一半的最大值；
- **小根堆 R** 存较大的一半，堆顶是这一半的最小值。

保持 `L.size() == R.size()` 或 `L.size() == R.size() + 1`，中位数就是 `L.top()`（奇数个）或 `(L.top()+R.top())/2`（偶数个）。

```cpp
priority_queue<int> L;
priority_queue<int, vector<int>, greater<int>> R;

void add(int x) {
    if (L.empty() || x <= L.top()) L.push(x);
    else R.push(x);
    if (L.size() > R.size() + 1) { R.push(L.top()); L.pop(); }
    if (R.size() > L.size())     { L.push(R.top()); R.pop(); }
}
```

每次插入 O(log n)，取中位数 O(1)。

### 60.6  多路归并与 Top-K

**合并果子**（P1090）：每次取最小的两堆合并，把和放回去，直到只剩一堆。用小根堆模拟，每次弹两个、压一个，总代价 O(n log n)。这是哈夫曼树的贪心过程。

**序列合并**（P1631）：两个长度为 n 的升序数组 a、b，各取一个数求和，求前 n 小的和。把每个 `a[i] + b[1]` 看成一条"有序链"，问题变成从 n 条链里做多路归并：

```cpp
priority_queue<pair<int, pair<int,int>>,
               vector<pair<int, pair<int,int>>>,
               greater<pair<int, pair<int,int>>>> pq;
for (int i = 1; i <= n; i++) pq.push({a[i] + b[1], {i, 1}});
for (int k = 1; k <= n; k++) {
    auto cur = pq.top(); pq.pop();
    int i = cur.second.first, j = cur.second.second;
    cout << cur.first << ' ';
    if (j < n) pq.push({a[i] + b[j + 1], {i, j + 1}});
}
```

每条链只推进一格，不会重复，也不会遗漏。

## 💻 例题

### 例 1  堆模板（P3378）

**题意**：维护一个初始为空的小根堆，支持插入 x、删除最小值、询问最小值。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 1000005;
int h[N], n;
void push(int x) {
    h[++n] = x;
    for (int i = n; i > 1 && h[i] < h[i / 2]; i /= 2)
        swap(h[i], h[i / 2]);
}
void pop() {
    h[1] = h[n--];
    for (int i = 1; 2 * i <= n; ) {
        int j = 2 * i;
        if (j + 1 <= n && h[j + 1] < h[j]) j++;
        if (h[i] <= h[j]) break;
        swap(h[i], h[j]);
        i = j;
    }
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q; cin >> q;
    while (q--) {
        int op; cin >> op;
        if (op == 1) { int x; cin >> x; push(x); }
        else if (op == 2) pop();
        else cout << h[1] << '\n';
    }
    return 0;
}
```

**解析**：`push` 从末尾上浮，`pop` 把末尾搬到根再下沉。注意 `pop` 前题目保证堆非空；实际比赛中要自己判 `n > 0`，否则 `h[1] = h[0]` 会读到脏数据。

### 例 2  合并果子（P1090）

**题意**：n 堆果子，每次合并两堆，代价为两堆数量之和，求合并成一堆的最小总代价。

```cpp
priority_queue<int, vector<int>, greater<int>> pq;
for (int i = 0; i < n; i++) { int x; cin >> x; pq.push(x); }
long long ans = 0;
while (pq.size() > 1) {
    int a = pq.top(); pq.pop();
    int b = pq.top(); pq.pop();
    ans += a + b;
    pq.push(a + b);
}
cout << ans;
```

**解析**：每次都让当前最小的两堆先合并，总代价最小——这是贪心，也是哈夫曼树的构造。答案可能超过 `int`，要用 `long long`。

### 例 3  序列合并（P1631）

**题意**：两个长度 n 的升序数组，各取一个数相加，输出最小的 n 个和。

```cpp
for (int i = 1; i <= n; i++) pq.push({a[i] + b[1], {i, 1}});
for (int k = 1; k <= n; k++) {
    auto cur = pq.top(); pq.pop();
    int i = cur.second.first, j = cur.second.second;
    cout << cur.first << ' ';
    if (j < n) pq.push({a[i] + b[j + 1], {i, j + 1}});
}
```

**解析**：把 `a[i] + b[1..n]` 看成 n 条升序链，堆里始终放每条链的当前头。弹出后把该链的下一个推进来，取 n 次就得到前 n 小。复杂度 O(n log n)，空间 O(n)。

## ⚠️ 常见错误

1. **下标从 0 开始还写 `2*i`**：父子关系全乱。手写堆统一从 1 开始存。
2. **大根堆/小根堆比较方向写反**：小根堆上浮条件是 `h[i] < h[i/2]`，下沉要先选**较小**的孩子。
3. **`pop` 时没有判空**：空堆 `top()` 是未定义行为，`pop()` 会把 `h[0]` 搬上来。
4. **自定义比较器写成 `>=`**：违反严格弱序，`priority_queue` 行为未定义。相等时必须返回 false。
5. **以为 `priority_queue` 能删除任意元素**：它只能删堆顶。其他元素用延迟删除或改用 `multiset`。
6. **对顶堆大小失衡**：插入后必须立刻调整，保证 `L.size()` 与 `R.size()` 差不超过 1。
7. **忘记 `long long`**：合并代价、区间和这类累加很容易超 `int`。

## 🧠 本章小结

```
二叉堆：完全二叉树 + 堆序，数组下标从 1 开始
  左孩子 2i，右孩子 2i+1，父亲 i/2

push：放到末尾，向上浮    O(log n)
pop ：末尾搬到根，向下沉  O(log n)
build：从 n/2 向前下沉     O(n)

priority_queue<int>                大根堆
priority_queue<int, vector<int>,
               greater<int>>       小根堆
自定义比较器：返回 true 表示 a 的优先级低于 b

对顶堆：大根堆存小半，小根堆存大半 → 动态中位数
多路归并：每条有序链的头放进堆，弹出后推进一格
```
