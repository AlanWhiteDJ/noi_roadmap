# 第 59 章  单调栈、单调队列与双端结构

---

> 🏗️ **前情回顾**：栈和队列是线性结构。这一章给它们加一个约束——保持内部元素单调。加了这个约束，很多"找下一个更大/区间最值"的问题就能做到 O(n)。

## 🎯 本章目标

- 用单调栈求"下一个更大/更小元素"
- 用单调队列维护滑动窗口最值
- 理解双端队列在 0-1 BFS 中的作用
- 能把单调队列用于 DP 优化

## 🧱 知识讲解

### 59.1  单调栈

问题：给一个数组，求每个数右边第一个比它大的数。

维护一个**从栈底到栈顶单调递减**的栈，存下标：

```cpp
stack<int> st;
for (int i = 1; i <= n; i++) {
    while (!st.empty() && a[st.top()] < a[i]) {
        ans[st.top()] = i;   // i 就是它的下一个更大元素
        st.pop();
    }
    st.push(i);
}
```

每个元素最多进栈、出栈一次，总复杂度 O(n)。

### 59.2  单调队列

问题：长度为 n 的数组，窗口大小 k，求每个窗口的最大值。

维护一个**从队头到队尾单调递减**的双端队列，存下标：

```cpp
deque<int> q;
for (int i = 1; i <= n; i++) {
    while (!q.empty() && q.front() <= i - k) q.pop_front();  // 过期
    while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();  // 保持单调
    q.push_back(i);
    if (i >= k) cout << a[q.front()] << ' ';
}
```

### 59.3  双端队列与 0-1 BFS

边权只有 0 和 1 时，用双端队列代替优先队列：

- 边权 0：从队头入队
- 边权 1：从队尾入队

这样最短路仍然是 O(n+m)，比 Dijkstra 少一个 log。

## 💻 例题

**例 1**：洛谷 P5788 单调栈模板——下一个更大元素。

**例 2**：洛谷 P1886 滑动窗口——单调队列求区间最值。

## ⚠️ 常见坑

1. 单调队列存下标，不存值，否则无法判断过期
2. 弹栈/弹队列时用 `<` 还是 `<=` 决定保留哪一个相等元素
3. 窗口大小 k 大于 n 时要特判
4. 0-1 BFS 中一个点可能多次入队，dist 更新后要重新入队
