# 第 59 章  单调栈、单调队列与双端结构

---

> 🏗️ **前情回顾**：栈是"后进先出"，队列是"先进先出"，`deque` 两头都能进出。它们本身只是容器，真正的威力在于给里面的元素加一条约束——**保持单调**。加了这条约束，"找下一个更大元素""求滑动窗口最值"这类问题就能从 O(n²) 降到 O(n)。

## 🎯 本章目标

学完这一章，你能：

- 说清单调栈"每个元素只进出一次"的原因
- 写出求左/右、严格/非严格更大更小元素的四种单调栈
- 用单调队列维护滑动窗口的最大值和最小值
- 用单调队列优化一类窗口转移的 DP
- 用双端队列实现 0-1 BFS

---

## 📖 故事引入

学校运动会看台只有一排座位。小周坐在第 i 个位置，他想知道：**右边第一个比他高的人是谁？** 因为那个人会挡住他的视线。

最直接的做法是往右一个个看，遇到更高的就停下。可如果队伍从左到右越来越矮，每个人都要看到队尾，总代价是 O(n²)。

换个角度：如果一个人右边出现了比他高的人，那么**所有比他矮、还排在更左边的人**，他们的答案也不可能是更右边那些更矮的人——他们会被当前这个高个子先挡住。换句话说，一旦某个元素"遇到比自己高的"，它就可以永久退场了。

每个元素只进场一次、退场一次，总操作 O(n)。这就是**单调栈**。

## 🧱 知识讲解

### 59.1  单调栈的模型

问题：给数组 a[1..n]，对每个 i 求最小的 j > i 使 a[j] > a[i]，不存在输出 0。

维护一个栈，里面存**下标**，并保证从栈底到栈顶，对应的 a 值**单调不增**：

```cpp
stack<int> st;
vector<int> ans(n + 1, 0);
for (int i = 1; i <= n; i++) {
    while (!st.empty() && a[st.top()] < a[i]) {
        ans[st.top()] = i;   // i 就是栈顶元素右边第一个更大值
        st.pop();
    }
    st.push(i);
}
```

为什么正确？栈顶是"还没找到答案、且最靠右"的元素。当前 a[i] 比它大，就说明 i 是它右边第一个更大值；弹出后继续检查新的栈顶。那些比 a[i] 大的元素留在栈里，等后面更高的人来解决。

**复杂度**：每个下标最多入栈一次、出栈一次，均摊 O(n)。

### 59.2  四种变体

决定弹出条件的是"你要严格还是非严格"：

| 需求 | 弹出条件 | 说明 |
|---|---|---|
| 右边第一个 **>** a[i] | `a[top] < a[i]` | 相等不弹，等更严格的大值 |
| 右边第一个 **>=** a[i] | `a[top] <= a[i]` | 相等也算答案 |
| 右边第一个 **<** a[i] | `a[top] > a[i]` | 栈改为单调不降 |
| 右边第一个 **<=** a[i] | `a[top] >= a[i]` | 相等也算答案 |

如果要求**左边**第一个更大/更小，可以从右往左扫，也可以正着扫、在 `push(i)` 之前先处理栈顶（此时栈里全是左边的元素）。

> 💡 记法：求"更大"就用递减栈，求"更小"就用递增栈；**严格就用 `<` / `>`，非严格就带等号**。

### 59.3  应用一：柱状图最大矩形

给一排宽度为 1、高度为 h[i] 的柱子，求能画出的最大矩形面积。

对每根柱子，向左右各找到**第一个比它矮**的位置 L[i]、R[i]，以它为高的矩形最宽只能到 `(L[i], R[i])`，面积 `h[i] * (R[i] - L[i] - 1)`。

在数组两端各加一个高度 0 的哨兵，省去清空栈的麻烦：

```cpp
int largestRectangle(vector<int> h) {
    h.insert(h.begin(), 0);
    h.push_back(0);
    int n = h.size(), ans = 0;
    stack<int> st;
    for (int i = 0; i < n; i++) {
        while (!st.empty() && h[st.top()] > h[i]) {
            int cur = st.top(); st.pop();
            int left = st.top();
            ans = max(ans, h[cur] * (i - left - 1));
        }
        st.push(i);
    }
    return ans;
}
```

这里栈内高度单调不降。当前 h[i] 比栈顶矮，说明栈顶柱子的右边界到了；弹出后新的栈顶就是它左边第一个更矮的柱子。

同类题还有"接雨水"：维护递减栈，弹出时用左右边界算出一层水的宽度和高度。

### 59.4  单调队列：滑动窗口最值

问题：长度 n 的数组，窗口大小 k，从左到右滑动，输出每个窗口的最大值。

维护一个双端队列，存下标，队列里的 a 值**从队头到队尾单调递减**：

```cpp
deque<int> q;
for (int i = 1; i <= n; i++) {
    while (!q.empty() && q.front() <= i - k) q.pop_front();  // 1. 过期
    while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();  // 2. 保持单调
    q.push_back(i);
    if (i >= k) cout << a[q.front()] << ' ';                 // 3. 输出
}
```

三步的顺序很重要：

1. **去头**：窗口左端是 `i-k+1`，下标 ≤ `i-k` 的已经出去；
2. **去尾**：新元素比队尾大，队尾永远不可能再成为最大值，弹掉；
3. **入队并输出**：队头就是当前窗口最大值。

每个下标最多进出一次，总复杂度 O(n)。求最小值时把比较改成 `>=`，队列变成单调递增。

### 59.5  单调队列优化 DP

有一类转移长这样：

```
dp[i] = max(dp[j]) + a[i]，其中 i-k ≤ j < i
```

如果每个 i 都枚举 j，是 O(nk)。但窗口 `[i-k, i-1]` 正好是一个滑动窗口，用单调队列维护窗口内 dp 的最大值，就能 O(n)。

```cpp
deque<int> q;
q.push_back(0);                 // dp[0] = 0 作为基底
for (int i = 1; i <= n; i++) {
    while (!q.empty() && q.front() < i - k) q.pop_front();
    dp[i] = dp[q.front()] + a[i];
    while (!q.empty() && dp[q.back()] <= dp[i]) q.pop_back();
    q.push_back(i);
}
```

经典题"切蛋糕"（P1714）：求长度不超过 m 的连续子段最大和。设前缀和 `pre[i]`，则需要最大化 `pre[i] - pre[j]`，其中 `i-m ≤ j < i`。固定 i，只要窗口内 `pre[j]` 最小：

```cpp
deque<int> q;
q.push_back(0);
int ans = -2e9;
for (int i = 1; i <= n; i++) {
    while (!q.empty() && q.front() < i - m) q.pop_front();
    ans = max(ans, pre[i] - pre[q.front()]);
    while (!q.empty() && pre[q.back()] >= pre[i]) q.pop_back();
    q.push_back(i);
}
```

### 59.6  双端队列与 0-1 BFS

普通 BFS 的边权都是 1，一层一层扩展。如果边权只有 0 和 1，可以用双端队列代替优先队列：

- 边权 0：新点从**队头**入队，它和当前点属于同一层；
- 边权 1：新点从**队尾**入队，它属于下一层。

```cpp
vector<int> dist(n + 1, 1e9);
deque<int> q;
dist[s] = 0; q.push_front(s);
while (!q.empty()) {
    int u = q.front(); q.pop_front();
    for (auto e : g[u]) {
        int v = e.to, w = e.w;
        if (dist[v] > dist[u] + w) {
            dist[v] = dist[u] + w;
            if (w == 0) q.push_front(v);
            else q.push_back(v);
        }
    }
}
```

这样队列里的 dist 始终最多相差 1，整体仍然有序，复杂度 O(n+m)，比 Dijkstra 少一个 log。

> ⚠️ 一个点可能多次入队（被更短的路径更新），所以不要用"访问过就跳过"的 visited 数组，而要用 `dist[v] > dist[u] + w` 判断松弛。

## 💻 例题

### 例 1  单调栈模板（P5788）

**题意**：给 n 个数，对每个 i 输出右边第一个大于 a[i] 的数的下标，不存在输出 0。

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n; cin >> n;
    vector<int> a(n + 1), ans(n + 1, 0);
    for (int i = 1; i <= n; i++) cin >> a[i];
    stack<int> st;
    for (int i = 1; i <= n; i++) {
        while (!st.empty() && a[st.top()] < a[i]) {
            ans[st.top()] = i;
            st.pop();
        }
        st.push(i);
    }
    for (int i = 1; i <= n; i++) cout << ans[i] << ' ';
    return 0;
}
```

**解析**：栈里存的是"还没找到更大值"的下标，值从栈底到栈顶不增。当前元素把所有比它小的栈顶一次性解决，然后自己入栈等待。每个下标进出各一次，O(n)。

### 例 2  滑动窗口（P1886）

**题意**：n 个数，窗口大小 k，输出每个窗口的最小值和最大值。

```cpp
deque<int> q;
for (int i = 1; i <= n; i++) {           // 最小值
    while (!q.empty() && q.front() <= i - k) q.pop_front();
    while (!q.empty() && a[q.back()] >= a[i]) q.pop_back();
    q.push_back(i);
    if (i >= k) cout << a[q.front()] << ' ';
}
q.clear();
for (int i = 1; i <= n; i++) {           // 最大值
    while (!q.empty() && q.front() <= i - k) q.pop_front();
    while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();
    q.push_back(i);
    if (i >= k) cout << a[q.front()] << ' ';
}
```

**解析**：两次扫描分别维护递增和递减队列。注意先删过期、再删队尾、最后入队；输出要等 `i >= k`，否则窗口还没满。

### 例 3  柱状图中的最大矩形

**题意**：n 根宽度为 1 的柱子，高度 h[i]，求最大矩形面积。

```cpp
int ans = 0;
stack<int> st;
vector<int> h2(n + 2);
for (int i = 1; i <= n; i++) h2[i] = h[i];
h2[0] = h2[n + 1] = 0;                  // 两端哨兵
for (int i = 0; i <= n + 1; i++) {
    while (!st.empty() && h2[st.top()] > h2[i]) {
        int cur = st.top(); st.pop();
        int left = st.top();
        ans = max(ans, h2[cur] * (i - left - 1));
    }
    st.push(i);
}
```

**解析**：哨兵高度 0 保证最后所有柱子都会被弹出，且 `st` 不会空。弹出 cur 时，i 是右边第一个更矮的位置，新的栈顶是左边第一个更矮的位置，宽度就是 `i - left - 1`。

## ⚠️ 常见错误

1. **单调队列存值不存下标**：无法判断队头是否已经滑出窗口。永远存下标，用 `a[q.front()]` 取值。
2. **过期条件写成 `< i - k`**：窗口左端是 `i-k+1`，所以 `q.front() <= i-k` 就该弹出。差一位会多留一个元素。
3. **相等元素乱弹**：求严格更大时用 `<`，相等保留；求非严格时用 `<=`。写反了答案会偏。
4. **窗口没满就输出**：必须 `if (i >= k)`，否则前 k-1 个窗口不完整。
5. **单调栈存值不存下标**：要填 `ans[top] = i` 时必须知道是谁的答案。
6. **0-1 BFS 用 visited 剪枝**：一个点可能被更短路径再次更新，必须允许重复入队。
7. **多组数据忘记清空栈和队列**：局部变量最安全，或每次 `while (!q.empty()) q.pop()`。

## 🧠 本章小结

```
单调栈：栈内存下标，值单调
  右边第一个更大：while (a[top] < a[i]) 弹出并记录
  右边第一个更小：while (a[top] > a[i])
  严格/非严格 → 比较要不要带等号

单调队列：deque 存下标，值单调
  1. 弹过期：q.front() <= i - k
  2. 弹队尾：保持单调
  3. 入队，窗口满了再输出
  滑窗最值、窗口 DP 优化都是它

0-1 BFS：边权 0 进队头，边权 1 进队尾
         用 dist 松弛，不用 visited 剪枝
```
