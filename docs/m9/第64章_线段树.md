# 第 64 章  线段树

---

> 🏗️ **前情回顾**：树状数组擅长"前缀和"，但遇到区间赋值、区间最值、区间加乘混合，它就力不从心了。**线段树**是区间操作的通用武器：建树 O(n)，单次修改或查询 O(log n)，而且只要信息能合并，它几乎什么都能维护。

## 🎯 本章目标

学完这一章，你能：

- 说清线段树的区间划分与 `4n` 空间
- 写出建树、单点修改、区间查询的递归框架

- 处理区间加 + 区间乘的双标记
- 了解权值线段树、动态开点与线段树合并

## 🧱 知识讲解

### 64.1  结构与建树

每个节点维护一个区间 `[l, r]`：

- `l == r` 时是叶子，存单点信息；
- 否则取 `mid = (l+r)/2`，左孩子管 `[l, mid]`，右孩子管 `[mid+1, r]`。

```cpp
const int N = 100005;
struct Node {
    long long sum, lazy;
} tr[N * 4];

void pushup(int u) {
    tr[u].sum = tr[u * 2].sum + tr[u * 2 + 1].sum;
}

void build(int u, int l, int r) {
    if (l == r) { tr[u].sum = a[l]; return; }
    int mid = (l + r) / 2;
    build(u * 2, l, mid);
    build(u * 2 + 1, mid + 1, r);
    pushup(u);
}
```

> ⚠️ 数组要开 `4*n`：它不是满二叉树，`2n` 不够。

### 64.2  单点修改与区间查询

单点修改：一路递归到叶子，改完回溯时 `pushup`。

```cpp
void update(int u, int l, int r, int pos, long long v) {
    if (l == r) { tr[u].sum = v; return; }
    int mid = (l + r) / 2;
    if (pos <= mid) update(u * 2, l, mid, pos, v);
    else update(u * 2 + 1, mid + 1, r, pos, v);
    pushup(u);
}
```

区间查询：把 `[ql, qr]` 拆成若干个完全覆盖的节点。

```cpp
long long query(int u, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return tr[u].sum;
    int mid = (l + r) / 2;
    long long res = 0;
    if (ql <= mid) res += query(u * 2, l, mid, ql, qr);
    if (qr > mid)  res += query(u * 2 + 1, mid + 1, r, ql, qr);
    return res;
}
```

### 64.3  懒标记：区间加 + 区间和

区间修改时，如果每次都推到叶子，复杂度退化成 O(n)。**懒标记**的做法是：整段被覆盖时，只更新这个节点的 `sum`，并在节点上记一个 `lazy`，表示"我的每个孩子还欠这么多"。

```cpp
void apply(int u, int l, int r, long long v) {
    tr[u].sum += v * (r - l + 1);
    tr[u].lazy += v;
}

void pushdown(int u, int l, int r) {
    if (tr[u].lazy == 0) return;
    int mid = (l + r) / 2;
    apply(u * 2, l, mid, tr[u].lazy);
    apply(u * 2 + 1, mid + 1, r, tr[u].lazy);
    tr[u].lazy = 0;          // 下传后必须清空
}

void add(int u, int l, int r, int ql, int qr, long long v) {
    if (ql <= l && r <= qr) { apply(u, l, r, v); return; }
    pushdown(u, l, r);
    int mid = (l + r) / 2;
    if (ql <= mid) add(u * 2, l, mid, ql, qr, v);
    if (qr > mid)  add(u * 2 + 1, mid + 1, r, ql, qr, v);
    pushup(u);
}
```

查询时也要先 `pushdown`。

**关键顺序**：进入子区间前下传，回溯时上传；`pushdown` 后把 `lazy` 清零。

### 64.4  区间加 + 区间乘

把 64.3 的 `lazy` 换成一个 `add` 和一个 `mul`（初始 0 和 1）。约定：节点真实值 = `sum * mul + add * len`。乘法的优先级高于加法，所以：

- 对节点乘 k：`sum *= k`，`mul *= k`，`add *= k`；
- 对节点加 k：`sum += k * len`，`add += k`。

```cpp
void apply_mul(int u, long long k) {
    tr[u].sum *= k;
    tr[u].mul *= k;
    tr[u].add *= k;
}
void apply_add(int u, int l, int r, long long k) {
    tr[u].sum += k * (r - l + 1);
    tr[u].add += k;
}
void pushdown(int u, int l, int r) {
    int mid = (l + r) / 2;
    if (tr[u].mul != 1) {
        apply_mul(u * 2, tr[u].mul);
        apply_mul(u * 2 + 1, tr[u].mul);
        tr[u].mul = 1;
    }
    if (tr[u].add != 0) {
        apply_add(u * 2, l, mid, tr[u].add);
        apply_add(u * 2 + 1, mid + 1, r, tr[u].add);
        tr[u].add = 0;
    }
}
```

**必须先下传乘法，再下传加法**。因为 `mul` 是后来乘上去的，如果先加后乘，就会把旧加法也乘进去，顺序反了。

### 64.5  权值线段树与动态开点

**权值线段树**的下标是值，节点维护值域内出现次数，能 O(log V) 求第 k 小、排名。

值域很大时用**动态开点**：访问到哪个区间才新建节点。

```cpp
int ls[N], rs[N], cnt[N], tot;
void insert(int &u, int l, int r, int x) {
    if (!u) u = ++tot;
    if (l == r) { cnt[u]++; return; }
    int mid = (l + r) / 2;
    if (x <= mid) insert(ls[u], l, mid, x);
    else insert(rs[u], mid + 1, r, x);
    cnt[u] = cnt[ls[u]] + cnt[rs[u]];
}
```

**线段树合并**把两棵权值线段树合并，常用于树上启发式合并。

## 💻 例题

### 例 1  线段树 1（P3372）

**题意**：区间每个数加 k，或求区间和。

```cpp
build(1, 1, n);
while (m--) {
    int op, l, r; long long k;
    cin >> op >> l >> r;
    if (op == 1) { cin >> k; add(1, 1, n, l, r, k); }
    else cout << query(1, 1, n, l, r) << '\n';
}
```

**解析**：`apply` 同时改 `sum` 和 `lazy`，`pushdown` 把欠孩子的标记发下去。查询也要下传，否则子节点还欠着父节点的修改。

### 例 2  线段树 2（P3373）

**题意**：区间加、区间乘、区间求和，三种操作。

```cpp
// 区间乘 v：apply_mul(1, 1, n, l, r, v)
void apply_mul(int u, long long k) {
    tr[u].sum *= k;
    tr[u].mul *= k;
    tr[u].add *= k;
}
```

**解析**：乘法标记初始为 1，加法为 0。下传乘法时孩子的 `add` 也要乘 k。顺序永远先乘后加，所有运算对题目给的模数取模。

### 例 3  区间最值（P1531）

**题意**：单点修改，询问区间最大值。

```cpp
void update(int u, int l, int r, int pos, int v) {
    if (l == r) { tr[u].mx = v; return; }
    int mid = (l + r) / 2;
    if (pos <= mid) update(u * 2, l, mid, pos, v);
    else update(u * 2 + 1, mid + 1, r, pos, v);
    tr[u].mx = max(tr[u * 2].mx, tr[u * 2 + 1].mx);
}
int query(int u, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return tr[u].mx;
    int mid = (l + r) / 2, res = -1e9;
    if (ql <= mid) res = max(res, query(u * 2, l, mid, ql, qr));
    if (qr > mid)  res = max(res, query(u * 2 + 1, mid + 1, r, ql, qr));
    return res;
}
```

**解析**：`sum` 换成 `mx`，`pushup` 改成取最大值即可。线段树的可维护信息必须满足**结合律**：和、最值、最大子段和、矩阵乘积都可以。

## ⚠️ 常见错误

1. **数组只开 `2n`**：要开 `4n`，否则深层越界。
2. **`pushdown` 后忘记清空 `lazy`**：标记会被重复下传，答案翻倍。
3. **查询时不下传**：子节点还欠着父节点的修改，读到旧值。
4. **乘法标记初始为 0**：应该初始为 1，否则一乘全变 0。
5. **加乘顺序反了**：必须先乘后加，否则旧加法被多乘一次。
6. **递归边界写错**：`l == r` 是叶子；`mid` 的划分要保证 `[l,mid]` 和 `[mid+1,r]` 不重不漏。
7. **忘记 `long long`**：区间和、乘法标记都可能溢出。

## 🧠 本章小结

```
线段树：每个节点管一个区间 [l,r]
  mid = (l+r)/2，左 [l,mid]，右 [mid+1,r]
  空间开 4n

build：递归到叶子，回溯 pushup
update：单点一路到底；区间整段覆盖时打 lazy
query：完全覆盖返回，否则 pushdown 后递归

懒标记：apply 改 sum 和 lazy；pushdown 下传并清空
加乘双标记：sum*mul + add*len，先乘后加

权值线段树：下标是值，求第 k 小
动态开点：值域大时只建用到的节点
```
