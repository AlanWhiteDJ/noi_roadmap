# 第 64 章  线段树

---

> 🏗️ **前情回顾**：树状数组擅长"前缀和"，但遇到区间赋值、区间最值、区间加乘混合就力不从心。线段树是区间操作的通用武器：建树 O(n)，修改/查询 O(log n)。

## 🎯 本章目标

- 建树、单点修改、区间查询的递归框架
- 懒标记：区间加/区间赋值 + 区间求和
- 权值线段树、动态开点、线段树合并（选学）

## 🧱 知识讲解

### 64.1  结构

每个节点维护一个区间 `[l, r]`，叶子是单点，内部节点由左右孩子合并：

```cpp
struct Node { int sum, lazy; } tr[N*4];
void pushup(int u) { tr[u].sum = tr[u*2].sum + tr[u*2+1].sum; }
void build(int u, int l, int r) {
    if (l == r) { tr[u].sum = a[l]; return; }
    int mid = (l + r) / 2;
    build(u*2, l, mid); build(u*2+1, mid+1, r);
    pushup(u);
}
```

### 64.2  懒标记

区间修改时，不立刻下推到叶子，而是在节点上记一个 `lazy`，查询/再次修改时再下传：

```cpp
void pushdown(int u, int l, int r) {
    if (!tr[u].lazy) return;
    int mid = (l + r) / 2;
    tr[u*2].sum += tr[u].lazy * (mid - l + 1);
    tr[u*2+1].sum += tr[u].lazy * (r - mid);
    tr[u*2].lazy += tr[u].lazy;
    tr[u*2+1].lazy += tr[u].lazy;
    tr[u].lazy = 0;
}
```

加乘双标记要注意顺序：先乘后加，或者分别维护。

### 64.3  区间查询

```cpp
int query(int u, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return tr[u].sum;
    pushdown(u, l, r);
    int mid = (l + r) / 2, res = 0;
    if (ql <= mid) res += query(u*2, l, mid, ql, qr);
    if (qr > mid)  res += query(u*2+1, mid+1, r, ql, qr);
    return res;
}
```

### 64.4  权值线段树与动态开点

- 权值线段树：下标是值域，维护每个值出现次数，可求第 k 小
- 动态开点：值域很大时，只开用到的节点
- 线段树合并：把两棵树的信息合并（选学）

## ⚠️ 常见坑

1. 数组要开 `4*n`
2. `pushdown` 后忘记清空 `lazy`
3. 加乘标记的顺序写反
4. 递归边界 `l == r` 写错
