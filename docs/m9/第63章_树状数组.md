# 第 63 章  树状数组

---

> 🏗️ **前情回顾**：前缀和查询 O(1)，但修改 O(n)。树状数组把修改和查询都做到 O(log n)，是最常用的动态前缀结构。

## 🎯 本章目标

- 理解 lowbit 与树状数组的区间划分
- 实现单点修改 + 前缀查询
- 实现区间修改 + 单点查询（差分）
- 用树状数组求逆序对、维护动态前缀最值

## 🧱 知识讲解

### 63.1  lowbit

```cpp
int lowbit(int x) { return x & -x; }
```

`lowbit(x)` 取 x 最低位的 1。树状数组的每个节点 `i` 管理区间 `(i-lowbit(i), i]`。

### 63.2  单点修改 + 前缀和

```cpp
void add(int i, int v) {
    for (; i <= n; i += lowbit(i)) tree[i] += v;
}
int sum(int i) {
    int s = 0;
    for (; i > 0; i -= lowbit(i)) s += tree[i];
    return s;
}
```

查询区间 `[l, r]` 就是 `sum(r) - sum(l-1)`。

### 63.3  差分版：区间修改 + 单点查询

在差分数组上建树状数组：区间 `[l, r]` 加 v，就是 `add(l, v)`、`add(r+1, -v)`；查询单点就是前缀和。

### 63.4  逆序对

离散化后，从左到右扫描：`ans += i - sum(a[i])`，再把 `a[i]` 加进去。

## 💻 例题

**例 2**：洛谷 P1908 逆序对——离散化 + 树状数组。

## ⚠️ 常见坑

1. 下标从 0 开始导致 `lowbit(0)=0` 死循环
2. 区间修改 + 区间查询需要两个树状数组
3. 逆序对要开 `long long`
4. 离散化后忘记去重
