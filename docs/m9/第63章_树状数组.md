# 第 63 章  树状数组

---

> 🏗️ **前情回顾**：前缀和让区间求和变成 O(1)，但数组一改，后面所有前缀和都要重算，修改是 O(n)。差分让区间修改变成 O(1)，可查询单点又要 O(n)。**树状数组**（Binary Indexed Tree，BIT）把两边都压到 O(log n)，是最常用的动态前缀结构。

## 🎯 本章目标

学完这一章，你能：

- 理解 `lowbit` 与树状数组的区间划分
- 实现单点修改 + 前缀查询
- 用差分树状数组实现区间修改 + 单点查询
- 用两个树状数组实现区间修改 + 区间求和
- 用树状数组求逆序对，并在树状数组上二分

---

## 📖 故事引入

班主任有一张成绩单，两个操作反复出现：

- 某个同学改了分数；
- 问前 k 个同学的总分。

用前缀和，查询一秒出答案，可一改分数，后面几十个前缀和全要重算；用普通数组，改分很快，查询又要从头加。

小周发现：**不需要每个前缀都精确，只要把区间切成几块，查询时拼起来就行。** 比如前 7 个的和，可以拆成"第 7 个""第 5~6 个""第 1~4 个"。每块的大小正好是 2 的幂，改一个数只需要更新包含它的那几块。

这就是树状数组：用二进制的低位，把数组组织成一棵"隐形的树"。

---

## 🧱 知识讲解

### 63.1  lowbit：取出最低位的 1

```cpp
int lowbit(int x) {
    return x & -x;
}
```

负数的补码表示里，`-x` 等于 `~x + 1`，所以 `x & -x` 恰好保留 x 最低位的那个 1：

| x | 二进制 | lowbit |
|---|---|---|
| 6 | 110 | 2 |
| 7 | 111 | 1 |
| 8 | 1000 | 8 |
| 12 | 1100 | 4 |

树状数组的节点 `i` 管理区间 `(i - lowbit(i), i]`，长度正好是 `lowbit(i)`。

### 63.2  树状数组的结构

```
i:      1   2   3   4   5   6   7   8
管理:  [1] [1,2] [3] [1..4] [5] [5,6] [7] [1..8]
```

- 节点 6 管理 `(6-2, 6] = [5,6]`；
- 节点 8 管理 `(8-8, 8] = [1,8]`；
- 节点 7 管理 `[7,7]`。

两个关键操作：

- **向上更新**：`i += lowbit(i)`，从 i 一路跳到所有包含 i 的节点；
- **向下查询**：`i -= lowbit(i)`，从 i 一路跳到 0，把沿途的块拼起来。

树高是 O(log n)，所以两个操作都是 O(log n)。

### 63.3  单点修改 + 前缀和

```cpp
const int N = 500005;
int n;
long long tree[N];

void add(int i, long long v) {
    for (; i <= n; i += lowbit(i)) tree[i] += v;
}

long long sum(int i) {
    long long s = 0;
    for (; i > 0; i -= lowbit(i)) s += tree[i];
    return s;
}
```

建树可以 O(n)：先把原数组放进 `tree`，再对每个 i 把 `tree[i]` 加到 `tree[i + lowbit(i)]`。

```cpp
for (int i = 1; i <= n; i++) {
    cin >> tree[i];
}
for (int i = 1; i <= n; i++) {
    int j = i + lowbit(i);
    if (j <= n) tree[j] += tree[i];
}
```

查询区间 `[l, r]`：`sum(r) - sum(l-1)`。

> 💡 初始值为 0 时不必建树，直接按操作 `add` 即可；只有读入初始数组时才需要上面的 O(n) 建树。

### 63.4  差分版：区间修改 + 单点查询

在**差分数组**上建树状数组。设 `d[i] = a[i] - a[i-1]`，则：

- 区间 `[l, r]` 加 v：`add(l, v)`、`add(r+1, -v)`；
- 查询 `a[i]`：`sum(i)`。

```cpp
// 区间加
add(l, v);
add(r + 1, -v);
// 单点查
cout << sum(i);
```

这就是"用树状数组维护差分"，把前缀和与差分的优点合在一起。

### 63.5  区间修改 + 区间求和

如果既要区间加，又要区间和，需要两个树状数组。设差分 `d`，则：

```
sum(a[1..x]) = Σ(i=1..x) Σ(j=1..i) d[j]
             = Σ(j=1..x) d[j] * (x - j + 1)
             = (x+1) * Σ d[j] - Σ j*d[j]
```

于是维护 `B1` 存 `d[j]`，`B2` 存 `j*d[j]`：

```cpp
void range_add(int l, int r, long long v) {
    add(B1, l, v);     add(B1, r+1, -v);
    add(B2, l, l*v);   add(B2, r+1, -(r+1)*v);
}
long long pre(int x) {
    return (x + 1) * sum(B1, x) - sum(B2, x);
}
long long range_sum(int l, int r) {
    return pre(r) - pre(l - 1);
}
```

### 63.6  逆序对

逆序对：`i < j` 但 `a[i] > a[j]`。值域大时先**离散化**成 1..m，再从右往左扫：

```cpp
// b 是离散化后的数组，值在 1..m
long long ans = 0;
for (int i = n; i >= 1; i--) {
    ans += sum(b[i] - 1);   // 右边比它小的个数
    add(b[i], 1);
}
```

也可以从左往右：`ans += (i-1) - sum(b[i])`，即"已经出现的数里比它大的"。

### 63.7  树状数组上二分

如果树状数组维护的是频次，可以 O(log n) 找到前缀和首次达到 k 的位置（第 k 小）：

```cpp
int kth(int k) {
    int pos = 0;
    for (int pw = 1 << 20; pw; pw >>= 1) {
        if (pos + pw <= n && tree[pos + pw] < k) {
            pos += pw;
            k -= tree[pos];
        }
    }
    return pos + 1;
}
```

这相当于在"隐形树"上做倍增，比二分套查询的 O(log²n) 更快。

## 💻 例题

### 例 1  树状数组 1（P3374）

**题意**：n 个数，m 次操作：`1 x k` 把 a[x] 加 k；`2 x y` 求区间 `[x,y]` 的和。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 500005;
int n, m;
long long tree[N];
int lowbit(int x) { return x & -x; }
void add(int i, long long v) {
    for (; i <= n; i += lowbit(i)) tree[i] += v;
}
long long sum(int i) {
    long long s = 0;
    for (; i > 0; i -= lowbit(i)) s += tree[i];
    return s;
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        long long x; cin >> x;
        add(i, x);
    }
    while (m--) {
        int op, x, y; cin >> op >> x >> y;
        if (op == 1) add(x, y);
        else cout << sum(y) - sum(x - 1) << '\n';
    }
    return 0;
}
```

**解析**：初始数组用 `add` 逐个插入，复杂度 O(n log n)，足够通过；想更快可以 O(n) 建树。答案用 `long long`，因为多次加法可能超 `int`。

### 例 2  逆序对（P1908）

**题意**：给 n 个数，求逆序对个数。

```cpp
vector<long long> v(a + 1, a + n + 1), xs = v;
sort(xs.begin(), xs.end());
xs.erase(unique(xs.begin(), xs.end()), xs.end());
int m = xs.size();
long long ans = 0;
for (int i = n; i >= 1; i--) {
    int r = lower_bound(xs.begin(), xs.end(), v[i-1]) - xs.begin() + 1;
    ans += sum(r - 1);
    add(r, 1);
}
cout << ans;
```

**解析**：离散化把大值域压到 1..m。从右往左扫，`sum(r-1)` 就是右边比当前值小的个数，正好与当前值组成逆序对。答案最大约 `n(n-1)/2`，n=5×10^5 时约 1.25×10^11，必须 `long long`。

### 例 3  树状数组 2（P3368）

**题意**：区间 `[x,y]` 每个数加 k，或查询单点 a[x]。

```cpp
while (m--) {
    int op; cin >> op;
    if (op == 1) {
        int x, y; long long k;
        cin >> x >> y >> k;
        add(x, k);
        add(y + 1, -k);
    } else {
        int x; cin >> x;
        cout << sum(x) << '\n';
    }
}
```

**解析**：树状数组维护差分。区间加变成两个单点修改，单点查变成前缀和。注意 `y+1` 可能等于 n+1，`add` 的循环条件 `i <= n` 会自动忽略，不会越界。

## ⚠️ 常见错误

1. **下标从 0 开始**：`lowbit(0) = 0`，`add` 会死循环。树状数组必须从 1 开始。
2. **数组开小**：`add` 会访问到 n，`tree` 至少开 n+1；多组数据要清空。
3. **忘记 `long long`**：区间和、逆序对都可能超 `int`。
4. **区间查询写成 `sum(r) - sum(l)`**：应该是 `sum(r) - sum(l-1)`。
5. **离散化没去重**：`lower_bound` 仍能工作，但排名会跳号，浪费空间且易错。
6. **差分更新漏了 `r+1`**：区间右端之外没有减回去，后面的值全被多加。
7. **在树状数组上二分的初值写死**：`1<<20` 要保证大于 n，或者取 `1 << (int)log2(n)`。

## 🧠 本章小结

```
lowbit(x) = x & -x        取出最低位的 1
节点 i 管理 (i-lowbit(i), i]

单点加：for (; i <= n; i += lowbit(i)) tree[i] += v
前缀和：for (; i > 0; i -= lowbit(i)) s += tree[i]
区间和：sum(r) - sum(l-1)

差分版：区间加 → add(l,v), add(r+1,-v)；单点查 → sum(i)
区间加 + 区间和：两个 BIT
  pre(x) = (x+1)*sum(B1,x) - sum(B2,x)

逆序对：离散化 + 从右往左 sum(r-1)
第 k 小：树上倍增，O(log n)
```
